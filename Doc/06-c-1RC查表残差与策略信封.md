## 一句话

查表 + \(k\) 仍是车上 SoX。AI 只出 1RC **值域外**的 \(\delta U\)（2β / 接法 Δ）。两端、大电流、低温快充用测量电压和加热门拉回参考点，不把网加宽。

## 0. 三问三答

查表已经贴教师（`Doc/05-c`：9×11×9 全网格 4.56 mV、约占核 0.3%），瘦网当同一张 \(R(I,s,T)\) 差约 5 mV 还更贵。于是问：

| 问 | 答 |
|----|----|

## 1. 2β 接法：电压残差，不是再出 \(\Delta R\)

当前车上冻结表已经是 1 阶 RC：\(9\times 11\times 9\) 出 \(R_0,R_1(I,s,T)\)。AI 性价比差，不是「表太准」，是 **1RC 自洽数据上没有剩下给网的活**（06-b：网和表在表示同一张函数）。

正确拆法（03-b 式 (5)，Plan 第 3 期）：

\[
\hat U_{t}
= U^{\mathrm{ECM}}_{1\mathrm{RC}}\!\bigl(R^{\mathrm{LUT}}(I,s,T)\cdot k\bigr)
+ \delta U_{\mathrm{AI}}(h,I,\ldots)
\]

| | 职责 |
|--|------|
| LUT 9×11×9 | 规格书平均曲面，出厂冻住 |
| 每芯 \(k\) 网格 | 同一点 \(R\) 已经变了（散差、老化） |
| \(\delta U_{\mathrm{AI}}\) | 1RC 值域外：慢尾巴、路径、非指数核 |
| 硬保护 | 只读 AFE，不读 \(\hat U\)、不读 \(\delta U\) |

约束沿用 03-b：\(\delta U\) 幅度封顶（数 mV～十几 mV），隐状态维数 \(\le 4\)，增量时 **冻残差只动 \(k\)**。否则头用任意慢形状贴电压，主电路重新不可观。NPU 吃 INT8 冻结图——残差头出厂训完冻住，和 \(k\) 分工一致。

三种接法不要混：

| 接法 | 公式 | 结论 |
|------|------|------|
| 点式 \(\Delta R\)（1c / 03-d 式 6） | \(R=\mathrm{LUT}+\Delta R(I,s,T)\) | **吃不到缺 \(\tau\)。** 1RC 拟合已经在做：影子 2RC 上 \(R_1\) +25%，短窗好看、慢尾巴还在。任务 A 上 18 个数也赢不了两个 \(k\) |
| 再烤一张 \(R_2(I,s,T)\) | 1RC 表 + 2RC 表 | \(R_2\) 若仍光滑点映射，**第二张 LUT 又打赢网**。这是换 BMS，单独立项 |
| \(\delta U\) / 小 GRU（接法 Δ） | 上式 | 表结构上写不进去：路径、非指数核、1RC 投影剩下的形状 |

回弹若已经是干净的第二指数，03-b 的优先级是：**先钉 \(C_2\) 的 2RC，不要用 GRU 暗含第二条 \(\tau\)。** 06-b 允许「BMS 仍 1RC + 残差头」，是为了不换滤波、不挡量产，不是说 GRU 比 2RC 更物理。接法 Δ 留给：2RC 之后仍有数 mV，或残差混了滞后 / \(t^{-1/2}\) / 路径。

不要故意把 LUT 降成可分 \(R(s)f(T)g(I)\) 再让网补交叉项。对照对象仍是现在这张密表（06-b §3.1）。

## 2. 「高阶耦合」剩下来的是什么

\((I,s,T)\) 曲面上的交叉项已经在三维表里。\(R_1\leftrightarrow C_1\) 被方案 B 钉死。同一点涨阻走 \(k\)。表写不进去的是下面几类，不要和「交叉项」混称。

| 剩下的是什么 | 表能不能写 | 该谁管 |
|--------------|------------|--------|
| 同一点 \(R(I,s,T)\) 的形状 / 交叉项 | **能** | 继续查表 |
| 散差 / 老化 | 不该写进共享表 | \(k\) 网格 |
| 缺一条 \(\tau\)（2RC 慢尾巴） | 1RC 值域外 | 先 2RC 或接法 Δ |
| 路径 / 滞后 / 连续谱 | 点式表没有隐状态 | 接法 Δ |
| 表面 OCP ≠ bulk OCV | 加 RC 补不上 | 接法 Δ 或策略关两端 |
| 零偏、\(\hat Q\)、AFE、析锂、热反号 | 不是极化 | 门 / 诊断 / 热，禁止进残差 |

OCP 非线性在本仓库里是 `Doc/01-a` §8.6：**颗粒表面计量的开路电位 ≠ CSV / ECM 里那条 bulk OCV**。不是「OCV–SOC 曲线弯」——弯已经在 OCV 表里。

2RC 和表面 OCP 不在同一段窗口：

| | 2RC 慢支路 | 表面 OCP 非线性 |
|--|--|--|
| 什么时候露 | 撤流后 30–120 s，同号指数尾巴 | **通电段**、两端 SOC，\(U_t\) 近直线 |
| 静置回弹 | 就是它 | 几乎没有（`Data/grid_pybamm` 90% / 19% 双指数 0.16 / 0.48 mV） |
| 1RC/2RC 能不能吃 | 1RC 吃不干净；2RC 对静置够 | **加 RC 补不上**（会饱和，真值还在掉） |
| 量级（常温 1C） | 叠加开环 6–24 mV（H：RMSE 12.18 mV）；训完静置仍 3–10 mV | 180 s 末端相对 2RC **10–20 mV**（模型偏乐观） |

中段 SOC（网格 54%）OCP 近似线性，通电段是「指数 + 斜坡」，这里的主残差就是 2RC。两端（~90%、~19%）才是直线，扣完 bulk OCV 之后 \(\eta\) 仍不像指数。只吃 2RC，静置尾巴能压下去，**两端长恒流仍有十几 mV**。

## 3. 两边都吃掉之后，还剩多少

数字全部来自已有文档，不是残差头跑出来的。

**常温、中 SOC、1C、数分钟（参考点）——可以很小**

| 还在的项 | 量级 | 出处 |
|----------|------|------|
| 3RC / 固相连续谱（10 min 静置） | 2–8 mV；默认 120 s 里约 3 mV | 01-a §8.2 / 02-b §10.4 |
| Warburg 形状 | 时域窗常 < 3 mV | 同上 |
| 查表插值 vs 教师 | ~0.3 mV | 05-c |
| 模板噪声 | 0.5 mV | 01-b |
| 1RC 自洽地板（MLP / LUT） | 1.3 / 4.6 mV | 06-b §2.2.1 / 05-c |

这个信封里，2RC + 表面 OCP 非线性确实是结构误差的两大块。吃干净后，开环可以落到 **数 mV**，接近查表打教师的水平。短窗 SOP（10 s）几乎无感（\(R_2(1-e^{-10/90})\approx 0.03\,\mathrm{m}\Omega\)，100 A 约 3 mV）。

**一离开参考点——仍可以很大，而且多半不该让 \(\delta U\) 去吃**

| 工况 | 还剩什么 | 量级 | 让 AI 残差吃？ |
|------|----------|------|----------------|
| 充放切换 | OCV 滞后 / staging | NCM **5–15 mV** | 可以（要路径）；优先分向 OCV |
| ≥1.5C 后停车 | 热弛豫，可能**反号** | 5–15 mV | 否，热模型 |
| ≤0 °C 长回弹 | \(\tau_{\mathrm{s}}\) 拉到小时 | 10–30 mV+ | 先补低温标定 / 加热 |
| ≥2C 连续、厚电极 | P2D 盐剖面、局部抽干 | 几十～**100 mV** | 否 |
| 低 SOC 末端触底 | 表面抽空 | 10–50 mV | 否；加密 SOC + 电压闭环 |
| 高镍充电末端 | H2–H3 | 10–30 mV | 否；加密 / 分向 |
| 快充 + 低温 | 非集总 + 析锂 | 几十 mV，还不可逆 | 否，诊断（2γ）+ 加热门 |
| OCV 表差几 mV | 梯度拧 \(R_1\)，看起来像 2RC | 几 mV 起 | 先重标 OCV |

「AI 吃掉」不等于剩下自动变小：

1. **形状不同，一个头未必两口都吃干净。** 2RC 是静置双指数；OCP 非线性是通电段直线。小 GRU 可以拟合，也很容易在 SEQUENCE 上记住「180 s 该怎么斜」，换倍率 / 换 SOC 窗口就漂。\(\tau\) 仍用静置估，不要为把通电段画弯去拉长 \(\tau_2\)（01-a 陷阱 12）。
2. **EKF 会抢。** 任务 H：开环 12.18 mV 时先验仍亚毫伏，休息 SOC 被拉 0.3 pp。\(\delta U\) 若不封顶、或进了创新，两端 \(\partial U_{\mathrm{ocv}}/\partial s\) 自己还在变，假 \(R\) 和假 \(s\) 叠在一起。不要加大 \(q_s\)。
3. **冻住的残差不跟老化。** \(k\) 改的是同一点的 \(R\)，补不了缺 \(\tau\)，也补不了表面 OCP 形状。
4. **生成器。** 练残差用拆分 2RC 或以后的真包，不要用叠加 `--rc2` 当教师（06-b §2.2.1）。

验收按片段切（边沿 / 前 30 s / 静置 60–120 s / 两端恒流），不要只报一条整轨 RMSE——中段好看、90% 恒流仍可能偏 10 mV。

## 4. 策略信封：保护可以，预言不能全换掉

离开参考点的大误差，优先用策略关进信封，而不是把残差头加宽。这和 06-b「SOP 1–3 min 偏乐观就报功率时说明、不为此升阶」同一句。

三层不要混：

| 层 | 用什么 | 模型错了会怎样 | 策略能不能顶 |
|----|--------|----------------|--------------|
| **硬保护**（过压 / 欠压 / 过流 / 过温） | AFE 测量 | 不允许依赖 \(\hat U\) | **必须**用测量值。A0-a：学习跑飞也退回规格书 \(R\)，保护链不经过 \(\hat U_t\) |
| **限流 / 功率闭环** | 最低 / 最高芯 \(U_{\mathrm{meas}}\) 接近限就降流 | 模型偏乐观时电压先撞墙，闭环把电流拉回来 | **能顶安全**，代价是顿挫、提前掉功率、少用一点能量 |
| **SOP / 剩余能量 / 充电时间** | \(R_{\mathrm{dyn}}(\Delta t)\)、OCV、SOC | 对外报大功率、数秒后被电压墙砍掉 | 策略**遮不住**；只能短视界 + 保守裕度 |

### 4.1 末端 / 大电流：测量电压限制功率

能盖住：表面 OCP 非线性、触顶触底掉切、高倍率 P2D 后段加速掉压。这些都会先出现在 \(U_{\mathrm{meas}}\) 上。包电流按 **最低芯 / 最高芯** 收，180 串不平衡一起管。

盖不住：还没撞墙时的可用功率；析锂（终端电压未到 \(U_{\max}\)，负极表面电位可能已过低）；SOC / 剩余能量（电压墙防打穿，显示仍走 OCV + EKF）。

做法是「短视界模型 + 电压闭环」，不是「取消 SOP、只看电压」：

- 对外功率用 **10 s** \(R_0+R_1\)（查表 × \(k\)）；分钟级只作内部参考并加裕度
- 任意芯进入限压带，切 CV 式限流，**以测量电压为准**
- 大电流再加 \(dU/dt\) 或「掉压比模型快」就提前收——P2D 超线性，等撞 \(U_{\min}\) 会晚

### 4.2 低温：先加热，再开快充

把工况搬回参考点，比让残差头去学 −10 °C 的 30–100 mV 干净。低于 0 °C 必须实测，不能常温外推（01-a）；快充 + 低温是析锂，不要把这段写进电阻表。

能盖住：低温快充、低温长回弹里 \(\tau\) 拉到数分钟～小时的结构差，以及析锂的主路径。

盖不住：放电和回收不能等热；加热电流本身要一份保守冷 SOP；800 V 快充模组可有 10–20 °C 温差（A0-a）——快充门看 **最冷芯**，不是进风口或包平均。大电流中芯温已升，用测量芯温查表，不要再加一只 RC（01-a 陷阱 6）。

门槛结构（具体数字要标定，这里只锁谁开门）：最冷芯过低则禁止快充、只允许小电流加热；进入温窗再按常温 SOP。

### 4.3 哪些能扛、哪些不能

| 离开参考点的情况 | 策略 | 还要不要模型 |
|------------------|------|----------------|
| 两端 SOC 通电直线、掉切 | 最值芯电压闭环；SOC 两端加密网格 | 10 s SOP 仍查表；不要为这段加 \(\tau\) |
| ≥2C、厚电极 P2D | 电流上限随 \(T\)、SOC 削；掉压加速就收 | 保护靠测量；不要 3RC 去贴 |
| 低温快充 | 最冷芯先加热再开门 | 冷放电 SOP 仍要偏保守的 \(R(T)\) |
| 充放滞后 5–15 mV | 分向 OCV / 限压带宽一点 | 休息 SOC 仍可能偏 |
| 大脉冲后热反号 | 测量温度查表；停车先限功率再看电压回爬 | 不要写成 \(k_1\) |
| 析锂 | 低温禁充 + 高 SOC 降流 + 2γ | **不能**只靠电压墙 |
| 2RC 静置尾巴 3–10 mV | **不必为保护加模型**；门控不让 \(k\) 追 | 休息 SOC 仍可能被拉 ~0.3 pp |
| 零偏 / \(\hat Q\) / AFE | 包级门 | 限压拆不开，仍是 06-a |

策略补的是「模型在信封外会偏乐观」；补不了「信封内还要把 \(R\) 和 SOC 估对」。也不许拿策略当借口：\(k\) 仍然不能追慢尾巴（06-a §3.5）；限压闭环走测量值，\(\hat U\) / \(\delta U_{\mathrm{AI}}\) 不准进 ASIL 过压判断。

## 5. 默认栈

```
硬保护            ← 只读 AFE（A0-a 已锁死）
末端 / 大电流      ← 最值芯测量电压闭环（CV 式限流）
低温快充          ← 最冷芯先加热再开门
10 s SOP          ← 1RC 查表 × k（2RC 可忽略）
1–3 min SOP       ← 同一张表 + 保守裕度，不升阶（06-b §2.2.4）
慢尾巴 / 路径      ← 可选 2β，冻残差，不写 k
析锂 / 异常        ← 2γ 诊断，不改 R 表
```

会打截止、会析锂、会冷充的，用策略关在参考信封里；信封里面的 SoX 继续查表 + \(k\)。

## 6. 2β 任务卡（不挡 2A / 2B）

> 冻结 1RC LUT + \(k\)；另训一个幅度封顶的 \(\delta U\) 头（GRU \(\le 4\) 或等价因果小核），只监督 1RC 开环在边沿之后仍同号的那段；同一套休息 SOC / NIS / 包门，新年份 RMSE 必须低于同期查表。

门没改之前不要开残差头：现在 `window.py` 默认回弹静置只动 \(k_1\)，慢尾巴正好长在静置窗里（06-b §2.2.2 第 3 条，改法在 06-a §3.5）。

最小对照（有 2RC 影子权重就能起步，不必等真包）：

1. 基线：`Data/ai_mlp` 烤的 9×11×9 + \(k=1\)，在拆分 2RC（不要叠加 `--rc2` 当教师）上按片段切开环。
2. 接法 Δ：同一张冻表加 \(\delta U\)，看静置尾巴掉多少、边沿 \(R_0\) 是否被带歪、休息 SOC 是否比任务 H 的 −0.33 pp 更差。
3. 负例：1RC 自洽轨迹上 \(\delta U\) 应近 0；无边沿长静置不准写 \(k_1\)，也不准残差头去追 OCV。
4. 两端恒流：90% / 19% 上 1C 数分钟，\(\delta U\) 若去贴直线，换倍率后必须还在；贴不住就交给电压闭环，不要拉长 \(\tau_2\)。

赢了才谈换默认；赢不了就把加速器叙事落到 2γ。和 06-b §4–§5 一致。

## 7. 明确不要

- 点式 \(\Delta R\) 当 2β（重演 1c）
- 故意把 LUT 变稀 / 变成可分乘子，再让网补交叉项
- 用叠加 `--rc2` 当残差教师；把 `Data/grid/` 默认改成 2RC
- 残差头和 \(k\) 一起解冻；\(\delta U\) 进 EKF 创新或加大 \(q_s\)
- 为通电段直线拉长 \(\tau_2\)、加全 SOC 的 PNGV \(C_0\)、拧 \(C_1^\star\)
- 残差头去学 P2D、热反号、析锂；把 \(\hat U\) 或 \(\delta U\) 送进保护核
- 用电压墙替代析锂诊断；用包平均温度开快充门
- 挡 06-a 的 2A / 2B；现在升 2RC BMS

## 8. 向上三句话

1. **SoX 量产仍是查表。** AI 要翻盘，只能吃表写不进去的 \(\delta U\)（慢尾巴、路径），不能再当一张 \(R(I,s,T)\)。
2. **2RC 和表面 OCP 是两段账。** 参考点上两边都吃掉，剩下大约数 mV；两端通电、冷、高倍率、热、析锂不在这两段里。
3. **信封外用策略，信封内才用模型。** 末端 / 大电流看最值芯测量电压；低温快充看最冷芯先加热。保护不读 \(\hat U\)。\(k\) 仍然不准追静置慢尾巴。
