## 一句话

查表 + \(k\) 仍是车上 SoX。1RC 以外的残差先按机理拆：\(R_0(I)\) 归表，静置双指数归 2RC，两端直线归表面 OCP 或策略。AI 只出这三口之后仍在的 \(\delta U\)（2β / 接法 Δ）。  
写 \(k\) 仍是滑窗 SGD（点到哪写哪），影子表在**被点到的工况**里验收再提交。用网出 \(k\)、用网当更新器、用网当写 \(k\) 的门，都不要。  
1RC+\(\delta U\) 吃不过物理 2RC 列就升阶；升完 \(C_2\) 钉死、\(R_2\) 表冻住，车上仍只写 \(k_0/k_1\)。  
点式 \(\Delta R\)、用 GRU 暗含第二条 \(\tau\)、故意把表变差再让网补、用 \(\delta U\) 进保护核，都不要。

## 1. 2β 接法：电压残差，不是再出 \(\Delta R\)

当前车上冻结表已经是 1 阶 RC：\(9\times 11\times 9\) 出 \(R_0,R_1(I,s,T)\)。AI 性价比差，不是「表太准」，是 **1RC 自洽数据上没有剩下给网的活**（06-b：网和表在表示同一张函数）。

正确拆法（03-b 式 (5)，Plan 第 3 期）：

\[
\hat U_{t}
= U^{\mathrm{ECM}}_{1\mathrm{RC}}\!\bigl(R^{\mathrm{LUT}}(I,s,T)\cdot k\bigr)
+ \delta U_{\mathrm{AI}}(h,I,\ldots)
\]

| | 职责 |
|--|------|
| LUT 9×11×9 | 规格书平均曲面，出厂冻住 |
| 每芯 \(k\) 网格 | 同一点 \(R\) 已经变了（散差、老化） |
| \(\delta U_{\mathrm{AI}}\) | 2RC+OCP **之后**：路径、非指数核。不要用它暗含第二条 \(\tau\) 或贴通电直线 |
| 硬保护 | 只读 AFE，不读 \(\hat U\)、不读 \(\delta U\) |

约束沿用 03-b：\(\delta U\) 幅度封顶（数 mV～十几 mV），隐状态维数 \(\le 4\)，增量时 **冻残差只动 \(k\)**。否则头用任意慢形状贴电压，主电路重新不可观。NPU 吃 INT8 冻结图——残差头出厂训完冻住，和 \(k\) 分工一致。动 \(k\) 的算法仍是滑窗 SGD，不是再训一个写 \(k\) 的头（§10）。

三种接法不要混：

| 接法 | 公式 | 结论 |
|------|------|------|
| 点式 \(\Delta R\)（1c / 03-d 式 6） | \(R=\mathrm{LUT}+\Delta R(I,s,T)\) | **吃不到缺 \(\tau\)。** 1RC 拟合已经在做：影子 2RC 上 \(R_1\) +25%，短窗好看、慢尾巴还在。任务 A 上 18 个数也赢不了两个 \(k\) |
| 再烤一张 \(R_2(I,s,T)\) | 1RC 表 + 2RC 表 | \(R_2\) 若仍光滑点映射，**第二张 LUT 又打赢网**。这是换 BMS，单独立项 |
| \(\delta U\) / 小 GRU（接法 Δ） | 上式 | 表结构上写不进去：路径、非指数核、1RC 投影剩下的形状 |

回弹若已经是干净的第二指数，03-b 的优先级是：**先钉 \(C_2\) 的 2RC，不要用 GRU 暗含第二条 \(\tau\)。** 本网格静置就是这种（双指数 0.16 mV）。06-b 允许「BMS 仍 1RC + 残差头」，是为了不换滤波、不挡量产，不是说 GRU 比 2RC 更物理。接法 Δ 留给：2RC + 表面 OCP 之后仍有数 mV，或残差混了滞后 / \(t^{-1/2}\) / 路径。方法对照 §9。

不要故意把 LUT 降成可分 \(R(s)f(T)g(I)\) 再让网补交叉项。对照对象仍是现在这张密表（06-b §3.1）。

## 2. 「高阶耦合」剩下来的是什么

\((I,s,T)\) 曲面上的交叉项已经在三维表里。\(R_1\leftrightarrow C_1\) 被方案 B 钉死。同一点涨阻走 \(k\)。表写不进去的是下面几类，不要和「交叉项」混称。

| 剩下的是什么 | 表能不能写 | 该谁管 |
|--------------|------------|--------|
| 同一点 \(R(I,s,T)\) 的形状 / 交叉项 | **能** | 继续查表 |
| 散差 / 老化 | 不该写进共享表 | \(k\) 网格 |
| 缺一条 \(\tau\)（2RC 慢尾巴） | 1RC 值域外 | **先 2RC**（钉 \(C_2\)）。不要 GRU 暗含 \(\tau\) |
| 路径 / 滞后 / 连续谱 | 点式表没有隐状态 | 接法 Δ（2RC+OCP **之后**） |
| 表面 OCP ≠ bulk OCV | 加 RC 补不上 | 电极 OCP 补偿或策略关两端；不要残差头去贴直线 |
| 零偏、\(\hat Q\)、AFE、析锂、热反号 | 不是极化 | 门 / 诊断 / 热，禁止进残差 |

OCP 非线性在本仓库里是 `Doc/01-a` §8.6：**颗粒表面计量的开路电位 ≠ CSV / ECM 里那条 bulk OCV**。不是「OCV–SOC 曲线弯」——弯已经在 OCV 表里。

2RC 和表面 OCP 不在同一段窗口：

| | 2RC 慢支路 | 表面 OCP 非线性 |
|--|--|--|
| 什么时候露 | 撤流后 30–120 s，同号指数尾巴 | **通电段**、两端 SOC，\(U_t\) 近直线 |
| 静置回弹 | 就是它 | 几乎没有（`Data/grid_pybamm` 90% / 19% 双指数 0.16 / 0.48 mV） |
| 1RC/2RC 能不能吃 | 1RC 吃不干净；2RC 对静置够 | **加 RC 补不上**（会饱和，真值还在掉） |
| 量级（常温 1C） | 叠加开环 6–24 mV（H：RMSE 12.18 mV）；训完静置仍 3–10 mV | 180 s 末端相对 2RC **10–20 mV**（模型偏乐观） |

中段 SOC（网格 54%）OCP 近似线性，通电段是「指数 + 斜坡」，这里的主残差就是 2RC。两端（~90%、~19%）才是直线，扣完 bulk OCV 之后 \(\eta\) 仍不像指数。只吃 2RC，静置尾巴能压下去，**两端长恒流仍有十几 mV**。

## 3. 两边都吃掉之后，还剩多少

信封内数字已经在 `Data/grid_pybamm` 上量过（`eval_nls.md` §7，`nls_ocp_summary.csv`）。下面「还在的项」仍来自 01-a / 02-b，是 2RC+OCP 之后的预算，不是残差头跑出来的。

**信封：\(T\ge 10^\circ\mathrm{C}\)、SOC \(\gtrsim 28\%\)、本网格 SEQUENCE（56 档）**

| | 整段 RMSE p50 | p90 | max |
|--|---------------|-----|-----|
| 常 \(R_0\) 2RC | 4.6 mV | 9.9 | 12.3 |
| +BV | 1.4 | 3.8 | 4.8 |
| +BV+OCP（共享 \(k\)） | **1.9** | **2.5** | **3.2** |

中段主要靠 2RC+BV（OCP 没有增益，73% 的档还略差约 0.4 mV）。90% 通电直线才是 OCP：末端从 +12 mV 收到 +1.4～2.1 mV。19% 共享 \(k\) 不够（末端仍 +12），要拆电极；10% 是信封外。

吃干净后开环约 **2 mV**，接近查表打教师。短窗 SOP（10 s）几乎无感（\(R_2(1-e^{-10/90})\approx 0.03\,\mathrm{m}\Omega\)，100 A 约 3 mV）。剩下的是脉冲前十几秒的 \(\sqrt{t}\) 和 BV 列近似。

**还可能在、本网格没激发的**

| 还在的项 | 量级 | 出处 |
|----------|------|------|
| 3RC / 固相连续谱（10 min 静置） | 2–8 mV；默认 120 s 里约 3 mV | 01-a §8.2 / 02-b §10.4 |
| Warburg 形状 | 时域窗常 < 3 mV | 同上 |
| 查表插值 vs 教师 | ~0.3 mV | 05-c |
| 模板噪声 | 0.5 mV | 01-b |
| 1RC 自洽地板（MLP / LUT） | 1.3 / 4.6 mV | 06-b §2.2.1 / 05-c |

**一离开参考点——仍可以很大，而且多半不该让 \(\delta U\) 去吃**

| 工况 | 还剩什么 | 量级 | 让 AI 残差吃？ |
|------|----------|------|----------------|
| 充放切换 | OCV 滞后 / staging | NCM **5–15 mV** | 可以（要路径）；优先分向 OCV |
| ≥1.5C 后停车 | 热弛豫，可能**反号** | 5–15 mV | 否，热模型 |
| ≤0 °C 长回弹 | \(\tau_{\mathrm{s}}\) 拉到小时 | 10–30 mV+ | 先补低温标定 / 加热 |
| ≥2C 连续、厚电极 | P2D 盐剖面、局部抽干 | 几十～**100 mV** | 否 |
| 低 SOC 末端触底 | 表面抽空 | 10–50 mV | 否；加密 SOC + 电压闭环 |
| 高镍充电末端 | H2–H3 | 10–30 mV | 否；加密 / 分向 |
| 快充 + 低温 | 非集总 + 析锂 | 几十 mV，还不可逆 | 否，诊断（2γ）+ 加热门 |
| OCV 表差几 mV | 梯度拧 \(R_1\)，看起来像 2RC | 几 mV 起 | 先重标 OCV |

「AI 吃掉」不等于剩下自动变小：

1. **形状不同，一个头未必两口都吃干净。** 2RC 是静置双指数；OCP 非线性是通电段直线。小 GRU 可以拟合，也很容易在 SEQUENCE 上记住「180 s 该怎么斜」，换倍率 / 换 SOC 窗口就漂。\(\tau\) 仍用静置估，不要为把通电段画弯去拉长 \(\tau_2\)（01-a 陷阱 12）。
2. **EKF 会抢。** 任务 H：开环 12.18 mV 时先验仍亚毫伏，休息 SOC 被拉 0.3 pp。\(\delta U\) 若不封顶、或进了创新，两端 \(\partial U_{\mathrm{ocv}}/\partial s\) 自己还在变，假 \(R\) 和假 \(s\) 叠在一起。不要加大 \(q_s\)。
3. **冻住的残差不跟老化。** \(k\) 改的是同一点的 \(R\)，补不了缺 \(\tau\)，也补不了表面 OCP 形状。
4. **生成器。** 练残差用拆分 2RC 或以后的真包，不要用叠加 `--rc2` 当教师（06-b §2.2.1）。

验收按片段切（边沿 / 前 30 s / 静置 60–120 s / 两端恒流），不要只报一条整轨 RMSE——中段好看、90% 恒流仍可能偏 10 mV。

## 4. 策略信封：保护可以，预言不能全换掉

离开参考点的大误差，优先用策略关进信封，而不是把残差头加宽。这和 06-b「SOP 1–3 min 偏乐观就报功率时说明、不为此升阶」同一句。

三层不要混：

| 层 | 用什么 | 模型错了会怎样 | 策略能不能顶 |
|----|--------|----------------|--------------|
| **硬保护**（过压 / 欠压 / 过流 / 过温） | AFE 测量 | 不允许依赖 \(\hat U\) | **必须**用测量值。A0-a：学习跑飞也退回规格书 \(R\)，保护链不经过 \(\hat U_t\) |
| **限流 / 功率闭环** | 最低 / 最高芯 \(U_{\mathrm{meas}}\) 接近限就降流 | 模型偏乐观时电压先撞墙，闭环把电流拉回来 | **能顶安全**，代价是顿挫、提前掉功率、少用一点能量 |
| **SOP / 剩余能量 / 充电时间** | \(R_{\mathrm{dyn}}(\Delta t)\)、OCV、SOC | 对外报大功率、数秒后被电压墙砍掉 | 策略**遮不住**；只能短视界 + 保守裕度 |

### 4.1 末端 / 大电流：测量电压限制功率

能盖住：表面 OCP 非线性、触顶触底掉切、高倍率 P2D 后段加速掉压。这些都会先出现在 \(U_{\mathrm{meas}}\) 上。包电流按 **最低芯 / 最高芯** 收，180 串不平衡一起管。

盖不住：还没撞墙时的可用功率；析锂（终端电压未到 \(U_{\max}\)，负极表面电位可能已过低）；SOC / 剩余能量（电压墙防打穿，显示仍走 OCV + EKF）。

做法是「短视界模型 + 电压闭环」，不是「取消 SOP、只看电压」：

- 对外功率用 **10 s** \(R_0+R_1\)（查表 × \(k\)）；分钟级只作内部参考并加裕度
- 任意芯进入限压带，切 CV 式限流，**以测量电压为准**
- 大电流再加 \(dU/dt\) 或「掉压比模型快」就提前收——P2D 超线性，等撞 \(U_{\min}\) 会晚

### 4.2 低温：先加热，再开快充

把工况搬回参考点，比让残差头去学 −10 °C 的 30–100 mV 干净。低于 0 °C 必须实测，不能常温外推（01-a）；快充 + 低温是析锂，不要把这段写进电阻表。

能盖住：低温快充、低温长回弹里 \(\tau\) 拉到数分钟～小时的结构差，以及析锂的主路径。

盖不住：放电和回收不能等热；加热电流本身要一份保守冷 SOP；800 V 快充模组可有 10–20 °C 温差（A0-a）——快充门看 **最冷芯**，不是进风口或包平均。大电流中芯温已升，用测量芯温查表，不要再加一只 RC（01-a 陷阱 6）。

门槛结构（具体数字要标定，这里只锁谁开门）：最冷芯过低则禁止快充、只允许小电流加热；进入温窗再按常温 SOP。

### 4.3 哪些能扛、哪些不能

| 离开参考点的情况 | 策略 | 还要不要模型 |
|------------------|------|----------------|
| 两端 SOC 通电直线、掉切 | 最值芯电压闭环；SOC 两端加密网格 | 10 s SOP 仍查表；不要为这段加 \(\tau\) |
| ≥2C、厚电极 P2D | 电流上限随 \(T\)、SOC 削；掉压加速就收 | 保护靠测量；不要 3RC 去贴 |
| 低温快充 | 最冷芯先加热再开门 | 冷放电 SOP 仍要偏保守的 \(R(T)\) |
| 充放滞后 5–15 mV | 分向 OCV / 限压带宽一点 | 休息 SOC 仍可能偏 |
| 大脉冲后热反号 | 测量温度查表；停车先限功率再看电压回爬 | 不要写成 \(k_1\) |
| 析锂 | 低温禁充 + 高 SOC 降流 + 2γ | **不能**只靠电压墙 |
| 2RC 静置尾巴 3–10 mV | **不必为保护加模型**；门控不让 \(k\) 追 | 休息 SOC 仍可能被拉 ~0.3 pp |
| 零偏 / \(\hat Q\) / AFE | 包级门 | 限压拆不开，仍是 06-a |

策略补的是「模型在信封外会偏乐观」；补不了「信封内还要把 \(R\) 和 SOC 估对」。也不许拿策略当借口：\(k\) 仍然不能追慢尾巴（06-a §3.5）；限压闭环走测量值，\(\hat U\) / \(\delta U_{\mathrm{AI}}\) 不准进 ASIL 过压判断。

## 5. 默认栈

```
硬保护            ← 只读 AFE（A0-a 已锁死）
末端 / 大电流      ← 最值芯测量电压闭环（CV 式限流）
低温快充          ← 最冷芯先加热再开门
10 s SOP          ← 1RC 查表 × k（2RC 可忽略）
1–3 min SOP       ← 同一张表 + 保守裕度，不升阶（06-b §2.2.4）

慢尾巴 / 路径      ← 可选 2β，冻残差，不写 k
析锂 / 异常        ← 2γ 诊断，不改 R 表
```

## 9. 用 AI 吃 1RC 以外残差：方法对照

车上冻结表已经是 \(R_0,R_1(I,s,T)\)。eval_nls 里常 \(R_0\) 的低温 18 mV **不是** 1RC LUT 的残差——电流维在表里。1RC 以外真正剩的，按机理拆，再决定要不要网。

### 9.1 先拆口，再谈网

| 口 | 信封内量级（本网格） | 物理做法 | 用 AI？ |
|--|--|--|--|
| \(R_0(I)\) / BV 边沿 | 常 \(R_0\) 才缺；LUT 已有 \(I\) | 表的电流维 | **否。** 点式 \(\Delta R\) 也吃不到 \(\tau\) |
| 缺 \(\tau_2\)（静置双指数） | 单指数 15 mV → 双指数 0.16 mV | 2RC，\(C_2\) 钉死或全局慢变 | **否。** GRU 暗含第二条 \(\tau\)（03-b §7） |
| 两端表面 OCP | 90% 1C 末端 +12 → +1.4 mV | \(U_{\mathrm{ocp}}(c_{\mathrm{surf}})\)，或策略关两端 | **不优先。** SEQUENCE 上会记住 180 s 该怎么斜 |
| 2RC+OCP 之后 | 整段 ~2 mV，脉冲前 \(\sqrt{t}\) | 接法 Δ 才轮到 | 可以；本网格太小，翻不了查表 |
| 充放滞后 / 路径 | 本网格没有（等温 SPM） | 先分向 OCV | 可以，要路径；真包再评 |
| 信封外（冷、10%、\(\ge 2\mathrm{C}\)、析锂） | 5–27 mV 起，可到上百 | 策略 / 2γ | **否** |

中段 SOC 的 1RC 残差几乎就是第二指数；两端才多一口直线。一个头两口，06-c 早就写了形状不同。现在有数字：物理栈已经把信封收到 2 mV，GRU 没有另一块 10 mV 可吃。

### 9.2 方法逐条

**A. 点式 \(\Delta R\)（03-d / 1c，\(R=\mathrm{LUT}+\Delta R(I,s,T)\)）**  
已经丢掉。仍是点映射，短窗可以把 \(R_1\) 抬 25%，静置尾巴还在。不能当 2β。

**B. 接法 R / 接法 V（GRU 出 \(R\) 或直接出电压）**  
03-b 已否。和 \(U_p\) 抢电压，曲面没有定义，增量锚不住。接法 V 放弃 \(R\)，和本仓库其余文档不一致。

**C. 接法 Δ：1RC LUT + GRU \(\delta U\)（现行 2β 写法）**  
把 §9.1 几口塞进一个头。中段学第二指数，两端学直线，\(I\) 轴若不够细还会去碰 \(R_0\)。本 SEQUENCE 上电压能贴；换脉宽 / 换 SOC 窗口就漂。  
仍允许当「BMS 不升 2RC」的工程补丁，但必须按 §6 带物理列对照。列 3 若只在 620 s 指令上赶上列 1 / 2，不算赢。幅度封顶、增量冻残差、负例 \(\delta U\approx 0\) 仍有效。

**D. 显式第二指数 / 钉 \(C_2\) 的 2RC**  
静置已经是干净双指数。这是正途，不是 AI。KF 只多一个 \(U_{p2}\)，仍是点映射。  
若坚持 BMS 1RC：车上加一只出厂钉死的 \(U_{p2}\)（\(\tau_2\) 全局慢变）= 换 BMS 的最小形式，仍不是网。`Plan.md` 第 3 期：升阶单独立项。

**E. 特征残差（线性）：BV 列 + \(q(I,\tau_2)\) 进 \(U_{\mathrm{ocp}}\)**  
eval_nls 已经做了，信封内 p50 1.9 mV。没有神经网络。\(k\) 不能出表（绑 Chen2020 的 \(D,R_p\)），这是离线诊断，不是车上 2β。真芯若有电极 OCP 曲线，优先用这条，不要用 GRU 重做。

**F. 双头：静置指数头 + 通电斜率头**  
比单 GRU 对症，本质仍是把 D+E 用网重做。缺电极 OCP 曲线时，通电头会过拟合脉宽。不优先于 D+E。

**G. 只训 2RC+OCP 之后的 \(\sqrt{t}\) / 路径（接法 Δ 的本职）**  
这才是 03-b「1RC+2RC 后还有慢尾巴」。本网格信封内只剩 1–2 mV，短窗 SOP 无感。做了也赢不了「加速器翻盘查表」。真包若出现滞后、10 min \(t^{-1/2}\)、充放环，这一档才变大——那时再开，教师不要用本 SEQUENCE 的整轨 RMSE。

**H. 物理信息网 / 算子学习去逼 SPM**  
信封内物理栈已经 2 mV，再上 PINN 是把仿真器装进 MCU。负荷、可观性、增量全不匹配。不做。

### 9.3 建议顺序

和 03-b §7 对齐，用本网格钉死：

1. 表吃 \(R(I,s,T)\) / BV。电流维已经在 9×11×9 里。
2. 静置给出 2RC（或冻结 \(U_{p2}\)），不写 \(k\)。
3. 两端 OCP：有电极曲线就补偿；没有就策略关信封，不要拉 \(\tau_2\)。
4. 仍有数 mV 非指数 / 路径 → 很小的冻住 \(\delta U\)（G，不是 C）。
5. 信封外策略。加速器叙事优先 2γ，不靠 2β 翻盘。

2β 收窄成 G。不要用 GRU 去复现 eval_nls 已经用线性特征吃掉的那两口。对照必须带物理 2RC+OCP 列。

## 10. 用 AI 更新 \(k\)：方法对照

2β 是冻残差、只动 \(k\)。于是有人会问：加速器空着，能不能让网来写 \(k\)？这一节把这句话拆开。**这不是 2β，也不是 2α。** 2β 出 \(\delta U\)；2α 改共享曲面；写 \(k\) 是每芯状态的辨识。1c 已经用小网做过一次，输给两个 \(k\) 和一张网格。

### 10.1 先分清：\(k\) 是状态，不是另一张函数

当前车上默认（支线 1，05-d）：

```
冻结 LUT 9×11×9
    → 每芯 (s,T) 上 k 网格（出厂全 1，双线性）
    → ECM 开环 e^{ol}
    → 窗级门（边沿只动 k0，回弹只动 k1，无激励不动，慢尾巴不写）
    → 滑窗 SGD：梯度只回被点到的 2～4 个顶点
```

\(k\) 的职责：同一 \((I,s,T)\) 上 \(R\) 已经变了（散差、老化）。  
更新器的职责：有激励的窗里，把 \(e^{\mathrm{ol}}\) 写成那几个节点。  
AI 若介入，只可能替换**第二件**。替换第一件 = 再做一张 \(R\) 表，回到 2α / 1c。

数字已经有了，不必先训一个写 \(k\) 的头再评：

| | 纯涨阻 A ×1.15 一遍 | 只抬 −10 °C 一遍 | 出处 |
|--|--|--|--|
| 1a 全局 \(k\) | **6.84 mV**，\(k\approx 1.19/1.17\) | 会把 25 °C 一起抬 | 05-d §1 / §4.2 |
| 1b \(k\) 网格 | 13.4 mV（四遍 8.6） | **中温 \(k\approx 1\)** | 05-d §4 |
| 1c 3×8×2 | 10.6 mV（四遍 8.6） | 中温 2.54→**5.63 mV** | 05-d §5，丢掉 |
| 负荷 | LUT + \(k\) 整包 SoX ~1% | `incr_kgrid` 窗 100 **0.13 ms，停车跑** | 05-c |

瓶颈是激励和门（06-a 的 \(b_I\)、慢尾巴、无边沿停放），不是更新公式太贵、也不是两个 \(k\) 容量不够。

### 10.2 几种接法

| 接法 | 做什么 | 结论 |
|------|--------|------|
| **A. 冻住的网出 \(k\)** | \(k=\mathrm{NN}(s,T)\) 或 \(\mathrm{NN}(I,s,T)\)，INT8 推理 | **否。** 全包同一张 \(k\)，不是每芯状态。老化、散差跟不上。等于第二张共享表，瘦网已经输给 9×11×9 |
| **B. 每芯小网出 \(\Delta R\) / \(k\)** | 1c：冻 \(\varphi\)，只动 18 个数；或更瘦 3×4×2 | **已丢掉。** 涨阻不赢 1a，形状不赢 1b，加性凑不出乘性 1.15，冷端窗抬中温 |
| **C. 冻住的更新器** | \(\Delta\log k=\mathrm{NN}(\text{窗特征})\)，再累加到网格。NPU 只推理，标量核只加 | **不优先。** 用网近似已经有的 ECM 雅可比 \(\partial U/\partial\log k\sim -IR\)。负荷比 SGD 贵，精度不该更好。唯一还像「把 AI 用上」的窄口，见 §10.4 |
| **D. 学门控** | 网决定这一窗写不写、写哪几个节点 | **否。** 边沿 / 回弹 / 包级中位数 / 慢尾巴不写，已经是物理门。学门认证更差；负例（零偏、AFE、长静置）会写坏 \(k\) |
| **E. 序列网回归整张网格** | GRU(窗) \(\to\) 20 个 \(k\) | **否。** 要攒波形，超 05-a；SEQUENCE 过拟合（03-b）。单窗分不出全局还是局部（05-d §4.4），网填满整张就是冷启动先走 1a |
| **F. 老化先验：一窗推断整张 \(k(s,T)\)** | 舰队老化形状训一个头，当前窗预测所有节点 | **否，当网。** 先验该写进参数化：Arrhenius 一个 \(B\)、低秩 2～3 个系数（05-b ①②），不是一只网。没有老样件不要立项 |
| **G. 脉冲 \(\Delta U/\Delta I\) 写 \(k\)** | 边沿 \(\hat R_0/R_0^{\mathrm{LUT}}\)，无反传 | **比 C 优先。** 05-b ⑫，MCU 几次减和除。未跑；要对照更新器，这一列必须在 |

不要把 A / B 说成「用 AI 更新 \(k\)」。A 没有每芯状态；B 已经赛过。

### 10.3 为什么 SGD 写点已经够

欧姆通道的更新几乎就是欧姆定律。窗内锁 \(R\)、开环损失对 \(\log k_0\) 的梯度：

\[
\frac{\partial L}{\partial\log k_0}\;\propto\;-e^{\mathrm{ol}}\,I\,(k_0 R_0)
\]

极化通道沿 \(U_p\) 递推，方案 B 下 \(C_1^\star\) 钉死，回弹窗只动 \(k_1\)。这不是「还没学到的映射」，是电路已经写好的雅可比。再训一个 \(\mathrm{NN}(e,I,s,T)\to\Delta\log k\)，就是在 SEQUENCE 上重做 \(-IR\)。

1b 一遍 13.4 mV、四遍才 8.6 mV，慢的是**节点没被点到**，不是梯度方向错。用网在未点到的格子上填数，等于更新前猜「整张还是局部」——05-a / 05-d 已经禁止。真要少参数，先试 \(k(T)\) 或 \(B\)（05-b ①⑥），仍不是网。

NPU 不吃 float SGD（A0-b）。把更新器冻成 INT8，可以让加速器「写 \(k\)」，但写进去的仍应是同一个 \(\Delta\log k\)。多出来的只是 ROM 和一条不可解释的第二路径。`incr_kgrid` 已经离开 0.1 s 环，占核不是理由。

和 2β 不要绑：更新网若与残差头共享特征，头会去抢 \(I\Delta R\) 那堵墙（该归 \(k\)）；若更新网去追静置慢尾巴，就是用 \(k_1\) 写 \(\tau_2\)（06-a §3.5 禁止）。冻残差、只动 \(k\) 仍然有效——动 \(k\) 的那一步继续用雅可比，不用网。

### 10.4 若仍要对照（不挡 2A / 2B，不换默认）

最小对照。**必须带 G 列**，否则「网打赢 SGD」可能只是打赢了一个没写的脉冲辨识：

| 列 | 更新器 | 用来证什么 |
|----|--------|------------|
| 0 | 1b 滑窗 SGD（当前默认） | 基线 |
| 1 | 脉冲 \(\Delta U/\Delta I\)（G） | 无梯度是否已经够 |
| 2 | 冻住的更新器（C），同一套门，只写被点到的节点 | 网是否只在学 \(-IR\) |
| 3 | 负例：更新器 + 放开慢尾巴门 | 会不会把 \(\tau_2\) 写成 \(k_1\) |

同一套任务 A / 只抬 −10 °C / 包级同向：

1. 新年份开环不差于列 0；只抬冷端时中温不差于 1b（不许再出现 1c 的 2.54→5.63）。
2. 旧探点恶化仍 < 20%；休息 SOC / NIS / \(b_I\) 门不比列 0 差。
3. 换脉宽后列 2 若垮、列 0 / 1 还在，就是过拟合窗长。
4. 1RC 自洽、无边沿长静置：列 2 的 \(\Delta k\) 应近 0。

列 2 赢不了列 0 / 1，就把「NPU 写 \(k\)」丢掉，加速器叙事仍看 2γ。列 2 即使贴上列 0，也不够换默认——多一条 INT8 路径，功能安全要再证一遍写 \(k\) 的链。不要为了喂饱 SIMD 立项。

### 10.5 建议顺序

1. 写 \(k\) 继续 1b 滑窗 SGD；节点齐了可用 1a。门按 06-a（含慢尾巴不写）。影子提交按 §10.6。
2. 要更便宜，先跑脉冲 \(\Delta U/\Delta I\)（05-b ⑫），不要先训更新器。
3. 要更瘦，先 \(k(T)\) / Arrhenius \(B\) / 低秩系数，不要网。
4. 2β 仍是 §9 的 G（2RC+OCP 之后的 \(\delta U\)），和写 \(k\) 分开。列 3 赢不了列 1 → §11 升阶，不加宽 GRU。
5. 加速器空着：2γ 诊断，不是写 \(k\)。

「用 AI 更新 \(k\)」收成：不当默认，不挡 2A / 2B，不和新的 2ε 档。C 只在有人坚持 NPU 必须碰 \(k\) 时当失败对照。影子 \(k\) 是提交策略，不让网合法化。

### 10.6 影子 \(k\)：工况内验收再提交

这是 05-b ㉒，不是新函数类，也不是「用 AI 写 \(k\)」的通行证。更新器仍是滑窗 SGD（或以后的脉冲辨识）。AI 写完再验收，验收的是一条已经评掉的路径。

```
门控通过的窗
    → 只写影子网格（正式 k 不动）
    → 同一 (s,T) 邻域后续若干窗：影子 vs 正式 并行开环
    → 影子更好 → 只提交被点到的节点
    → 更差 / 超时没再路过 → 丢弃影子
```

SoX / EKF / SOP **一直读正式 \(k\)**。影子只做开环对照，不准进创新、不准进保护。否则坏影子先把 \(s\) 拧歪，后面没法比。

**只比被点到的工况。** 双线性权重大的那 2～4 个顶点、后续窗还落在这一带，才算「更新过的工况」。整轨 RMSE、没去过的温区、另一段 SOC，都不算数——否则冷端写坏、中温碰巧变好也会提交。

电压单独下降不能提交（和第 0 / 1 期同一句）：

| 必须同时 | 为什么 |
|----------|--------|
| 该邻域开环 \(e^{\mathrm{ol}}\) 低于正式 \(k\) | 「残差比原来小」只在这一带成立 |
| 休息 SOC / NIS 不更差 | 电压贴上、SOC 歪了是 03-c；影子会把假 \(R\) 写成真 |
| 包级同向门沉默 | 全包一起「变好」先查 \(b_I\) / AFE，06-a |
| 慢尾巴段不变好、也不变差当理由 | 60–120 s 同号掉下去 = 在写 \(\tau_2\)，06-a §3.5 禁止提交 |

验收窗**不要再写影子**（或写了也不拿来比）。刚拟合的那一窗残差小，永远像成功。冻结影子，拿后面若干个同邻域、过门的窗比。路过太少就超时丢弃，不要挂着一份过期影子等冬天。

RAM 是再一份 5×4×2，约 160 B/芯，180 串 ~30 KB，信封里零头。双前向只多一次 \(k\) 插值 + 一次 ECM，仍不进 0.1 s 环。

明确不要：

- 用影子当学门（§10.2 D）：写不写仍靠物理门；影子只决定提交不提交
- 影子过了就把整张网格换掉：没动的节点保持正式值
- 影子期间解冻残差头或 2RC 参数
- 「跑一段时间」理解成壁钟几小时、混合工况平均——那会把未点到的格子一起验收

§10.4 若真跑更新器对照，列 0 / 1 / 2 **都要走影子提交**，否则「网打赢 SGD」可能只是提交策略不齐。

## 11. 若 1RC+\(\delta U\) 吃不干净：升 2RC，仍只写 \(k\)

担心成立，而且 §6 已经把门写好了。信封内静置双指数 15 mV → 0.16 mV 是 2RC 干的；GRU 列 3 若只在本 SEQUENCE 上赶上列 1，换脉宽就漂。**吃不过物理 2RC 列，就换 BMS，不要加宽残差头。**

现在仍不升，不挡 2A / 2B。升阶是第 3 期、真包确认回弹是第二指数之后的单独立项（`Plan.md`）。本节只锁：升完车上谁还能动。

### 11.1 什么时候才升

| 看到 | 动作 |
|------|------|
| §6 列 3 静置尾巴 / 换脉宽 **不赢** 列 1 | 丢掉「1RC+GRU 代替 2RC」 |
| 半对数弯折、静置 \(\Delta s\) 不长 | 缺 \(\tau\)，不是涨阻；继续不写 \(k_1\) |
| 真包同样弯折 | **立项 2RC BMS** |
| 列 3 贴上列 1 但换 90 s / 300 s 垮 | 过拟合指令，仍升 2RC，不是再训 GRU |
| 列 4 再抠 0.5 mV | 不够换默认，更不够挡升阶 |

两端通电直线是表面 OCP / 策略，**不是**升 2RC 的理由。加 \(U_{p2}\) 补不上那口直线（§2）。冷、≥2C、析锂仍走 §4。

### 11.2 升完怎么拆

```
硬保护 / 限流 / 低温门     ← 不变，不读 \(\hat U\)
2RC LUT (R0, R1, R2)      ← 出厂冻住；R2 仍是点映射，第二张表会打赢网
C1*, C2*                  ← 钉死（和方案 B 同一句）
每芯 k0, k1 网格          ← 滑窗 SGD + 影子提交（§10.6）
τ2 / C2 / R2 表           ← 车上不写、不轻易写
δU                        ← 只监督 2RC 之后仍在的路径 / 非指数；增量冻住
```

EKF 多一个 \(U_{p2}\)。撤流后慢段归 \(U_{p2}\)，\(k_1\) 的窗仍是 \(\sim 2\tau_1\)（约 40 s）快回弹——06-a §3.5 升阶后变成电路自己吃，不是靠门硬砍。边沿仍只动 \(k_0\)。

\(R_2\) 若光滑点映射，烤进查找表，不要用网当第二张 \(R_2(I,s,T)\)（§1）。规格书链仍是：包电压训等效曲面 → 烤表 → 出厂 \(k=1\)。真芯拆分 2RC，不要叠加 `--rc2` 当教师。

### 11.3 2RC 参数为什么不轻易更新

和 \(C_1^\star\) 同一类不可观：短窗里 \(R_2\leftrightarrow C_2\) 是零空间，长静置才看见 \(\tau_2\)，而长静置又和 OCV、AFE 漏电、\(b_I\) 长得像。

| 参数 | 车上 | 原因 |
|------|------|------|
| \(C_2^\star\) | **钉死** | 拧电容迁就 90 s = 方案 A 的覆辙 |
| \(\tau_2(T)\) | **冻住** | 一次搁置写 \(\tau_2\)，别的温区全歪；Arrhenius 该出厂写进表 |
| \(R_2(I,s,T)\) 表 | **冻住** | 共享曲面，和 \(R_0,R_1\) 一样只下线改 |
| \(k_2\) | **默认没有** | 慢支路窗像漏电。真要乘性老化，极慢全局一档、影子 + 长搁置诊断之后，不当 10 s 滑窗 |
| \(k_0,k_1\) | **照旧写** | 同一点快支路已经变了（散差、老化） |

老化若把慢支路也抬了：宁可休息 SOC 留一口、或下线重烤 \(R_2\)，也不要让 \(k_1\) 兼 \(R_2\)——那是退回 1RC 拟合（影子 2RC 上 \(R_1\) +25%，慢尾巴还在）。\(k_2\) 一旦开，门要比 \(k_1\) 更紧：半对数已经弯折、静置 \(\Delta s\) 不长、包门沉默、影子验收只看 60–120 s 那一段。默认关。

### 11.4 升阶也不改谁写 \(k\)

2RC 解决的是缺 \(\tau\)，不是「SGD 写 \(k\) 不够聪明」。雅可比多一条 \(U_{p2}\)，\(k_0/k_1\) 的更新公式还是电路算出来的。§10 的 A–F 仍然否；脉冲 \(\Delta U/\Delta I\) 仍比更新网优先；影子提交仍叠在 SGD 上。

不要把升阶讲成：终于可以让 NPU 写 \(k\) 网格、2RC 冻住当骨干。骨干可以换成 2RC LUT；写点的仍是滑窗 + 门 + 影子，不是网。
