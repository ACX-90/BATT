## 1. 现在 MLP 实际在做什么

逐步、无记忆：

\[
\bigl(R_{0,k},R_{1,k}\bigr)
=f_\theta(\tilde I_k,\tilde s_k,\tilde T_k)
\tag{1}
\]

\(C_1\equiv C_1^\star\)（方案 B）。时间只走在电路里：

\[
U_{p,k}=\alpha_k U_{p,k-1}+R_{1,k}(1-\alpha_k)I_k,\qquad
\hat U_{t,k}=U_{\mathrm{ocv},k}-I_k R_{0,k}-U_{p,k}
\tag{2}
\]

同一组 \((I,s,T)\) 必须给出同一组 \(R\)。这不是缺点：参数规范、特性文档、曲面图、KF 用预测 SOC 查表、03-d 的残差头，都建立在「\(R\) 是状态的函数，不是轨迹的函数」上。

网格训练的 SEQUENCE 里有充、放、静置，但 MLP **看不见顺序**，只看见当前三元组。历史效应若已经被 \(U_p\) 和 \(f_{\mathrm{dir}}(s,I)\) 吸收，它就不必再记。

## 2. 三种接法，不要混着评

### 2.1 接法 R：RNN 仍出 \(R_0,R_1\)，ECM 不动

\[
h_k=\mathrm{RNN}(h_{k-1},\,\tilde x_k),\qquad
(R_{0,k},R_{1,k})=g(h_k)
\tag{3}
\]

再送进 (2)。灰箱壳还在，网络从点映射变成**有记忆的参数发生器**。下文默认评这一条——它和现有 `ecm_forward`、电压损失、方案 B 改动最小。

### 2.2 接法 V：RNN 直接出电压，拆掉 ECM

\[
\hat U_{t,k}=\mathrm{RNN}(h_{k-1},I_k,s_k,T_k,\ldots)
\tag{4}
\]

黑箱。电压可以更贴，但没有 \(R_0,R_1\)，不能画曲面、不能给 KF 当参数、不能做 03-d 那种 \(\Delta R\) 头。和本仓库目标不一致，只在 §6 作对照。

### 2.3 接法 Δ：MLP 仍出主 \(R\)，RNN 只拟合 1RC 吃不下的残差

\[
\hat U_{t,k}=U_t^{\mathrm{ECM}}(R^{\mathrm{MLP}})+\delta U_k,\qquad
\delta U_k=\mathrm{GRU}(h_{k-1},I_k,e_{k-1},\ldots)
\tag{5}
\]

或加第二支路 \(R_2C_2\)，而不是换 backbone。这是「1RC 不够」时的正途，见 §7。

## 3. 接法 R 可能的优点

相对点式 MLP，RNN 多记住的是**路径**，不是当前工作点。

| 现象 | 1RC + 点式 \(R(s,T,I)\) | GRU / LSTM 可能多出来的 |
|------|-------------------------|-------------------------|
| 充放滞后 | 只有 \(f_{\mathrm{dir}}\)，看当前 \(I\) 符号 | 能记住「刚刚在充还是在放」 |
| 石墨 staging / 局部鼓包 | 写成 SOC 上的静态凸起 | 能随嵌锂历史左右挪一点 |
| 慢扩散（本该 2RC） | 折进 \(R_1\) 或残差 | 隐状态当第二条时间尺度 |
| 输入毛刺 | 逐步 \(R\) 跟着抖 | \(h\) 低通，\(R\) 更滑 |
| SOC 短暂不准 | \(R\) 立即用错 \(s\) | 短时仍靠电流史撑着 |

电压拟合上限会升高：同一条回弹，RNN 可以用 \(h\) 补 1RC 对不齐的尾巴。合成网格上 SEQUENCE 固定，这个便宜尤其明显——网络记住「静置 120 s 后该怎么回」，不真正学 \(R(s,T)\)。

LSTM 比 GRU 多个细胞门，长依赖略稳，参数大约多 1/3。本问题时间常数是十几秒到一两分钟，不是千步语言依赖，**GRU 通常够，上 LSTM 收益很小**。

## 4. 接法 R 的缺点（对本仓库是主因）

### 4.1 和 \(U_p\) 抢电压，可观性比方案 A 更差

04 已经说明：\(R_1\) 与 \(C_1\) 对冲会让 Hessian 变扁。RNN 再加 \(h\in\mathbb{R}^{d}\)（\(d=8\sim 32\)），同一段 \(\hat U_t\) 可以来自：

- 改 \(R_0\)（边沿）
- 改 \(R_1\)（幅度 / \(\tau\)）
- 改 \(h\)（任意慢形状）
- 改 \(U_p\) 初值

电压贴上了，\(R_0,R_1\) 对不上教师列、换一条轨迹对不上，是预期行为而不是调参问题。方案 B 钉死 \(C_1\) 省下的那一个自由度，会被 \(h\) 立刻吃回去。

### 4.2 不再是「可查询的参数表」

\(R_k=g(h_k)\)，\(h_k\) 依赖整段历史。不能再问「SOC=50%、25 °C、1C 的 \(R_0\) 是多少」——还要问从哪段电流走来。于是：

- `plot_ecm_surfaces.py` 那类 \((s,T)\) 曲面没有定义  
- 03-c 里「用 \(s_{k|k-1}\) 查 MLP 再测更新」少了确定的 \(R\)  
- 03-d 残差头、每芯 18 个数、写死基准，都假定点映射  
- 参考点 \(0.80/0.65\,\mathrm{m}\Omega\) 无法当锚

### 4.3 隐状态初值 = 放大的 \(U_p(0)\) 问题

03-a §5.8：片段不是从静置开始时，\(U_{p0}=0\) 会把前几十秒误差打到 \(R_1\)。RNN 的 \(h_0\) 维数更高、更不可观。训练网格每条都从 rest 起、\(h_0=0\)，现场从行驶中间切开就会漂。

可学每条轨迹的 \(h_0\)，等于再给一条隐变量，离线行、车上不行。

### 4.4 增量、回放、缩放全变难

03-a 的 Replay / 参数锚 / \(k_0,k_1\) 都作用在点映射上。RNN 增量时：

- 只微调新年份：旧温区的 \(h\) 动态一起改，遗忘比 MLP 快  
- 探点蒸馏：没有「探点上的 \(R\)」，除非再存一批旧轨迹的隐状态回放  
- \(k_0,k_1\) 缩放仍能做，但 RNN 会用 \(h\) 绕过缩放去拟合电压  
- `scaler.json` 仍要冻；RNN 对输入分布更敏，冻错更痛

03-d 不建议的「每 0.1 s 反传」若再配 RNN，等于逐步 BPTT 过隐状态，MCU 上比 3×8×2 重一个数量级，和 A0-a 的 PPU 预算对着干。

### 4.5 和 EKF 的接口变脏

03-c 的顺序是：安时预测 \(s^-\) → 点式 \(R\) → 极化预测 → 新息 → 更新 \(s,U_p\)。RNN 的 \(h\) 要不要进状态？

| 做法 | 后果 |
|------|------|
| \(h\) 只前向、不进 \(\mathbf{P}\) | 滤波当 \(R\) 已知，但 \(R\) 其实依赖未建模的 \(h\)，NIS 会偏 |
| \(h\) 扩进 EKF | 维数 \(2+d\)，雅可比要过 GRU，不可观，等于联合估神经网络 |
| 每拍把 \(h\) 当过程噪声 | 能跑，等于承认 \(R\) 有色噪声，KF 调参更玄 |

局部 \(\delta R_0\) 随机游走（03-c §3.2）已经能吸收「这一趟偏 50 µΩ」。RNN 不是这个缺口的正确答案。

### 4.6 过拟合训练 SEQUENCE

网格默认 rest–放电–rest–充电–短脉冲。RNN 很容易学会「第 210 s 该回弹」而不是 \(\tau_1=R_1C_1\)。换 `gen_common` 的指令序列，电压会差一截，\(R\) 对照更差。MLP 没有这条捷径。

### 4.7 算力和实现

| | 现用 MLP 64×64 | 小 GRU \(d=16\) 出 2 维 |
|--|----------------|-------------------------|
| 参数量 | \(\sim 4\,\mathrm{k}\) | 同量级或略少 |
| 单步 | 两层 GEMM，可并行查整段 | 必须逐步，难向量化整条 \(T\) |
| 训练 | 点式 + BPTT 只过 ECM | BPTT 过 RNN+ECM，图更长 |
| 部署 | 和 03-d 的 3×8×2 同类 | 要存 \(h\)，增量要存优化器态 |

LSTM 更重，本任务没有对应收益。Transformer / 长窗口自注意力：网格轨迹约 \(10^3\sim 10^4\) 步，注意力平方，更不合适。

## 5. 小容量点映射在单点增量下的曲面漂移

3×8×2 一类窄网在某个 \((s,T)\) 上停留很久、又逐步用电压误差更新时，再画出的 \(R(s,T)\) 往往会偏离增量前的曲面。03-d §6.4 已从相关样本角度写过：无 Replay、每 0.1 s 反传，18 个数会被当前窗口洗掉。本节只补「这是不是因为 MLP 没有隐状态、换成 GRU 能否保住其它工况」。

### 5.1 两种记忆不要混

| | 存在哪 | 记住什么 | 换到另一个 \((s,T)\) 还在吗 |
|--|--------|----------|------------------------------|
| **权重 \(\theta\)** | \(W_1,W_2\) 或 GRU 的 \(W_{ir},W_{hr},\ldots\) | 整张 \(R(I,s,T)\) 怎么算 | 在。这就是曲面。增量 SGD 改的也是它 |
| **隐状态 \(h_k\)** | 只在 RNN 里，跟当前这一趟走 | 最近几秒到一两分钟的路径（刚充过、极化还没消） | **不在。** 一换点、一复位、一出车就不是原来的 \(h\) |

MLP 没有 \(h\)，不是「没有记忆所以忘曲面」。曲面从来都在 \(\theta\) 里。待久了曲面歪，是 **\(\theta\) 被当前点的梯度改写了**，不是因为网络是前馈。

GRU 多出来的 \(h\) 是**本趟行程的短时记忆**，不是「上个月 0 °C、SOC=20% 的 \(R_0\)」那种联想记忆。没有按 \((s,T)\) 编址的槽，就谈不上「换回旧工况把旧 \(R\) 取出来」。

### 5.2 为什么 3×8×2 待久了曲面会塌

设当前长时间停在 \(x_\star=(I_\star,s_\star,T_\star)\)，每拍用电压误差更新。3×8×2 的 8 个隐单元、18 个后层参数是**全体工况共用**的。\(x_\star\) 上 \(\varphi\) 几乎常值，梯度反复是同一方向：

\[
\Delta W_2 \propto e_k\,\varphi(x_\star)^\top
\tag{5a}
\]

\(W_2\) 一改，**所有** \(x\) 的 \(\Delta R=W_2\varphi(x)\) 一起动。前层若也解冻，8 个特征探测器还会转向「只对 \(x_\star\) 敏感」。再拿一张 \((s,T)\) 网格去画 \(R\)，其它档位已经不是拟合刚结束时的数。这不是画图 bug，是小容量点映射的**灾难遗忘 / 表征干涉**。

网越窄、更新越勤、越没有旧点回放，塌得越快。本仓库 \(64\times 64\) 也会在「只在一个温区增量、无 Replay」时慢慢歪，只是比 3×8×2 慢。03-d 的结论仍然成立：该降频、该冻前层、该 Replay 或锚探点，不是该换时序核。

对照：真正「只改当前格、其它格不动」的是 **\((s,T)\) 分箱表**。待在一格里更新，邻格保持原值。那是空间上的局部写入，和 GRU 无关。

### 5.3 换成 GRU，待久了会怎样

接法 R 在同一点 \(x_\star\) 上长时间反传，更新的是 GRU 的全部共享权重，不是把 \(R(x_\star)\) 写进某个只属于 \(x_\star\) 的格子。之后任意 \(x\) 都走同一套 \(W\)：

- 旧温区 / 旧 SOC 的前向一样被改掉，**遗忘不会比 MLP 轻，通常更重**（参数更多、还多一条 \(h\) 通道把电压误差散开）
- 画曲面更麻烦：同一 \((s,T)\) 的 \(R\) 还依赖 \(h_0\) 和怎么走到这一点，得到的是另一条路径下的另一个 \(R\)，不是旧工况存档
- 若权重大改之后再回到旧 \((s,T)\)，GRU 用的是**这一趟新的 \(h\)**，不是上次离开时存档的 \(R\)

若目标是「换工况后权重里的 \(R\) 表还在」，GRU 做不到。若目标是「几分钟内的充放滞后」，那是 \(h\) 的本职，点式 MLP 加方向因子或 2RC 也能管，不必用它冒充整张曲面。

### 5.4 容易和「有记忆」搅在一起的两件事

1. **增量时 \(\theta\) 被当前点改写**（曲面漂移）。应对是 Replay、探点锚、冻前层、分箱表、少更新，见 §5.5。  
2. **同一趟里刚从 A 到 B，\(R\) 还带着 A 的路径依赖**（\(h\)）。GRU 能做这个；画成静态 \(R(s,T)\) 曲面本就会糊。停一夜 \(h\) 清零，路径记忆消失，权重遗忘仍在。

固定 SEQUENCE 上 GRU 电压更贴、\(R\) 看起来「稳」，多半是过拟合指令节奏（§4.6），不是保住了多工况曲面。换一条没见过的温区扫描，会一起垮。

### 5.5 要保住其它工况用什么

按「谁不该被当前点改掉」选，不要按网络是否带隐状态选。

| 手段 | 当前点待很久时，其它 \((s,T)\) |
|------|--------------------------------|
| 3×8×2 解冻 + 0.1 s 反传 | 一起漂 |
| 3×8×2 冻前层 + 降频 + 大电流才更新 | 好一些，18 个数仍会慢漂 |
| Replay / 探点蒸馏（03-a） | 旧点电压或旧 \(R\) 把 \(\theta\) 拉住 |
| \(k_0,k_1\) 或有界 \(\delta R\)（03-a / 03-c / 03-d） | 形状不动，只整体挪 |
| \((s,T)\) 分箱表，只写当前格 | 其它格原封不动 |
| 接法 R：GRU 出 \(R\) | **不保护曲面**，还取消「格」的定义 |
| 外置键值记忆，键是量化后的 \((s,T)\) | 才是「按工况存 \(R\)」；已不是标准 GRU |

增量默认仍按 03-d / 03-a：小头、冻特征、开环误差、有激励才更新、旧探点抽查曲面。不为此把骨干换成 GRU。滑窗少更新是另一套协议，见 §6，与本节独立。

## 6. 滑窗 1RC：短时恒定 \(R\) 与多时刻电压监督

本节评估一种**增量 / 辨识协议**（下称滑窗 1RC），与 §1–5 的循环骨干无关。协议四条：

1. 滑一个长度为 \(N\) 的时间窗。  
2. 窗很短，\(R_0,R_1\) 近似当成常数。  
3. 窗内用同一套 1RC（与 `ecm_forward` 相同）滚 \(N\) 拍，\(N\) 个端电压残差一起当监督。  
4. 梯度在窗内累加，**只 `step` 一次**，以降低噪声、减少无效更新。

这是完整、合理的协议。它约束的是**损失的时间支撑和更新频率**，不要求参数头是 RNN。

### 6.1 在算什么

窗 \([k,k+N)\)。短时恒定：

\[
R_{0},R_{1}\;\equiv\;R_{0,k:k+N},\;R_{1,k:k+N}
\qquad\text{（由窗中心或窗均值的 }(I,s,T)\text{ 查点式网络一次）}
\tag{6a}
\]

极化仍逐步走，物理约束在电路里，不在网络里：

\[
\begin{aligned}
U_{p,j+1}
&=\alpha U_{p,j}+R_1(1-\alpha)I_j,
\qquad
\alpha=\exp\bigl(-\Delta t/(R_1 C_1^\star)\bigr)
\\
e_j
&=U_{t,j}^{\mathrm{meas}}-\bigl(U_{\mathrm{ocv},j}-I_j R_0-U_{p,j+1}\bigr)
\end{aligned}
\tag{6b}
\]

窗损失、一次更新：

\[
L_{\mathrm{win}}
=\frac1N\sum_{j=k}^{k+N-1} e_j^2,
\qquad
\theta\leftarrow\theta-\eta\sum_{j}\frac{\partial L_{\mathrm{win}}}{\partial\theta}
\tag{6c}
\]

\(U_p\) 跨窗可以续（和仿真 / EKF 一致），不要每个窗从 0 起。

### 6.2 这是序列监督，不是序列网络

「连续 \(N\) 时刻共同监督」说的是损失跨了多少拍，不是骨干必须是 RNN。本仓库离线训练已经是这个结构：`ecm_forward` 整段滚，`voltage_loss` 对 \(T\) 取均值，每个 batch **一次** `opt.step()`。`--tbptt N` 就是显式滑窗。协议多出来的硬约束是 **窗内 \(R\) 锁死**，以及增量时「累积后再更新」——对着 03-d 批评的每 0.1 s 一步。

与 §3–5 的循环参数头对照（二者独立提出，这里只比机制）：

| | 滑窗 1RC（协议） | GRU 出 \(R\)（架构） |
|--|------------------|----------------------|
| 问题 | 逐步更新噪声大、次数多 | 担心单点增量冲掉曲面 |
| 谁在跨时刻 | **ECM 的 \(U_p\)** | 网络隐状态 \(h\) 再加 \(U_p\) |
| 窗内 \(R\) | **当作常数** | 每拍随 \(h\) 变 |
| 是否采纳 | 协议可采纳 | 不换骨干 |

### 6.3 为什么短时恒定 \(R\) 是对的

\(R(s,T)\) 随 SOC / 温度走，秒级几乎不动；\(U_p\) 的 \(\tau_1\) 才是十几秒。1C 放电 10 s 只动约 0.28% SOC。把窗长放在 \(1\sim 5\,\tau_1\)（大约 2～30 s，\(N=20\sim 300\)）时：

- \(N\) 个残差估两个数（再加一个续上的 \(U_p\)），比单拍估两个数稳一个数量级  
- 窗里若既有 \(\Delta I\) 又有静置，\(R_0\)（边沿）和 \(R_1\)（回弹）被**同一对常数**绑在一起，拆得开，这是 HPPC / 窗最小二乘的老办法  
- \(R\) 不会每 0.1 s 跟着电压噪声抖；相对单点逐步 SGD，同向更新次数大约少 \(N\) 倍  

相对逐步 SGD，降噪和更稳的 \(R_0/R_1\) 拆分成立。相对本仓库已经按整条轨迹反传的离线训练，增益主要在**边缘增量协议**，不在换核。实现本协议不必改 `ParamMLP`：序列已经在 ECM 里。

本协议要求窗内 \(R\) **不要变**。这与接法 R（\(R_k=g(h_k)\) 逐步变）机制相反，因此**不能**从滑窗 1RC 推出「参数头应改成 GRU」。

### 6.4 本仓库怎么对齐

离线：已经对齐大半。若还要「窗内 \(R\) 真锁死」，对每个窗用中心 \((I,s,T)\) 只调一次 MLP，再 `ecm_forward`；或把现有 `lambda_smooth` 理解成软锁（已经在罚 \(\ln R\) 逐步差）。

增量 / 对齐 03-d 的 0.1 s demo：

1. 滑窗 \(N\)（先试 50～200 步，5～20 s），残差用 \(e^{\mathrm{ol}}\)  
2. 窗内 \(R_0,R_1\) 用该窗中心查 3×8×2 或 \(64\times 64\) **一次**  
3. 梯度累加满窗再 `step` 一次；不要每拍 `step`  
4. 窗里没有边沿也没有回弹则**不更新**（激励门）  
5. 前层仍冻；旧探点 Replay 或抽查曲面  

这就是 03-d §6.5「相关样本降频 / 累加 \(N\) 拍再一步」的物理版：不但少更新，还加上「一对 \(R\) 解释整窗」。

### 6.5 窗太长、太短会怎样

| 窗 | 风险 |
|----|------|
| \(N=1\)（0.1 s） | 回到 demo 逐步反传，噪声大、曲面洗得快 |
| \(N\approx 2\sim 5\,\tau_1\) 且含激励 | 协议的甜点 |
| \(N\) 大到 SOC / \(T\) 已明显变 | 「\(R\) 恒定」假，锁出会偏；应切窗或让点式 MLP 逐步变、只把 `step` 仍放在窗末 |
| 整窗都是静置 / 小电流 | \(N\) 再大也拆不开 \(R_0,R_1\)，常偏会进电阻 |
| 窗重叠很多、每步都滑 1 拍再更新 | 又变相关样本，降噪有、降更新次数无 |

重叠滑窗可以每 \(N/2\) 步更新一次，不要每步都更新。

## 7. 什么时候值得动时序结构

先看开环 \(e^{\mathrm{ol}}\)（03-c），不要先换 backbone。

| 残差长什么样 | 先试什么 | 不要先上 |
|--------------|----------|----------|
| 边沿差一点、回弹形状对 | 更大 MLP / 更好激励 / 方案 B+ | GRU |
| 回弹有明显第二指数 | **2RC**（再钉死或慢变 \(C_2\)） | 用 GRU 暗含第二条 \(\tau\) |
| 充放环、路径依赖大 | 分充放两张 MLP，或输入加「上次方向」滞后 | 全替换 LSTM |
| 1RC+2RC 后还有慢尾巴 | 接法 Δ：很小的残差 GRU 出 \(\delta U\)，主 \(R\) 仍 MLP | 接法 R / 接法 V |
| 只是 SOC 漂、电流偏 | EKF + 开环增量（03-c） | 任何 RNN |

2RC 比 GRU 优先：多一对 \((R_2,C_2)\)，物理清楚，KF 只多一个 \(U_{p2}\)，仍是点映射。特性文档已经写 1RC 是折中，扩散应用 2RC。

接法 Δ 的约束：\(\delta U\) 幅度封顶（数 mV）、\(h\) 维数 \(\le 4\)、增量时冻 GRU 只更 MLP 或 \(k_0,k_1\)。否则残差头会重新吞掉主电路。

## 8. 其它非 MLP，一句话

| 结构 | 和本问题的关系 |
|------|----------------|
| LSTM | 同 GRU，略重；不优先于 GRU |
| 双向 RNN | 要用未来电流，车上不能用；离线拟合可以，和 KF 实时矛盾 |
| TCN / 因果卷积 | 固定感受野，比 GRU 好部署一点，仍有 4.1–4.6 |
| Transformer | 过重，参数表仍变成历史函数 |
| KAN | 仍是点映射，可解释性宣传多；曲面光滑时不如加大 MLP 实在 |

## 10. 结论与落地

两条结论分开写。

**架构（§1–5）。** 不要用 GRU / LSTM 替换 `ParamMLP`。本仓库要的是可查询、可滤波、可增量的 \(R(s,T,I)\)；时序已经在 \(U_p\) 里。RNN 出 \(R\) 会重演并放大方案 A 的不可观，还拆掉 03-c / 03-d 的接口。3×8×2 在单点上逐步反传会把曲面洗歪，根子是共享 \(\theta\) 被当前梯度改写，不是前馈缺少 \(h\)。GRU 挡不住这件遗忘。要保住旧点：Replay、探点锚、冻前层、分箱只写当前格。

**协议（§6）。** 滑窗 1RC 可采纳：窗内 \(R\) 近似恒定、\(N\) 拍电压残差共同监督、梯度累积后更新一次。离线 `voltage_loss` + `ecm_forward` 已经在做；边缘侧用它代替每 0.1 s 一步。该协议不要求、也不支持把点式头换成 GRU。

若 \(e^{\mathrm{ol}}\) 在回弹段呈明显双指数，先加 2RC，\(C_2\) 钉死或全局慢变。仍有数 mV 慢残差，再用维数很小的接法 Δ，增量时冻住它。

一期明确不做：接法 V、LSTM 换骨干、双向 RNN、把 \(h\) 扩进 EKF、每 0.1 s 对 GRU 反传。一期可做：增量滑窗 \(N=50\sim 200\)、窗内锁 \(R\)、有激励才 `step`。
