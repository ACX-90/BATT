公开资料里英飞凌 + Eatron / Ekkono 只写到「边缘侧按车 / 按电芯做增量」，**没有**找到与「后层清零 + 常值基准 + \(\Delta R\)」一一对应的应用笔记。下文评估的是上述**现场演示结构**，不把它当成已核实的官方规范。

现场演示窗口大约 **300 s**，口径是 SOC 误差 1% 以内。300 s 在 1C 上只走约 8 pp SOC。容量错 5% 大约贡献 0.4 pp，5 A 零偏大约 0.4 pp，都还在 1% 里。这不是算法过关，是**积分误差还没长出来**。拉到小时级，同一套错配会把安时拉开几个到十个百分点；若再把电压误差写进 \(\Delta R\)，SOC 和电阻一起飞。第 0 期的小时级负例、\(\hat Q\neq Q\)、EKF 与增量分工，就是冲着这扇窗做的。展开见 §6.6、`Doc/03-c` §5.3。

## 1. 先把方案写严

记预训练网络为

\[
z = W_{\mathrm{head}}\,\varphi_\theta(I,s,T)+b_{\mathrm{head}}
\]

demo 的部署方式：

1. **前层** \(\varphi_\theta\) 用实验室 / 车队数据预训练，部署时拷到每只电芯。  
2. **后层** \(W_{\mathrm{head}}=0\)，\(b_{\mathrm{head}}=0\)，于是 \(z\equiv 0\)。  
3. **写死基准**（规格书或参考点，不随 \((I,s,T)\) 变）

\[
R_0^\star,\; R_1^\star
\quad\text{（本仓库模板是 }0.80\,\mathrm{m}\Omega,\; 0.65\,\mathrm{m}\Omega\text{）}
\]

4. 网络输出残差，再相加：

\[
R_0 = R_0^\star + \Delta R_0(z),\qquad
R_1 = R_1^\star + \Delta R_1(z)
\tag{1}
\]

初始化时 \(\Delta R=0\)，ECM 立刻用基准电阻算电压，不会冒出随机大电阻。

5. **每只电芯一份** \(\theta_{\mathrm{cell}}\)（至少后层；前层可共享可复制）。  
6. **SOC 用 EKF**（安时预测 + 电压更新）。现场演示带滤波，不是纯安时。  
7. 用该电芯自己的工况电压做增量，让 \(\Delta R(I,s,T)\) 贴上这只电芯。  
8. **事件触发反传**（与本仓库离线批次不同）：

\[
\lvert e_k\rvert > 10\,\mathrm{mV}
\;\Rightarrow\;
\text{对当前拍做一次 } \partial L/\partial\theta
\tag{1c}
\]

\(e_k\) 按端电压预测误差理解（\(\hat U_t-U_t^{\mathrm{meas}}\)）。一直大于 10 mV，就**每 0.1 s 反传一次**，步长与仿真 / 采样一致。小于门限则权重不动。

和本仓库现有头的差别：

| | 本仓库 `ParamMLP` | demo 残差头 |
|--|-------------------|-------------|
| 末层权重 | 已是 0 | 0 |
| 末层偏置 | \(\mathrm{softplus}^{-1}(R^\star-R_{\min})\)，输出约等于 \(R^\star\) | 0，输出 \(\Delta R=0\) |
| 电阻从哪来 | \(R_{\min}+\mathrm{softplus}(z)\)，初值是常值曲面 | \(R^\star+\Delta R(z)\)，初值是规格书点 |
| 正性 | softplus 保证 | **加法不保证**，要另夹 |
| 个性 | 全库一张网 | 每芯一套（或每芯一个头） |

末层权重清零这件事，本仓库预训练头已经做了。demo 多出来的是：**把「常值」从网络偏置里拿出来，变成显式基准；网络只负责偏差；偏差按电芯存。**

### 1.1 输入归一化（demo 与本仓库 scaler）

进网之前还有一截仿射。按现场演示的约定（不是已核实的官方笔记）：电流改成倍率、SOC 已是 0–1、温度把 \([-20,50]\,^\circ\mathrm{C}\) 拉到 \([0,1]\)。

\[
\tilde I = \frac{I}{I_{1\mathrm{C}}},\qquad
\tilde s = s,\qquad
\tilde T = \frac{T-T_{\mathrm{lo}}}{T_{\mathrm{hi}}-T_{\mathrm{lo}}}
\tag{1d}
\]

本模板 \(I_{1\mathrm{C}}=100\,\mathrm{A}\)，\(T_{\mathrm{lo}}=-20\,^\circ\mathrm{C}\)，\(T_{\mathrm{hi}}=50\,^\circ\mathrm{C}\)。三个数都是**设计时写死的**，不看训练集。

本仓库 `FeatureScaler` 是舰队第一次训练时从 `Data/grid/` 估的 z-score，电流仍是安培：

\[
\tilde x_i=\frac{x_i-\mu_i}{\sigma_i},\qquad
x=\bigl(I/\,\mathrm{A},\; s,\; T/^\circ\mathrm{C}\bigr)
\]

当前 `Data/ai_mlp/scaler.json`（10×10、默认 SEQUENCE）：

\[
\mu=(23.09\,\mathrm{A},\;0.424,\;20.75\,^\circ\mathrm{C}),\quad
\sigma=(59.24\,\mathrm{A},\;0.287,\;19.25\,^\circ\mathrm{C})
\]

同一物理点进网后的坐标（demo 按 (1d)，本仓库按上式）：

| 物理量 | demo \(\tilde x\) | 本仓库 \(\tilde x\) |
|--------|-------------------|---------------------|
| 静置 \(I=0\) | \(0\) C | \(-0.39\) |
| 1C 放电 \(100\,\mathrm{A}\) | \(+1\) | \(+1.30\) |
| 1C 充电 \(-100\,\mathrm{A}\) | \(-1\) | \(-2.08\) |
| 2C \(200\,\mathrm{A}\) | \(+2\) | \(+2.99\) |
| SOC \(0/0.5/1\) | \(0/0.5/1\) | \(-1.48/\,+0.26/\,+2.01\) |
| \(-20\,^\circ\mathrm{C}\) | \(0\) | \(-2.12\) |
| \(-10\,^\circ\mathrm{C}\)（网格左端） | \(0.14\) | \(-1.60\) |
| \(25\,^\circ\mathrm{C}\) | \(0.64\) | \(+0.22\) |
| \(50\,^\circ\mathrm{C}\) | \(1\) | \(+1.52\) |

| | demo (1d) | 本仓库 `scaler.json` |
|--|-----------|----------------------|
| 谁写 | 工程师：\(Q_n\)、温窗 | 数据：该次网格的 \(\mu,\sigma\) |
| 电流单位 | 倍率，换容量 1C 仍是 \(1\) | 安培。50 Ah 上 1C 只有 50 A，对本网像「半电流」 |
| SOC | 原样 0–1 | 再减均值。50% 不是 0，是 \(+0.26\) |
| 温度 | 声明的盒子 \([-20,50]\to[0,1]\) | 相对训练均值。网格其实从 \(-10\,^\circ\mathrm{C}\) 起，没有 \(-20\) |
| 出界 | \(T<-20\) 或 \(>50\) 立刻出盒子 | 门控用 \(\mu\pm 4\sigma\)：温度大约 \(-56\sim +98\,^\circ\mathrm{C}\)，车上几乎永不触发 |
| 和工况的耦合 | 与 SEQUENCE 里休息占比无关 | \(\sigma_I\) 被大量 \(I=0\) 和几段脉冲一起拉；换工况重训，scaler 会变 |
| MCU | 三个常数乘加，不必存 json | 六个 float，必须和权重成套 |
| 增量 | 同样不许改这组仿射 | 冻 `scaler.json`，见 03-a §5.1 |

两套都是「权重坐标系」，冻的理由相同。**不能**拿 demo 的 (1d) 去喂现成 `best.pt`，也不能把本仓库的 \(\mu,\sigma\) 套到按 (1d) 训的 3×8×2 上。以后若对齐 demo 做残差头，输入仿射要在预训练里就定成 (1d)，不要沿用这份 z-score。

z-score 的具体代价：电流绑死容量；「出 scaler」对汽车温区几乎是空门。demo 盒子的代价：\(-20\,^\circ\mathrm{C}\) 是设计端点，本仓库舰队没见过；\(T=51\,^\circ\mathrm{C}\) 在 demo 里已经出界，在本仓库里只是 \(+1.57\sigma\)。

## 2. 网络是 3×8×2，容量就卡在这里

结构按一层隐层读：

\[
[I,\,s,\,T]
\;\xrightarrow{\;W_1\in\mathbb{R}^{8\times 3}\;}
\mathbb{R}^{8}
\;\xrightarrow{\;\sigma\;}
\varphi
\;\xrightarrow{\;W_2\in\mathbb{R}^{2\times 8}\;}
(\Delta R_0,\,\Delta R_1)
\tag{1a}
\]

| 层 | 权重 | 偏置 | 小计 |
|----|------|------|------|
| \(3\to 8\) | 24 | 8 | 32 |
| \(8\to 2\) | 16 | 2 | 18 |
| **合计** | | | **50** |

float32 整网 200 B；只存后层 72 B。100 只电芯若只复制后层，约 7 kB 加一份共享前层。本仓库默认 `hidden=(64,64)` 方案 B 约 4546 个数（\(3\to64\to64\to2\)），大约是它的 **90 倍**。

前向大约 50 次乘加，0.1 s 一拍在 AURIX 上可以忽略。规模首先是给 MCU 预算定的，不是按「逼近整张 \(R(I,s,T)\) 曲面」定的。

### 2.1 后层全 0 时，真正能训的只有 18 个数

\(W_2=0\) 则 \(\partial z/\partial\varphi=0\)，前层 32 个数收不到梯度。增量若冻前层，每只电芯只更新

\[
W_2\in\mathbb{R}^{2\times 8},\; b_2\in\mathbb{R}^{2}
\quad\Rightarrow\quad 18\text{ 个参数}
\tag{1b}
\]

\(\Delta R_0\)、\(\Delta R_1\) 各是 8 维特征的一个线性组合。电芯之间的差别，被假设成「同一组 8 个非线性特征，换一套读出」。

比 03-a 的 \(k_0,k_1\)（2 个数）宽，比解冻整网（50 个数）窄。18 相对 2 的增益，全部来自 \(\varphi\) 里已经有没有「像电阻曲面」的方向。

### 2.2 8 个隐单元要干的活

非线性全在 \(3\to 8\)。8 个 \(\sigma\)（tanh / ReLU / GELU）最多划出大约 8 条脊或折，却要同时伺候：

- SOC 的 U 形（两端各翘）
- Arrhenius 的 \(1/T\)
- 电流软饱和、充放不对称
- 高镍高 SOC 那一小段鼓包（规范里的相变项）

这不是「略简化」，是把整张乘性曲面压进 32 个前层参数。预训练必须在**宽温区、宽 SOC、有脉冲**的数据上把这 8 个特征摆对；增量再改 18 个数读出，不能发明第 9 个「低温专用」方向。

因此：

| 任务 | 3×8×2 够不够 |
|------|----------------|
| 中温附近、相对 \(R^\star\) 偏几十到一两百 µΩ | 往往够，这是 demo 的舒适区 |
| 整张 Arrhenius + U 形都由 \(\Delta R\) 从常值长出来 | 紧。前层必须已经在全温区预训练好 |
| 某 SOC 窗口鼓包、高镍后期变形 | 8 维特征大概率摊平，拟合不足 |
| 预训练没见过的温区（填洞） | 不够。冻前层时线性头补不出新特征 |
| 同一只电芯跨寿命 | 仍缺 SOH 维；50 个参数会被新数据整表改写 |

常值基准 \(R^\star\) 把「随工况变的那一大块」全部推给这 50 个数。网越窄，§5.1 的乘性物理越痛：不是写法不对，是**函数类不够大**。

### 2.3 每芯存整网其实也便宜，但仍应只存头

50 个数 × 100 芯 ≈ 20 kB，在 MCU 上复制整网不再荒谬——下面 §5.5 按 64 宽网说的「不要每芯一份」对 **3×8×2 要减弱**。即便如此，仍建议前层共享：

- 50 个数里 32 个是特征探测器。每芯各训一套，等于每芯自己重新发明 Arrhenius，样本少时 8 个神经元会滑到最近的工况，旧温区先塌。
- 只训 18 个数，前层锁在车队预训练上，遗忘面更小，也更符合「后层全 0」的梯度结构。

### 2.4 和本仓库默认网不要拿同一把尺

对照实验若把本仓库 \(64\times 64\) 的绝对 MLP 去比英飞凌的 3×8×2 残差头，赢的是容量不是算法。要对齐 demo：

- 舰队 / 实验室仍可用宽网当 \(f_{\mathrm{fleet}}\)（本仓库现状）
- 模仿英飞凌的那一路，隐层就是 8，输出 2，不要先加宽再宣布「残差头更好」

## 3. 它在 03-a 的分类里是哪一类

03-a 把「新」分成填洞、换对象、老化。demo 的主场景是**换对象**：

- 前层 = 车队 / 模板学到的 \((I,s,T)\) 特征  
- 基准 = 这一化学体系的规格点  
- 后层 = 这一只电芯相对规格点的曲面

这和 03-a §3.5 缩放适配是亲戚，但更宽：

\[
\begin{aligned}
\text{缩放（已实现）}&\quad R = k\cdot f_\theta(I,s,T)\\
\text{demo 残差}&\quad R = R^\star + W_{\mathrm{cell}}\,\varphi(I,s,T)\\
\text{更完整的残差}&\quad R = f_{\mathrm{fleet}}(I,s,T)+\delta_{\mathrm{cell}}(I,s,T)
\end{aligned}
\tag{2}
\]

缩放只有 2 个自由度，只能整体抬电阻，形状不动。  
3×8×2 的线性残差头是 **18 个数**，能在 8 维特征里改读出，改不了特征本身。  
「舰队绝对电阻 + 电芯残差」才是把预训练曲面留下来、只学偏差；demo 把绝对曲面扔掉，只留 8 维 \(\varphi\)，用常值顶上。网一窄，这 8 维必须在预训练里就对准物理，增量没有补课的余量。

对老化：仍然**没有 SOH 维**。增量只能改这只电芯的 \(\Delta R(I,s,T)\)。时间长了，昨天的中温点和今天的中温点抢同一组权重。demo 的「每芯独立」能阻止电芯 A 的老化写进电芯 B，**挡不住同一只电芯自己的遗忘**。

### 3.1 函数形式像增量，运行时更像局部辨识

03-a 的分层：在线辨识改当前工况附近的局部 \(R\)（秒～分钟）；增量改整张 \((s,T,I)\) 曲面（出车 / 批次）。demo 被放进「换对象」，是因为它的**对象**——每芯一份 \(\Delta R(I,s,T)\)，带工况下标，不是 \(\delta R_0\) 那种没地址的偏置。

**运行时**已经站在辨识那一层：

1. **时间。** \(\lvert e\rvert>10\,\mathrm{mV}\) 就当前拍 SGD，持续则 \(0.1\,\mathrm{s}\)。这是 03-a §3.7 说的车上逐步，不是离线批次。
2. **自由度。** 冻前层后只动 18 个数。8 个 \(\varphi\) 是预训练回归量，头是它们的线性组合，和 RLS 的 \(y=\varphi^\top\theta\) 同类，只是没有 \(P\)、没有 \(\lambda\)（`Doc/Learn/Base/00-0402`）。
3. **容量。** 3×8×2 撑不起乘性曲面（§2.2）。所谓电芯曲面，是规格书点 + 8 维读出。

它也**不是**合格的局部辨识：

| | \(\delta R_0\) / RLS | \((s,T)\) 分箱 | demo 18 个数 |
|--|----------------------|----------------|----------------|
| 写什么 | 这一分钟的偏置 | 只写当前格 | 全体工况共用的 \(W_2\) |
| 待在一点上 | 偏置被带到新区 | 邻格不动 | 所有 \(x\) 的 \(\Delta R=W_2\varphi(x)\) 一起动（`Doc/03-b` §5.2） |
| 遗忘 | \(\lambda\) 是设计 | 不改别的格 | 相关样本洗到当前窗（事故） |

更准的归类：冻住的 8 个特征当回归量，每芯 18 个数当 \(\theta\)，用开环电压误差做**无 \(P\)、无 \(\lambda\) 的逐步辨识**。函数形式像曲面，统计行为像局部 \(R\)。`Doc/Learn/Base/00-0401` 说它介于 \(\delta R_0\) 和离线曲面之间，就是这个意思。

谱：\(\delta R_0\)（1 个数，这一分钟）→ \(k_0,k_1\)（2 个数，形状不动）→ 本头（18 个数）→ Replay / 宽网（真改曲面）。

第 6 节的大电流闸、降频、滑窗累加再 `step`，是往合格的局部辨识收；增量该留下的是「每芯一份头 + 冷启动等于规格书」这个存储结构。

## 4. 这套结构做对了什么

### 4.1 冷启动可交付

后层全 0 ⇒ 第一秒的 \(R\) 就是写死的基准。BMS 标定、HIL、功能安全比「随机初始化再等收敛」好讲：电压先按规格书走，再慢慢长出 \(\Delta R\)。

本仓库用 softplus 偏置也能得到常值 \(R^\star\)，但 \(R^\star\) 藏在激活里，和「规格书电阻」不是同一个旋钮。demo 把规格书留在电路外面，更干净。

### 4.2 换对象不该共用一张绝对曲面

03-a 写过：另一只电芯应小适配或单独一套权重。每芯一份后层，正是这个判断。一只电芯激励不足把 \(R_0/R_1\) 拆错，不会污染邻芯。

### 4.3 零初始化让残差的含义清楚

\(W=0,b=0\) 时 \(\Delta R\equiv 0\)，后面学到的就是「相对基准的偏差」。不会出现「舰队均值已经在头里、再加一份规格书」的双计。

### 4.4 后层可训、前层可冻，适合 MCU

关键梯度：

\[
z=Wh+b,\quad
\frac{\partial z}{\partial h}=W^\top
\tag{3}
\]

\(W=0\) 时 **\(\partial z/\partial h=0\)**，梯度到不了前层。  
所以「后层全 0 + 冻前层」在数学上就是：**只训一个接到冻结特征上的线性头**。  
\(\partial L/\partial W=(\partial L/\partial z)\,h^\top\) 仍然在，头可以从 0 长出来。这是有意的：先做线性探针。3×8×2 下每芯只多 18 个数、72 B，和「边缘增量」的演示目标一致。

若稍后解冻前层，必须等 \(W\) 已经非零，否则前层仍然收不到梯度。

### 4.5 和 ECM / 电压损失 / KF 兼容

电路不用改。增量损失仍应走 03-c 的开环 \(e^{\mathrm{ol}}\)，不要走 \(e^{\mathrm{post}}\)。KF 里的慢变 \(\delta R_0\)（03-c §3.2）是「这一分钟的局部偏置」；demo 的 \(\Delta R(I,s,T)\) 函数形式上是「这只电芯的曲面」。两者可以叠，不要互相替代——叠的前提是头不要每拍都刷，否则和 \(\delta R_0\) 抢同一条创新。\(0.1\,\mathrm{s}\) 裸 SGD 时统计上更像局部辨识，见 §3.1。

## 5. 不要照搬的地方

### 5.1 常值基准扛不住乘性物理

规范里 \(R\) 是

\[
R = R_{\mathrm{ref}}\cdot f_{\mathrm{SOC}}\cdot f_T\cdot f_I\cdot f_{\mathrm{dir}}
\]

\(f_T\) 是 Arrhenius，降温是**相乘**不是相加。−10 °C 相对 25 °C，\(R_0\) 很容易到参考点的 2～3 倍。  
若 \(R^\star\) 钉在 25 °C、50%、1C，则 \(\Delta R\) 必须在低温自己长出一整块 \(+1\,\mathrm{m}\Omega\) 量级的曲面。3×8×2 里这件事几乎完全压在预训练好的 8 个特征上：线性头只能重加权，**不能新造一个 \(1/T\) 探测器**。特征若是在中温预训练的，低温就是 03-a 说的**出 scaler 的填洞**，冻前层补不出来。

更稳的加法是叠在**已经随工况变的表**上：

\[
R = f_{\mathrm{fleet}}(I,s,T)+\Delta R_{\mathrm{cell}}
\quad\text{或}\quad
R = k_{\mathrm{cell}}\,f_{\mathrm{fleet}}(I,s,T)
\tag{4}
\]

前者是「舰队形状 + 电芯偏置曲面」，后者是已实现的缩放。demo 的常值 \(R^\star\) 只适合：电芯偏离规格不大、温度窗不宽、或者 \(\varphi\) 确实在全温区预训练过。

### 5.2 \(\Delta R\) 无约束会出负电阻

\(R^\star+\Delta R\) 没有 softplus。电压损失在电流符号一变、或 \(R_0/R_1\) 对冲时，完全可以打到 \(R<0\)。至少要

\[
\Delta R = \Delta R_{\max}\tanh(z)
\quad\text{或}\quad
R = R_{\min}+\mathrm{softplus}\bigl(\mathrm{sp}^{-1}(R^\star-R_{\min})+z\bigr)
\tag{5}
\]

第二种仍保证为正，且 \(z=0\) 时 \(R=R^\star\)，和 demo 的冷启动一致，又比裸加安全。

### 5.3 「后层全 0」只能是最后一层线性头

若把倒数第二层也清零，\(h\) 本身是 0，最后一层永远看不到特征，增量只剩两个偏置，退化成与 \((I,s,T)\) 无关的常值平移——比缩放适配还弱（缩放至少保留形状）。

demo 里有用的清零，**仅限输出头**。

### 5.4 激励不足时 \(\Delta R_0\) 和 \(\Delta R_1\) 仍然拆不开

03-a §5.4、03-c §3.1 在这里原样成立。恒流走到极化稳态：

\[
e \approx -I(\Delta R_0+\Delta R_1)+\Delta U_{\mathrm{ocv}}
\]

增量会把误差随便塞进一个通道。每芯独立只是把拆错关在这只电芯里，不会让拆对。门控（边沿或 \(\ge 30\,\mathrm{s}\) 静置）照旧要。

### 5.5 3×8×2 复制整网不再贵，但共享前层仍然更稳

| 存什么 | 每芯个数 | float32 | 能改的东西 |
|--------|----------|---------|------------|
| 两个标量 \(k_0,k_1\) | 2 | 8 B | 整体涨阻 |
| 输出头 \(8\to 2\)（demo） | 18 | 72 B | 8 维特征上的读出 |
| 整份 3×8×2 | 50 | 200 B | 特征也会动，旧温区先漂 |
| 本仓库 \(64\times 64\) 整网 | ≈4546 | ≈18 kB | 容量大，每芯复制才真正贵 |

100 芯全复制 3×8×2 大约 20 kB，MCU 上做得到。仍建议默认**前层一份、每芯 18 个数**：不是因为存不下，是因为 8 个特征探测器经不起每芯用几天工况去重估。

### 5.6 10 mV / 0.1 s 反传不是「禁止」四个字能打发的

03-a §3.7 写过不要把 `train.py` 嵌进 0.1 s 步进。demo 偏是这么干的，只是加了 10 mV 死区。计算上 3×8×2 扛得住，统计上会出问题。展开见第 6 节。

### 5.7 scaler 和 OCV 的坑原样在

每芯微调不得改输入仿射。对本仓库就是不得重估 `scaler.json`；对 demo 就是不得改 (1d) 的 \(I_{1\mathrm{C}}\) 和温窗。两套仿射不能互换，见 §1.1。OCV 表过期时电压误差会进 \(\Delta R\)，脉冲边沿会对不上（03-a §5.10）。温度计偏 3 °C 会被写成这只电芯的「假内阻」。持续超 10 mV 时第 6 节的逐步反传会把这些系统误差更快写进 18 个数。

## 6. \(\lvert e\rvert>10\,\mathrm{mV}\) 就反传，持续则每 0.1 s 一次

这是 demo 和本仓库增量最大的运行时差别。本仓库是攒轨迹、离线更新；它是**车上按拍、过门限就 SGD**。

### 6.1 规则

\[
\theta_{k}
=
\begin{cases}
\theta_{k-1}-\eta\,\nabla_\theta L(e_k) & \lvert e_k\rvert>10\,\mathrm{mV}\\
\theta_{k-1} & \text{否则}
\end{cases}
\tag{7}
\]

一直超限就每个采样拍都走上面第一支，\(\Delta t=0.1\,\mathrm{s}\)。3×8×2、只训后层时，一拍就是 18 个数的外积，MCU 算得动。门限的用意也清楚：测量噪声附近不要动权重。

### 6.2 10 mV 相对噪声和 \(I\Delta R\)

| 场景 | 10 mV 意味着什么 |
|------|-------------------|
| 本仓库仿真噪声 0.5 mV | 约 \(20\sigma\)，几乎不会被噪声触发，死区偏宽 |
| 实车电压噪声 2～10 mV | 约 \(1\sim 5\sigma\)，噪声尖峰会误触发 |
| 1C（100 A） | 等价于和电阻偏了 \(0.10\,\mathrm{m}\Omega\)（约 \(R_0^\star\) 的 12%） |
| 0.1C（10 A） | 等价于 \(1.0\,\mathrm{m}\Omega\)，普通内阻偏差**触发不了** |
| 静置 \(I=0\) | \(\partial U_t/\partial R_0=0\)，10 mV 几乎一定是 OCV / SOC / \(U_p\)，不是电阻 |

所以门限是按「大约 1C 上看得见的电阻误差」标的，不是按本仓库合成噪声标的。小电流、静置时超 10 mV，物理上多半不该改 \(R\)。

03-c 若同开：后验 \(e^{\mathrm{post}}\) 本来就被 KF 压到 1 mV 以下（本仓库闭环实测先验约 0.8 mV、后验约 0.1 mV），**用后验当 \(e\) 会几乎永不触发**。demo 要这个规则生效，用的必须是开环或先验电压误差。本仓库增量已经规定只吃 \(e^{\mathrm{ol}}\)，这里对齐。

### 6.3 为什么他们要这么做

边缘侧通常**存不下**本仓库那种回放轨迹（一条 6200 步 × 若干列）。3×8×2 一拍反传又极便宜。事件触发 SGD 是「没有 Replay 缓冲区时，还能做增量」的工程解，不是论文里的最优解。

10 mV 死区本身值得学：和 03-c §4.1「开环要明显高于测量噪声才进增量集」是同一句话，只是他们把阈值写成了固定 10 mV。

### 6.4 一直大于 10 mV 时，0.1 s 一步会出什么事

相邻两拍的 \((I,s,T)\) 几乎一样，梯度高度相关。持续超限 10 s 就是约 **100 次几乎同方向的 SGD**；10 min 就是 6000 次。18 个数会被当前工况洗到拟合当前窗口，其它 SOC / 温度上的读出一起漂。网越窄，漂得越快。

更具体的失败模式：

| 现象 | 每 0.1 s 反传会做什么 |
|------|----------------------|
| 电流阶跃边沿，\(\lvert e\rvert>10\,\mathrm{mV}\) 几个拍 | 合理。\(R_0\) 可观，更新次数少 |
| 恒流稳态一直偏 12 mV | \(e\approx -I(\Delta R_0+\Delta R_1)\)，拆不开，两个通道乱分；相关样本把和电阻估飞 |
| 静置一直偏 12 mV | \(R_0\) 梯度为 0，误差来自 OCV / \(s_0\) / \(U_p\)。要么空转，要么拧 \(R_1\) 去补极化 |
| 容量错、电流零偏 | 开环电压慢慢斜，长期超门限。电阻头去拟合本该由 \(q\) 或 KF 管的漂（03-c §5.3） |
| OCV 表过期 | 常偏 >10 mV，每拍都改 \(\Delta R\)，脉冲边沿随后对不上（03-a §5.10） |
| 用了 \(e^{\mathrm{post}}\) | KF 已经把电压贴上，要么不触发，要么学残渣 |

计算可行 ≠ 统计可观。03-a §3.7 禁的是「无门控、无激励、逐步反传整张曲面」；demo 有门限，但**持续超限时门限等于关掉**，退化成逐步反传。

### 6.5 若要对齐 demo，门限之外还要第二道闸

只抄 10 mV / 0.1 s 不够。至少再加：

1. **用 \(e^{\mathrm{ol}}\)，不用 \(e^{\mathrm{post}}\)。**  
2. **小电流 / 静置不更新电阻**，例如 \(\lvert I\rvert < 0.2\,\mathrm{C}\) 即使 \(\lvert e\rvert>10\,\mathrm{mV}\) 也只让 KF 改 \(s,U_p\)。  
3. **相关样本降频**：超限后不要每 0.1 s 都走；每隔 1 s，或梯度累加 \(N\) 拍再一步。物理版见 `Doc/03-b` §6 滑窗 1RC：窗内 \(R_0,R_1\) 当常数、\(N\) 拍残差一起监督、满窗才 `step`。  
4. **学习率按触发频率缩**。连续触发时 \(\eta\) 再降一档，避免 100 次同向累加把 18 个数打飞。  
5. **激励门**：\(\lvert\Delta I\rvert\) 够或回弹段才允许拆 \(R_0/R_1\)；平台区超 10 mV 最多动一个标量 \(k\) 或 \(\delta R_0\)。  
6. 本仓库合成数据把门限降到 2～3 mV，否则 0.5 mV 噪声下 10 mV 几乎不触发，对照失真。

车上逐步只让 18 个数的头动；前层 32 个数仍冻。解冻前层再 0.1 s 反传，8 个特征会跟着当前工况走，旧温区先塌。

单点停留过久再画 \(R\) 曲面会偏离增量前的形状。根子是共享的 \(\theta\) 被当前点洗掉，不是因为 MLP 没有隐状态。循环隐状态保不住其它工况的 \(R\)。展开见 `Doc/03-b` §5。

### 6.6 300 s 报 1% SOC：窗口太短，不是过关

现场演示大约放 **300 s**，口径 SOC 误差 1% 以内。把积分误差摊开：

| 错配 | 300 s、1C 上 \(s^{\mathrm{ah}}\) 会偏多少 | 进不进 1% |
|------|------------------------------------------|-----------|
| 容量 \(\hat Q=0.95Q\) | \(8.3\,\mathrm{pp}\times(1/0.95-1)\approx 0.44\,\mathrm{pp}\) | 进 |
| 5 A 零偏、100 Ah | \(5\times 300/(100\times 3600)\approx 0.42\,\mathrm{pp}\) | 进 |
| 容量 10% | \(\approx 0.93\,\mathrm{pp}\) | 刚进 |

要让 5% 容量错配顶破 1%，净安时得超过约 19 Ah：1C 大约 11 min，0.3C 大约 38 min。**300 s 结构上验不出**「容量 / 零偏会不会把 SOC 拉飞」。

同一套错配，本仓库小时级（`cc_rest`，0.3C × 2 h，净 60 Ah）：

| | 安时终点 | EKF 终点 | 开环 / mV |
|--|----------|----------|-----------|
| \(\hat Q=95\,\mathrm{Ah}\) | **−3.16 pp** | +0.04 pp | 21.9 |
| \(\hat Q=105\,\mathrm{Ah}\) | **+2.86 pp** | +0.08 pp | 9.5 |
| 5 A 零偏 | **−10.0 pp** | +1.40 pp | 143 |

时间一拉长，安时跑飞。demo **已经有 EKF**；电阻仍跟着飞，是因为 10 mV 一超就把同一条电压误差喂给 \(\Delta R\)，和滤波抢创新。本仓库要拆开的就是这件事：

1. **EKF 每拍吃创新，不设 10 mV 的 SOC 死区**；不要用电阻头去跟斜坡。  
2. **增量只吃开环、有激励才动 \(R\)**；门控过了仍要先问是不是 \(Q\) / \(b_I\)。  
3. **验收窗口必须长到积分误差能长出来**；默认网格约 10 min，负例走小时级，不要用 300 s 结题。

现场还看到：SOC 误差**先完全线性增长**，过大约 **2%** 才慢慢收到 **真值 +3% 多一点** 停住。线性段就是开环安时：\(\lvert e\rvert<10\,\mathrm{mV}\) 时滤波增益几乎为 0，EKF 等于没工作。中段 \(\partial U_{\mathrm{ocv}}/\partial s\approx 3\sim 5\,\mathrm{mV}/\%\)，\(\delta s\approx 2\%\) 时创新才刚到 10 mV，电压回拉这才开始。停在 3% 多，是死区没收到 0。开环安时做不到「稳住」。

OCV 在 demo 里不是查表，是冻死的 **1×4×8×4×1**，相对 PyBaMM 最差大约 30 mV。中段若全信能折成数 pp～10 pp；现场停在 +3%，更贴合 10 mV 死区。30 mV 主要风险是拟合差的区段一直超门限，\(\Delta R\) 去吃 OCV 残差。

停在 +3% 而不是 0，最干净的对应仍是 **10 mV 死区折到中段 OCV 斜率上**。本仓库 25 °C 表，SOC 30–50%：

\[
\frac{\partial U_{\mathrm{ocv}}}{\partial s}\approx 0.28\sim 0.32\,\mathrm{V}
\;=\;
2.8\sim 3.2\,\mathrm{mV}/(1\%\ \mathrm{SOC})
\]

\[
\delta s \approx \frac{10\,\mathrm{mV}}{\partial U_{\mathrm{ocv}}/\partial s}\approx 3\sim 3.6\,\mathrm{pp}
\]

电压还差一个死区，被当成 SOC 偏了约 3%。两端斜率大，同样 10 mV 只对应 1 pp 量级，所以这个常偏主要出现在中段平台。符号为 +（估计高于真值）：回拉是从安时偏高的一侧贴到死区边缘——\(\hat Q>Q\)、或放电时 IR 补多了，都会从上面靠近。这不是「容量刚好错了 3%」：那种误差随安时继续长，不会停。

本仓库 EKF 没有把 10 mV 当 SOC 死区，创新每拍都进 \(s\)。同样 \(\hat Q=105\,\mathrm{Ah}\) 的小时级，安时终点 +2.86 pp，EKF 终点只有 +0.08 pp。差别就是：demo 在死区边缘停车，我们把电压残差收到亚毫伏。

数字和公式见 `Doc/03-c` §5.3、`Doc/04-a` 任务 F。

## 7. 和本仓库三条路怎么比

| | 本仓库宽网 + Replay | \(k_0,k_1\) 缩放 | demo 3×8×2 残差头（冻前层） |
|--|-------------------|-----------------|------------------------------|
| 冷启动 | 旧绝对曲面 | 旧绝对曲面 ×1 | 规格书常值 |

| 老化（形状还在） | 容易改写整张表 | **最贴** | 中（18 个数会倾斜读出） |
| 老化（某 SOC 鼓包） | 宽网能改，易忘 | 不够 | **不够**（8 维摊平） |
| 新温区填洞 | 要解冻前层 + 回放 | 不能 | **不能**（8 个特征里没有） |

| 实现 | `increment.py --mode replay` | `--mode scale` | 未做 |

没有哪一行全面压过另外两行。demo 的独特价值是**换对象 + 可交付冷启动 + MCU 上存不下轨迹时的事件触发 SGD**；不是老化的最优解，更不是填洞的解。10 mV 死区可学，**持续超限仍每 0.1 s 反传不可照搬**。

## 8. 若要落地，建议改成这样

不建议原样抄「常值 \(R^\star\) + 全网每芯一份」。按贴合程度：

**一期（小，和现有代码顺）**

1. 保持方案 B，\(C_1\) 钉死。  
2. 舰队 / 网格仍训现在的 `ParamMLP`，得到 \(\varphi\) 和一张绝对曲面 \(f_{\mathrm{fleet}}\)。  
3. 每只电芯一个头，二选一（先做 3a）：  
   - **3a** 已有缩放：\(R=k\,f_{\mathrm{fleet}}\)  
   - **3b** demo 残差：结构对齐 3×8×2（不要先加宽），末层清零，\(R=R^\star+\Delta R_{\max}\tanh(z)\)，冻 \(\varphi\)  
4. 增量默认仍走离线：`--no-pretrain`，冻 scaler，损失用 \(e^{\mathrm{ol}}\)，门控同 06。  
5. 若对照英飞凌在线头：只训 18 个数，\(\lvert e^{\mathrm{ol}}\rvert>10\,\mathrm{mV}\) **且** \(\lvert I\rvert\) 够大才一步；连续触发要降频、缩 \(\eta\)。合成数据把门限降到 2～3 mV。  
6. 解冻前层只作为对照实验，必须加 Replay，禁止 0.1 s 解冻反传。

**更好的残差（二期）**

\[
R = f_{\mathrm{fleet}}(I,s,T)+\Delta R_{\mathrm{cell}}(I,s,T)
\tag{6}
\]

冷启动用的是**已经随 SOC / T / I 变的舰队表**，不是一个点。\(\Delta R_{\mathrm{cell}}\) 只消化「这只电芯比舰队偏 50 µΩ、某 SOC 鼓一点」。这比 demo 的常值基准更接近物理，也更接近 03-c 的「MLP 先验 + 局部残差」。

**不要做**

- 后层不止一层被清零  
- 用 \(64\times 64\) 去「复现英飞凌」再和 3×8×2 比精度  
- 每芯解冻 3×8 前层当默认（50 个数里不该每芯重估那 32 个）  
- 无边沿、无回弹的日常工况里拆 \(\Delta R_0/\Delta R_1\)  
- 用 \(e^{\mathrm{post}}\) 当 10 mV 门限  
- 静置或小电流下因 10 mV 常偏每 0.1 s 反传  
- 解冻 3×8 前层再按 0.1 s 反传  
- 指望这套结构兼管寿命（缺 SOH 维时，该立项扩维，见 03-a §3.6）

## 9. 验收时看什么

在合成数据上可以用「缩放教师电阻」冒充另一只电芯（例如整张 \(R_0,R_1\) 乘 1.15，或只抬低温），不必真准备第二套化学。

| 检查 | 通过 |
|------|------|
| 头未更新 | \(R\equiv R^\star\)（或 \(f_{\mathrm{fleet}}\)），电压 RMSE 就是规格书 / 舰队误差 |
| 换电芯、激励够 | 该芯开环 RMSE 下降；其它芯的头不动，电压不变 |
| 旧温区 / 旧 SOC | 冻前层时不应明显差于增量前；解冻 3×8 前层而无 Replay 则允许变差，并记成失败对照 |
| 3×8×2 vs \(k_0,k_1\) | 纯整体涨阻时 18 个数不该明显好于 2 个数；只有形状真偏（某 SOC / 某 T）时头才该赢 |
| 参考点 \(R_0,R_1\) | 换电芯任务下相对 \(R^\star\) 的偏差应单调、幅度可解释（15% 缩放不该学成 80%） |
| 无脉冲新年份 | 只报 \(R_0+R_1\)，不单独信拆开的 \(\Delta R_0,\Delta R_1\) |
| 负电阻 | 全程 \(R_0,R_1>R_{\min}\) |
| KF 同开 | \(e^{\mathrm{ol}}\) 随增量下降；休息点 SOC 不恶化（03-c §7） |
| \(\lvert e\rvert<10\,\mathrm{mV}\) | 权重完全不动 |
| 边沿超 10 mV 数拍 | 允许更新，\(R_0\) 朝可解释方向动 |
| 静置常偏 >10 mV | **不应**靠每 0.1 s 反传把误差吃进 \(\Delta R\)；SOC / OCV 应单独处理 |
| 恒流稳态持续超限 | 降频后 \(R_0+R_1\) 可变；拆开的 \(\Delta R_0/\Delta R_1\) 仍不可单独信 |

电压贴上了但休息 SOC 歪了，先查 03-c §5.1（SOC 和 \(R\) 抢创新），不要先加头的学习率。

## 10. 结论

demo 的核心不是「又一种 MLP」，而是四句话，外加一扇必须拆掉的窗：

1. **电阻 = 可解释的基准 + 网络残差**，冷启动等于规格书。  
2. **网就是 3×8×2（50 个数）**；后层清零之后每芯增量只有 **18 个数**。这是 MCU 预算，不是逼近整张乘性曲面的容量。  
3. **后层清零**保证残差从 0 长，并挡住对 8 维特征的梯度——前层必须靠预训练一次摆对。  
4. **\(\lvert e\rvert>10\,\mathrm{mV}\) 才反传**是合理死区；**一直大于 10 mV 就每 0.1 s 反传**是没 Replay 时的工程折中，不是好的统计。相关样本会把 18 个数洗到当前窗口。  
5. **demo 也有 EKF。** 300 s 报 1% 不能结题；跑飞后停在 +3% 是 10 mV 死区。差别不是「多上一个卡尔曼」，而是每拍吃创新、不和 \(\Delta R\) 抢同一条误差（§6.6）。

这和 03-a 对「换对象」的建议一致，也和 03-c「不要把整张权重塞进 KF」一致。函数形式是每芯一份 \(\Delta R(I,s,T)\)，运行时（18 个数、\(0.1\,\mathrm{s}\) SGD、无 Replay）更像冻结特征上的局部辨识，不是改曲面的增量，见 §3.1。8 个隐单元**不能**替代缩放去管单纯涨阻，也**不能**替代 Replay / 扩维去管填洞和寿命。10 mV 门限**不能**替代激励门：静置和小电流上的 10 mV 多半不是电阻。

对本仓库：默认增量仍离线。若对照 demo，做成 3×8×2 头 + \(e^{\mathrm{ol}}\) + 10 mV **且**大电流才一步，连续触发降频。不要解冻前层按 0.1 s 反传。更稳的加法仍是 **舰队曲面 + 有界 \(\Delta R_{\mathrm{cell}}\)**。
