## 一句话

第 1 期已经做完。第 0 期证明：整体涨阻走两个乘子，填洞要回放，同分布不要更新。这期换成「假装自己是那颗缺资源的 MCU」：读不到旧网格、不能 Adam、不能攒波形、反传离开 0.1 s。

结论三条：

1. **没有旧集、SGD、10 s 窗，两个乘子仍然能收掉 \(I\Delta R\) 墙。**
2. **车上默认不要先抬两个全局 \(k\)。** 单窗分不出整张涨还是只这一温区涨。把乘子铺成 \((s,T)\) 网格，只写当前窗点到的节点；全局还是局部事后从格子上读。
3. **18 个数的残差头丢掉。** 纯涨阻赢不了两个 \(k\)，只抬冷端会把中温一起写坏。

实验对象仍是仓库里的 100 Ah NMC **模板**，数字用来比较方法，不能直接当出厂标定。逐窗设置和复现命令在 [`Doc/05-d`](05-d-车上增量精度评估.md)。

## 第 1 期用的架构

和第 0 期同一套电路和滤波，**没有**换成残差头或循环网络。变的是：舰队表冻住只推理，车上只改每芯几个乘子；改乘子的方式从「整段 Adam」换成滑窗 SGD。

```
(I, s, T)
    │
    ├──── 冻住的舰队表 f_fleet（64×64，出厂一份，车上不训）──► (R0, R1)
    │                                                              │
   s, T ──► 该芯 k ：1×1 两个数，或 5×4 网格插值 ──► (k0, k1) ──────►
                                                                   │
                                                    R0' = k0 R0 ， R1' = k1 R1
                                                                   │
                                                    ECM（C1 钉死）──► 开环 Ût
                                                                   │
测量 Ut ──► e_ol = Ût − Ut （不经过 EKF）──► 满窗才可能改 k
```

10 Hz 环里仍然是第 0 期那三块，增量**不进**这个环。一拍顺序不变：

1. 安时算出预测 SOC \(s^-\)
2. 冻表用 \(s^-\) 出 \(R_0,R_1\)，再乘该芯的 \(k\)
3. ECM 算出先验电压
4. 电压误差进 EKF，得到后验 \(s^+,U_p^+\)
5. 本拍电阻锁在预测 SOC 上，不用后验再算一遍；也不在这一拍改 \(k\)

\(k\) 只在停车或降频任务里、满窗且过门控之后才动。

| 块 | 第 1 期怎么用 | 不管什么 | 多快动一次 |
|----|----------------|----------|------------|
| 舰队表 | 出厂烧入，冻住 | 不估 SOC，车上不反传 | 每拍推理（负载紧了改查找表） |
| \(k\) | 每芯一份；默认网格顶点 | 不改 MLP 权重 | 有激励的 10 s 窗，一步 SGD |
| ECM | 用 \(k\cdot R\) 算开环电压 | 不学参数 | 窗内钉住中心点电阻再滚 |
| EKF | 仍每拍吃新息 | 不改 \(k\)，不用后验当损失 | 0.1 s |

电阻始终是乘性的：

\[
R_0'=k_0\,f_{\mathrm{fleet}},\qquad R_1'=k_1\,f_{\mathrm{fleet}},\qquad C_1\equiv C_1^\star
\]

1a 把 \(k_0,k_1\) 当成两个全局数（1×1 网格）。1b 把它们铺在 SOC×温度的 20 个出厂节点上，当前 \((s,T)\) 双线性插值，梯度只回点到的 2～4 个顶点。1c 曾试过舰队表再加 18 个数的加性残差，对照后丢掉。

损失仍是开环电压。SOC 用安时（或最多预测 SOC），不用后验。scaler 冻住。

## 滑窗怎么做

一条轨迹大约 10 分钟、6200 拍（0.1 s）。车上存不下整段波形，也不做整段反传。切成相邻的 10 s 窗（\(N=100\)），窗与窗只递推一个极化电压 \(U_p\)。RAM 跟 \(k\) 的个数走，不跟窗长 × 串数走。

对每一个窗，按这个顺序：

1. **拼上窗缝。** 电流序列前面接上一窗最后一拍。1C 起跳经常落在 10 s 对齐上，只看窗内差分会漏掉边沿。
2. **门控。** 有 \(\lvert\Delta I\rvert\ge 20\,\mathrm{A}\) 的边沿（相邻两拍，不是整窗累计），或窗内静置 ≥3 s，才允许更新。长恒流既没有边沿也没有回弹，整窗跳过——本期探针 85 个 1C 窗、0 次更新。真车是否容易过、残差大能不能降阈值、加热膜当激励、\(I\)–\(U\) 差几毫秒：暂存在 [`Doc/05-f`](05-f-车上激励与采样同步暂存.md)，不改本期默认。
3. **钉住中心电阻。** 只在窗中心那一拍查 \(f_{\mathrm{fleet}}(I,s,T)\) 和 \(k\)，得到一组 \(R_0,R_1\)，复制到窗内每一拍。短窗里 \((s,T)\) 几乎不动，不必每拍改 \(R\)。
4. **开环滚 100 拍。** 用钉住的 \(R\) 和窗首 \(U_p\) 走 ECM，得到 \(\hat U_t\)。误差是 \(\hat U_t-U_t^{\mathrm{meas}}\)，不经过卡尔曼。
5. **太小不更新。** 窗 RMSE 低于 2 mV，当噪声，\(k\) 不动。极化状态仍推到窗末，交给下一窗。
6. **一步 SGD。** 损失 \(\frac12\mathrm{mean}(e^{\mathrm{ol}})^2\)，反传到 \(\log k\)（或网格上被点到的顶点）。动量 0，没有 Adam 的 \(m,v\)。\(k\) 夹在 0.5～2。
7. **拆通道。** 窗电流有效值 ≥20 A 才动 \(k_0\)（欧姆边沿）；静置够长才动 \(k_1\)（回弹）。恒流稳态两通道梯度都清掉。
8. **默认只扫一遍。** 新年份每条轨迹从左到右走完即止。再扫是「以后又开到这个温区」，不是回放旧网格。

1b 只改第 3、6 步：中心 \((s,T)\) 插值四个角，梯度按插值权重分回去；没碰到的节点保持 1。邻点光滑只罚本窗活着的角，免得没去过的格子被拉走。

和 demo 的差别就在第 2、6 步：他们过 10 mV 就对当前拍 SGD，一直超限则 0.1 s 一次。我们把 100 拍合成一步，而且没边沿、没回弹根本不 `step`。

## 这期换了什么场地

架构上一节已经写了。和第 0 期实验室缩放对表，差在**怎么改 \(k\)**，不在电路：

| | 实验室缩放（04-a） | 车上滑窗（本期） |
|--|-------------------|------------------|
| 可变参数 | \(k_0,k_1\) | 同，或铺成 5×4 网格 |
| 冻 MLP / scaler | 是 | 是 |
| 损失 | 开环电压 | 开环电压 |
| 读旧网格训练 | 否 | **断言不读** |
| 优化器 | Adam | **SGD，无动量** |
| 时间 | 整段 × 10 epoch | **10 s 窗，新年份默认一遍** |
| 窗内电阻 | 每拍查 MLP | **中心点查一次**，钉住再滚电路 |
| 门控 | 轨迹级 | **窗级**：边沿或 ≥3 s 静置；恒流跳过 |

目标不是把 4 mV 地板再压 1 mV，而是在信封里把「电流 × 多出来的电阻」那堵墙收掉。不写 MCU 固件。负荷看 [`Doc/05-c`](05-c-TC4D7资源与负载评估.md)：窗 100 约 0.13 ms，不进 10 Hz；64×64 共享表 180 串 × 10 Hz 占核约 44%，车上推理应改查找表，不要据此去训宽网。

## 和英飞凌 demo、第 0 期比，改了什么

demo 是过 10 mV 就每拍改 18 个数。第 0 期改成离线批次、按任务选档。第 1 期再把「离线批次」收成车上滑窗，但**没有**把 demo 的 0.1 s 反传搬回来。

| | 英飞凌 demo | 第 0 期实验室 | 第 1 期车上 |
|--|-------------|---------------|-------------|
| 电阻表 | 常值点 + 3×8×2 | 64×64 舰队曲面 | 舰队冻住，只改每芯 \(k\) |
| 每芯能改的 | 冻前层后 18 个数 | 先两个乘子 | **默认 \(k\) 网格顶点**；两个全局 \(k\) 是 1×1 特例 |

## 1a. 两个全局乘子（对照，算得快）

同一套 10 s 窗、SGD、门控、新年份只走一遍。舰队仍是现役长训表（全网格地板 **4.24 mV**），不重新做 100 轮底板——这期问的是墙，不是和第 0 期 7.8 mV 对齐。

| | A ×1.15 | D 测量列 | G \(q=0.90\) |
|--|---------|---------|--------------|
| 冻结新 / mV | 20.80 | 25.97 | 18.86 |
| 滑窗新 / mV | **6.84** | **16.04** | **7.25** |
| 旧 冻→窗 | 4.24→21.66 | 13.00→25.70 | 4.24→18.56 |
| \(k_0/k_1\) | 1.19 / 1.17 | 1.18 / 1.18 | 1.15 / 1.17 |
| 目标乘子 | 1.15 / 1.15 | 1.15 / 1.15 | 1.10 / 1.15 |
| 恒流更新 | 0 | 0 | 0 |

1C 上 15% 电阻大约 22 mV。\(\sqrt{4.24^2+22^2}\approx 22\,\mathrm{mV}\)，冻结新年份 20.8 mV，墙就是 \(I\Delta R\)。一遍滑窗收到 6.8 mV，离地板大约还差 2.6 mV。没有旧集、没有 Adam、没有 10 轮重扫。

怎么读：

- **\(k\) 朝乘子走，两通道大致齐。** 不是第 0 期只微调那种拆开。G 的 \(k_1>k_0\) 是寿命因子里 \(a_1>a_0\)，不是拆错。
- **旧集变差是缺维。** 同一 \((I,s,T)\) 不能同时记住新电芯和 ×1.15。
- **恒流 85 窗、0 次更新。** 拆通道仍然只靠边沿和回弹。
- **边沿必须看窗缝。** 第一版只在窗内做差分，1C 起跳落在 10 s 对齐上，\(k_0\) 几乎不动。拼上窗前一拍之后，大电流更新变成 82。MCU 同样不能只看窗内。
- **D 不改排位。** 7 mV 噪声只垫底板、打穿 2 mV 窗门；边沿门还在。

实验室已经知道「整张 ×1.15」时，1a 一遍比网格快。车上没有这张标签，见下面选档。

## 1b. \((s,T)\) 网格（车上默认写点）

两个全局 \(k\) 换成出厂写死的节点：SOC 10/30/50/70/90% × 温度 −10/10/30/50 °C，共 20 点。当前格子双线性插值；梯度只回这窗点到的 2～4 个顶点。没去过的格保持 1。

**整张 ×1.15**（和 1a 同一份新年份）：

| | 新 / mV | 旧 / mV | \(k_0\) 冷 / 中 / 热 |
|--|---------|---------|----------------------|
| 1a 一遍 | **6.84** | 21.66 | 到处 1.19 |
| 网格一遍 | 13.42 | 11.75 | 1.16 / 1.08 / 1.04 |
| 网格四遍 | **8.62** | 14.59 | **1.13 / 1.14 / 1.12** |

25 条轨迹拆到 20 个节点，一遍喂不饱。四遍后 \(k_0\) 各列都在 1.09～1.17，算齐刷到约 1.15。\(k_1\) 热端几乎不动：高温极化幅度小，15% 回弹过不了 2 mV 门。车上「四遍」的意思是以后还会开到该温区，不是回放旧网格。

**只抬 −10 °C**（车上版填洞，不读旧集）：

| | 新全体 | 冷端 | 中温 ≥20 °C | 参考点 \(k(0.5,25^\circ\mathrm{C})\) |
|--|--------|------|-------------|--------------------------------------|
| 冻结 | 14.98 | 32.87 | **2.54** | 1 / 1 |
| 网格一遍 | 9.88 | 21.11 | **2.39** | **0.996 / 1.000** |

\(k_0\) 列均：冷 **1.13**，中温 **0.995**，热 **1.008**。中温几乎没动。邻列 T+10 会略被双线性扳一点（数据里有 +5 °C）；T+30 / T+50 仍是 1。1a 做不到——两个数一抬，25 °C 一起走。

冷端电压 32.9→21.1 mV，一遍同样喂不饱单列。隔离已经成立；贴回地板靠以后再开到冷端，不要解冻宽网。

## 1c. 3×8×2 残差头（对照，丢掉）

冻住舰队和 3×8 前层，只训 18 个数，电阻 = 舰队表 + 有界残差。同一套窗和门控。用来回答：18 个数有没有比网格多出来的东西。

| | 纯涨阻一遍 | 纯涨阻四遍 | 只抬 −10 °C，中温 |
|--|------------|------------|-------------------|
| 1a | **6.84 mV** | — | 会把 25 °C 一起抬 |
| 1b | 13.4 mV | **8.62 mV** | **2.54→2.39 mV**，\(k\approx 1\) |
| 1c | 10.58 mV | 8.60 mV | **2.54→5.63 mV**，参考点 \(k\sim 1.08\) |

纯涨阻不得赢全局 \(k\)：10.6 对 6.8。四遍只跟网格打平，第二遍 8.22 最好，之后回升——18 个数在不同温区抢同一组权重。形状也赢不了网格：冷端窗把中温读出一起抬了，中温比冻结更差。加性残差凑不出乘性 1.15（热端相对幅度大、冷端小）。

**车上丢掉。** 不要加宽再比，不要当默认增量。

## 车上怎么选 1a / 1b

实验室可以对着生成好的新年份说「这是整张 ×1.15」或「这是只抬 −10 °C」。车上单看当前这一窗，两个假设的开环误差长得一样。先走 1a 再「发现形状不对」会来不及：中温已经被两个全局 \(k\) 抬过。

拆成两问。先许不许可写电阻，再写到哪几个格子。后一件**不猜**。

| 先：许不许可写 | 车上 |
|----------------|------|
| 开环几乎没高、无边沿 / 无回弹 | 不写 |
| 全包同向、安时在漂 | 先查分流器 / 容量，不写 \(k\) |
| 只有这一趟边沿大 | 滤波里的慢偏置 \(\delta R_0\)；连续多天同号再写 \(k\) |
| 连续多天同号、有激励 | 写**当前窗点到的**网格顶点 |

| 后：节点上读到 | 含义 | 不要 |
|----------------|------|------|
| 各温区 \(k\) 都到约 1.15 | 整张乘性涨阻，网格自己齐刷 | 更新前先切 1a |
| 只有冷端动、中温仍 ≈1 | 局部，隔离成立 | 两个全局 \(k\) |
| 只去过一列温区 | **还不知道**是不是全局 | 把这一列抄到别处；解冻宽网 |

1a（1×1）只留两处：这篇报告里任务 A 那种已经贴好标签的对照；或者车上若干温区节点已经齐了，再把后续窗收到两个数当加速档。不要冷启动先 1a。

完整表在 [`Doc/04-b`](04-b-增量学习应用手册.md) §2.3。

## 可以带走的规则

| 你看到的现象 | 该做什么 | 不该做什么 |
|--------------|----------|------------|
| 几乎没高、无边沿 | 不更新 | 电压偏就改 \(k\) |
| 有激励、连续多天同号 | 写当前窗的网格顶点 | 先猜「整张还是局部」 |
| 各温区节点后来都到约 1.15 | 读成全局涨阻；可选收到 1×1 | 回放旧网格 |
| 只有冷端节点动 | 中温保持 1，这就是车上版填洞 | 两个全局乘子；解冻宽网 |
| 只去过一列 | 还不知道，别的格保持 1 | 外推到没去过的温区 |
| 只有这一趟边沿大 | \(\delta R_0\) | 立刻写 \(k\) |
| 全包同向、安时在漂 | 先查分流器 / 容量 | 每芯都涨阻 |
| 残差头电压也好看一点 | 丢掉 | 加宽再比；当默认 |

另外几条：

- **电压单独下降不能结题。** 1a 在任务 A 上最快，1b 在只抬冷端时才隔离，1c 中温会变差。
- 更新路径不准读旧网格。scaler 不准重算。
- 边沿门要看窗缝前一拍，否则 10 s 对齐会把 1C 起跳漏掉。
- 恒流不许拆 \(R_0/R_1\)。本期 85 窗、0 次更新。
- 休息点 SOC / NIS 本期不重跑滤波。乘子朝 1.15 走，和第 0 期缩放同一类错配，口径沿用 04-a。包级再看休息 SOC。
- 64×64×180×10 Hz 占核约 44%。增量协议是滑窗 \(k\)；车上推理默认改查找表，不要据此去车上训宽网。

## 完成度，以及第 2 期

这期故意没做、也不该算欠账的：不写 MCU 固件、车上不解冻 64×64、不做 Replay、不上残差头、不把查找表和第一次 \(k\) 对照绑在一起、外置 Flash 不是前置。窗长 50 / 200、第二遍扫描，05-d 写明不充数。
