# 07 残差头增量学习（英飞凌 demo 结构）评估

> 对象：用户转述的英飞凌 demo——网络 **3×8×2**，预训练前层、后层全 0、写死基准 \(R_0^\star,R_1^\star\)，网络只出 \(\Delta R\)，每只电芯一套权重；\(\lvert e\rvert>10\,\mathrm{mV}\) 才反传，持续超限则每 \(0.1\,\mathrm{s}\) 反传  
> 对照：`Doc/03` 电压反传、`Doc/04` 方案 B、`Doc/05` 增量分类、`Doc/06` 开环残差与 KF  
> 对齐：本仓库 `ParamMLP`（末层权重已是 0）、`ScaleAdapter`（\(k_0,k_1\)）、`Src/AI/KF`  
> 目的：还原这套结构在数学上在做什么，和本仓库哪一条路同类，哪些该学、哪些不要照搬  
> 本文只做评估，不改代码

公开资料里英飞凌 + Eatron / Ekkono 只写到「边缘侧按车 / 按电芯做增量」，**没有**找到与「后层清零 + 常值基准 + \(\Delta R\)」一一对应的应用笔记。下文评估的是**你看到的 demo 结构**，不把它当成已核实的官方规范。

---

## 1. 先把方案写严

记预训练网络为

\[
z = W_{\mathrm{head}}\,\varphi_\theta(I,s,T)+b_{\mathrm{head}}
\]

demo 的部署方式：

1. **前层** \(\varphi_\theta\) 用实验室 / 车队数据预训练，部署时拷到每只电芯。  
2. **后层** \(W_{\mathrm{head}}=0\)，\(b_{\mathrm{head}}=0\)，于是 \(z\equiv 0\)。  
3. **写死基准**（规格书或参考点，不随 \((I,s,T)\) 变）

\[
R_0^\star,\; R_1^\star
\quad\text{（本仓库模板是 }0.80\,\mathrm{m}\Omega,\; 0.65\,\mathrm{m}\Omega\text{）}
\]

4. 网络输出残差，再相加：

\[
R_0 = R_0^\star + \Delta R_0(z),\qquad
R_1 = R_1^\star + \Delta R_1(z)
\tag{1}
\]

初始化时 \(\Delta R=0\)，ECM 立刻用基准电阻算电压，不会冒出随机大电阻。

5. **每只电芯一份** \(\theta_{\mathrm{cell}}\)（至少后层；前层可共享可复制）。  
6. 用该电芯自己的工况电压做增量，让 \(\Delta R(I,s,T)\) 贴上这只电芯。  
7. **事件触发反传**（与本仓库离线批次不同）：

\[
\lvert e_k\rvert > 10\,\mathrm{mV}
\;\Rightarrow\;
\text{对当前拍做一次 } \partial L/\partial\theta
\tag{1c}
\]

\(e_k\) 按端电压预测误差理解（\(\hat U_t-U_t^{\mathrm{meas}}\)）。一直大于 10 mV，就**每 0.1 s 反传一次**，步长与仿真 / 采样一致。小于门限则权重不动。

和本仓库现有头的差别：

| | 本仓库 `ParamMLP` | demo 残差头 |
|--|-------------------|-------------|
| 末层权重 | 已是 0 | 0 |
| 末层偏置 | \(\mathrm{softplus}^{-1}(R^\star-R_{\min})\)，输出约等于 \(R^\star\) | 0，输出 \(\Delta R=0\) |
| 电阻从哪来 | \(R_{\min}+\mathrm{softplus}(z)\)，初值是常值曲面 | \(R^\star+\Delta R(z)\)，初值是规格书点 |
| 正性 | softplus 保证 | **加法不保证**，要另夹 |
| 个性 | 全库一张网 | 每芯一套（或每芯一个头） |

末层权重清零这件事，本仓库预训练头已经做了。demo 多出来的是：**把「常值」从网络偏置里拿出来，变成显式基准；网络只负责偏差；偏差按电芯存。**

## 2. 网络是 3×8×2，容量就卡在这里

结构按一层隐层读：

\[
[I,\,s,\,T]
\;\xrightarrow{\;W_1\in\mathbb{R}^{8\times 3}\;}
\mathbb{R}^{8}
\;\xrightarrow{\;\sigma\;}
\varphi
\;\xrightarrow{\;W_2\in\mathbb{R}^{2\times 8}\;}
(\Delta R_0,\,\Delta R_1)
\tag{1a}
\]

| 层 | 权重 | 偏置 | 小计 |
|----|------|------|------|
| \(3\to 8\) | 24 | 8 | 32 |
| \(8\to 2\) | 16 | 2 | 18 |
| **合计** | | | **50** |

float32 整网 200 B；只存后层 72 B。100 只电芯若只复制后层，约 7 kB 加一份共享前层。本仓库默认 `hidden=(64,64)` 方案 B 约 4546 个数（\(3\to64\to64\to2\)），大约是它的 **90 倍**。

前向大约 50 次乘加，0.1 s 一拍在 AURIX 上可以忽略。规模首先是给 MCU 预算定的，不是按「逼近整张 \(R(I,s,T)\) 曲面」定的。

### 2.1 后层全 0 时，真正能训的只有 18 个数

\(W_2=0\) 则 \(\partial z/\partial\varphi=0\)，前层 32 个数收不到梯度。增量若冻前层，每只电芯只更新

\[
W_2\in\mathbb{R}^{2\times 8},\; b_2\in\mathbb{R}^{2}
\quad\Rightarrow\quad 18\text{ 个参数}
\tag{1b}
\]

\(\Delta R_0\)、\(\Delta R_1\) 各是 8 维特征的一个线性组合。电芯之间的差别，被假设成「同一组 8 个非线性特征，换一套读出」。

比 05 的 \(k_0,k_1\)（2 个数）宽，比解冻整网（50 个数）窄。18 相对 2 的增益，全部来自 \(\varphi\) 里已经有没有「像电阻曲面」的方向。

### 2.2 8 个隐单元要干的活

非线性全在 \(3\to 8\)。8 个 \(\sigma\)（tanh / ReLU / GELU）最多划出大约 8 条脊或折，却要同时伺候：

- SOC 的 U 形（两端各翘）
- Arrhenius 的 \(1/T\)
- 电流软饱和、充放不对称
- 高镍高 SOC 那一小段鼓包（规范里的相变项）

这不是「略简化」，是把整张乘性曲面压进 32 个前层参数。预训练必须在**宽温区、宽 SOC、有脉冲**的数据上把这 8 个特征摆对；增量再改 18 个数读出，不能发明第 9 个「低温专用」方向。

因此：

| 任务 | 3×8×2 够不够 |
|------|----------------|
| 中温附近、相对 \(R^\star\) 偏几十到一两百 µΩ | 往往够，这是 demo 的舒适区 |
| 整张 Arrhenius + U 形都由 \(\Delta R\) 从常值长出来 | 紧。前层必须已经在全温区预训练好 |
| 某 SOC 窗口鼓包、高镍后期变形 | 8 维特征大概率摊平，拟合不足 |
| 预训练没见过的温区（填洞） | 不够。冻前层时线性头补不出新特征 |
| 同一只电芯跨寿命 | 仍缺 SOH 维；50 个参数会被新数据整表改写 |

常值基准 \(R^\star\) 把「随工况变的那一大块」全部推给这 50 个数。网越窄，§5.1 的乘性物理越痛：不是写法不对，是**函数类不够大**。

### 2.3 每芯存整网其实也便宜，但仍应只存头

50 个数 × 100 芯 ≈ 20 kB，在 MCU 上复制整网不再荒谬——下面 §5.5 按 64 宽网说的「不要每芯一份」对 **3×8×2 要减弱**。即便如此，仍建议前层共享：

- 50 个数里 32 个是特征探测器。每芯各训一套，等于每芯自己重新发明 Arrhenius，样本少时 8 个神经元会滑到最近的工况，旧温区先塌。
- 只训 18 个数，前层锁在车队预训练上，遗忘面更小，也更符合「后层全 0」的梯度结构。

### 2.4 和本仓库默认网不要拿同一把尺

对照实验若把本仓库 \(64\times 64\) 的绝对 MLP 去比英飞凌的 3×8×2 残差头，赢的是容量不是算法。要对齐 demo：

- 舰队 / 实验室仍可用宽网当 \(f_{\mathrm{fleet}}\)（本仓库现状）
- 模仿英飞凌的那一路，隐层就是 8，输出 2，不要先加宽再宣布「残差头更好」

## 3. 它在 05 的分类里是哪一类

05 把「新」分成填洞、换对象、老化。demo 的主场景是**换对象**：

- 前层 = 车队 / 模板学到的 \((I,s,T)\) 特征  
- 基准 = 这一化学体系的规格点  
- 后层 = 这一只电芯相对规格点的曲面

这和 05 §3.5 缩放适配是亲戚，但更宽：

\[
\begin{aligned}
\text{缩放（已实现）}&\quad R = k\cdot f_\theta(I,s,T)\\
\text{demo 残差}&\quad R = R^\star + W_{\mathrm{cell}}\,\varphi(I,s,T)\\
\text{更完整的残差}&\quad R = f_{\mathrm{fleet}}(I,s,T)+\delta_{\mathrm{cell}}(I,s,T)
\end{aligned}
\tag{2}
\]

缩放只有 2 个自由度，只能整体抬电阻，形状不动。  
3×8×2 的线性残差头是 **18 个数**，能在 8 维特征里改读出，改不了特征本身。  
「舰队绝对电阻 + 电芯残差」才是把预训练曲面留下来、只学偏差；demo 把绝对曲面扔掉，只留 8 维 \(\varphi\)，用常值顶上。网一窄，这 8 维必须在预训练里就对准物理，增量没有补课的余量。

对老化：仍然**没有 SOH 维**。增量只能改这只电芯的 \(\Delta R(I,s,T)\)。时间长了，昨天的中温点和今天的中温点抢同一组权重。demo 的「每芯独立」能阻止电芯 A 的老化写进电芯 B，**挡不住同一只电芯自己的遗忘**。

## 4. 这套结构做对了什么

### 4.1 冷启动可交付

后层全 0 ⇒ 第一秒的 \(R\) 就是写死的基准。BMS 标定、HIL、功能安全比「随机初始化再等收敛」好讲：电压先按规格书走，再慢慢长出 \(\Delta R\)。

本仓库用 softplus 偏置也能得到常值 \(R^\star\)，但 \(R^\star\) 藏在激活里，和「规格书电阻」不是同一个旋钮。demo 把规格书留在电路外面，更干净。

### 4.2 换对象不该共用一张绝对曲面

05 写过：另一只电芯应小适配或单独一套权重。每芯一份后层，正是这个判断。一只电芯激励不足把 \(R_0/R_1\) 拆错，不会污染邻芯。

### 4.3 零初始化让残差的含义清楚

\(W=0,b=0\) 时 \(\Delta R\equiv 0\)，后面学到的就是「相对基准的偏差」。不会出现「舰队均值已经在头里、再加一份规格书」的双计。

### 4.4 后层可训、前层可冻，适合 MCU

关键梯度：

\[
z=Wh+b,\quad
\frac{\partial z}{\partial h}=W^\top
\tag{3}
\]

\(W=0\) 时 **\(\partial z/\partial h=0\)**，梯度到不了前层。  
所以「后层全 0 + 冻前层」在数学上就是：**只训一个接到冻结特征上的线性头**。  
\(\partial L/\partial W=(\partial L/\partial z)\,h^\top\) 仍然在，头可以从 0 长出来。这是有意的：先做线性探针。3×8×2 下每芯只多 18 个数、72 B，和「边缘增量」的演示目标一致。

若稍后解冻前层，必须等 \(W\) 已经非零，否则前层仍然收不到梯度。

### 4.5 和 ECM / 电压损失 / KF 兼容

电路不用改。增量损失仍应走 06 的开环 \(e^{\mathrm{ol}}\)，不要走 \(e^{\mathrm{post}}\)。KF 里的慢变 \(\delta R_0\)（06 §3.2）是「这一分钟的局部偏置」；demo 的 \(\Delta R(I,s,T)\) 是「这只电芯的曲面」。两者可以叠，不要互相替代。

## 5. 不要照搬的地方

### 5.1 常值基准扛不住乘性物理

规范里 \(R\) 是

\[
R = R_{\mathrm{ref}}\cdot f_{\mathrm{SOC}}\cdot f_T\cdot f_I\cdot f_{\mathrm{dir}}
\]

\(f_T\) 是 Arrhenius，降温是**相乘**不是相加。−10 °C 相对 25 °C，\(R_0\) 很容易到参考点的 2～3 倍。  
若 \(R^\star\) 钉在 25 °C、50%、1C，则 \(\Delta R\) 必须在低温自己长出一整块 \(+1\,\mathrm{m}\Omega\) 量级的曲面。3×8×2 里这件事几乎完全压在预训练好的 8 个特征上：线性头只能重加权，**不能新造一个 \(1/T\) 探测器**。特征若是在中温预训练的，低温就是 05 说的**出 scaler 的填洞**，冻前层补不出来。

更稳的加法是叠在**已经随工况变的表**上：

\[
R = f_{\mathrm{fleet}}(I,s,T)+\Delta R_{\mathrm{cell}}
\quad\text{或}\quad
R = k_{\mathrm{cell}}\,f_{\mathrm{fleet}}(I,s,T)
\tag{4}
\]

前者是「舰队形状 + 电芯偏置曲面」，后者是已实现的缩放。demo 的常值 \(R^\star\) 只适合：电芯偏离规格不大、温度窗不宽、或者 \(\varphi\) 确实在全温区预训练过。

### 5.2 \(\Delta R\) 无约束会出负电阻

\(R^\star+\Delta R\) 没有 softplus。电压损失在电流符号一变、或 \(R_0/R_1\) 对冲时，完全可以打到 \(R<0\)。至少要

\[
\Delta R = \Delta R_{\max}\tanh(z)
\quad\text{或}\quad
R = R_{\min}+\mathrm{softplus}\bigl(\mathrm{sp}^{-1}(R^\star-R_{\min})+z\bigr)
\tag{5}
\]

第二种仍保证为正，且 \(z=0\) 时 \(R=R^\star\)，和 demo 的冷启动一致，又比裸加安全。

### 5.3 「后层全 0」只能是最后一层线性头

若把倒数第二层也清零，\(h\) 本身是 0，最后一层永远看不到特征，增量只剩两个偏置，退化成与 \((I,s,T)\) 无关的常值平移——比缩放适配还弱（缩放至少保留形状）。

demo 里有用的清零，**仅限输出头**。

### 5.4 激励不足时 \(\Delta R_0\) 和 \(\Delta R_1\) 仍然拆不开

05 §5.4、06 §3.1 在这里原样成立。恒流走到极化稳态：

\[
e \approx -I(\Delta R_0+\Delta R_1)+\Delta U_{\mathrm{ocv}}
\]

增量会把误差随便塞进一个通道。每芯独立只是把拆错关在这只电芯里，不会让拆对。门控（边沿或 \(\ge 30\,\mathrm{s}\) 静置）照旧要。

### 5.5 3×8×2 复制整网不再贵，但共享前层仍然更稳

| 存什么 | 每芯个数 | float32 | 能改的东西 |
|--------|----------|---------|------------|
| 两个标量 \(k_0,k_1\) | 2 | 8 B | 整体涨阻 |
| 输出头 \(8\to 2\)（demo） | 18 | 72 B | 8 维特征上的读出 |
| 整份 3×8×2 | 50 | 200 B | 特征也会动，旧温区先漂 |
| 本仓库 \(64\times 64\) 整网 | ≈4546 | ≈18 kB | 容量大，每芯复制才真正贵 |

100 芯全复制 3×8×2 大约 20 kB，MCU 上做得到。仍建议默认**前层一份、每芯 18 个数**：不是因为存不下，是因为 8 个特征探测器经不起每芯用几天工况去重估。

### 5.6 10 mV / 0.1 s 反传不是「禁止」四个字能打发的

05 §3.7 写过不要把 `train.py` 嵌进 0.1 s 步进。demo 偏是这么干的，只是加了 10 mV 死区。计算上 3×8×2 扛得住，统计上会出问题。展开见第 6 节。

### 5.7 scaler 和 OCV 的坑原样在

每芯微调不得重估 `scaler.json`。OCV 表过期时电压误差会进 \(\Delta R\)，脉冲边沿会对不上（05 §5.10）。温度计偏 3 °C 会被写成这只电芯的「假内阻」。持续超 10 mV 时第 6 节的逐步反传会把这些系统误差更快写进 18 个数。

## 6. \(\lvert e\rvert>10\,\mathrm{mV}\) 就反传，持续则每 0.1 s 一次

这是 demo 和本仓库增量最大的运行时差别。本仓库是攒轨迹、离线更新；它是**车上按拍、过门限就 SGD**。

### 6.1 规则

\[
\theta_{k}
=
\begin{cases}
\theta_{k-1}-\eta\,\nabla_\theta L(e_k) & \lvert e_k\rvert>10\,\mathrm{mV}\\
\theta_{k-1} & \text{否则}
\end{cases}
\tag{7}
\]

一直超限就每个采样拍都走上面第一支，\(\Delta t=0.1\,\mathrm{s}\)。3×8×2、只训后层时，一拍就是 18 个数的外积，MCU 算得动。门限的用意也清楚：测量噪声附近不要动权重。

### 6.2 10 mV 相对噪声和 \(I\Delta R\)

| 场景 | 10 mV 意味着什么 |
|------|-------------------|
| 本仓库仿真噪声 0.5 mV | 约 \(20\sigma\)，几乎不会被噪声触发，死区偏宽 |
| 实车电压噪声 2～10 mV | 约 \(1\sim 5\sigma\)，噪声尖峰会误触发 |
| 1C（100 A） | 等价于和电阻偏了 \(0.10\,\mathrm{m}\Omega\)（约 \(R_0^\star\) 的 12%） |
| 0.1C（10 A） | 等价于 \(1.0\,\mathrm{m}\Omega\)，普通内阻偏差**触发不了** |
| 静置 \(I=0\) | \(\partial U_t/\partial R_0=0\)，10 mV 几乎一定是 OCV / SOC / \(U_p\)，不是电阻 |

所以门限是按「大约 1C 上看得见的电阻误差」标的，不是按本仓库合成噪声标的。小电流、静置时超 10 mV，物理上多半不该改 \(R\)。

06 若同开：后验 \(e^{\mathrm{post}}\) 本来就被 KF 压到 1 mV 以下（本仓库闭环实测先验约 0.8 mV、后验约 0.1 mV），**用后验当 \(e\) 会几乎永不触发**。demo 要这个规则生效，用的必须是开环或先验电压误差。本仓库增量已经规定只吃 \(e^{\mathrm{ol}}\)，这里对齐。

### 6.3 为什么他们要这么做

边缘侧通常**存不下**本仓库那种回放轨迹（一条 6200 步 × 若干列）。3×8×2 一拍反传又极便宜。事件触发 SGD 是「没有 Replay 缓冲区时，还能做增量」的工程解，不是论文里的最优解。

10 mV 死区本身值得学：和 06 §4.1「开环要明显高于测量噪声才进增量集」是同一句话，只是他们把阈值写成了固定 10 mV。

### 6.4 一直大于 10 mV 时，0.1 s 一步会出什么事

相邻两拍的 \((I,s,T)\) 几乎一样，梯度高度相关。持续超限 10 s 就是约 **100 次几乎同方向的 SGD**；10 min 就是 6000 次。18 个数会被当前工况洗到拟合当前窗口，其它 SOC / 温度上的读出一起漂。网越窄，漂得越快。

更具体的失败模式：

| 现象 | 每 0.1 s 反传会做什么 |
|------|----------------------|
| 电流阶跃边沿，\(\lvert e\rvert>10\,\mathrm{mV}\) 几个拍 | 合理。\(R_0\) 可观，更新次数少 |
| 恒流稳态一直偏 12 mV | \(e\approx -I(\Delta R_0+\Delta R_1)\)，拆不开，两个通道乱分；相关样本把和电阻估飞 |
| 静置一直偏 12 mV | \(R_0\) 梯度为 0，误差来自 OCV / \(s_0\) / \(U_p\)。要么空转，要么拧 \(R_1\) 去补极化 |
| 容量错、电流零偏 | 开环电压慢慢斜，长期超门限。电阻头去拟合本该由 \(q\) 或 KF 管的漂（06 §5.3） |
| OCV 表过期 | 常偏 >10 mV，每拍都改 \(\Delta R\)，脉冲边沿随后对不上（05 §5.10） |
| 用了 \(e^{\mathrm{post}}\) | KF 已经把电压贴上，要么不触发，要么学残渣 |

计算可行 ≠ 统计可观。05 §3.7 禁的是「无门控、无激励、逐步反传整张曲面」；demo 有门限，但**持续超限时门限等于关掉**，退化成逐步反传。

### 6.5 若要对齐 demo，门限之外还要第二道闸

只抄 10 mV / 0.1 s 不够。至少再加：

1. **用 \(e^{\mathrm{ol}}\)，不用 \(e^{\mathrm{post}}\)。**  
2. **小电流 / 静置不更新电阻**，例如 \(\lvert I\rvert < 0.2\,\mathrm{C}\) 即使 \(\lvert e\rvert>10\,\mathrm{mV}\) 也只让 KF 改 \(s,U_p\)。  
3. **相关样本降频**：超限后不要每 0.1 s 都走；每隔 1 s，或梯度累加 \(N\) 拍再一步。3×8×2 省下的算力应用在少更新、更新准。  
4. **学习率按触发频率缩**。连续触发时 \(\eta\) 再降一档，避免 100 次同向累加把 18 个数打飞。  
5. **激励门**：\(\lvert\Delta I\rvert\) 够或回弹段才允许拆 \(R_0/R_1\)；平台区超 10 mV 最多动一个标量 \(k\) 或 \(\delta R_0\)。  
6. 本仓库合成数据把门限降到 2～3 mV，否则 0.5 mV 噪声下 10 mV 几乎不触发，对照失真。

车上逐步只让 18 个数的头动；前层 32 个数仍冻。解冻前层再 0.1 s 反传，8 个特征会跟着当前工况走，旧温区先塌。

## 8. 若要落地，建议改成这样

不建议原样抄「常值 \(R^\star\) + 全网每芯一份」。按贴合程度：

**一期（小，和现有代码顺）**

1. 保持方案 B，\(C_1\) 钉死。  
2. 舰队 / 网格仍训现在的 `ParamMLP`，得到 \(\varphi\) 和一张绝对曲面 \(f_{\mathrm{fleet}}\)。  
3. 每只电芯一个头，二选一（先做 3a）：  
   - **3a** 已有缩放：\(R=k\,f_{\mathrm{fleet}}\)  
   - **3b** demo 残差：结构对齐 3×8×2（不要先加宽），末层清零，\(R=R^\star+\Delta R_{\max}\tanh(z)\)，冻 \(\varphi\)  
4. 增量默认仍走离线：`--no-pretrain`，冻 scaler，损失用 \(e^{\mathrm{ol}}\)，门控同 06。  
5. 若对照英飞凌在线头：只训 18 个数，\(\lvert e^{\mathrm{ol}}\rvert>10\,\mathrm{mV}\) **且** \(\lvert I\rvert\) 够大才一步；连续触发要降频、缩 \(\eta\)。合成数据把门限降到 2～3 mV。  
6. 解冻前层只作为对照实验，必须加 Replay，禁止 0.1 s 解冻反传。

**更好的残差（二期）**

\[
R = f_{\mathrm{fleet}}(I,s,T)+\Delta R_{\mathrm{cell}}(I,s,T)
\tag{6}
\]

冷启动用的是**已经随 SOC / T / I 变的舰队表**，不是一个点。\(\Delta R_{\mathrm{cell}}\) 只消化「这只电芯比舰队偏 50 µΩ、某 SOC 鼓一点」。这比 demo 的常值基准更接近物理，也更接近 06 的「MLP 先验 + 局部残差」。

**不要做**

- 后层不止一层被清零  
- 用 \(64\times 64\) 去「复现英飞凌」再和 3×8×2 比精度  
- 每芯解冻 3×8 前层当默认（50 个数里不该每芯重估那 32 个）  
- 无边沿、无回弹的日常工况里拆 \(\Delta R_0/\Delta R_1\)  
- 用 \(e^{\mathrm{post}}\) 当 10 mV 门限  
- 静置或小电流下因 10 mV 常偏每 0.1 s 反传  
- 解冻 3×8 前层再按 0.1 s 反传  
- 指望这套结构兼管寿命（缺 SOH 维时，该立项扩维，见 05 §3.6）

## 9. 验收时看什么

在合成数据上可以用「缩放教师电阻」冒充另一只电芯（例如整张 \(R_0,R_1\) 乘 1.15，或只抬低温），不必真准备第二套化学。

| 检查 | 通过 |
|------|------|
| 头未更新 | \(R\equiv R^\star\)（或 \(f_{\mathrm{fleet}}\)），电压 RMSE 就是规格书 / 舰队误差 |
| 换电芯、激励够 | 该芯开环 RMSE 下降；其它芯的头不动，电压不变 |
| 旧温区 / 旧 SOC | 冻前层时不应明显差于增量前；解冻 3×8 前层而无 Replay 则允许变差，并记成失败对照 |
| 3×8×2 vs \(k_0,k_1\) | 纯整体涨阻时 18 个数不该明显好于 2 个数；只有形状真偏（某 SOC / 某 T）时头才该赢 |
| 参考点 \(R_0,R_1\) | 换电芯任务下相对 \(R^\star\) 的偏差应单调、幅度可解释（15% 缩放不该学成 80%） |
| 无脉冲新年份 | 只报 \(R_0+R_1\)，不单独信拆开的 \(\Delta R_0,\Delta R_1\) |
| 负电阻 | 全程 \(R_0,R_1>R_{\min}\) |
| KF 同开 | \(e^{\mathrm{ol}}\) 随增量下降；休息点 SOC 不恶化（06 §7） |
| \(\lvert e\rvert<10\,\mathrm{mV}\) | 权重完全不动 |
| 边沿超 10 mV 数拍 | 允许更新，\(R_0\) 朝可解释方向动 |
| 静置常偏 >10 mV | **不应**靠每 0.1 s 反传把误差吃进 \(\Delta R\)；SOC / OCV 应单独处理 |
| 恒流稳态持续超限 | 降频后 \(R_0+R_1\) 可变；拆开的 \(\Delta R_0/\Delta R_1\) 仍不可单独信 |

电压贴上了但休息 SOC 歪了，先查 06 §5.1（SOC 和 \(R\) 抢创新），不要先加头的学习率。

## 10. 结论

demo 的核心不是「又一种 MLP」，而是四句话：

1. **电阻 = 可解释的基准 + 网络残差**，冷启动等于规格书。  
2. **网就是 3×8×2（50 个数）**；后层清零之后每芯增量只有 **18 个数**。这是 MCU 预算，不是逼近整张乘性曲面的容量。  
3. **后层清零**保证残差从 0 长，并挡住对 8 维特征的梯度——前层必须靠预训练一次摆对。  
4. **\(\lvert e\rvert>10\,\mathrm{mV}\) 才反传**是合理死区；**一直大于 10 mV 就每 0.1 s 反传**是没 Replay 时的工程折中，不是好的统计。相关样本会把 18 个数洗到当前窗口。

这和 05 对「换对象」的建议一致，也和 06「不要把整张权重塞进 KF」一致。8 个隐单元**不能**替代缩放去管单纯涨阻，也**不能**替代 Replay / 扩维去管填洞和寿命。10 mV 门限**不能**替代激励门：静置和小电流上的 10 mV 多半不是电阻。

对本仓库：默认增量仍离线。若对照 demo，做成 3×8×2 头 + \(e^{\mathrm{ol}}\) + 10 mV **且**大电流才一步，连续触发降频。不要解冻前层按 0.1 s 反传。更稳的加法仍是 **舰队曲面 + 有界 \(\Delta R_{\mathrm{cell}}\)**。
