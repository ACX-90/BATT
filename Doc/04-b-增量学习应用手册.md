## 1. 这本手册管什么

增量是：**分布变了**，还要从旧权重出发，并且旧区域不能无故塌。`Script/train_1000_resume.bat` 同一网格再训不是增量（`Doc/03-a` §1）。

本仓库默认估计器不变：点式 `ParamMLP`、方案 B（\(C_1\equiv C_1^\star\)）、损失只用开环 \(e^{\mathrm{ol}}\)、SOC 用 \(s^{\mathrm{ah}}\)（最多 \(s^-\)）。时序记忆在 \(U_p\)，不在网络（`Doc/03-b`）。

三层时间尺度不要抢活：

| 层 | 改什么 | 时间 | 对应 |
|----|--------|------|------|
| 滤波 | \(s,U_p\)，可选 \(\delta R_0\) | 一拍 / 一趟 | 04-a E、F、H 的 SOC |
| 离线增量 | \(k_0,k_1\) 或一小块曲面 | 一次实验、一周、一批日志 | 04-a A–D、G |
| 车上增量 | 默认写 \(k\) 网格顶点；1a 是齐了之后的 1×1 | 有激励的 10 s 窗，SGD 一步 | 05-d 1b；选档 §2.3 |
| 换模型 | SOH 输入、BMS 升 2RC | 立项 | 04-a H 已见慢尾巴，**先不升阶** |

KF 不能补上缺失的 SOH 维。它只能把「表错了」暂时按到 \(s\) 或 \(\delta R_0\) 上（`Doc/03-c` §4.3）。

## 2. 先判断任务，再选档

`Doc/03-a` §2 三种「新」加上 04-a 的同分布 / 激励不足，验收不能混用。

| 任务 | 同一 \((I,s,T)\) 的 \(R\) | 正途 | 旧集 RMSE | 04-a |
|------|---------------------------|------|-----------|------|
| 整体涨阻 / 换对象 / \(q<1\) | 已经变了 | **缩放** | 变差是缺维的定义 | A、D、G |
| 填洞（新温区） | 不该变 | **Replay / 重训** | 恶化应 &lt; 20% | B |
| 同分布再贴 | 没变 | **冻结** | 不应明显动 | C |
| 一趟表偏 | 曲面没变 | **\(\delta R_0\)**，连续多天同号再缩放 | 不动 MLP | E |
| 激励不足 / 零偏 / \(Q\) 错 | 不可观 | **不拆 \(R\)** | 强行微调算失败 | F |
| 真值比 BMS 多一条 \(\tau\) | 1RC 表本身对 | **不增量**；允许回弹慢尾巴 | 不动 MLP | H |

没有「某档永远最好」。只报新年份电压，三张表会给出三个冠军（A 微调、B Replay、C 冻结）。

### 2.1 从现象往回走

先看滤波日志，不要先开 `finetune`。

```
开环 e_ol 相对舰队底板
    │
    ├─ 几乎没高（C：6 vs 4 mV；F 健康长恒流 1.2 mV）
    │     → 没有增量对象。冻结。
    │
    ├─ 边沿大、各温区同号，量级 ≈ IΔR
    │     （A：26 mV；G：21.7 mV，q=0.90）
    │     → 缺维涨阻。缩放。均匀 ×k 时 k0≈k1；
    │       a1≠a0 时 k0、k1 可以对着两个乘子分开，不是拆错。
    │
    ├─ 边沿还行，回弹后段同号慢尾巴（数秒后仍几 mV）
    │     （H：1C 后静置 60–120 s 开环约 −9 mV，先验仍 0.66 mV）
    │     → 缺一条 τ，不是表幅度错了。不增量。
    │       不要加大 qs 去吃；升 2RC 是换 BMS。
    │
    ├─ 只在未覆盖的 T / s 大，邻区还好
    │     （B：−10 °C 10.4 vs 旧 7.5 mV）
    │     → 填洞。Replay。缩放 k 会拆开，不用。
    │
    ├─ 开环大、先验 / NIS 仍健康、安时在漂
    │     （F：5 A 零偏开环 143 mV，先验 0.66 mV，安时 −10 pp）
    │     → 先查分流器 / 容量。不要拆 R0/R1。
    │
    └─ 开环边沿大，关掉 δR0 时休息 SOC 被拉
          （E：关 δR0 终点 +0.47 pp，开则回到 −0.05 pp）
          → 这一趟用 δR0。连续多天同号再离线缩放。
```

温度先看直方图是否落在旧 scaler 的 \(\mu\pm 4\sigma\)。超出先当填洞，不当老化（`Doc/03-a` §5.9）。注意：本仓库 z-score 的 \(4\sigma\) 温区大约 −56～+98 °C，车上几乎永不触发；**真正的温区洞要靠覆盖表，不能靠这道门**（`Doc/03-d` §1.1）。

全包 \(\Delta R\) 同向先排除共用电流零偏（`Doc/A0` §2.4）。任务 F 已经说明：NIS 可以仍是 \(O(1)\)，门控照样过。

### 2.2 五档算法各自干什么

| 档 | 动什么 | 什么时候用 | 04-a 里它赢在哪 |
|----|--------|------------|-----------------|
| 冻结 | 无 | 同分布；开环没有内容 | C 正途 |
| 缩放 | 只 \(k_0,k_1\) | 形状还在的整张涨阻 / \(q<1\) | A / D / G 正途；B 失败（\(k\) 反号） |
| Replay | 网 + 旧轨迹混批 | 填洞，旧 CSV 还在 | B 正途；A 里同一格拉锯 |
| 合集重训 | 网 + 旧集全量 | 实验室上界，不是车上增量 | B 与 Replay 一档；A 被旧数据按回去 |
| 只微调 | 只扫新年份 | 旧芯退役、旧温区不再关心 | A 电压最好、参数最脏；C 假成功 |

\(k_0,k_1\) **不是** `scaler.json`。scaler 管输入坐标，\(k\) 管输出电阻幅度，见 04-a §0 与 `Doc/03-a` §5.1。

### 2.3 车上怎么选（第 1 期已齐）

实验室可以 Replay 旧网格、Adam、整段 BPTT。车上没有这些（`Doc/05-a`）。第 1 期对照已经跑完（`Doc/05-d`）。

**单看当前这一窗，分不出「整张涨」还是「只这一温区涨」。** 25 °C 上偏 15%，两个假设的开环误差长得一样。先走全局 \(k\)（1a）再「发现形状不对」会来不及：两个数一抬，中温已经跟着走。05-a 写的「各温区同号 → 1a」是实验室读完新年份之后的标签，不是车上分类器。

车上拆成两问：先许不许可写 \(R\)，再写到哪几个格子。后一件**不猜**，默认写 1b。1a 是 1×1 的网格。

| 先：许不许可写 | 车上 |
|----------------|------|
| 开环几乎没高、无边沿 / 无回弹 | 不写 |
| 全包同向、安时在漂 | 先查分流器 / 容量，不写 \(k\) |
| 只有这一趟边沿大 | \(\delta R_0\)；连续多天同号再写 \(k\) |
| 连续多天同号、有激励 | 写**当前窗点到的** \(k\) 网格顶点（默认 1b） |
| 没去过的节点 | 保持 \(k=1\)，不要抄别的温区 |

| 后：节点上读到 | 含义 | 不要 |
|----------------|------|------|
| 各温区 \(k\) 都到约 1.15 | 整张乘性涨阻，网格自己齐刷 | 不必事先切 1a |
| 只有冷端动、中温仍 ≈1 | 局部，隔离成立 | 两个全局 \(k\) 会把中温一起抬 |
| 只去过一列温区 | **还不知道**是不是全局 | 把这一列的 \(k\) 写到别处；解冻宽网 |

1a 只留两处：实验室已经知道是任务 A 时对照算得快；车上**若干温区节点已经齐了**之后，可把后续窗收到 1×1 当加速档。不要冷启动先 1a。

3×8×2 残差头（1c）已对照：纯涨阻 10.6 mV 不赢 1a 的 6.8 mV；只抬 −10 °C 时中温 2.54→5.63 mV。**丢掉，不上车。** 填洞（任务 B）车上允许失败。

入口：`Src/AI/EV_Local/kgrid.py`（默认写点）、`window.py`（1×1 对照 / 齐了之后的加速）。SGD，10 s 窗，默认一遍，更新不读 `Data/grid/`。

## 4. 一次离线增量怎么走

对齐 `Doc/03-c` §4.4，用 04-a 的入口落地。

1. **记账。** 每拍：\(I,T,s^{\mathrm{ah}},s^-,s^+,U_t,e^{\mathrm{ol}},e^{\mathrm{pri}},\mathrm{NIS},R_0,R_1,\delta R_0\)（若开）。  
2. **门控。** `run.py` 会打 `gate.py`。拒了就停。过了仍要走 §2.1，门控过 ≠ 该拆 \(R\)（任务 F）。  
3. **组轨迹。** 写出类似网格的 CSV。现场列至少 `i_meas_a, t_meas_c, soc_ah, u_t_meas_v`；`--new-style field`。\(U_{p0}\) 用段首滤波值，不要写死 0。  
4. **选档。** 按 §2。涨阻 / \(q<1\)：`--mode scale`。填洞：`--mode replay --replay-dir Data/grid`（或洞舰队自己的旧集）。同分布、2RC 慢尾巴：不要跑。  
5. **冻 scaler，禁止预热。** `--best` 加载旧 `best.pt`。现场权重用 `Data/ai_mlp_meas`。  
6. **验收两套。** 新年份开环；旧网格 / 旧探点开环；参考点（50%、25 °C、1C）的 \(R_0,R_1\)。表是 **last**，同时看 `best.pt`（04-a §5）。  
7. **部署后。** \(\delta R_0\) 清零；\(\mathbf{P}\) 的 \(s\) 方差可略增大一拍，让滤波重新信任新表。

`test.py` 只读权重。增量是单独批次。

```powershell
python Src/AI/KF/increment.py --mode scale --best --mlp-dir Data/ai_mlp_meas --new-dir Data/ai_kf/logs --eval-old-dir Data/grid_noisy --out-dir Data/ai_kf/incr --epochs 10 --lr 1e-2
python Src/AI/KF/increment.py --mode replay --best --mlp-dir Data/ai_mlp_meas --new-dir Data/ai_kf/logs --replay-dir Data/grid_noisy --replay-n 50 --eval-old-dir Data/grid_noisy --out-dir Data/ai_kf/incr --epochs 10
python Src/AI/KF/run.py --mlp-dir Data/ai_kf/incr --best
```

对照四档（实验室，不是车上每趟都跑）：

```powershell
python Src/AI/KF/compare.py --new-dir <新年份> --old-dir Data/grid_noisy --mlp-dir Data/ai_mlp_meas --out-dir Data/ai_kf/compare_<本次>
```

不要覆盖 `Data/ai_kf/compare/`（任务 A 正式表）。

## 5. 门控怎么读

`gate.py` 同时查：NIS 带、开环是否高于噪声、有没有边沿或 ≥30 s 静置、温度是否出 scaler。

04-a 任务 F 改写了事先的预期：

| 现象 | 门控实际 | 该不该增量 |
|------|----------|------------|
| 健康长恒流，开环 1.2 mV | **拒**（开环没内容） | 否。激励项本来会过（0.3C 边沿、30 min 停车），挡住的是「没东西可学」 |
| 充电 + 长停，开环 2.4 mV | **过**（刚过 \(3\times 0.5\,\mathrm{mV}\)） | 否。长停拆不开 \(R_0/R_1\) |
| 5 A 零偏 / \(Q\times 0.95\) | **过**（开环 143 / 22 mV；NIS 仍 0.13） | **否。** 安时已漂。电压是 SOC 啃回去的 |
| 默认短波、表没偏 | 拒 | 否 |
| 表 \(R_0\times 1.2\)（任务 E） | 过 | 滤波层用 \(\delta R_0\)，不要立刻 Replay |

所以：**门控是必要过滤，不是任务分类器。** 过了还要问：是 \(I\Delta R\)、是温区洞、是安时漂，还是同分布噪声。

现有门控**挡不住**电流零偏和容量错。包级全串同向涨阻，先按 `Doc/A0` 查 \(b_I\)。

长轨迹不要对 `increment.py` 做满小时 BPTT（无 `--tbptt`，2 h × 0.1 s 约 9 万步）。负例以 `run.py` + 门控为主。要拆通道必须有脉冲 / 回弹，不是把网格加长。

## 6. 分任务：怎么做、怎么收

### 6.1 整体涨阻 / 换对象（A、D）

形状还在，整张 \(R\) 乘了一个数。三输入网没有 SOH 维，同一格子不能同时记住 BOL 和老化。

- 用 `--mode scale`。学习率约 \(10^{-2}\)，6 轮左右早停，或看 \(\lvert k-k^\star\rvert\)。  
- 通过：\(k_0\approx k_1\)，朝目标走（×1.15 时 last 约 1.18，略过冲）；新年份降到本舰队旧集量级；旧集变差是 \(k\) 动了，**不是遗忘失败**。  
- 不要为了旧集 7.8 mV 解冻整网。必须同时记住两张表：加 SOH 输入，或每芯 / 每个寿命存一份 \(k\)。  
- Replay / 重训在同一 \((I,s,T)\) 上对打新旧电压，A 里两边半吊子。  
- 只微调中途新年份可以贴上底板（约 8.5 mV），最后一轮弹回；参考点 \(R_0+10\%\) / \(R_1+17\%\) 不齐——电压一度好看、参数最脏。旧芯退役才可以接受。

测量列舰队（D）排位与 A 相同。A 冻结旧集 7.8 mV，D 抬噪声后 11.8 mV（**+4 mV**）。四个毫伏推不翻「走缩放」。现场增量挂 `Data/ai_mlp_meas`。不要拿 500+ 轮的 4 mV 来减。

### 6.2 填洞（B）

旧格子的 \(R\) 不该变。现成 `Data/ai_mlp` 已经见过 −10 °C，**不能**当填洞起点，否则退化成 §6.3。

- 另训洞舰队（`hole.py`），再 `--mode replay`。  
- 通过：新 RMSE 降到旧集量级；旧集恶化 &lt; 20%；参考点接近增量前。  
- 缩放不是填洞工具。B 里 \(k_0=1.017\)、\(k_1=0.943\) 反号，新年份几乎不降。  
- 只微调这轮旧 RMSE 没炸（10 轮、邻档 −3 °C），不要当成「微调也安全」；参考点已经比 Replay 挪得多。  
- 洞舰队只训 100 轮时，旧集变好是预训练没跑完，不是填洞副作用。口径要干净，先把洞舰队训到与现役同量级再对照。

### 6.3 同分布（C）

舰队已经见过这批数据。冻结就是正途。

- 缩放应停在 \(k\approx 1\)（C：0.994 / 1.010）。  
- Replay / 重训在噪声里晃；只微调新略降、旧 +10%，是假成功。  
- `Plan.md` Q1：同分布再贴电压，不能当 Replay 优于微调的证据。

### 6.4 一趟表偏（E）

`--r0-scale` 只放大 MLP 读出，电芯没变。开环关、开 `--dr0` 一样大（约 10 mV），这是锚。

- 打开后 \(\delta R_0\approx -160\,\mu\Omega\)（表偏大，符号为负），先验 / NIS / 休息 SOC 回到默认滤波。  
- 电压贴上但 SOC 歪了：先开 \(\delta R_0\) / 调 \(\mathbf{Q}\)，不要开增量（`Doc/03-c` §5.1）。  
- 连续多天同号再送离线缩放。默认 `--dr0` 仍关；要不要改默认是第 2 期的事。

### 6.5 激励不足（F）

\(\Delta U\approx I(R_0+R_1)\) 拆不开通道。只报 \(R_0+R_1\)。

- 健康长恒流：门控拒。  
- 零偏 / 容量错：门控过了也不许拆。  
- 不要改默认 SEQUENCE 去迁就；长工况走 `nmc100ah_ecm_gen_long.py`。

## 7. 验收（按任务换一句）

参考点固定：SOC 50%、25 °C、1C。模板约 \(0.80/0.65\,\mathrm{m}\Omega\)，已训网会略偏，看相对漂移。

| 检查 | 涨阻 / 换对象 | 填洞 | 同分布 |
|------|----------------|------|--------|
| 新开环 | 低于冻结，降到本舰队旧集量级 | 低于冻结，贴近旧集 | 冻结已够；再降零点几毫伏不算赢 |
| 旧开环 | 变差说明 \(k\) 动了 | 恶化 &lt; 20% | 不应明显动 |
| 参考点 | \(k\) 齐、幅度可解释（15% 不该学成 80%） | 接近旧值 | 不动 |
| 两通道 | \(k_0\approx k_1\) | 不要靠全局 \(k\) | \(k\approx 1\) |

另外（`Doc/03-c`、`Plan.md` §8）：

- 休息点 SOC 增量后不恶化。电压贴上、SOC 歪了，先查滤波，再动网。  
- NIS 回到 \(O(1)\)，不是靠把 \(R_v\) 调爆。  
- 无脉冲只报和电阻。  
- `compare.py` / `increment.py` 写入的是 **last**。缩放 `best` 常在中途（A 第 4 轮 \(k\approx 1.11\)，第 10 轮 1.18）。`best` 分数是「新 RMSE + \(\beta_{\mathrm{eval}}\)×旧 RMSE」，会偏向折中轮。  
- 新 RMSE 若只切 5 条（或填洞 2 条）验证轨迹，上下几毫伏不要过分解读。旧 90–100 条更稳。

**100 轮底板约 7.8 mV。** 任务 A 用 `Data/ai_mlp_100`，冻结旧集 7.80 mV。现役 `Data/ai_mlp` 训到 500+ 才到约 4 mV，留给 C / E / F / G / H。A 和 D 只对齐 100 轮，不追 4 mV。
