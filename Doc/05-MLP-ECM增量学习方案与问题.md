Powered by SpaceXAI Grok 4.6

> 对象：已训好的灰箱 MLP，\((I,T,\mathrm{SOC})\rightarrow(R_0,R_1)\)，电路与离散化不变  
> 对照：`Doc/03-MLP-ECM物理信息参数估计.md`、`Doc/04-MLP-ECM固定C1方案与对比.md`  
> 对齐代码：`Src/AI/MLP/train.py` 的 `--resume`、`scaler.json`、`Data/grid/`  
> 目的：分清「接着训同一批数据」和「来了新轨迹还要保住旧曲面」，列出可做的方案和本仓库会踩的坑  
> 本文只做分析，不改训练脚本

现有流程是**离线一批网格、一次训完**。车上和实验室里数据是分批来的：补测低温、换电芯、跑了三个月、现场只有日常充放。若每次从头训，旧数据可能已经丢了；若只拿新轨迹微调，旧 SOC / 温度上的 \(R_0,R_1\) 会塌。这就是增量学习要管的事。

---

## 1. 先把两个容易混的概念拆开

| | 现有 `--resume` | 本文说的增量学习 |
|--|-----------------|------------------|
| 数据 | 还是同一份 `Data/grid/` | 来了**新分布**的轨迹 |
| 权重 | 从 `epoch_XXXXX.pt` 接着跑 | 从旧权重出发，吸收新样本 |
| 归一化 | 必须沿用 `scaler.json` | 同样必须冻住，见 §5.1 |
| 预热 | 续训时跳过 | 现场数据没有教师 \(R,C\)，只能走电压损失 |
| 风险 | 过拟合同一网格 | **灾难遗忘** + 激励不足导致参数拧歪 |

`train_1000_resume.bat` 只是「同一批数据再跑 1000 个电压 epoch」。网格没变、scaler 没变、验证集没变。**这不是增量学习。**

增量学习的触发条件至少满足一条：

1. **覆盖变了**：新温度档、新起始 SOC、新电流序列（HPPC → 工况循环）
2. **对象变了**：另一只电芯、模组、批次
3. **时间变了**：循环老化 / 日历老化，同一 \((I,T,s)\) 对应的 \(R_0,R_1\) 已经不是当初那张曲面
4. **旧样本拿不齐**：只能留一小撮回放，或只剩权重

第 3 条和第 1、2 条常常缠在一起。低温一天看起来像「电阻涨了」，其实是温度维没盖住；当成老化去增量更新，会把整张曲面抬高。

## 2. 要学的到底是什么

MLP 是一张静态表：

\[
\bigl(R_0,R_1\bigr)=f_\theta(\tilde{I},\tilde{s},\tilde{T})
\]

方案 B 下 \(C_1\equiv C_1^\star\) 不进网络（见固定 C1 文档）。新数据对这张表有三种不同的「新」：

| 类型 | 含义 | 正确反应 |
|------|------|----------|
| 填洞 | 旧网格没覆盖的 \((s,T,I)\) | 在空洞处长出曲面，**已覆盖处尽量不动** |
| 换对象 | 另一只电芯，形状相近、参考点不同 | 小适配（缩放 / 偏置），或单独一套权重 |
| 老化 | 同一只电芯，\(R_0,R_1\) 随 SOH 升、\(C_1\) 降 | 输入里缺 SOH 维时，**增量更新会和「换对象」无法区分** |

参数规范写明：模板是 BOL，**不含 SOH 维**，老化后应重标或整体缩放。三输入网络没有「第几周」这个旋钮。把老化轨迹拿去微调，网络只能改已有三个输入上的曲面——等于用一张 BOL 表去兼当寿命表，旧工况上的电压会变差。

因此：**缺维时不要用增量学习硬扛。** 要么加输入（SOH / 循环周次 / 日历天），要么只学一个慢变缩放，要么承认这是另一张表。

## 3. 技术方案

下面按「对本仓库的贴合程度」排，不是按论文热度。电路、损失仍是

\[
L = L_v + \lambda_{\mathrm{smooth}} L_{\mathrm{smooth}},\qquad
L_v=\tfrac12\mathrm{mean}\bigl(\hat U_t-U_t^{\mathrm{meas}}\bigr)^2
\]

主损失只有电压。新轨迹若没有阶跃和回弹，\(R_0\) 与 \(R_1\) 分不开，增量更新会把误差随便塞进一个通道。

### 3.1 全量重训（上界，不是增量）

旧网格 + 新轨迹拼在一起，`--fresh` 从头训，或冻 scaler 后 `--resume` 在**合集**上再训。

- 优点：没有遗忘，实现为零；电压 RMSE 的上限就在这儿
- 缺点：必须留得住全部 CSV；`gen_grid.bat` 现在会先删 `Data/grid/*.csv`，直接重跑网格会把旧档位清掉
- 何时用：实验室还能再生成 / 还留着历史文件；当作其它方案的对照

### 3.2 只在新数据上微调

`data-dir` 换成新目录，`--resume` 加载旧权重，只扫新轨迹。

- 优点：几分钟就能贴上新电压
- 缺点：没用到的 \((s,T)\) 会漂。新数据若全是 25 °C，−10 °C 的 \(R_0\) 过几个 epoch 就不是原来的数
- 何时用：只做一次性适配、旧区域再也不关心（换电芯且旧电芯退役）

这是最容易在 `train.py` 里「看起来能跑」的做法，也是遗忘最狠的做法。

### 3.3 经验回放（Replay）

保留一个旧轨迹子集 \(\mathcal{B}_{\mathrm{old}}\)（例如每档 SOC×T 留 1 条，或按 `index.csv` 分层抽），每次和新年份 / 新电芯轨迹 \(\mathcal{D}_{\mathrm{new}}\) 混批：

\[
L = L_v(\mathcal{D}_{\mathrm{new}}) + \beta\, L_v(\mathcal{B}_{\mathrm{old}})
\]

\(\beta\) 按条数或按覆盖体积来，避免新年份把梯度淹没。

- 优点：和现有 `TrajectoryDataset` 同构，只需改组 batch；旧区域有电压锚
- 缺点：要决策「留哪些」。只留中温中 SOC，低温仍会忘；全留则退化成 3.1
- 何时用：**本仓库第一期就该做这个**

回放的是**轨迹**，不是逐步样本。整条 BPTT 才看得到回弹，打散成单步会让 \(R_1\) 更不可观。

### 3.4 输出蒸馏 / 参数锚（正则增量）

在旧网格的探点 \(\{x_j\}\) 上，记下旧网络的 \((R_0^{(0)},R_1^{(0)})\)，新损失加

\[
L_{\mathrm{anc}}
=\mathrm{mean}_j\Bigl[
\bigl(\ln R_0(x_j)-\ln R_0^{(0)}(x_j)\bigr)^2
+\bigl(\ln R_1(x_j)-\ln R_1^{(0)}(x_j)\bigr)^2
\Bigr]
\]

不必存旧 CSV，只需一张探点表（可直接用解析模型或旧 MLP 现场算）。EWC 是同一思想：按旧任务 Fisher 对角加权，改得勤的参数罚得重。

- 优点：存储极小；三维输入上探点便宜；和方案 B 的 log 域平滑同一套量纲
- 缺点：锚的是**参数**不是电压。若旧参数本身在某个探点不可观（乱飘的 \(R_1\)），会把错误钉死
- 何时用：旧 CSV 已删，只剩 `best.pt` + `scaler.json`

探点要盖住旧温度两端，不要只在 25 °C、SOC=50% 钉一个点。

### 3.5 浅层适配：只学缩放 / 偏置

冻住 MLP 全部权重，只加

\[
R_0' = k_0 R_0,\qquad R_1' = k_1 R_1
\]

或再加很慢的偏置。\(k_0,k_1\) 用新轨迹的电压损失更新，学习率低于本体。

这和参数规范「老化后整体缩放」一致，也和特性文档「\(R_0\) 是最稳的电学 SOH」一致。方案 B 下老化引起的 \(C_1\) 下降本来就会折进 \(R_1\)，\(k_1\) 会偏大一点，电压仍可能贴上。

- 优点：几乎不遗忘形状；两个标量，现场也能更
- 缺点：形状真变了（高镍后期、某 SOC 窗口鼓包）拟合不够
- 何时用：确认是同一只电芯、主要在涨内阻，而不是补测新温区

### 3.6 扩维：SOH / 周次进输入

\[
x=[I,\,s,\,T,\,q],\qquad q=\mathrm{SOH}\ \text{或循环周次}
\]

这是**换模型**，不是增量学习。旧三输入权重不能直接续。需要：

- 旧数据标 \(q=1\)（BOL）
- 新数据有可靠的 \(q\)（容量标定，或至少用 \(R_0\) 代理并声明循环依赖）
- 重新 `fit_scaler`（四维），等于新实验

现场 \(q\) 往往比 \(R_0\) 还难测。用「循环计数」代替 SOH 会把日历老化漏掉。

### 3.7 不要逐步去训 MLP

车上 0.1 s 一拍用 RLS / EKF 更 \(R_0\)（有时 \(R_1\)），MLP 只当先验或初值。那是**在线辨识**，和增量学习不同层：

| | 在线 RLS / EKF | 增量 MLP |
|--|----------------|----------|
| 时间尺度 | 秒～分钟 | 一次出车、一次实验、一周 |
| 改什么 | 当前工况附近的局部 \(R\) | 整张 \((s,T,I)\) 曲面 |
| 激励 | 当前有没有脉冲 | 这一批轨迹整体是否可观 |
| 遗忘 | 遗忘因子 \(\lambda\) | 旧区域的曲面塌陷 |

两者可以叠：MLP 出先验，RLS 出残差；积累一批「先验对不上」的轨迹再增量更新 MLP。**不要**把 `train.py` 嵌进仿真步进里。

## 4. 方案对照

| 方案 | 旧区域电压 | 新区域电压 | 存储 | 实现量 | 缺 SOH 维时 |
|------|------------|------------|------|--------|-------------|
| 全量重训 | 最好 | 最好 | 全量 CSV | 现成 | 仍会把老化抹进三输入曲面 |
| 只微调新数据 | 差 | 好 | 无 | 现成 `--resume` + 换目录 | 最容易把老化写成「全域涨阻」 |
| Replay | 好 | 好 | 子集 | 中（组 batch） | 旧 BOL 回放能挡住乱涨 |
| 参数锚 / 蒸馏 | 中～好 | 好 | 探点表 | 中 | 会拒绝合理的老化变形 |
| 缩放适配 | 形状保留 | 中（只平移） | 无 | 小 | **最贴老化假设** |
| 扩维 \(q\) | 需重训 | 好 | 全量 + \(q\) 标签 | 大 | 正途，但不是增量 |
| 逐步 RLS | 不动 MLP | 只改局部 | 无 | 另一套 | 不管曲面 |

没有「一个开关解决所有增量」的算法。先判断新数据是填洞、换对象，还是老化，再选行。

## 5. 本仓库会踩的坑

### 5.1 `scaler.json` 必须冻住

`scaler.json` 不是电阻缩放，也不是 \(k_0,k_1\)。它只保存舰队第一次训练时输入 \((I,s,T)\) 的均值和标准差，把物理量映到 MLP 看到的坐标：

\[
\tilde x = (x-\mu)/\sigma,\qquad
\mu,\sigma\in\mathbb{R}^3
\]

推理是

\[
(I,s,T)\;\xrightarrow{\mathrm{scaler}}\;\tilde x\;\xrightarrow{\mathrm{MLP}}\;(R_0,R_1)\;\xrightarrow{k_0,k_1}\;(k_0 R_0,\,k_1 R_1)
\]

（没有缩放头时最后一截是 \(k\equiv 1\)。）scaler 管输入；\(k\) 管输出幅度（§3.5）；二者不要混。

权重是在这套 \(\tilde x\) 里学的。增量时若对新年份重算均值方差：

- 旧权重看到的 \(\tilde I,\tilde s,\tilde T\) 全部错位
- 看起来 loss 先炸再「重新学会」，其实是把旧曲面扔掉

规则：增量沿用旧 scaler。`increment.py` 会把同一份文件拷到对照目录，不是重新 `fit_scaler`。新年份若超出旧 \(\mu\pm 4\sigma\)（例如第一次最高 35 °C，后来来了 50 °C），应**声明这是扩覆盖**，要么把该维的 \(\sigma\) 人工放大并接受旧权重在该维上的轻微错位，要么走 3.1 重训。不要静默 `fit_scaler`。

现有 `train.py` 续训已经坚持读旧 scaler，这一点是对的。换 `data-dir` 微调时不要顺手删 `scaler.json`。缩放档冻 scaler **并且**冻 MLP 权重，只更新 \(k\)；其它增量档只冻 scaler，网可以动。

英飞凌 demo 的输入不是这份 z-score，而是写死的倍率 / SOC 0–1 / 温度盒子，见 `Doc/07` §1.1。冻的理由相同（坐标系不能改），公式不能混用。

### 5.2 现场没有教师 \(R_0,R_1\)

合成网格里有 `r0_ohm` / `r1_ohm`，预热用它们。增量来的实车 CSV 通常只有 \(I,T,s,U_t\)。

- 不要对实车再开 `--pretrain-epochs`
- 现有续训已经跳过预热，保持
- 评估时不要拿「和教师列的 RMSE」当主指标，只看电压；参数对错用旧网格上的对照，或 HPPC 抽检

### 5.3 方案 B 把老化折进 \(R_1\)

\(C_1\) 钉死后，真电芯老化 \(C_1\downarrow\)、\(\tau\) 变长，只能表现为 \(R_1\uparrow\)。增量电压拟合会继续加大 \(R_1\)。电压可能变好，内阻 SOH 仍可读，但 \(\tau\) 的物理解释更糊。

增量期不要切到方案 A「让 \(C_1\) 跟着老化变」——可观性比离线训练更差，\(R_1,C_1\) 对冲会更凶。若必须跟 \(\tau\)，用 B+ 动一个全局 \(C_1\)，并给它比 \(R\) 小一个数量级的学习率。

### 5.4 新轨迹激励不够

网格默认 SEQUENCE 含 1C 放电、静置回弹、短时 2C，\(R_0\)（边沿）和 \(R_1\)（回弹）分得开。现场常见长时恒流 + 停车，走到极化稳态后 \(C_1\) 梯度接近 0，\(R_0\) 与 \(R_1\) 在电压里几乎共线：

\[
\Delta U \approx I(R_0+R_1)
\]

增量更新此时只能学到和电阻，随便拆。表现是电压 RMSE 下降、\(R_0/R_1\) 对旧 HPPC 对不上。

对策：新批次里至少掺几段有边沿和 30 s 以上静置的轨迹；或冻结 \(R_1\) 只更 \(R_0\)（浅层适配的变种）。

### 5.5 `use_true_inputs` 与测量噪声

配置默认用 `i_true` / `soc_true` / `t_true`。合成数据干净。实车只有测量列。增量若不改 `use_true_inputs=False`，接口对不上；改了则输入分布比训练时更噪，等于又一次域偏移。

应在离线阶段就用测量列训一版「现场权重」，增量只在这版上做。不要用真值列训完的网络直接吃带噪声的 SOC。

### 5.6 验证集和 `best.pt`

`val_ratio` 从**当前 `data-dir`** 里切。只拿新轨迹当 `data-dir` 时，`best.pt` 会按新年份验证集存，旧区域变差也看不见。

增量验收至少两套数：

- 旧探点 / 旧网格子集：电压 RMSE 不许明显变差（例如相对原 `best` 恶化 < 20%）
- 新轨迹：电压 RMSE 要下来

`best.pt` 的定义要改成「旧+新的加权」，或干脆增量期不用自动 best，人工看两套曲线再打标签。

### 5.7 `gen_grid` 会删旧 CSV

`nmc100ah_ecm_gen_grid.py` 正式跑会清掉输出目录全部 `*.csv`。这是为了换 5×5 / 10×10 时不脏训。和 Replay 冲突：想留旧网格就不能对同一目录再跑一遍 gen。

增量数据应写到新目录（`Data/grid_202608/`），旧的 `Data/grid/` 只读。回放从旧目录抽，新年份从新目录读。不要改「清目录」的默认行为去迁就增量。

### 5.8 短片段的 \(U_p(0)\)

仿真默认静置开始、\(U_p=0\)。从行驶中间截一段，极化不是 0。增量若把 \(U_{p0}=0\) 写死，前几十秒的电压误差会误打到 \(R_1\) 上。

要么只收「静置足够长再出发」的片段，要么把起始 \(U_p\) 当每条轨迹的隐变量（不进 MLP），或丢掉开段 \(\sim 3\tau_1\) 再计损失。

### 5.9 温度 vs 老化

\(R_0,R_1\) 的 Arrhenius 很陡。新数据若温度计漂移 3 °C，或用环境温度代替电芯温度，增量会学到一张「假老化」曲面。特性文档里高温还加速真老化，两个效应同向。

增量前先查新年份的 \(T\) 直方图是否落在旧 scaler 范围内；超出则先当「填洞」而不是「SOH 变了」。

### 5.10 OCV 当外生量

\(\hat U_t=U_{\mathrm{ocv}}-IR_0-U_p\)。\(U_{\mathrm{ocv}}\) 不学习。老化后 OCV 平台也会变（尤其高 SOC）。电压误差会全部算到 \(R\) 头上，增量把 \(R_0\) 抬去补 OCV 亏空，脉冲边沿会对不上。

OCV 表过期时先重标 OCV，再动 MLP。不要指望增量学习顺便把开路电压吃进内阻。

### 5.11 平滑正则的错方向

\(L_{\mathrm{smooth}}\) 罚的是**一条轨迹内部**相邻拍的 \(\ln R\)。它不保护「昨天那张曲面」。跨任务遗忘要靠回放或锚点，不能把 `lambda_smooth` 加大当增量算法。

## 6. 问题清单（按严重程度）

1. **缺 SOH 维**：三输入网络无法同时记住 BOL 和老化；硬增量等于改写旧表  
2. **只微调新年份**：未出现的温区 / SOC 灾难遗忘  
3. **激励不足**：电压变好、参数拆错，旧 HPPC 对照崩  
4. **重算 scaler**：旧权重坐标系作废  
5. **温度 / OCV / \(U_p0\) 系统误差**：被当成电阻变化写进网络  
6. **`best.pt` 只看新年份**：静默丢掉旧区域  
7. **清网格目录**：Replay 的数据源被自己删掉  
8. **对实车再预热**：没有教师列，或用错列  
9. **增量期改方案 A**：\(R_1,C_1\) 对冲，比离线更不可观  
10. **把 `--resume` 当成已经做了增量**：同一网格多训一会解决不了分布漂移

## 7. 建议落地顺序

不改代码也能先做的：

0. 文档和脚本注释里分开「续训」和「增量」。`train_1000_resume.bat` 继续只服务同一网格。  
1. 新年份、新电芯写到新目录，保留 `Data/grid/`。对照实验：全量重训 vs 只微调，量化旧网格 RMSE 涨多少。  
2. 若遗忘不可接受：Replay（分层抽旧轨迹）+ 冻 scaler + 电压损失 only。验收用 §5.6 两套指标。  
3. 若确认是同一只电芯在涨阻：优先 3.5 缩放适配，不要先上 EWC。  
4. 若确认要跨寿命用一张网：立项扩维，当新模型，不要在三输入上无限增量。  
5. 车上仍用 RLS / EKF 跟当前 \(R_0\)；MLP 增量放在有人看曲线的离线批次里。

一期明确不做：逐步反传 MLP、增量方案 A、静默重拟合 scaler、在 `test.py` 里更新权重。

## 8. 验收时看什么

在旧参考点（SOC = 50%，25 °C，1C 放电）记下增量前后的 \(R_0,R_1\)。模板是 \(0.80\,\mathrm{m}\Omega\) / \(0.65\,\mathrm{m}\Omega\)，已训网络会略偏，但增量后相对漂移应远小于新年份上电压 RMSE 的改善。

| 检查 | 通过 |
|------|------|
| 旧网格电压 RMSE | 不明显差于增量前 `best.pt` |
| 新轨迹电压 RMSE | 明显低于增量前（冻结权重直接推理） |
| 旧参考点 \(R_0,R_1\) | 填洞任务下接近旧值；老化任务下单调、幅度可解释 |
| 新年份若无脉冲 | 不单独相信拆开的 \(R_0/R_1\)，只报 \(R_0+R_1\) |

电压贴上而旧参考点电阻跳了 20%，优先怀疑 §5.4 和 §5.9，而不是再降学习率猛训。
