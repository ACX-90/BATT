## 1. 它是什么

极化电阻 \(R_1\) 是并联 RC 里那只电阻。电流加上之后，过电位**逐渐**长到约 \(I R_1\)；撤流后按同一时间常数消退：

\[
\dot U_p = -\frac{U_p}{R_1 C_1} + \frac{I}{C_1},\qquad
\tau_1 = R_1 C_1
\tag{1}
\]

常值 \(R,I\) 时 \(U_p(t)=IR_1(1-e^{-t/\tau_1})+U_p(0)e^{-t/\tau_1}\)。电压看见它的是两件事：

- **幅度**：脉冲够长后的稳态极化 \(\approx I R_1\)
- **快慢**：和 \(C_1\) 绑在一起的 \(\tau_1\)（回弹形状）

参考点模板 \(0.65\,\mathrm{m}\Omega\)。100 A 上满幅度 65 mV；配 \(C_1=2.8\times 10^{4}\,\mathrm{F}\) 得 \(\tau_1=18.2\,\mathrm{s}\)。

边沿直跳是 \(R_0\)（`00-0201`），跟 \(R_1\) 无关：电容两端电压不能突变，阶跃瞬间 \(U_p\) 还没动。

## 2. 物理来源

1RC 里 \(R_1\) 是界面动力学的集总，比 \(R_0\) 更「电化学」：

| 贡献 | 过程 | 时间尺度 |
|------|------|----------|
| 电荷转移 \(R_{\mathrm{ct}}\) | 离子在固/液界面得失电子（Butler–Volmer） | 亚秒到数秒，主对应 |
| SEI / CEI 膜离子迁移 | Li⁺ 穿过表面膜 | 常与 \(R_{\mathrm{ct}}\) 并成一个中频半圆 |
| 部分浓差极化 | 孔隙 / 颗粒内浓度梯度（本应给 Warburg 或 \(R_2\)） | 更慢；1RC 只能吞一截 |

EIS：中频半圆直径 \(\approx R_{\mathrm{ct}}+R_{\mathrm{SEI}}\)。HPPC：\((\Delta U_{\mathrm{end}}-\Delta U_{\mathrm{instant}})/I\)，再扣掉这段里 OCV 随 SOC 走的 \(\Delta U_{\mathrm{ocv}}\)。

「极化」在这里就是相对平衡电位的过电位 \(\eta\)。小电流下 \(\eta\approx I R_{\mathrm{ct}}\)，所以能用一只线性电阻近似；大过电位时动力学不再线性，见第 4 节。

---

## 3. 为什么是「逐渐」而不是瞬时

电荷转移发生在双电层上。界面要先积累（或释放）电荷，过电位才建立；撤流后双电层通过 \(R_{\mathrm{ct}}\) 放电，过电位才消退。电路上就是 \(R_1\) 旁并联 \(C_1\)：电流先给电容充电，电压按 \(\tau_1\) 指数爬。

这和欧姆项的分工：

```
电子/离子通路、无界面储能     →  R0，瞬时
界面得失电子 + 双电层充电     →  R1C1，秒级
固/液相扩散、浓度场           →  本应 R2C2；1RC 里被部分并进 R1C1
```

1RC 用一个 \(\tau_1\) 同时拟合 1 s 内的电荷转移和 100 s 级扩散，必然顾此失彼。关心 10 s 功率通常够；长搁置、长恒流末端会露出慢尾巴（`00-0204`）。

## 4. 随工况变的物理原因

**温度（三个 1RC 参数里最陡）。** 电荷转移是典型热激活，交换电流密度 \(i_0\) 随 \(T\) 指数变。模板 \(E_a=32\,\mathrm{kJ/mol}\)（\(R_0\) 只有 16）：−10 °C 约 ×5.6，−20 °C 约 ×10。常温 \(R_1\) 与 \(R_0\) 同量级；低温 \(R_1\gg R_0\)，总极化改由这一支主导。同样电流下过电位大，负极电位更容易被打到 0 V vs Li/Li⁺ 以下——这是低温功率差和低温充电易析锂的电路侧原因。

**SOC（深 U / 浴缸）。** \(i_0\) 随表面锂浓度变。低 SOC（<20%，尤其 <10%）：负极脱锂末期 / 正极嵌锂末期，常到中段的 2–5 倍。高 SOC（>85%）：正极高脱锂、高镍相变、电解液氧化倾向。石墨 staging、H2–H3 附近可有局部峰。低 SOC 放电与高 SOC 快充的电压动态误差，多半来自 \(R_1\) 而不是 \(R_0\)。

**电流（Butler–Volmer）。** 小电流 \(R_{\mathrm{ct}}\) 近似常数；大过电位下表观电荷转移电阻下降：

\[
R_{\mathrm{ct,eff}}(I) \propto \frac{\eta}{i_0\sinh(\alpha F\eta / RT)}
\]

模板用 \(\mathrm{asinh}(|I|/I_s)/(|I|/I_s)\)，\(I_s=50\,\mathrm{A}\)。0.5C 辨出的 \(R_1\) 用于 3C 会偏大；大电流辨出的用于小电流会偏小。自热叠加上去，大电流表观值再低一点。这是界面动力学，不是欧姆通路的弱软化。

**充放不对称。** 比 \(R_0\) 明显：低 SOC 放电更大（正极嵌锂 / 负极脱锂末期），高 SOC 充电更大（正极高脱锂）。OCV 滞后若没单独建模，会被吞进 \(R_1\)，表现为充放参数对不上。

**老化。** 活性比表面积下降（颗粒隔离、岩盐相、导电网络断裂）→ \(i_0\) 下降 → \(R_{\mathrm{ct}}\) 上升；SEI/CEI 增厚 → 膜电阻上升；析锂后可阶跃。相对增幅常常大于 \(R_0\)，尤其日历老化和低温循环——限制环节在界面而不在电解液体相。

## 5. 不要和谁混

| 不要当成同一个 | 差别 |
|----------------|------|
| \(R_0\) | 瞬时、无储能；\(R_1\) 要给双电层充电 |
| EIS 的 \(R_{\mathrm{ct}}\) | 1RC 的 \(R_1\) 还吞了膜和一部分扩散 |
| \(R_2\) | 慢扩散的幅度；1RC 里被部分折进 \(R_1\) |
| 方案 B 的等效 \(R_1\) | \(C_1\) 钉死后，同一个旋钮兼幅度和快慢，不宜直接比半圆直径 |

核心就一句：\(R_1\) 是界面电荷转移（加一点膜和扩散）的集总电阻，决定极化能长到多高；它和 \(C_1\) 一起按秒级指数建立、消退，不是边沿上那一跳。
