## 1. 它是什么

极化电容 \(C_1\) 是并联 RC 里那只电容。它不是焊在板上的电子学电容，而是把**双电层充电**、以及被 1RC 吞掉的部分扩散，集总成一个能存电荷的元件。

\[
\tau_1 = R_1 C_1
\]

稳态电压里没有它：脉冲足够长后 \(U_p\to I R_1\)，与 \(C_1\) 无关。它只决定极化**建立 / 消退有多快**。\(R_1\) 一定时，\(C_1\) 越大 \(\tau_1\) 越长，动态越钝。

参考点模板 \(2.8\times 10^{4}\,\mathrm{F}\)，配 \(R_1=0.65\,\mathrm{m}\Omega\) 得 \(\tau_1=18.2\,\mathrm{s}\)。看到「两万八千法拉」是正常的：

\[
C_1 \sim C_{\mathrm{dl}}\cdot A_{\mathrm{active}}
\]

电极真实电化学面积极大，双电层比电容乘上去就是千法到十万法。100 Ah 方壳 / 软包常见 \(10^{4}\)–\(10^{5}\,\mathrm{F}\)；18650 常见 \(10^{3}\)–\(10^{4}\,\mathrm{F}\)。

\(C_1\) 不产生欧姆热。产热是 \(I^2 R_0 + I\cdot U_p\)。

## 2. 物理来源

固/液界面两侧带相反电荷，形成双电层，单位面积电容 \(C_{\mathrm{dl}}\) 大约 µF/cm² 量级。多孔电极把几何面积放大几个数量级，总电容变成法拉到万法。电流要改变界面过电位，必须先给这层「电容」充（放）电，充电回路经过电荷转移电阻 \(R_{\mathrm{ct}}\)——这就是 \(R_1\parallel C_1\)。

1RC 还把一部分扩散动力学折进这只电容。扩散在频域接近 Warburg（\(\propto 1/\sqrt{j\omega}\)），不是单只电容；硬塞进 \(C_1\) 之后，辨出的电容会随激励频谱漂：脉冲短则偏小，搁置短则偏大。真正的慢扩散应另给 \(C_2\)（`00-0205`）。

电容两端电压不能突变：电流阶跃瞬间 \(U_p\) 不动，边沿仍是 \(IR_0\)。随后 \(C_1\) 按 \(\tau_1\) 充电，端电压才出现指数弯。

## 3. 为什么数量级是万法

普通电解电容要很大体积才到法拉。这里面积不是极片的长×宽，而是活性颗粒的内外表面：

- 颗粒半径 µm 级，比表面积 m²/g
- 100 Ah 电芯活性物质几十到上百克
- \(C_{\mathrm{dl}}\sim 10\)–\(50\,\mu\mathrm{F/cm}^2\) 乘上去，落到 \(10^4\) F 这一档

所以 \(\tau_1=R_1 C_1\) 能到十几秒：电阻是毫欧，电容是万法，乘积是秒。单位没有写错。

拆成 2RC 时，快支路电容通常小于 1RC 那只（电荷转移更「纯」），慢支路 \(C_2\) 更大（扩散「储锂」更多），见 `00-0205`。

## 4. 随工况变的物理原因

规律不如 \(R_0/R_1\) 稳定。辨识上 \(C_1\) 与 \(R_1\) 强耦合：同一条回弹，\(R_1\) 偏大、\(C_1\) 偏小（或反过来）往往仍能拟合——电压看见的是 \(\tau_1\) 和 \(IR_1\)，不是单独的 \(C_1\)。下面说的是物理倾向，曲线抖动大时先怀疑辨识，不要当成电芯结构。

**SOC。** 常见中高 SOC 较大、低 SOC 减小：低 SOC 有效活性面积或表观 \(C_{\mathrm{dl}}\) 下降。也有随 SOC 缓升或中段平坦的报道。更稳的做法是先盯 \(\tau_1\) 是否光滑，再算 \(C_1=\tau_1/R_1\)。

**温度。** 双电层电容随温度轻度增加（模板 \(E_a=-3\,\mathrm{kJ/mol}\)，升温因子略大于 1）。\(\tau_1(T)=R_1(T)C_1(T)\) 的主因仍是 \(R_1\) 的 Arrhenius：升温回弹变快，降温又高又钝。低温短脉冲走不到稳态，表观 \(C_1\) 更容易漂。

**电流。** 双电层本身几乎不随倍率变。模板对 \(C_1\) 不做电流修正。大电流下表观 \(\tau\) 变短，多半是 \(R_1\) 的 BV 下降加自热，不是电容变了。

**老化。** 活性表面积损失、孔隙堵塞、颗粒失联 → \(C_1\) 总体下降。同时 \(R_1\) 上升，\(\tau_1\) 方向不确定：\(R_1\) 涨得多则回弹变慢（常见），面积损失主导则 \(\tau\) 也可能缩短。不要单独用 \(C_1\) 或 \(\tau_1\) 当 SOH。

## 5. 不要和谁混

| 不要当成同一个 | 差别 |
|----------------|------|
| 电子学电容 / 滤波电容 | 数量级和机理都不同；这里是界面面积 × \(C_{\mathrm{dl}}\) |
| \(R_1\) | 幅度；\(C_1\) 只改快慢 |
| \(C_2\) | 慢扩散的集总，通常比 \(C_1\) 大一个数量级 |
| 方案 B 的 \(C_1^\star\) | 约定钉死的参考电容，不是辨出来的 \(C_{\mathrm{dl}}(s,T)\) |

核心就一句：\(C_1\) 是双电层（加一点扩散）的集总电容，用法拉到万法是因为活性面积大；它不改稳态极化幅度，只和 \(R_1\) 一起定秒级的建立 / 回弹快慢。
