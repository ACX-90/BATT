---

## 1. 它是什么

本仓库的网格和单条仿真由解析模型 `NMC100AhECM` 生成。每一步它先按 \((I,T,s)\) 算出自己的电路参数，再代入与训练相同的离散 ECM，得到电压。写进 CSV 的那三列

\[
R_0^{\mathrm{tch}},\ R_1^{\mathrm{tch}},\ C_1^{\mathrm{tch}}
\]

就叫**教师参数**：教师网络（这里是闭式乘性因子，不是另一个 MLP）当时用的 \(R,C\)。

它们是「生成器手里的旋钮」，**不是**实验室 HPPC 拟合出来的标签，更不是实车上能测到的量。`Doc/02-a` 开篇就写：监督信号只有端电压，**没有** \(R_0,R_1,C_1\) 标签。教师列是合成数据附赠的对照，主损失不许吃它们。

和另外几个「真」的差别：

| 列 / 量 | 是什么 | 能当主监督吗 |
|---------|--------|----------------|
| `u_t_meas_v` | 端电压测量（合成时 = 真电压 + 噪声） | **能，而且应该** |
| `u_t_true_v` | 无噪声真电压 | 合成对照可以；现场没有 |
| `r0_ohm` 等教师列 | 解析模型自己的 \(R,C\) | **不能**当主损失 |
| `soc_true` | 仿真积分出来的 SOC | 是输入，不是 \(R\) 的标签 |

现场 CSV 通常只有 \(I,T,s,U_t\)。教师列根本不存在。

---

## 2. 为什么还要保留这些列

三件事，按允许的力度从弱到强：

### 2.1 事后对照

`test.py` / `infer.py` 把 MLP 的 \(R_0,R_1\) 和教师列画在一起，看阶跃是否对上 \(R_0\)、低温是否抬 \(R_1\)。这是**诊断**，不是训练信号。电压已经贴上而教师对不上，优先怀疑激励不足、\(R_1\leftrightarrow C_1\) 对冲（方案 A），或方案 B 下 \(R_1\) 只是「该 \(C_1^\star\) 的等效值」。

### 2.2 监督预热（teacher pretrain）

随机初始化的 MLP 给出的 \(R\) 可以差几个数量级，\(\tau\to 0\) 会让 \(\alpha\) 炸掉。先用教师列在对数域拉几步，把网络放到物理量级上，再切到纯电压损失。`Doc/02-a` §8：比随机初值稳得多。

代码（`teacher_loss`）：

\[
L_{\mathrm{tch}}
=\frac12\mathrm{mean}
\Bigl[
\bigl(\ln\hat R_0-\ln R_0^{\mathrm{tch}}\bigr)^{2}
+\bigl(\ln\hat R_1-\ln R_1^{\mathrm{tch}}\bigr)^{2}
+\mathbf{1}_{A}\bigl(\ln\hat C_1-\ln C_1^{\mathrm{tch}}\bigr)^{2}
\Bigr]
\tag{1}
\]

方案 B / B+ 没有第三项（\(C_1\) 不由 MLP 出）。默认 `pretrain_epochs=5`，然后电压阶段不再加 \(L_{\mathrm{tch}}\)。

用 \(\ln\) 和 \(\ln\tau\) 正则同一理由：电阻按倍数变，线性 MSE 会被大 \(C_1\) 主导。

### 2.3 造「另一只电芯」（对照实验）

`Doc/03-d`：把教师电阻整张乘 1.15，或只抬低温，冒充换对象，用来验收缩放头 / 残差头。这里教师仍不是物理真值，只是可控的合成差异。

不允许的用法：把 \(L_{\mathrm{tch}}\) 和 \(L_v\) 长期加在一起当主损失。那样网络在学「复述解析模型」，灰箱退回学生模型，电压误差穿过 ECM 的那条路被短路。真实电芯的曲面比乘性因子歪，复述教师会学错。

## 3. 预热在计算图上做了什么

预热阶段**不走** ECM，也没有 \(U_p\)、没有 BPTT：

```
x̃ → MLP → (R0, R1[, C1]) → 对数域对教师列
```

电压阶段才是

```
x̃ → MLP → (R0, R1) → ECM → Ût → e = Ût − Ut_meas
```

所以预热给的是参数空间的初值，不给电压梯度。切到 \(L_v\) 之后，网络被允许离开教师曲面——这是设计，不是没训够。合成数据上过拟合一条 HPPC、能收回 \(R_0\) 和 \(\tau_1\)，只是开工检查；上真实电芯后教师列消失，只剩电压。

`ParamMLP` 末层偏置已按 \(R^\star\) 反解 softplus，即使不做预热，冷启动也接近参考点。预热的价值是把 **SOC / 温度形状**先摆到解析模型附近，而不是再定一次参考点。

## 4. 现场和增量：没有教师

`Doc/03-a` §5.2：

- 实车不要开 `--pretrain-epochs`（`increment.py` 已强制 `pretrain_epochs=0`）；
- 续训同一网格时跳过预热，保持；
- 评估主指标是电压 RMSE，不要拿「和教师列的 RMSE」当现场验收。

没有教师还去预热，常见翻车：

- 列不存在，脚本读到 NaN 或填 0，对数域爆炸；
- 误把测量电压、或把 OCV 当 \(R\) 用；
- 用上一只电芯的教师列预热下一只，等于把旧参考点写进头里。

增量验收若仍想看参数，用**旧网格**上的教师对照（合成还在），或抽一段真 HPPC；新年份无脉冲则只报 \(R_0+R_1\)，不单独信拆开的通道。

## 5. 和「真值」有关的其它词

不要和教师参数挤在同一个抽屉里。

| 说法 | 指什么 |
|------|--------|
| 教师参数 | 解析模型逐步写出的 \(R_0,R_1,C_1\) |
| 教师预热 | 用上面这些列做几轮 \(L_{\mathrm{tch}}\) |
| 静置预热 | \(U_{p0}=0\) 或先跑一段 \(I=0\)，与教师无关 |
| `use_true_inputs` | 输入用 `i_true/soc_true/t_true`，不是 \(R\) 的标签 |
| `voltage_target=true` | 电压监督用无噪 \(U_t\)，仍不是教师 \(R\) |
| 方案 B 的等效 \(R_1\) | 钉死 \(C_1^\star\) 后保 \(\tau\) 的 \(R_1\)，即使对上教师 \(R_1\) 也只是同约定下的对照 |
| 舰队 \(f_{\mathrm{fleet}}\) | 已训 MLP 的绝对曲面，部署后当先验；不是 CSV 教师列 |

教师是**离线合成阶段**的产物。上了车，先验改叫 MLP / 表 / \(R^\star\)，残差改叫 \(\delta R_0\) 或 \(\Delta R_{\mathrm{cell}}\)，中间没有「现场教师」。

## 6. 几个容易混的点

**「合成数据上教师 RMSE 降了，说明可以上实车。」**  
合成里教师和电压来自同一套方程，复述教师几乎一定让电压变好。实车没有这套方程。过关条件是：电压损失单独也能收回 \(R_0\) 和 \(\tau_1\)，而且旧探点不塌。

**「主损失加上一点点教师，会更稳。」**  
合成上会把网络焊在乘性因子上，学不到「更歪的真曲面」。要稳用预热 + 平滑 + 方案 B，不要把 \(L_{\mathrm{tch}}\) 留在电压阶段。

**「`test.py` 画了真值 \(R_0\)，那就是标签。」**  
图例里的「真值」在合成上就是教师列。换现场文件，那条曲线应是空的或来自另一次 HPPC，不能回灌进 `teacher_loss`。

**「方案 A 预热了 \(C_1\)，电压阶段就能信 \(C_1\)。」**  
预热只给初值。可观性仍由激励决定。缺回弹时 \(C_1\) 照样漂，该加 \(\ln\tau\) 或改方案 B（`00-0602`）。

**「增量用旧 `best.pt`，要不要再预热一次？」**  
不要。权重大致已在物理量级；现场又没有教师列。`--no-pretrain`。
