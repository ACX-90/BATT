Powered by SpaceXAI Grok 4.6

代码对照：`Src/AI/KF/ekf.py` 的可选 \(\delta R_0\)（默认关）。

「在线」在这里不是「车上跑了神经网络」，而是：**参数跟着当前工况、在秒到分钟的尺度上被递推改写，而且只代表附近那一小块，不是整张 \((s,T,I)\) 曲面。**

---

## 1. 它是什么

电芯一阶 Thevenin 的 \(R_0,R_1,C_1\) 不是常数。离线做法是实验室扫 HPPC，做成表或训一张 MLP。车上没有这种试验，只有不断到来的

\[
\{I_k,\,T_k,\,U_{t,k}^{\mathrm{meas}}\}
\]

以及滤波给出的 \(s_k,U_{p,k}\)。在线辨识用这些流式数据，**每拍或每隔几拍**更新当前工作点附近的电阻（偶尔也更新 \(R_1\)），供本分钟的 SOC / SOP / 电压预测使用。

它记住的是一句话：

> 这一趟、这一段工况，表（或 MLP）偏了大约多少。

不是：

> 整张 \(R(s,T,I)\) 应该长什么样。

`Doc/05` 把它和增量 MLP 拆开：

| | 在线辨识（RLS / 扩状态 EKF） | 增量学习（MLP） |
|--|------------------------------|-----------------|
| 时间尺度 | 秒～分钟 | 一次出车、一次实验、一周 |
| 改什么 | 当前工况附近的局部 \(R\) | 整张 \((s,T,I)\) 曲面 |
| 激励 | 当前有没有脉冲 / 回弹 | 这一批轨迹整体是否可观 |
| 遗忘 | 遗忘因子，**故意**忘掉更早的局部值 | 旧温区 / 旧 SOC 的曲面塌掉（事故） |
| 存储 | 几个状态、一块协方差 | 权重 + 最好还有回放轨迹 |

两者可以叠：MLP 出先验 \(R^{\mathrm{MLP}}\)，在线辨识只跟残差 \(\delta R\)；残差在同一 \((s,T)\) 区连续多天同号，再把片段送去离线增量。**不要**把 `train.py` 嵌进 0.1 s 步进里——那既不是合格的在线辨识，也不是合格的增量学习。

---

## 2. 为什么车上需要这一层

表和 MLP 都是开环先验：

- 老化后同一 \((s,T)\) 的真 \(R_0\) 已经涨了，表还是 BOL；
- 温度计偏 3 °C，查到的是邻档电阻；
- 这一只电芯比舰队均值大 50 µΩ；
- 开机 \(s_0\)、电流零偏会让安时漂，电压对不齐。

SOP、过压裕度、一致性看的是**此刻**的欧姆压降。等下次进实验室重标，来不及。在线辨识的职责就是用当前电压创新，把「表错了多少」吸收进一个很慢、维数很少的状态，而不去改整张曲面。

`Doc/01` 也写：老化后至少应对 \(R_0\) 做在线更新或缩放，否则 SOC 会漂、SOP 偏大。首选特征是 \(R_0\)（边沿可观、稳健），不是 \(C_1\)。

## 3. 「局部」到底有多局部

典型写法（本仓库 `Doc/06` 式 (11)，`ekf.py` 打开 `--dr0` 时）：

\[
R_0^{\mathrm{used}}
= R_0^{\mathrm{MLP}}(I,s^-,T)+\delta R_{0,k}
\tag{1}
\]

\(\delta R_{0,k}\) 是随机游走：

\[
\delta R_{0,k}=\delta R_{0,k-1}+w_k,\qquad
w_k\sim\mathcal{N}(0,q_{\delta R})
\tag{2}
\]

过程噪声 \(q_{\delta R}\) 比 SOC 的 \(q_s\) 还小几个数量级（配置默认 `q_dr0=1e-12`，`q_s=1e-8`）。所以：

- 它跟的是「这一分钟比表偏大 50 µΩ」这种慢偏差；
- 它**没有** \((s,T)\) 下标，换到另一个 SOC / 温度，同一个 \(\delta R_0\) 会被错误地带走，直到新的电压创新把它拧过来；
- 它不写回 MLP，也不生成一张新表。

这和 \((s,T)\) 分箱表不同：分箱是「只改当前格、邻格不动」。随机游走是「全空间共用一个偏置」。更宽的在线头（`Doc/07` 的 18 个数 \(\Delta R(I,s,T)\)）介于两者之间：能随特征变一点，但仍不是离线训好的曲面。

## 4. 两种常用算法

### 4.1 RLS（递推最小二乘）

把测量写成对未知参数线性（或冻结非线性部分之后线性）的回归，再逐步更新。遗忘因子 \(\lambda\in(0,1)\)（常见 0.98–0.999）让旧样本的权按 \(\lambda^{k-j}\) 衰减，记忆长度大约 \(1/(1-\lambda)\) 拍。

对 \(R_0\) 最干净的信息是电流阶跃：

\[
R_0\approx\frac{\Delta U_{\mathrm{instant}}}{I}
\]

边沿上回归几乎就是这一下。极化支路要先减掉 \(U_p\) 和 \(\Delta U_{\mathrm{ocv}}\)，否则快极化会混进 \(R_0\)（`Doc/01` 的采样延迟陷阱，在线版同样成立）。

RLS 便宜、好放 MCU，不管曲面。遗忘因子是**设计出来的遗忘**：希望跟上慢变，不是灾难遗忘。

### 4.2 把电阻扩进 EKF（双估计 / AEKF）

最小 SOC 滤波的状态是 \(\mathbf{x}=(s,U_p)\)，**不是**在线辨识。把 \(R_0\) 或 \(\delta R_0\) 扩进去，才变成局部在线辨识：

\[
\mathbf{x}_k=\begin{bmatrix}s_k\\ U_{p,k}\\ \delta R_{0,k}\end{bmatrix}
\]

测量方程多一条对电阻的通道。本仓库在 `estimate_dr0=True` 时：

\[
\mathbf{H}_k
=\bigl[
\partial U_{\mathrm{ocv}}/\partial s,\;
-1,\;
-I_k
\bigr]
\tag{3}
\]

第三列就是 \(\partial\hat U_t/\partial(\delta R_0)=-I\)：静置 \(I=0\) 时这一列是 0，本拍不提供 \(R_0\) 信息——和 `Doc/03` 里电压对 \(R_0\) 的局部导相同。

\(s\)、\(U_p\)、\(\delta R_0\) 抢同一条创新 \(e^{\mathrm{pri}}\)。靠过程噪声分赃：

- \(q_s\) 过大：电阻老化被改成 SOC 漂移，满电点越来越歪；
- \(q_{\delta R}\) 过大：电流零偏、OCV 误差被写成内阻；
- 调反了，在线辨识比不辨更糟。

`Doc/06` 写明：可以当 MLP 的残差通道，**不要用它替代增量学习**。也不要把整张 MLP 权重塞进 KF——维数几百、不可观、和 \(s\) 强耦合。

联合估 \(C_1\) 在线尤其危险：`Doc/01` §5.6 要求对 \(C_1\) 做上下界和慢变化约束，否则飞；工程上宁可辨 \((R_0,R_1,\tau_1)\)，或方案 B 把 \(C_1\) 钉死，只跟 \(R_0\)（最多 \(R_1\)）。

## 5. 可观性：没有激励就不要改 \(R\)

在线辨识和离线电压训练看见的是同一套电路：

| 波形 | 主要可观 | 在线该不该动 \(R\) |
|------|----------|-------------------|
| 电流阶跃边沿 | \(R_0\) | 可以，更新次数少 |
| 脉冲末段近稳态 | \(R_1\)（方案 B 即幅度） | 可以 |
| 搁置回弹 | \(\tau_1=R_1C_1\) | 可动 \(R_1\)；不要这时猛改 \(R_0\) |
| 长时恒流 | 几乎只有 \(R_0+R_1\) | 只信和电阻，拆开的两个通道不可单独信 |
| 静置、\(I=0\) | \(\partial\hat U/\partial R_0=0\) | **不要**改 \(R_0\)；让 KF 改 \(s,U_p\) |
| OCV 平台、小电流 | SOC 也弱可观 | 降低增益，或放大 \(R_v\) |

恒流走到极化稳态后：

\[
e\approx -I(R_0+R_1)+\Delta U_{\mathrm{ocv}}
\]

卡尔曼会用 \(s\) 去补和电阻误差。在线辨识若在这时猛更新，就会把容量误差、OCV 过期、电流零偏写进 \(\delta R\)。门控和增量那一套相同：要有边沿，或有相对 \(\tau_1\) 足够长的静置；平台区最多慢纠 \(s_0\)。

本仓库 SOC-EKF 已用 \(\lvert\partial U_{\mathrm{ocv}}/\partial s\rvert\) 调度 \(R_v\)（`schedule_rv`），那是保护 SOC，不是给电阻辨识发执照。电阻通道还要自己看 \(\lvert I\rvert\) 和 \(\lvert\Delta I\rvert\)。

## 6. 本仓库实际在哪一层

默认闭环（`Src/AI/KF`，`estimate_dr0=False`）：

```
每 0.1 s：
  安时预测 s⁻ → MLP(I, s⁻, T) → R0, R1
  ECM 预测 Up⁻、Ût⁻
  EKF 只更新 (s, Up)
```

这是**在线 SOC / 极化估计**，电阻完全来自离线 MLP。文档一期明确：KF 不改 \(\theta\)。

打开 `--dr0` 才多一个慢变 \(\delta R_0\)，这才是仓库里那条真正的在线辨识通道，而且默认关。增量（`increment.py` 的 replay / scale / finetune）是停车后的离线批次，不是在线辨识。

和其它层的关系：

```
离线 MLP / 表     整张 R(s,T,I)          小时～周，人看曲线
     │
     ▼
EKF (s, Up)       纠安时、跟极化          每拍 0.1 s
     │
     ▼  可选
δR0 随机游走      这一趟局部偏置          分钟级，很慢
     │
     ▼  可选、离线
增量 MLP / k0,k1  改曲面或整体缩放        出车 / 一天
```

`Doc/07` 的 10 mV / 0.1 s 反传 18 个数，是 MCU 上「存不下 Replay 时」的工程折中。计算上是在线的，统计上是无回放、相关样本刷头。文档态度：10 mV 死区可学，持续超限仍每 0.1 s 改 \(R\) 不要照搬；至少加电流闸和降频。那一路更接近「很瘦的在线增量」，不是本节的 \(\delta R_0\) / RLS。

## 7. 不要在线辨的东西

| 对象 | 原因 |
|------|------|
| \(C_1(s,T)\) 逐步 | 可观性比离线更差，和 \(R_1\) 对冲更凶；`Doc/01` 说要加界，仍容易飞 |
| 整张 MLP 的 \(\theta\) | 维数大、和 \(s\) 耦合；逐步反传 = 用当前窗口洗掉旧曲面 |
| OCV 表 | 外生。表过期时电压误差会进电阻，脉冲边沿随后对不上 |
| SOH / 寿命维 | 在线状态里没有「第几周」；缺维时涨阻和换对象、和温度对不上分不清 |
| 包级电流零偏（每芯各学一份） | 800 V 上 \(b_I\) 是一条分流器。每芯 \(\delta R\) 会一起涨，看起来像全包 SOH 掉了（`Doc/08`） |

`Doc/04` 把方案 B 定为电压估计、SOP、**在线内阻**的默认：\(C_1\) 钉死，在线只跟 \(R_0\)（老化引起的 \(\tau\) 变长会折进 \(R_1\)，电压仍可能贴上，物理解释更糊，但比联合估 \(C_1\) 稳）。

## 8. 几个容易混的点

**「EKF 每拍都在跑，所以已经在做在线辨识。」**  
默认 EKF 只辨 \(s,U_p\)。电阻若锁在 MLP 上，辨的是状态不是参数。

**「在线辨识就是增量学习的实时版。」**  
时间尺度、改的对象、遗忘的含义都不同。在线跟的是局部残差；增量改的是曲面。把局部残差的轨迹攒起来再增量，才是文档推荐的叠法。

**「遗忘因子和灾难遗忘是一回事。」**  
RLS 的 \(\lambda\) 是让**当前格**的旧估计过期，以便跟踪慢变。MLP 无 Replay 地扫新温区，是把**没出现的格**一并改掉。前者是功能，后者是事故。

**「静置电压还有几毫伏，赶紧改 \(R_0\)。」**  
\(I=0\) 时 \(\partial\hat U/\partial R_0=0\)。那几毫伏是 OCV、\(s_0\) 或残余 \(U_p\)。`Doc/07` 的 10 mV 在静置上是错触发。

**「\(\delta R_0\) 跟了几天都是正的，说明在线辨识已经把老化学会了。」**  
它只会一个偏置。形状变了（某 SOC 鼓包）、新温区没覆盖，它既填不上洞，也记不住寿命维。该交给缩放 \(k_0,k_1\) 或离线增量，并先排除电流零偏和 OCV 过期。

**「联合估的 \(R_0\) 可以直接当 SOH。」**  
只有激励够、\(q\) 没调反、休息点 SOC 仍钉住时，\(\delta R_0\) 的趋势才有健康含义。否则它是「电压对不齐」的垃圾桶。
