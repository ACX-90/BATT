## 1. 它是什么

慢极化电容 \(C_2\) 是二阶 Thevenin 里第二条并联 RC 的电容。它同样不是一只真实电容器，而是把**扩散过程里能「暂存」的锂**集总成储能元件：

\[
\tau_2 = R_2 C_2
\]

\(R_2\) 定慢极化能长到多高（`00-0204`），\(C_2\) 定这条指数有多慢。稳态时 \(U_{p2}\to I R_2\)，与 \(C_2\) 无关——和 \(C_1\) 不进稳态电压是同一件事，只是时间尺度换成几十秒到数分钟。

叠加模板参考点 \(C_{2,\mathrm{ref}}=3.2\times 10^{5}\,\mathrm{F}\)，配 \(R_2=0.28\,\mathrm{m}\Omega\) 得 \(\tau_2\approx 90\,\mathrm{s}\)。比快支路 \(C_1=2.8\times 10^{4}\,\mathrm{F}\) 大约一个数量级：扩散「储」的电荷比双电层多。

---

## 2. 物理来源

液相孔隙和固相颗粒里的浓度场，本身就是分布参数：厚度（或半径）上每一个薄层都有一点容量。频域 Warburg / 有限空间扩散对应的是连续时间常数谱。2RC 把它收成一只电容，只保住谱里最显眼的那一档（约 \(\tau_2\sim L^2/D\) 或 \(R_{\mathrm{p}}^2/D_{\mathrm{s}}\)）。

和 \(C_1\) 的分工：

| | \(C_1\) | \(C_2\) |
|--|---------|---------|
| 主要物理 | 双电层 \(C_{\mathrm{dl}}\times\) 活性面积 | 浓度场里可逆的「储锂」 |
| 充电回路经过 | \(R_{\mathrm{ct}}\)（界面） | 扩散等效电阻 \(R_2\) |
| 数量级（100 Ah） | 万法 | 十万法 |
| 典型 \(\tau\) | 数秒到十几秒 | 几十秒到数分钟 |

电容电压仍不能突变：撤流瞬间 \(U_{p2}\) 还在，然后按 \(\tau_2\) 慢慢放掉。这就是回弹后段那条慢尾巴——快支路已经消完，慢电容还在吐电荷。

再低频的准电容爬升、第二个很大的弧，一只 \(C_2\) 也吃不干净，那是 3RC / Warburg / 分数阶的事，BMS 默认都不上。

---

## 3. 为什么比 \(C_1\) 更大、更漂

双电层只涉及界面几个纳米的电荷分离；扩散涉及整张极片和整颗颗粒里的锂浓度。可参与「暂存」的锂多得多，等效电容就大。\(\tau_2=R_2 C_2\) 要到 90 s：\(R_2\) 只有 \(R_1\) 的四成左右，全靠 \(C_2\) 把时间常数拉长。

辨识上 \(C_2\) 比 \(C_1\) 更不可观：

- 要看见它，搁置得够到 \(\sim 3\tau_2\)（模板至少数分钟）；默认 SEQUENCE 的 120 s 静置只有约 \(1.3\tau_2\)，尾巴看得到、电容定不准
- 与 \(R_2\) 对冲：同一条慢指数，\(R_2 C_2\approx\mathrm{const}\) 的双曲线照样存在
- 和 \(R_1\)、OCV 静置不够、温度漂移抢同一段慢电压

所以物理上先盯 \(\tau_2\) 是否光滑、是否和 \(\tau_1\) 差开，再算 \(C_2=\tau_2/R_2\)。工程上更稳的是钉死 \(\tau_2\) 或钉死 \(C_2\)，只让 \(R_2\) 随工况变——和快支路方案 B 钉 \(C_1^\star\) 是同一逻辑。

---

## 4. 随工况变的物理原因

**SOC。** 与 \(C_1\) 类似：两端有效扩散容量往往略降，中段相对高。曲线极易被辨识噪声弄脏，不要从 \(C_2\)–SOC 读结构。

**温度。** 扩散系数热激活，主要改的是 \(R_2\)（降温电阻升）。\(C_2\) 本身随温度轻度增加（规范 \(E_a=-4\,\mathrm{kJ/mol}\)）。\(\tau_2(T)\) 的主因仍是 \(R_2(T)\)：低温慢尾巴可以拖到数分钟。

**电流。** 浓度场容量不随倍率线性变。规范对 \(C_2\) 不做电流修正。

**老化。** 孔隙堵塞、裂纹、掉活性 → 等效扩散容量下降，\(C_2\) 总体降。不要单独用它当 SOH。

生成器落地：\(\tau_2\) 钉在 90 s，\(R_2\propto R_1\)，于是 \(C_2=\tau_2/R_2\) 随 \(R_2\) 反比变。这比规范里 \(C_2(s,T)\) 的独立因子更粗，但保证快慢永远差开。规范因子表里低温 \(\tau_2\) 会拉到数分钟；代码里 \(\tau_2\) 不随温度变，冷态慢支路更快、幅度更大（因为跟着 \(R_1\) 的 Arrhenius）。读对照曲线时以代码为准。

## 5. 不要和谁混

| 不要当成同一个 | 差别 |
|----------------|------|
| \(C_1\) | 双电层，秒级；\(C_2\) 是扩散储锂，分钟级 |
| 电子学电容 | 同样是界面/浓度场集总，不是元件标称值 |
| 固定的 \(\tau_2\) | 生成器钉的是时间常数；\(C_2\) 随 \(R_2\) 反比，不是第二张独立曲面 |
| OCV 没静置够 | 小时级电压还在爬，那是更慢的弛豫 / 滞后，不是这只 \(C_2\) |

核心就一句：\(C_2\) 把扩散浓度场收成一只比双电层大一个数量级的电容，只定慢极化有多慢；稳态幅度在 \(R_2\) 上，缺长搁置时它比 \(C_1\) 更不可观。
