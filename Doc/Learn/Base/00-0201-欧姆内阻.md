## 1. 它是什么

欧姆内阻 \(R_0\) 是电流一变、端电压立刻跟上的那一段压降，**不经过电容充电**。一阶 Thevenin 里它是串在回路里的纯电阻，不进极化状态 \(U_p\)：

\[
U_t = U_{\mathrm{ocv}}(s,T) - I R_0 - U_p
\tag{1}
\]

瞬时压降 \(\Delta U_0 = I R_0\)。参考点（SOC 50%、25 °C、1C）模板值 \(0.80\,\mathrm{m}\Omega\)，100 A 上就是 80 mV 的边沿跳变。

它不是口头上那个「电芯内阻」。10 s DCR、动态电阻 \(R_{\mathrm{dyn}}\) 都还含极化支路。本仓库 \(R_0\) 只指瞬时项；极化幅度是 \(R_1\)（`00-0202`），快慢是 \(C_1\)（`00-0203`）。

---

## 2. 物理来源

\(R_0\) 是电子通路和离子通路里那些**没有储能、电流一过就有欧姆压降**的部分的集总：

| 贡献 | 发生在哪 | 为什么是「欧姆」 |
|------|----------|------------------|
| 电解液 / 隔膜孔隙里的离子电阻 | 液相 Li⁺ 在孔隙中迁移 | 浓度来不及重新分布时，就是 \(IR\) |
| 集流体、极耳、焊点、软连接 | 电子从极耳进电极 | 金属电阻，µs 级就稳定 |
| 颗粒–颗粒、颗粒–集流体接触 | 导电剂 / 接触点 | 接触电阻，同样瞬时 |
| 电极电子导电网络 | 活性颗粒 + 导电炭 | 电子在固相里走 |
| SEI / CEI 的欧姆分量 | 表面膜的电子/离子阻抗里偏阻性的那截 | 膜电容很小，边沿上看起来像电阻 |

电化学上真正的电荷转移和扩散都带电容或浓差，时间常数从亚秒到数分钟，进 \(R_1C_1\) 或 \(R_2C_2\)。\(R_0\) 把「来不及储能」的那一截单独拎出来。

EIS：Nyquist 高频实轴截距 \(R_\Omega\)。HPPC：电流阶跃后第一个采样点的 \(\Delta U/I\)。频域截距比时域第一个点更干净——0.1 s 采样已经把一部分快极化的头算进 \(R_0\) 了。

## 3. 为什么是瞬时的

金属里的电子、电解液里尚未形成浓度梯度的离子迁移，时间尺度是 µs–ms。相对 BMS 的 0.1 s 步长，它们在一个采样间隔内已经走完。电路上就是一只没有并联电容的电阻：电流阶跃时电压同步阶跃，没有指数弯。

极化支路则要给 \(C_1\)（以及 2RC 的 \(C_2\)）充电，\(U_p\) 按 \(\tau=RC\) 爬升。所以一条脉冲电压天然分成两截：

```
边沿直跳  →  R0          （欧姆，无储能）
随后指数弯 →  R1C1（+ R2C2） （极化，有储能）
```

热上也不同：欧姆热 \(I^2 R_0\) 电流一过就有；极化热 \(I\cdot U_p\) 要等电容上的电压长起来。中高倍率、中高温，产热大头通常是 \(I^2 R_0\)。

## 4. 随工况变的物理原因

\(R_0\) 不是常数。模板写成乘性因子，参考点 \(0.80\,\mathrm{m}\Omega\)。方向都来自上面那些通路怎么变：

**温度（最强）。** 电解液电导率和 SEI 离子传导都是热激活，近似 Arrhenius。模板 \(E_a=16\,\mathrm{kJ/mol}\)，在三个 1RC 参数里最小：−20 °C 约升到 3 倍，不如 \(R_1\) 猛。低温功率差不要只怪 \(R_0\)。

**SOC（浅 U）。** 中段通路最好。低 SOC：正极电子电导下降、电解液锂离子活度变、负极近空嵌，接触和离子通路都变差。高 SOC：高镍 H2–H3 相变（约 4.15–4.25 V）晶格收缩，接触变差，可出现局部台阶。中段小凸起多来自负极石墨 staging。

**电流。** 真欧姆与 \(I\) 无关。0.1 s 边沿已经把亚秒级电荷转移走完，工程 \(R_0=R_\Omega+R_{\mathrm{ct}}^{\mathrm{fast}}(I)\)，所以 2C 边沿低于 1C，低温更明显。补偿闭式（对称 BV）：

\[
\eta_{\mathrm{BV}}=\frac{2RT}{F}\,\mathrm{asinh}\bigl(I/I_s\bigr),\qquad
R_{\mathrm{ct}}(I)=R_{\mathrm{ct}}^0\,\frac{\mathrm{asinh}(|I|/I_s)}{|I|/I_s}
\]

电阻乘性 \(R_0(I)=R_{0,\mathrm{ref}} h(I)/h(I_{\mathrm{ref}})\)，或电压加性 \(\Delta U_0=IR_\Omega+\eta_{\mathrm{BV}}\)。仓库默认弱软化 \(h=1/(1+k_0|I|/I_{1\mathrm{C}})\)，\(k_0=0.06\)，不是全量 asinh——全量写在 \(R_1\)（`00-0202`）。不要两边各乘一份。自热、采样偏晚会再叠一点软化。详见 `Doc/01-a` §3.4。

**老化。** SEI 变厚、电解液消耗、岩盐相、颗粒开裂、导电剂脱落、产气松接触——条条都加欧姆通路。所以 \(R_0\) 几乎随 SOH 单调升，是最稳的电学老化指标。日历老化同样抬，通常慢于循环。

**充放。** 不对称弱于 \(R_1\)：低 SOC 放电略高，高镍高 SOC 充电侧可能更高。根子仍是两端接触和离子活度，不是 Butler–Volmer。

## 5. 不要和谁混

| 不要当成 \(R_0\) 的 | 差别 |
|---------------------|------|
| 10 s DCR / \(R_{\mathrm{dyn}}\) | 已含 \(R_1(1-e^{-t/\tau})\)，有时还有一点点 \(R_2\) |
| \(R_0+R_1\) | 长时直流内阻；恒流末端看见的是和，不是边沿 |
| EIS 半圆直径 | 那是 \(R_{\mathrm{ct}}\) 一类，对应 \(R_1\) |
| 采样偏晚的「第一个点」 | 已经掺了快极化，偏大 |
| 全量 BV \(\eta_{\mathrm{BV}}\) / asinh | 那是 \(R_1\)；边沿里快头才进工程 \(R_0\)，不要补两次 |

核心就一句：\(R_0\) 是电子/离子通路里不储能的那截电阻，电流阶跃时电压同步跳；极化要给电容充电，不进这一项。
