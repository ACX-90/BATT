## 13. 容易混的一对词

| 不要当成同一个 | 差别 |
|----------------|------|
| 续训 vs 增量 | 同一网格接着跑 epoch ≠ 新分布还要保住旧曲面 |
| 在线 RLS/EKF vs 增量 MLP | 秒～分钟改局部 \(R\) ≠ 批次改整张曲面 |
| \(e^{\mathrm{ol}}\) / \(e^{\mathrm{pri}}\) / \(e^{\mathrm{post}}\) | 增量吃开环；滤波吃先验；后验已被状态吞掉 |
| \(s^{\mathrm{ah}}\) / \(s^-\) / \(s^+\) | 纯安时 / 预测 / 后验；MLP 用 \(s^-\)，损失用 \(s^{\mathrm{ah}}\) |
| \(U_p\) vs \(h\) | 电路极化（要留）vs 网络路径记忆（会和 \(U_p\) 抢电压） |
| 方案 A 的 \(C_1(s,T)\) vs \(C_1^\star\) | 每步自由量 vs 约定电容；B 的 \(R_1\) 是等效值 |
| 物理 \(R_1\) vs 等效 \(R_1\) | A 追求前者；B 在固定 \(C_1^\star\) 下保 \(\tau\) |
| \(R_1\) vs \(R_2\) | 界面秒级 vs 扩散分钟级；BMS 只出前者 |
| \(C_1\) vs \(C_2\) | 双电层万法 vs 扩散储锂十万法；缺长搁置时 \(C_2\) 更不可观 |
| 叠加 2RC vs 拆分 2RC | 生成器在 1RC 上再加慢支路 vs 实验室把原 \(R_1\) 拆成快+慢 |
| Replay 轨迹 vs 逐步样本 | 整条 BPTT 才看得见回弹；打散成单步 \(R_1\) 更不可观 |
| 10 mV 死区 vs 激励门 | 噪声附近不动 ≠ 静置/小电流也不该改 \(R\) |
| SGD vs Adam | 无状态、车上必须；有 \(m,v\)、实验室默认。不能把 Adam 的 `lr` 抄到 \(\log k\) 上 |
| 窗级 SGD vs 按拍 SGD | 10 s 合成一步 ≠ demo 的 0.1 s 一步。前者是协议，后者会洗头 |
| 填洞 vs 老化 | 新温区该长曲面 ≠ 同一 \((s,T)\) 的 \(R\) 已经变了 |
| 缩放 \(k\) vs 残差头 18 个数 | 整体涨阻用 2 个数；形状真偏才需要头 |
| 残差头 vs \(\delta R_0\) / RLS | 对象是每芯 \(\Delta R(I,s,T)\)；运行时是无 \(P\)、无 \(\lambda\) 的逐步辨识 |
| ASIL 保护 vs QM 学习 | 过压过流不经 \(\hat U_t\)；头可回退，保护不能回退 |
| 滑窗 1RC vs GRU 出 \(R\) | 更新协议 vs 换骨干；前者可采纳，后者不换 |
