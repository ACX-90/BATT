## 0. 和实验室缩放不是同一个实验

第 0 期 `increment.py --mode scale` 用 Adam，整条 6200 步 BPTT，新年份扫 10 轮。车上没有这个。1a 换成：

| | 实验室缩放（04-a A） | 车上滑窗（本篇） |
|--|---------------------|------------------|
| 可变参数 | \(k_0,k_1\) | 同 |
| 冻 MLP / scaler | 是 | 是 |
| 损失 | 开环电压 | 开环电压 |
| 读旧网格训练 | 否（scale 本来就不读） | **断言不读** |
| 优化器 | Adam | **SGD，无动量** |
| 时间 | 整段轨迹 × 10 epoch | **10 s 窗，新年份只走一遍** |
| 窗内 \(R\) | 每拍 MLP | **中心 \((I,s,T)\) 查一次**，钉住再滚 ECM |
| 门控 | 轨迹级（边沿 / 30 s 静置） | **窗级**：边沿或 ≥3 s 静置；恒流跳过 |
| 通道 | 两 \(k\) 一起动 | 大电流只动 \(k_0\)，回弹静置只动 \(k_1\) |

验收仍用 04-a 涨阻口径：新年份低于冻结、\(k\) 朝电阻乘子走且两通道大致齐、旧集变差是缺维。车上目标是收掉 \(I\Delta R\) 墙，不是把 4 mV 地板再压 1 mV。

断言（写进脚本，不是口头）：

- 更新路径不读 `Data/grid/`
- 优化器是 SGD
- 默认 `passes=1`
- 不覆盖 `Data/ai_mlp`

## 2. 怎么读

1. **墙收掉了大半。** 冻结 20.8 mV 是 \(I\Delta R\)；一遍滑窗到 6.8 mV，离地板 4.2 mV 还有约 2.6 mV。没有旧集、没有 Adam、没有 10 轮重扫，已经能当车上 1a。
2. **\(k\) 朝 1.15 走，两通道大致齐。** 1.19 / 1.17，和离线缩放 last 的过冲同形态。参考点 +19% / +17%，不是微调那种拆通道。
3. **旧集 4.2→21.7 mV 不是遗忘失败。** 缺维：同一 \((I,s,T)\) 不能同时记住 BOL 和 ×1.15。`Doc/03-a` §3.5。
4. **恒流不更新成立。** 85 窗、0 步。拆 \(R_0/R_1\) 仍然只靠边沿和回弹。
5. **边沿必须看窗缝。** 第一版 `np.diff` 只在窗内做，1C 起跳落在 10 s 对齐缝上，\(k_0\) 几乎不动。拼上窗前一拍之后，大电流更新从几乎 0 变成 82。MCU 实现同样不能只看窗内差分。
6. **全局 \(k\) 会晃。** 低 SOC 冷端 \(k_0\) 先到 1.09，中段贴 1.15，SOC 90% / −10 °C 掉到 1.09 再爬到 1.19。这是 1×1 网格的上限，不是门控坏了。形状任务交给 1b。
7. **D 不改排位。** \(k\) 仍是 1.18 / 1.18，朝 1.15。7 mV 噪声只垫底板、打穿 2 mV 窗门；边沿 / 恒流门还在。
8. **G 两通道本来不齐。** \(k_0\to 1.10\)、\(k_1\to 1.15\)，轻一档涨阻，正途仍是缩放。

1a 三任务并排（同一套窗 / SGD / 门控 / 一遍）：

## 4. 1b：\((s,T)\) 上 5×4 \(k\) 网格（已跑）

和 1a 同一套滑窗 / 门控 / SGD / 中心电阻 / 无 Replay。全局两个 \(k\) 换成 MCU 那张出厂节点：SOC 10/30/50/70/90% × \(T\) −10/10/30/50 °C。双线性插值；梯度只回权重大的 2～4 个顶点；大电流只动 \(k_0\)、回弹只动 \(k_1\)；邻点光滑只罚**本窗活着的角**，免得没去过的格子被拉走。

### 4.2 只抬 −10 °C（车上版填洞）

### 4.3 1b 怎么读

1. **形状任务网格赢。** 只抬 −10 °C 时中温 \(k\approx 1\)、中温电压 2.54→2.39 mV；1a 会把参考点乘到 1.17。
2. **整张涨阻网格不比 1a 快。** 20 个节点要多趟才齐；一遍电压 13.4 mV，差 1a 的 6.8 mV。这是实验室已经知道任务 A 时的速度差，**不是**车上先走 1a 的理由：单窗分不出全局还是局部，先抬两个 \(k\) 会把中温写坏。
3. **\(k_1\) 热端门控看不见。** 高温极化幅度小，15% 涨阻过不了 2 mV。不是插值漏了。
4. **双线性会渗到邻列。** 错配在 −10 °C、数据有 +5 °C 时，T+10 会略偏。再远的节点保持 1。
5. **恒流仍 0 更新。** 和 1a 同一道门。

### 4.4 车上怎么选 1a / 1b

更新前不要做「各温区同号吗？」这种分类。当前窗只看见当前 \((s,T)\)。

1. 许不许可写 \(R\)：没激励 / 全包同向先查零偏 / 只有这一趟 → \(\delta R_0\)。与 1a、1b 无关。
2. 许可写则**默认写 1b**：梯度只回这窗点到的 2～4 个顶点。没去过的格保持 1。
3. 事后读节点：各列都到约 1.15 就是全局涨阻；只有冷端动就是局部。只去过一列时还不知道，不要把这一列抄走。
4. 1a（1×1）留给：本篇任务 A 这种已经贴好标签的对照；或者车上若干温区节点已经齐了，再把后续窗收到两个数。不要冷启动先 1a。

## 5. 1c：3×8×2 残差头（只对照，已跑）

### 5.3 1c 怎么读

1. **纯涨阻不赢 1a。** 一遍 10.58 mV，对 1a 的 6.84 mV；四遍 8.60，对 1a 仍差，只跟 1b 四遍打平。过关条件「不得赢全局 \(k\)」成立。
2. **形状不赢 1b。** 只抬 −10 °C 时中温 \(k\sim 1.08\)、中温电压变差；网格中温几乎不动。过关条件「形状也赢不了则丢掉」成立。
3. **加性 18 个数凑不出乘性 1.15。** 热端 \(k_0\) 到 1.27、冷端 1.09，是 \(\Delta R\) 叠在已经随 \(T\) 变的表上的几何，不是门控坏了。
4. **多扫会抢权重。** 第二遍 8.22 最好，三四遍回升。没有局部节点可隔离。
5. **恒流仍 0 更新。** 和 1a / 1b 同一道门。边沿跳过 619，与 1a 相同。
6. **车上丢掉。** 不要加宽、不要当默认增量。可变集是 1b 的 \(k\) 网格；1a 是节点已齐之后的加速档。
