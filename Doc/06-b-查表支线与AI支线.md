第 1 期已经把能上车的 SoX 收成：**离线把网烤成表，车上只改每芯 \(k\) 网格。** 这是支线 1，继续做，精度还能抠。

## 1. 为什么要拆

`Doc/05-c` 已经把这条路走完一截：

| 车上冻结表 | 全网格电压 | 180 串 × 10 Hz（400 MHz 单核） |
|------------|------------|--------------------------------|
| 64×64 前向 | 4.24 mV | **43.6%**，超 05-a 一成核 |
| 16×16 蒸馏 | 9.81 mV | 4.8% |
| **3D 查找表 9×11×9** | **4.56 mV**（贴教师） | **估 ~0.3%** |

查完再乘 \(k\) 网格，整包 SoX 大约 1%。3×8×2 头第 1 期已经丢掉（`Doc/05-d` §5）：纯涨阻赢不了两个 \(k\)，只抬冷端会写坏中温。

于是出现一个向上不好讲的结果：

- 项目名叫 AIBMS，量产路径却是 **查找表 + 每芯几十个乘子**。
- TC4D7 的 PPU、ST / NXP 的 NPU，按现在这套活都用不上（`Doc/A0-a`：3×8×2 是杀鸡；`Doc/A0-b`：NPU 吃 INT8 推理，不吃 float SGD）。
- 若到结题还只有支线 1，等于告诉上面：AI 只在实验室当教师，车上和传统标定表同类。

拆支线不是为了否定查表。查表是目前唯一塞进 `Doc/05-a` 信封、精度还贴教师的 SoX。拆开是为了：**查表继续当能过门的主交付；加速器另立一条，必须拿出比表更好的数字，否则就承认加速器干的是别的活。**

点式 \(R(I,s,T)\) 本身就是一张光滑曲面。网和表在表示**同一张函数**。AI 不可能在「当表」这件事上稳定超过密表——`Doc/05-c` 已经是反例：蒸馏瘦网比烤表差约 5 mV，负荷还更重。支线 2 要赢，必须做**表写不进去的事**。

### 2.1 出厂数据：少量 HPPC 换成整包训规格书 MLP

以前的表是这样来的：抽几只电芯，按 SOC × 温度做 HPPC，拟合 \(R_0,R_1\) 填格子。样本少，工况是实验室脉冲，和装成包之后的热 / 电流环境不是同一件事。

现在这条支线改成：

```
抽几包已组装的包
    │
整包激励（不同环境温、不同 SOC 窗口、有边沿、有回弹）
    │
每芯 V + 包电流 I + 模组 / 芯温 T   ← 大量电芯，没有 R 标签
    │
训一份规格书 MLP（方案 B，电压反传）
    │
烤成三维查找表，出厂烧入（全包一份，冻住）
    │
每芯 k 网格出厂全 1，车上自己把散差 / 老化收进去
```

| | 以前 | 现在（支线 1） |
|--|------|----------------|
| 对象 | 几只拆下来的电芯 | 抽已组装的包 |
| 激励 | 实验室 HPPC 网格 | 整包工况：充放 / 脉冲 / 搁置 |
| 标签 | 拟合出来的 \(R_0,R_1\) 点 | **只有端电压**，没有电阻标签 |
| 共用什么 | 每只芯自己的电流 | 一条包电流，每芯一条电压 |
| 产物 | 直接填 \(R(s,T)\) 表 | 一份规格书 MLP → 烤同一张 \(R(I,s,T)\) 表 |
| 芯差 | 标定样本外推，或每芯再做 HPPC | 出厂 \(k\equiv 1\)，车上滑窗自己调 |

规格书 MLP 学的是**这一规格的平均曲面**，不是某一只芯。制造公差、模组位置、后来的涨阻，全部留给每芯 \(k\)。出厂 \(k=1\) 就是「先按规格书走」；冷启动不靠常值 \(R^\star\) 去长 Arrhenius（`Doc/05-a`、`Doc/04-b`）。下线用一次局部 \(k\) 铺进全网格当初值：评在 [`Doc/05-f`](05-f-车上激励与采样同步暂存.md) §6，**默认仍全 1**，不改本条。

和「抽一包跑一圈 = 现成 `Data/grid/`」不是一回事，下面几条已经锁死，跟同事讲的时候不要省：

1. **一只包盖不住 \((s,T)\) 盒子。** 串联包 SOC 挤在几个百分点，温度按模组梯度（`Doc/06-a`）。规格书曲面要靠多包、多起始 SOC、多环境温拼覆盖，不是一包一次充放。
2. **激励必须有边沿和回弹。** 长恒流只能看见 \(R_0+R_1\)，拆不开通道（`Doc/03-a`、`Doc/04-a` F）。整包激励里没有脉冲 / 搁置，训出来的规格书极化是假的。
3. **监督仍是电压。** MLP 出的是方案 B 下的等效 \(R\)，不是 HPPC 拆出来的那套标签。烤表吃的是这张等效曲面。
4. **包电流上的零偏 / AFE 漏电不要写进规格书。** 那是包级状态，出厂训练集就要按 06-a 的门处理；否则平均表会把分流器偏置烤进去，车上 \(k\) 再跟一次。
5. **烤完车上不训网。** 规格书 MLP 只在下线；量产 0.1 s 环查表、乘 \(k\)。
6. **慢尾巴不写 \(k\)。** 真芯 2RC 的静置后段是结构差，不是散差 / 老化。门控见 `Doc/06-a` §3.5，口径见 §2.2。

仓库里现在的 `Data/grid/` + `Data/ai_mlp` 是这条链的**合成替身**（解析模型当「规格书真值」）。真包数据来了，只换教师数据源，不换：方案 B、烤表、出厂 \(k=1\)、车上滑窗。重标按 `Doc/01-b` §8 改 JSON，不改乘性结构。

**向上怎么讲：** 以前用几只芯的 HPPC 填表；现在用整包激励、每芯电压，训一份规格书网，再烤成表。AI 在**出厂以前**，用来从大量 \(V,I,T\) 里抽出可查询的平均曲面。装上车的是表 + 每芯乘子，乘子出厂为 1，后面自己调。这是能过功能安全、能关断学习的 SoX，不是「车上没 AI」。

### 2.2 真芯是 2RC：规格书链还成不成立

**结论：成立。** 2RC 改的是规格书那张表是什么、能准到哪，不是这条出厂链该不该走。§2.1 第 3 条已经写死：监督只有电压，产物是方案 B 下的**等效 \(R(I,s,T)\)**。真芯有慢支路，正是在训这张等效曲面，不是训失败。机制与数量级见 `Doc/02-b` §10、`Doc/02-a` §11、`Doc/01-b` §11、`Doc/04-a` §7.7。本节只收「对支线 1 / 第 2 期门」的口径。

BMS 继续锁 1RC。要改的是数据源、验收和门控，不是把网格改成 2RC，也不是升阶。

#### 2.2.1 先分清两档误差

同一套默认 SEQUENCE、同一噪声种子、同一份 1RC 方案 B 权重（`Data/ai_mlp/last.pt`，3×64×64×2）：

| | `gen_common.bat`（1RC 真值） | `gen_common_rc2.bat`（2RC 真值，权重未改） |
|--|--|--|
| 图 | `Fig/mlp_ecm_test.png` | `Fig/mlp_ecm_test_rc2.png` |
| 电压 RMSE / MAE / MAX | 1.30 / 1.00 / 6.68 mV | **11.56 / 8.89 / 25.84 mV** |
| \(R_0\) RMSE / MAX | 0.008 / 0.023 mΩ | 一样 |
| \(R_1\) RMSE / MAX | 0.042 / 0.118 mΩ | 一样 |

\(R_0/R_1\) 叠得上：点式 \((I,s,T)\mapsto(R_0,R_1)\) 没读 \(R_2\)，教师列仍是快支路。电压误差的慢弯就是 \(U_{p2}\)（叠加约定 \(R_2\approx 0.43\,R_1\)、\(\tau_2=90\,\mathrm{s}\)）。1C 放电 180 s 末 \(\approx IR_2(1-e^{-2})\approx 25\,\mathrm{mV}\)，对着 MAX 25.84 mV。这是 `02-b` **§10.1**（参数尚未被 1RC 拟合改写），也是 04-a H 开环 0.94 → 12.18 mV 的 MLP 版。

真去用 2RC 电压训 1RC 网，不是这个数。那是 **§10.2**：

| | 相对 1RC 真值 | 含义 |
|--|--|--|
| \(R_0\) | 漂 \(\lesssim 5\%\) | 边沿仍可观 |
| \(R_1\) | **+15%～+40%**（参考点常到 0.75–0.90 mΩ） | 兼当一部分 \(R_2\)；\(C_1^\star\) 钉死，慢尾巴全部挤进 \(R_1\) |
| 短窗 RMSE（≤30 s） | 可回到数 mV | 看起来「训好了」 |
| 静置 1–3 min 的 \(e^{\mathrm{ol}}\) | 仍剩 **3–10 mV 同号** | 不在 1RC 值域里，加 epoch 消不掉 |

仓库 `--rc2` 是 **叠加**（1RC 的 \(R_1\) 原样 + 额外 \(R_2\)），总直流内阻被算大一截，故意制造「1RC 吃不干净」。真芯实验室标 2RC 一般是 **拆分**（\(R_1+R_2\approx\) 旧 1RC \(R_1\)）。规格书训真包，幅度冲突比叠加探针小，剩下的主要是一个指数对不上两个指数的形状差。

**不要用叠加 `--rc2` 网格当真芯训练集**，否则 \(R_1\) 会被多抬一截。`--rc2` 只保留作结构差探针，写独立目录（`Data/grid_rc2/`），不要冲 `Data/grid/` 或默认 `Data/nmc100ah_ecm_sim.csv`。

#### 2.2.2 仿真上先做（真包还没来）

默认 `Data/grid/`、`train.py`、烤表、方案 B、\(C_1^\star=2.8\times 10^4\,\mathrm{F}\) **都不要动**。另开影子路径。

1. **「1RC 网在 2RC 电压上训练」已跑。** 网格 `Data/grid_rc2/`（10×10，−10～50 °C，叠加 `--rc2`），`--scheme B --no-pretrain`，权重 `Data/ai_mlp_rc2/`。不要写回 `Data/ai_mlp`。

   电压 epoch ~70 轮后 val 钉在 **15–16 mV**，再续 1000 也下不去。这不是没训够。§10.2 的「短窗回数 mV」是 25 °C 参考点；val 是整条 620 s、20% 抽检，冷端会把平均数钉住。`best.pt` 按温度拆开环（2026-08-28）：

   | | 1RC 教师 / 常温 1C | 2RC 网格上训完 |
   |--|--|--|
   | 参考点 \(R_0\) | 0.80 mΩ | **0.79 mΩ** |
   | 参考点 \(R_1\) / \(\tau_1\) | 0.65 mΩ / 18 s | **0.81 mΩ（+25%）/ 23 s** |
   | 23 °C 整轨 RMSE / MAX | — | **5.4 / 15 mV** |
   | −10 °C 整轨 RMSE / MAX | — | **31 / 97 mV** |
   | 100 条平均 RMSE | — | **11.5 mV**（val 15–16 视抽到的冷条） |
   | 常温 1C 充放峰 | 未改写 25.8 mV（§2.2.1） | 仍约 **26 mV**（\(IR_2\) 量级，\(C_1^\star\) 吃不掉） |

   −10 °C、1C 上 \(\hat R_1\) 被拉到约 7 mΩ、\(\tau_1\approx 200\,\mathrm{s}\)，一只 RC 去追 6–7 min 的慢支路，快回弹对不齐。常温已经落到 §10.2；网格地板是冷端 + 叠加双重计算。真包走拆分，常温地板应对着 23 °C 那一行，不是 −10 °C 的 30 mV。

   不要把 15 mV 当失败去拧 \(C_1^\star\)、切方案 A、或把 `ai_mlp_rc2` 当成规格书。看三件事即可：参考点 \(R_1\) 相对 0.65 mΩ 的偏离（这次 +25%，算通过）、常温短窗是否数 mV、静置半对数是否弯折。

2. **开环按片段切**（`test.py` / `kf_rc2` 都要）：边沿、前 30 s、静置 60–120 s。静置段半对数图：1RC 残差近直线，弯折就是第二 \(\tau\)。贴到 μV 优先怀疑生成器没加上 \(U_{p2}\)，不是 1RC 突然够用。

3. **门控现在会过，这是真问题。** 04-a H：2RC 开环 12 mV，`gate.py`「开环高于 \(3\times\) 噪声」会过。车上更紧：`window.py` 默认 `--rest-s 3`，大电流只动 \(k_0\)、**回弹静置只动 \(k_1\)**。慢尾巴正好长在静置窗里，会把 \(U_{p2}\) 写成每芯 \(k_1\)。要改的门写在 `Doc/06-a` §3.5，不在本期把 2RC 叠进 2A / 2B。

4. **不要为吃尾巴加大 \(q_s\)。** 先验几乎不变是因为滤波已经把慢尾巴啃进 \(s,U_p\)（H：休息 SOC −0.03 → −0.33 pp）。加大 \(q_s\) 会把结构差写成容量。

#### 2.2.3 真包来了：只换教师，不换 BMS

顺序锁死（`Plan.md` 第 N 期 + 本节 + §2.1）：

```
OCV 表（静置够久）
  → 多包、多 SOC、多环境温、有边沿有回弹
  → 规格书 MLP 方案 B，--no-pretrain
  → 烤 9×11×9，出厂一份，k=1
  → 车上滑窗 k；慢尾巴不写 k
```

| 约束 | 为什么 |
|------|--------|
| 先 OCV，再 MLP | OCV 差几 mV，梯度拧 \(R_1\) 去补，看起来像 2RC，其实是表错 |
| `--no-pretrain` | 真芯没有 1RC 教师列；预热会把 \(R_1\) 钉在模板 0.65 mΩ |
| 必须有边沿 + 短搁置 | 长恒流只看见 \(R_0+R_1+R_2\) 投影。搁置至少看到 \(\tau_1\)（20–40 s）；≥5 min 只用来**诊断**双指数，不用长静置电压去压 RMSE |
| \(C_1^\star\) 不动 | 不要为迁就 \(\tau_2\) 把电容拧到 \(10^5\) |
| 零偏 / AFE 按 06-a 的门处理后再进训练集 | 否则平均表把分流器烤进去，车上 \(k\) 再跟一次 |
| 参考点 \(R_1\) 对不上 0.65 mΩ **算通过** | 对上了反而要查是不是还在用仿真教师 |
| 验收不要追仿真 1.3 mV | 常温短窗数 mV、默认静置剩几 mV 弯折，才说明 2RC 真写进数据了 |

\(\tau_2\) 的 \(E_a\) 不小于 \(R_1\)。低温等效 \(R_1\) 膨胀更凶，一包一次充放更盖不住盒子——§2.1 第 1 条更要，不是松了。

#### 2.2.4 落到各层

| 层 | 1RC 仿真（现在） | 真 2RC 训规格书 | 动作 |
|--|--|--|--|
| 规格书 MLP / 烤表 | 短窗 1.3 mV，\(R_1\) 贴 0.65 mΩ | 短窗数 mV；\(R_1\) 是约定 \(C_1^\star\) 下的等效极化电阻 | 烤这张等效曲面。不要和 EIS / HPPC 快支路对表当失败 |
| SOP 10 s | 对齐 | \(R_2(1-e^{-10/90})\approx 0.03\,\mathrm{m}\Omega\)，100 A 约 3 mV | 可忽略 |
| SOP 1–3 min | 对齐 | 偏乐观，量级 \(I^2 R_2\) 的一部分 | 报功率时说明；不为此升阶 |
| EKF | 开环 ~1 mV，休息 SOC 几乎不拉 | 未改写时开环 ~12 mV；训完短窗数 mV + 静置尾巴。先验仍亚毫伏。休息 SOC 可被拉 ~0.3 pp，回弹结束后应退 | 休息点留下常偏先查 OCV / \(U_{p0}\)，不要加大 \(q_s\)。\(\delta R_0\) 静置 \(I=0\) 吃不到尾巴，可保持默认开；长恒流末段盯它会不会把 \(U_{p2}\) 当欧姆 |
| 车上 \(k\) | 「回弹只动 \(k_1\)」对：快回弹就是 \(R_1\) | 60–120 s 同号误差也是「回弹」，\(k_1\) 会慢爬（停车、长搁置、低温 \(\tau_2\) 到数分钟） | **只边沿涨阻，不追慢尾巴。** 看起来像每芯极化在涨，其实是缺 \(\tau\)。全包同号时静置 \(\Delta s\) **不长**，和 06-a 的 \(b_I\) / AFE 能拆开 |
| 包级 2A / 2B | 不需要 2RC | 06-a §5.8 已排在第一列之外 | 门改好即可跑；多出来的是全包同一条静置弯折，中位 \(\Delta s\) 不应被它拉成 \(b_I\) |

四件事不要再绑在同一套电压 RMSE 上：

- **曲面**：用包电压重训规格书，接受等效 \(R_1\)
- **滤波**：允许啃一点 \(s\)，休息点不留常偏
- **\(k\)**：只边沿涨阻，不追慢尾巴
- **门**：开环高不再等于「该增量」；要看残差是 \(I\Delta R\) 还是第二指数

慢尾巴是 **2β** 的对象（表写不进去的残差），先不升阶、不挡 2A / 2B。接法是 \(\delta U\) 不是 \(\Delta R\)，离开参考点用策略关信封，见 [`Doc/06-c`](06-c-1RC查表残差与策略信封.md)。\(k\) 收的是同一 \((I,s,T)\) 上 \(R\) 已经变了（散差、老化）；2RC 是同一点 \(R\) 没变、只是少一条 \(\tau\)。

#### 2.2.5 明确不要

- 把 `Data/grid/` / `gen_grid.bat` 默认改成 `--rc2`
- 用 11.6 mV 或 val 15 mV 当「规格书训失败」，加 epoch 去追 1.3 mV；影子续到 1000
- 方案 A、MLP 出 \(R_2,C_2\)、把 \(C_1^\star\) 拧去迁就 90 s
- 为吃尾巴加大 \(q_s\) 或用 \(e^{\mathrm{post}}\) 反传
- 车上用静置慢尾巴写 \(k_1\)
- 拿叠加 `--rc2` 的 \(R_1\) 去对 HPPC 标签
- 现在升 2RC BMS（`Plan.md`：残差确认是第二指数之后单独立项，钉死 \(C_2\)）。§6 列 3 赢不了列 1 才升；升完车上仍只写 \(k_0/k_1\)，口径 [`Doc/06-c`](06-c-1RC查表残差与策略信封.md) §11

## 3. 支线 2 — 把 AI 用上（追表，尝试超过）

**目标：** 加速器上跑真正的网（或 SIMD 批量网），在**同一套验收**上追支线 1，看能否超过。超过之前，不替换车上默认。

「用上 AI」只允许下面几类。其它先当重演失败。

| 档 | 加速器干什么 | 有没有机会超过查表 | 现在 |
|----|--------------|--------------------|------|
| **2α 车上改共享权** | 冻表不够，要动网本身（瘦网 / 特征） | 只在「还想车上改共享曲面」时成立；纯涨阻不该赢 \(k\) | 16×16 蒸馏已差表 5 mV；3×8×2 已丢掉 |
| **2β 表写不进去的残差** | 1RC 表吃不下的慢尾巴、滞后、路径 | 有，但先按机理拆。信封内 2RC+BV+OCP 已收到 ~2 mV（`eval_nls.md` §7）；GRU 不要去复现双指数 / 通电直线。接法是 \(\delta U\) 不是 \(\Delta R\)；离开参考点用策略关信封 | 口径 [`Doc/06-c`](06-c-1RC查表残差与策略信封.md) §9；未跑残差头；BMS 仍 1RC；先改门，不升阶 |
| **2γ 诊断网** | SOH / 析锂 / 异常，INT8 推理 | **不和 SoX 电压比**。这是 NPU 的本职，也是原厂把 AI 画进 BMS 的叙事（Eatron / P3E / K5） | 未做。PPU/NPU 空着的正当理由 |
| **2δ 180 芯一批滤波** | PPU 打 EKF / ECM / 前向，不是再加宽网 | 不比精度，比占核。查表之后标量核已 ~1%，这一档是「宽网前向还在」才值得 | 05-c：LUT 之后 PPU 留给诊断 |

默认要追的是 **2β 和 2γ**。2α 必须先写出「表做不到、网做得到」的任务，禁止拿任务 A（整张 ×1.15）再训一个头。2δ 不是 AI 故事，是负荷故事，单独记账。

**不要加「用网写 \(k\)」档。** \(k\) 是每芯状态，更新是滑窗 SGD（或以后的脉冲 \(\Delta U/\Delta I\)）。冻住的网出 \(k\) 不是每芯；每芯小网出 \(\Delta R\) 是 1c，已经丢掉；学更新器是在近似 \(-IR\)。口径 [`Doc/06-c`](06-c-1RC查表残差与策略信封.md) §10，不挡 2A / 2B，不换默认。

### 3.1 怎么才算超过查表

对照对象固定：支线 1 的 **3D 9×11×9 + \(k\) 网格**（包级再加 06-a 的门）。不许另选一个更烂的表当靶子。

| 检查 | 支线 2 通过 |
|------|-------------|
| 新年份开环 RMSE | **低于** 同期查表 + \(k\)，不是只低于冻结教师 |
| 旧探点 / 未点到的温区 | 不比查表更差（恶化仍 < 20%） |
| 休息点 SOC / NIS | 不比查表更差；电压贴上但 SOC 歪了先查 03-c |
| 包级同向 | 同样先排除 \(b_I\)，不许靠更猛的网把零偏写成 \(\Delta R\) |
| 车上信封 | 仍不 OTA、不外发、反传离开 0.1 s；ROM/RAM/乘加单独报，可以比查表贵，但必须说清楚贵在哪 |
| 加速器 | 日志里要有 PPU 或 NPU 真正干活；标量核重跑一遍网 **不算** 用上 AI |

电压 RMSE 单独下降不能结题。和第 0 / 1 期同一句。

2γ（诊断）另立指标：漏报 / 误报、和 \(k\) 网格解耦（诊断不改 \(R\) 表，SoX 不靠诊断网改 SOC）。不要把析锂头的准确率拿来宣称「SoX 超过了查找表」。

### 3.2 支线 2 明确不做

这些 `Plan.md` §2、`Doc/05-a`、`Doc/03-b` 已经答完，不借「要用上 PPU」重开：

- 不要 GRU / LSTM 换点式骨干
- 不要增量期切方案 A，或让 \(C_1\) 逐步自由
- 不要原样抄「\(\lvert e\rvert>10\,\mathrm{mV}\) 就每 0.1 s 反传」
- 不要把 3×8×2 加宽再赛一次任务 A
- 不要为了喂饱 SIMD 就在车上解冻 64×64
- 不要用 NPU 做 float SGD（`Doc/A0-b`：工具链是冻结图、INT8、推理）
- 不要用网出 \(k\)、不要用网当写 \(k\) 的门；冻网出 \(\Delta k\) 必须赢同一套特征上的闭式，否则拿掉（口径 [`Doc/06-c`](06-c-1RC查表残差与策略信封.md) §10.3）
- 不要挡 06-a 的 2A / 2B

## 4. 和第 2 期怎么排

## 5. 向上三句话

1. **能上车的 SoX 是查表。** 抽整包测 \(V,I,T\)，训一份规格书 MLP，烤成 7 KB 的三维表；每芯 \(k\) 出厂为 1，自己收散差和涨阻。真芯是 2RC：表是方案 B 下的等效 \(R\)，不是 HPPC 拆签；慢尾巴允许留着，不准让车上 \(k\) 去追（§2.2）。第 1 期数字：涨阻墙能收，18 个数的头收不掉。
2. **AI 加速器另开一条对照。** 同一套电压和 SOC 口径去追这张表。点式电阻曲面上表已经打赢瘦网；要赢只能做表没有的残差或诊断（慢尾巴是 2β，接 \(\delta U\)，口径 `Doc/06-c`；先不升阶）。
3. **两条都要有数字。** 查表继续抠精度；AI 支线要么超过表，要么明确加速器干的是诊断 / 批量滤波，不是把 SoX 再训练一遍。
