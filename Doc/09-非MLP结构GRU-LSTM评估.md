# 09 非 MLP 结构评估：GRU / LSTM 及其它时序网络

> 对象：现有灰箱里「\((I,s,T)\rightarrow(R_0,R_1)\)」这一块，现在是点式 MLP  
> 对照：`Doc/03` 电压反传、`Doc/04` 方案 B、`Doc/05` 增量、`Doc/06` EKF 分工、`Doc/07` 残差头  
> 对齐：`ParamMLP`（无隐状态）、`ecm_forward`（\(U_p\) 已是时序状态）、方案 B（\(C_1\) 钉死）  
> 目的：GRU / LSTM 能不能换掉 MLP、会多出什么、会毁掉什么；并核对「3×8×2 待在一个工况上会忘其它点，换 GRU 能保住」这句印象  
> 本文只做评估，不改 `model.py`

03 写过：参数曲面光滑，两到三层全连接足够。时序记忆现在由 **ECM 的 \(U_p\)** 承担，不由网络承担。换成 GRU / LSTM，等于再引入一套隐状态，和 \(U_p\)、\(R_1C_1\) 抢同一段电压。下面按「接到现有电路上」而不是按 NLP 习惯来评。

---

## 1. 现在 MLP 实际在做什么

逐步、无记忆：

\[
\bigl(R_{0,k},R_{1,k}\bigr)
=f_\theta(\tilde I_k,\tilde s_k,\tilde T_k)
\tag{1}
\]

\(C_1\equiv C_1^\star\)（方案 B）。时间只走在电路里：

\[
U_{p,k}=\alpha_k U_{p,k-1}+R_{1,k}(1-\alpha_k)I_k,\qquad
\hat U_{t,k}=U_{\mathrm{ocv},k}-I_k R_{0,k}-U_{p,k}
\tag{2}
\]

同一组 \((I,s,T)\) 必须给出同一组 \(R\)。这不是缺点：参数规范、特性文档、曲面图、KF 用预测 SOC 查表、07 的残差头，都建立在「\(R\) 是状态的函数，不是轨迹的函数」上。

网格训练的 SEQUENCE 里有充、放、静置，但 MLP **看不见顺序**，只看见当前三元组。历史效应若已经被 \(U_p\) 和 \(f_{\mathrm{dir}}(s,I)\) 吸收，它就不必再记。

---

## 2. 三种接法，不要混着评

### 2.1 接法 R：RNN 仍出 \(R_0,R_1\)，ECM 不动

\[
h_k=\mathrm{RNN}(h_{k-1},\,\tilde x_k),\qquad
(R_{0,k},R_{1,k})=g(h_k)
\tag{3}
\]

再送进 (2)。灰箱壳还在，网络从点映射变成**有记忆的参数发生器**。下文默认评这一条——它和现有 `ecm_forward`、电压损失、方案 B 改动最小。

### 2.2 接法 V：RNN 直接出电压，拆掉 ECM

\[
\hat U_{t,k}=\mathrm{RNN}(h_{k-1},I_k,s_k,T_k,\ldots)
\tag{4}
\]

黑箱。电压可以更贴，但没有 \(R_0,R_1\)，不能画曲面、不能给 KF 当参数、不能做 07 那种 \(\Delta R\) 头。和本仓库目标不一致，只在 §6 作对照。

### 2.3 接法 Δ：MLP 仍出主 \(R\)，RNN 只拟合 1RC 吃不下的残差

\[
\hat U_{t,k}=U_t^{\mathrm{ECM}}(R^{\mathrm{MLP}})+\delta U_k,\qquad
\delta U_k=\mathrm{GRU}(h_{k-1},I_k,e_{k-1},\ldots)
\tag{5}
\]

或加第二支路 \(R_2C_2\)，而不是换 backbone。这是「1RC 不够」时的正途，见 §6。

---

## 3. 接法 R 可能的优点

相对点式 MLP，RNN 多记住的是**路径**，不是当前工作点。

| 现象 | 1RC + 点式 \(R(s,T,I)\) | GRU / LSTM 可能多出来的 |
|------|-------------------------|-------------------------|
| 充放滞后 | 只有 \(f_{\mathrm{dir}}\)，看当前 \(I\) 符号 | 能记住「刚刚在充还是在放」 |
| 石墨 staging / 局部鼓包 | 写成 SOC 上的静态凸起 | 能随嵌锂历史左右挪一点 |
| 慢扩散（本该 2RC） | 折进 \(R_1\) 或残差 | 隐状态当第二条时间尺度 |
| 输入毛刺 | 逐步 \(R\) 跟着抖 | \(h\) 低通，\(R\) 更滑 |
| SOC 短暂不准 | \(R\) 立即用错 \(s\) | 短时仍靠电流史撑着 |

电压拟合上限会升高：同一条回弹，RNN 可以用 \(h\) 补 1RC 对不齐的尾巴。合成网格上 SEQUENCE 固定，这个便宜尤其明显——网络记住「静置 120 s 后该怎么回」，不真正学 \(R(s,T)\)。

LSTM 比 GRU 多个细胞门，长依赖略稳，参数大约多 1/3。本问题时间常数是十几秒到一两分钟，不是千步语言依赖，**GRU 通常够，上 LSTM 收益很小**。

## 4. 接法 R 的缺点（对本仓库是主因）

### 4.1 和 \(U_p\) 抢电压，可观性比方案 A 更差

04 已经说明：\(R_1\) 与 \(C_1\) 对冲会让 Hessian 变扁。RNN 再加 \(h\in\mathbb{R}^{d}\)（\(d=8\sim 32\)），同一段 \(\hat U_t\) 可以来自：

- 改 \(R_0\)（边沿）
- 改 \(R_1\)（幅度 / \(\tau\)）
- 改 \(h\)（任意慢形状）
- 改 \(U_p\) 初值

电压贴上了，\(R_0,R_1\) 对不上教师列、换一条轨迹对不上，是预期行为而不是调参问题。方案 B 钉死 \(C_1\) 省下的那一个自由度，会被 \(h\) 立刻吃回去。

### 4.2 不再是「可查询的参数表」

\(R_k=g(h_k)\)，\(h_k\) 依赖整段历史。不能再问「SOC=50%、25 °C、1C 的 \(R_0\) 是多少」——还要问从哪段电流走来。于是：

- `plot_ecm_surfaces.py` 那类 \((s,T)\) 曲面没有定义  
- 06 里「用 \(s_{k|k-1}\) 查 MLP 再测更新」少了确定的 \(R\)  
- 07 残差头、每芯 18 个数、写死基准，都假定点映射  
- 参考点 \(0.80/0.65\,\mathrm{m}\Omega\) 无法当锚

### 4.3 隐状态初值 = 放大的 \(U_p(0)\) 问题

05 §5.8：片段不是从静置开始时，\(U_{p0}=0\) 会把前几十秒误差打到 \(R_1\)。RNN 的 \(h_0\) 维数更高、更不可观。训练网格每条都从 rest 起、\(h_0=0\)，现场从行驶中间切开就会漂。

可学每条轨迹的 \(h_0\)，等于再给一条隐变量，离线行、车上不行。

### 4.4 增量、回放、缩放全变难

05 的 Replay / 参数锚 / \(k_0,k_1\) 都作用在点映射上。RNN 增量时：

- 只微调新年份：旧温区的 \(h\) 动态一起改，遗忘比 MLP 快  
- 探点蒸馏：没有「探点上的 \(R\)」，除非再存一批旧轨迹的隐状态回放  
- \(k_0,k_1\) 缩放仍能做，但 RNN 会用 \(h\) 绕过缩放去拟合电压  
- `scaler.json` 仍要冻；RNN 对输入分布更敏，冻错更痛

07 不建议的「每 0.1 s 反传」若再配 RNN，等于逐步 BPTT 过隐状态，MCU 上比 3×8×2 重一个数量级，和 08 的 PPU 预算对着干。

### 4.5 和 EKF 的接口变脏

06 的顺序是：安时预测 \(s^-\) → 点式 \(R\) → 极化预测 → 创新 → 更新 \(s,U_p\)。RNN 的 \(h\) 要不要进状态？

| 做法 | 后果 |
|------|------|
| \(h\) 只前向、不进 \(\mathbf{P}\) | 滤波当 \(R\) 已知，但 \(R\) 其实依赖未建模的 \(h\)，NIS 会偏 |
| \(h\) 扩进 EKF | 维数 \(2+d\)，雅可比要过 GRU，不可观，等于联合估神经网络 |
| 每拍把 \(h\) 当过程噪声 | 能跑，等于承认 \(R\) 有色噪声，KF 调参更玄 |

局部 \(\delta R_0\) 随机游走（06 §3.2）已经能吸收「这一趟偏 50 µΩ」。RNN 不是这个缺口的正确答案。

### 4.6 过拟合训练 SEQUENCE

网格默认 rest–放电–rest–充电–短脉冲。RNN 很容易学会「第 210 s 该回弹」而不是 \(\tau_1=R_1C_1\)。换 `gen_common` 的指令序列，电压会差一截，\(R\) 对照更差。MLP 没有这条捷径。

### 4.7 算力和实现

| | 现用 MLP 64×64 | 小 GRU \(d=16\) 出 2 维 |
|--|----------------|-------------------------|
| 参数量 | \(\sim 4\,\mathrm{k}\) | 同量级或略少 |
| 单步 | 两层 GEMM，可并行查整段 | 必须逐步，难向量化整条 \(T\) |
| 训练 | 点式 + BPTT 只过 ECM | BPTT 过 RNN+ECM，图更长 |
| 部署 | 和 07 的 3×8×2 同类 | 要存 \(h\)，增量要存优化器态 |

LSTM 更重，本任务没有对应收益。Transformer / 长窗口自注意力：网格轨迹约 \(10^3\sim 10^4\) 步，注意力平方，更不合适。

## 5. 「待在一个工况上会忘其它点」——现象对，药方不是 GRU

讨论里有过一句很具体的印象：

> 3×8×2 的 MLP 在某个温度 / SOC 上待久了，会忘掉其它工况的 \(R\)，拟合好的曲面再画就歪了。换成 GRU，换工况时还能留住原来工况的特性。

前半句对应的是真实现象，07 §6.4 已经写过：小网、无 Replay、\(\lvert e\rvert>10\,\mathrm{mV}\) 就每 0.1 s 反传，18 个数会被当前窗口洗掉。后半句把两种完全不同的「记忆」叠在一个词上，GRU 保不住那张曲面。

### 5.1 先拆开两种记忆

| | 存在哪 | 记住什么 | 换到另一个 \((s,T)\) 还在吗 |
|--|--------|----------|------------------------------|
| **权重 \(\theta\)** | \(W_1,W_2\) 或 GRU 的 \(W_{ir},W_{hr},\ldots\) | 整张 \(R(I,s,T)\) 怎么算 | 在。这就是曲面。增量 SGD 改的也是它 |
| **隐状态 \(h_k\)** | 只在 RNN 里，跟当前这一趟走 | 最近几秒到一两分钟的路径（刚充过、极化还没消） | **不在。** 一换点、一复位、一出车就不是原来的 \(h\) |

MLP 没有 \(h\)，不是「没有记忆所以忘曲面」。曲面从来都在 \(\theta\) 里。待久了曲面歪，是 **\(\theta\) 被当前点的梯度改写了**，不是因为网络是前馈。

GRU 多出来的 \(h\) 是**本趟行程的短时记忆**，不是「上个月 0 °C、SOC=20% 的 \(R_0\)」那种联想记忆。没有按 \((s,T)\) 编址的槽，就谈不上「换回旧工况把旧 \(R\) 取出来」。

### 5.2 为什么 3×8×2 待久了曲面会塌

设当前长时间停在 \(x_\star=(I_\star,s_\star,T_\star)\)，每拍用电压误差更新。3×8×2 的 8 个隐单元、18 个后层参数是**全体工况共用**的。\(x_\star\) 上 \(\varphi\) 几乎常值，梯度反复是同一方向：

\[
\Delta W_2 \propto e_k\,\varphi(x_\star)^\top
\tag{5a}
\]

\(W_2\) 一改，**所有** \(x\) 的 \(\Delta R=W_2\varphi(x)\) 一起动。前层若也解冻，8 个特征探测器还会转向「只对 \(x_\star\) 敏感」。再拿一张 \((s,T)\) 网格去画 \(R\)，其它档位已经不是拟合刚结束时的数。这不是画图 bug，是小容量点映射的**灾难遗忘 / 表征干涉**。

网越窄、更新越勤、越没有旧点回放，塌得越快。本仓库 \(64\times 64\) 也会在「只在一个温区增量、无 Replay」时慢慢歪，只是比 3×8×2 慢。07 的结论仍然成立：该降频、该冻前层、该 Replay 或锚探点，不是该换时序核。

对照：真正「只改当前格、其它格不动」的是 **\((s,T)\) 分箱表**。待在一格里更新，邻格保持原值。那是空间上的局部写入，和 GRU 无关。

### 5.3 换成 GRU，待久了会怎样

接法 R 在同一点 \(x_\star\) 上长时间反传，更新的是 GRU 的全部共享权重，不是把 \(R(x_\star)\) 写进某个只属于 \(x_\star\) 的格子。之后任意 \(x\) 都走同一套 \(W\)：

- 旧温区 / 旧 SOC 的前向一样被改掉，**遗忘不会比 MLP 轻，通常更重**（参数更多、还多一条 \(h\) 通道把电压误差散开）
- 画曲面更麻烦：同一 \((s,T)\) 的 \(R\) 还依赖 \(h_0\) 和怎么走到这一点。你以为「保住了旧工况」，其实是另一条路径下的另一个 \(R\)
- 若权重大改之后再回到旧 \((s,T)\)，GRU 用的是**这一趟新的 \(h\)**，不是上次离开时存档的 \(R\)

所以：「换工况时保留原来工况的特性」——若指**权重里的那张表**，GRU 做不到；若指**几分钟内的充放滞后**，那是 \(h\) 的本职，MLP+方向因子或 2RC 也能管，而且不该靠它冒充整张曲面。

### 5.4 印象从哪来的（善意还原）

对方多半看到了两件叠在一起的事，用「有记忆」一个词概括了：

1. **增量时曲面被当前点洗掉**（\(\theta\) 问题）。正确联想是 Replay、探点锚、冻前层、分箱表、少更新。GRU 听起来像「有记忆」，种类错了。  
2. **同一趟车里刚从 A 开到 B，\(R\) 还带着 A 的味**（\(h\) 问题）。GRU 确实能这样。那是路径依赖 / 滞后，画成「静态 \(R(s,T)\) 曲面」本就会糊；回去 A 时若还没改权重，看起来像「还记得 A」，其实只是 \(h\) 还没忘这一趟。停一夜 \(h\) 清零，A 的「记忆」立刻没了，但权重遗忘还在。

第三种更误导的实验：GRU 在固定 SEQUENCE 上电压更贴，再画 \(R\) 觉得「稳」。那往往是过拟合指令节奏（§4.6），不是保住了多工况曲面。换一条没见过的温区扫描，会一起垮。

### 5.5 想保住其它工况，该用什么

按「谁不该被当前点改掉」选，不要按「谁名字里有记忆」选。

| 手段 | 当前点待很久时，其它 \((s,T)\) |
|------|--------------------------------|
| 3×8×2 解冻 + 0.1 s 反传 | 一起漂（印象里的故障） |
| 3×8×2 冻前层 + 降频 + 10 mV 且大电流才更新 | 好一些，18 个数仍会慢漂 |
| Replay / 探点蒸馏（05） | 旧点电压或旧 \(R\) 把 \(\theta\) 拉住 |
| \(k_0,k_1\) 或有界 \(\delta R\)（05 / 06 / 07） | 形状不动，只整体挪 |
| \((s,T)\) 分箱表，只写当前格 | 其它格原封不动 |
| 接法 R：GRU 出 \(R\) | **不保护曲面**，还取消「格」的定义 |
| 外置键值记忆，键是量化后的 \((s,T)\) | 才是「按工况存 \(R\)」；那已不是标准 GRU |

一期仍按 07 / 05：小头、冻特征、开环误差、有激励才更新、旧探点抽查曲面。不要为了这句印象把骨干换成 GRU。

## 6. 什么时候值得动时序结构

先看开环 \(e^{\mathrm{ol}}\)（06），不要先换 backbone。

| 残差长什么样 | 先试什么 | 不要先上 |
|--------------|----------|----------|
| 边沿差一点、回弹形状对 | 更大 MLP / 更好激励 / 方案 B+ | GRU |
| 回弹有明显第二指数 | **2RC**（再钉死或慢变 \(C_2\)） | 用 GRU 暗含第二条 \(\tau\) |
| 充放环、路径依赖大 | 分充放两张 MLP，或输入加「上次方向」滞后 | 全替换 LSTM |
| 1RC+2RC 后还有慢尾巴 | 接法 Δ：很小的残差 GRU 出 \(\delta U\)，主 \(R\) 仍 MLP | 接法 R / 接法 V |
| 只是 SOC 漂、电流偏 | EKF + 开环增量（06） | 任何 RNN |

2RC 比 GRU 优先：多一对 \((R_2,C_2)\)，物理清楚，KF 只多一个 \(U_{p2}\)，仍是点映射。特性文档已经写 1RC 是折中，扩散应用 2RC。

接法 Δ 的约束：\(\delta U\) 幅度封顶（数 mV）、\(h\) 维数 \(\le 4\)、增量时冻 GRU 只更 MLP 或 \(k_0,k_1\)。否则残差头会重新吞掉主电路。

## 7. 其它非 MLP，一句话

| 结构 | 和本问题的关系 |
|------|----------------|
| LSTM | 同 GRU，略重；不优先于 GRU |
| 双向 RNN | 要用未来电流，车上不能用；离线拟合可以，和 KF 实时矛盾 |
| TCN / 因果卷积 | 固定感受野，比 GRU 好部署一点，仍有 4.1–4.6 |
| Transformer | 过重，参数表仍变成历史函数 |
| KAN | 仍是点映射，可解释性宣传多；曲面光滑时不如加大 MLP 实在 |
| 解析乘性模型（`NMC100AhECM`） | 已有，当教师 / 对照，不是学习器 |
| 纯查表 + 插值 | 点映射的极限；网格密且无老化时够，缺泛化 |
| 接法 V 端到端 | 电压赛冠军，放弃 \(R\) 和本仓库其余文档 |

| | 点式 MLP + ECM（现状） | 接法 R：GRU/LSTM 出 \(R\) | 接法 V：RNN 出电压 | 接法 Δ：残差 GRU |
|--|------------------------|---------------------------|--------------------|------------------|
| 电压上限 | 受 1RC 限制 | 更高 | 最高 | 略高于 MLP |
| \(R_0,R_1\) 可解释 | 好 | 差，换轨迹易漂 | 无 | 主 \(R\) 仍好 |
| 与方案 B | 配套 | 抵消钉 \(C_1\) 的好处 | 无关 | 可保留 |
| 曲面 / 参考点 | 有 | 无定义 | 无 | 有 |
| EKF（06） | 直接查表 | 接口脏 | 难 | 主通道仍可查 |
| 增量（05/07） | Replay / \(k\) / 残差头 | 遗忘快、锚不住 | 只能蒸馏电压 | 冻残差、更主 \(R\) |

| 实现量 | 已落地 | 中，训练不稳 | 大，换目标 | 小～中 |
| 建议 | **默认留下** | 不换 | 不做 | 1RC 残差有结构再试 |

## 9. 结论与落地

**不要用 GRU / LSTM 替换 `ParamMLP`。** 本仓库要的是可查询、可滤波、可增量的 \(R(s,T,I)\)；时序已经在 \(U_p\) 里。RNN 出 \(R\) 会重演并放大方案 A 的不可观，还拆掉 06 / 07 的接口。

「3×8×2 待在一个 SOC / 温度上会把曲面洗歪」是真的，根子是**共享权重被当前点的逐步反传改写**，不是前馈没有隐状态。GRU 记住的是本趟路径，不是其它工况的 \(R\)；换它挡不住这件遗忘，还会让「曲面」失去单值定义。要保住旧点：Replay、探点锚、冻前层、分箱只写当前格，见 §5。

若合成或实车上 \(e^{\mathrm{ol}}\) 在回弹段呈明显双指数，先加 2RC，\(C_2\) 钉死或全局慢变，重复方案 B 的逻辑。仍有数 mV 慢残差，再用维数很小的接法 Δ，且增量时冻住它。
