## 0. 和方案的差别

06-a 第一列写「不叠 PyBaMM」。真包短期内没有测试资源，生成器开 `--engine pybamm` 顶电压。BMS 仍是 1RC 查表 + \(k\) 网格。为了对上 2A1 的「同一点涨阻」而不是改 \(D_s\)：

| | 做法 | 为什么 |
|--|------|--------|
| 真电流 | 一条 SEQUENCE，180 串相同 | 串联包 |
| 电压 | 每芯一条等温 SPM（Chen2020→100 Ah） | 顶真包 |
| ×1.15 | 端电压再减 \(I(k-1)(R_0+R_1)_{\mathrm{ref}}\)，\((k-1)\times 1.45\,\mathrm{m}\Omega\) | SPM 的 Contact resistance 不进 \(U_t\)；1C 上 +21.8 mV |
| OCV | 本包 bulk \(U_{\mathrm{ocv}}\) 插值 | 仓库 `ocv.py` 和 Chen2020 差约 120 mV，门会把 180 只当成零偏 |
| 包级门 | \(\lvert m\rvert\) / 斜率都要轨迹 \(\ge 15\,\mathrm{min}\) | 10 min 上 EKF 啃 SPM 残差会假同号约 1 pp |
| \(k_1\) | 撤流后只允许 \(\sim 2\tau_1\)（40 s） | 06-a §3.5；60–120 s 慢尾巴不写 |

对照舰队仍是 `Data/ai_mlp`。不读 `Data/grid`，不覆盖 `Data/ai_mlp`。

## 3. 正式 2A1（\(n=180\)）

设置：`--engine pybamm`，种子 201，\(s_0=0.70\pm 0.02\)，\(T=25^\circ\mathrm{C}\)，\(b_I=0\)，20 只 \(k=1.15\)（id 0–19），160 只 \(k=1\)。滑窗 10 s、SGD `lr=10`、一遍。JSON `Data/pack/2a1_kgrid/pack_run.json`。

### 3.1 门

| | 值 |
|--|----|
| \(m\) | **−0.29 pp** |
| \(f_{\mathrm{same}}\) | 0.61（符号混） |
| 斜率 | −0.016 pp/h |
| 时长 | 0.17 h |
| 拦？ | **否** |

没有全包同向涨阻。中位 \(\Delta s\) 远小于 1 pp。

杂音：6 只 \(\lvert\Delta s\rvert>3\,\mathrm{pp}\)，最差未涨芯 id 130 **+19 pp**。开环仍约 12 mV，是 EKF 啃 SPM 残差把 \(s^+\) 拉飞，不是分流器。休息 SOC 不和 2A1 隔离绑在一起。

### 3.2 \(k\) 和电压

点到的节点（工况 SOC≈0.70、25 °C，插在 T=10 / 30 之间）：

| | \(k_0\) p05 / p50 / p95 | \(k_1\) p50 | 冻结 RMSE | 增量后 | 变化 |
|--|-------------------------|-------------|-----------|--------|------|
| 20 只 ×1.15 | 1.031 / **1.038** / 1.043 | 0.999 | 18.5 mV | 17.2 mV | **−1.33 mV** |
| 160 只 \(k=1\) | 0.991 / **0.992** / 0.993 | 0.999 | 12.7 mV | 12.7 mV | ~0 |

涨阻最小 \(k_0=1.030\)，未涨最大 0.993，**间隙 0.037，无重叠**。

平均 \(k_0\) 网格（行 SOC 0.10→0.90，列 T −10 / 10 / 30 / 50）：

涨阻芯：

```
1.000  1.000  1.000  1.000
1.000  1.000  1.000  1.000
1.000  1.003  1.009  1.000
1.000  1.017  1.052  1.000
1.000  1.000  1.000  1.000
```

未涨芯同一格略低于 1（s=0.70、T=30 约 0.989）。s=0.10 / 0.30、T=−10 / 50 两边都是 1。不要用 \(k(0.50,25^\circ\mathrm{C})\) 验收：那一格几乎没点到。

### 3.3 和 06-a 通过条件

| 条件 | |
|------|--|
| 160 只 \(k_0,k_1\) 在 \(1\pm 0.03\) | **过** |
| 20 只 \(k\) 朝 1.15 | **方向过，幅度不够**（1.04 不是 1.15） |
| 两通道大致齐 | **不过**（\(k_1\) 钉死是门，串联 IR 只像 \(k_0\)） |
| 涨阻芯电压低于冻结 | **过**，只掉 1.3 mV |
| 包级门不触发 | **过** |

**跨芯隔离成立。** 不能写成已经估到 1.15，或 \(I\Delta R\) 墙收掉了。

### 3.4 为什么停在 1.04

1. 一条 SEQUENCE、一遍 SGD：每芯 62 窗、更新 23 窗。单芯 1b 当时是 25 条网格。
2. 未涨芯已经 12.7 mV（1RC 打 SPM）。×1.15 整段只再多约 6 mV；增量吃掉 1.3 mV，剩下 \(\sqrt{t}\) / 双指数 / OCP。
3. 真值是串联欧姆，\(k_1\) 在撤流 40 s 后不准写（21 窗 `skip_park`）。
4. 未涨芯也更新 23 窗：SPM 残差 > 2 mV，窗级门过了。它们把 \(k_0\) 略往下拧，RMSE 看不出。隔离靠「涨的往上、没涨的几乎不动」，不是「没涨的零更新」。
