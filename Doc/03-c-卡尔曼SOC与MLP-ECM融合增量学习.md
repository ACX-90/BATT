## 1. 卡尔曼为什么能估 SOC

### 1.1 只做安时积分会漂

容量 \(Q_n=100\,\mathrm{Ah}\)，\(q=Q_n\cdot 3600\,\mathrm{C}\)。与仿真相同：

\[
s_k = s_{k-1}-\frac{I_k\,\Delta t}{q}
\tag{1}
\]

放电 \(I>0\)，\(s\) 下降。误差来源：

| 来源 | 后果 |
|------|------|
| 电流零偏 \(b_I\) | \(s\) 以 \(b_I/q\) 匀速漂，停多久错多少 |
| 容量用错 \(\hat q\neq q\) | 倍率误差，全程 SOC 被拉长或压短 |
| 初值 \(s_0\) 不准 | 常偏，电压一直对不齐 |
| 库仑效率 / 漏电 | 慢漂，日历停放时更明显 |

安时是开环。要纠偏，必须再看一个与 \(s\) 有关的量。端电压就是这个量。

英飞凌现场 demo **也用 EKF**，大约放 **300 s** 就报 SOC 1% 以内。1C 上 300 s 只走约 8 pp SOC：5% 容量错约 0.4 pp，5 A 零偏约 0.4 pp，都还在 1% 里。窗口太短，\(b_I\) 和 \(\hat q\neq q\) 还没长到能看见。拉到小时级同一套错配会到数 pp～10 pp（§5.3、任务 F）。他们停在真值 +3%，是 10 mV 既当学习门限又当 SOC 死区。本仓库的差别不是「多上一个卡尔曼」，而是 **EKF 每拍吃创新、不设这道死区，并且不要把电压斜坡写成电阻**。

### 1.2 电压怎样「看见」SOC

一阶 ECM（与现有离散化一致）：

\[
\begin{aligned}
U_{p,k}
&=\alpha_k U_{p,k-1}+R_{1,k}(1-\alpha_k)I_k,
\qquad
\alpha_k=\exp\bigl(-\Delta t/(R_{1,k}C_{1,k})\bigr)
\\[4pt]
\hat U_{t,k}
&=U_{\mathrm{ocv}}(s_k,T_k)-I_k R_{0,k}-U_{p,k}
\end{aligned}
\tag{2}
\]

\(s\) 进测量方程的主通道是 \(U_{\mathrm{ocv}}\)。平台区 \(\partial U_{\mathrm{ocv}}/\partial s\approx 0\)，电压几乎不告诉你 SOC；两端斜率大，几毫伏就能拉动 \(s\)。\(R_0,R_1\) 不直接等于 SOC，但会通过 \(\hat U_t\) 搅进创新，所以**参数错了会被卡尔曼误当成 SOC 错了**。

反过来也成立：电压死区会被折成 SOC 常偏。英飞凌 demo 的 10 mV 门限，在本仓库中段 OCV（约 3 mV / 1% SOC）上就是大约 **3 pp**。现场误差先线性长、过约 2% 才往 3% 多收敛：2% 是创新刚摸到 10 mV（增益从 0 打开），3% 是死区边缘。他们的 OCV 是冻死的 1×4×8×4×1，相对 PyBaMM 最差约 30 mV，量级上能偏几个百分点，现场 +3% 停车仍更像死区而不是 30 mV 全折进去。本仓库 EKF 每拍都吃创新，没有这道 SOC 死区。展开见 `Doc/03-d` §6.6。

### 1.3 状态选什么

推荐本仓库用的最小 EKF：状态只有电路动态，参数交给 MLP。

\[
\mathbf{x}_k=\begin{bmatrix}s_k\\ U_{p,k}\end{bmatrix}
\tag{3}
\]

过程（预测，\(I_k,T_k\) 当已知输入）：

\[
\begin{aligned}
s_{k|k-1}
&=s_{k-1|k-1}-\frac{I_k\Delta t}{q}
\\
U_{p,k|k-1}
&=\alpha_k U_{p,k-1|k-1}+R_{1,k}(1-\alpha_k)I_k
\end{aligned}
\tag{4}
\]

\(R_{0,k},R_{1,k}\) 由 MLP 用**预测 SOC** 算出，见 §2.2，避免代数环。方案 B：\(C_{1,k}\equiv C_1^\star\)。

测量：

\[
\hat U_{t,k|k-1}
=U_{\mathrm{ocv}}(s_{k|k-1},T_k)-I_k R_{0,k}-U_{p,k|k-1}
\tag{5}
\]

创新（先验电压误差）：

\[
e_k^{\mathrm{pri}}
=U_{t,k}^{\mathrm{meas}}-\hat U_{t,k|k-1}
\tag{6}
\]

观测雅可比（OCV 对 \(s\) 求导，\(R\) 在本拍当常数）：

\[
\mathbf{H}_k
=\Bigl[
\partial U_{\mathrm{ocv}}/\partial s,\;
-1
\Bigr]
\tag{7}
\]

过程噪声 \(\mathbf{Q}\)：给 \(s\) 一小项（电流/容量不确定），给 \(U_p\) 一项（未建模的快动态）。测量噪声 \(R_v\)：与仿真噪声同量级即可（模板里电压约 \(0.5\,\mathrm{mV}\) 标准差，实车常取 \(2\sim10\,\mathrm{mV}\)）。

标准 EKF：\(\mathbf{P}_{k|k-1}=\mathbf{F}_k\mathbf{P}_{k-1}\mathbf{F}_k^\top+\mathbf{Q}\)，增益 \(\mathbf{K}_k=\mathbf{P}_{k|k-1}\mathbf{H}_k^\top(\mathbf{H}_k\mathbf{P}_{k|k-1}\mathbf{H}_k^\top+R_v)^{-1}\)，再

\[
\mathbf{x}_{k|k}=\mathbf{x}_{k|k-1}+\mathbf{K}_k e_k^{\mathrm{pri}}
\tag{8}
\]

\(s\) 裁到 \([0,1]\)。\(\mathbf{F}_k\) 是 (4) 对 \(\mathbf{x}_{k-1}\) 的雅可比：\(s\) 行是 \([1,\,0]\)；\(U_p\) 行里 \(\alpha_k\) 还经 \(R_1(s)\) 弱依赖 \(s\)，工程上常把 \(\alpha\) 当常数，只留 \(\partial U_p/\partial U_p=\alpha_k\)。

### 1.4 线性 KF 不够，UKF / AEKF 何时要

\(U_{\mathrm{ocv}}(s)\) 非线性，\(R(s)\) 也非线性，线性 KF 只能在工作点附近凑合。EKF 对这个二维状态足够。UKF 在 OCV 拐点、低 SOC 更稳一点，代价是多几次 ECM 前向，本仓库不必先上。

AEKF / 双估计：把 \(R_0\) 或 \((R_0,R_1)\) 扩进状态当随机游走。那是**局部在线辨识**，记住的是「这一分钟的电阻」，不是 \((s,T)\) 曲面。可以当 MLP 的残差通道（§3.3），不要用它替代增量学习。

### 1.5 SOC 什么时候可观

| 工况 | \(\partial U_{\mathrm{ocv}}/\partial s\) | 创新主要反映 | 对 \(s\) 的修正 |
|------|------------------------------------------|--------------|-----------------|
| 中段平台、小电流 | 很小 | \(R\)、OCV 表误差、噪声 | 弱，应把 \(R_v\) 看大或降低 \(K\) 的 \(s\) 分量 |
| 低/高 SOC | 大 | \(s\) 和 \(R_0\) | 强 |
| 电流阶跃边沿 | 中 | 主要 \(I R_0\) | 若当成 \(s\) 会打一个尖 |
| 静置回弹 | 中 | \(U_p\)、\(\tau_1\) | 先修正 \(U_p\)，\(s\) 慢跟 |

可观性不足时，卡尔曼应几乎退回安时，而不是猛纠 SOC。实现上可用 \(\lvert\partial U_{\mathrm{ocv}}/\partial s\rvert\) 调度 \(R_v\) 或增益上限。

## 2. MLP、ECM、卡尔曼怎么融

### 2.1 分工，不要揉成一个大滤波器

| 块 | 管什么 | 不管什么 | 时间尺度 |
|----|--------|----------|----------|
| ECM | \(\hat U_t\) 的物理方程，离散化与仿真同一套 | 不学参数 | 每拍 |
| MLP | \((I,s,T)\rightarrow(R_0,R_1)\)，方案 B 下 \(C_1\) 钉死 | 不估 SOC，不逐步反传 | 离线 / 批次增量 |
| EKF | \(s,U_p\) 的贝叶斯融合 | 不改 MLP 权重 | 每拍 \(0.1\,\mathrm{s}\) |

03-a 写过：车上逐步 RLS/EKF 跟局部 \(R\)，MLP 增量放在有人看曲线的离线批次。这里把 SOC 也放进同一套 EKF，**仍然不要**在 0.1 s 里对 \(\theta\) 做 `loss.backward()`。

### 2.2 一拍里的顺序（解开代数环）

MLP 要 \(s\)，EKF 要 \(R\)，不能互相等本拍后验。固定顺序：

```
已有  s_{k-1|k-1}, U_{p,k-1|k-1}
读入  I_k, T_k, U_{t,k}^{meas}

1. 安时预测          s_{k|k-1}
2. MLP(I_k, s_{k|k-1}, T_k)  →  R0,k, R1,k     （C1 = C1★）
3. 极化预测          U_{p,k|k-1}，式 (4)
4. 先验电压          Ût,k|k-1，式 (5)
5. 创新              e_k^{pri}，式 (6)
6. EKF 更新          s_{k|k}, U_{p,k|k}
7. 可选：用 s_{k|k} 再评一次 MLP，只记录，不回代本拍
```

第 7 步若回代再算 \(R\) 再更新，等于在非线性环里迭代，增益对不上线性化点，容易抖。本拍参数锁在预测 SOC 上。

现有 `ecm_forward` 假定整段 \(s\) 已给定。融合后，逐步 EKF 自己推 \(U_p\)，不要另开一条 BPTT 和滤波抢状态。离线再训 MLP 时，仍用 `ecm_forward`，输入改成滤波后的 \(s\) 序列或安时序列（§4.2）。

### 2.3 信息流

```
          I, T                         U_t^meas
           │                               │
           ├──── 安时预测 s^- ─────┐       │
           │                       ▼       │
           │                 MLP → R0,R1   │
           │                       │       │
           │                       ▼       │
           │              ECM (4)(5) Ût^-  │
           │                       │       │
           │                       ▼       │
           │              e^pri = U_meas-Ût^-
           │                       │       │
           └──────────────► EKF 更新 s, Up ◄┘
                                   │
                    日志 / 门控 ───┴──► 离线增量 MLP
```

OCV 表仍是外生的，与 02-a、03-a 相同。KF 不学 OCV。

### 2.4 和现有离线管线怎么接

| 现有 | 融合后 |
|------|--------|
| 训练输入 `soc_true` / `soc_meas` | 现场改为 EKF 的 \(s_{k|k-1}\) 或 \(s_{k|k}\) |
| `test.py` 开环：给定 CSV 里的 SOC 出电压 | 加闭环：只给 \(I,T,U_t\)，EKF 自己出 \(s\) |
| 电压 RMSE 对测量 | 拆成开环 RMSE 和滤波后创新方差，见 §3 |
| `use_true_inputs=True` | 车上必须走测量列；离线应先训一版测量输入权重（03-a §5.5） |

合成数据上可先做对照：用真 SOC 开环 vs EKF 闭环，看 \(s\) 误差和电压创新。模板参考点仍是 SOC 50%、25 °C、1C 时 \(R_0=0.80\,\mathrm{m}\Omega\)、\(R_1=0.65\,\mathrm{m}\Omega\)。

## 3. 电压误差有三种，增量只能吃其中一种

滤波会把一部分电压误差**吞进 SOC**。若拿后验残差去训 MLP，网络以为自己已经对了。

\[
\begin{aligned}
e_k^{\mathrm{ol}}
&=
U_{t,k}^{\mathrm{meas}}
-\bigl[U_{\mathrm{ocv}}(s_k^{\mathrm{ah}},T_k)-I_k R_{0,k}-U_{p,k}^{\mathrm{ol}}\bigr]
\\[4pt]
e_k^{\mathrm{pri}}
&=
U_{t,k}^{\mathrm{meas}}-\hat U_{t,k|k-1}
\\[4pt]
e_k^{\mathrm{post}}
&=
U_{t,k}^{\mathrm{meas}}
-\bigl[U_{\mathrm{ocv}}(s_{k|k},T_k)-I_k R_{0,k}-U_{p,k|k}\bigr]
\end{aligned}
\tag{9}
\]

\(s^{\mathrm{ah}}\) 是纯安时（可加开机校正，但中间不看电压）。\(U_p^{\mathrm{ol}}\) 用同一套 (2)、同一套 MLP，不经过 KF。

| 残差 | 谁用 | 能不能训 MLP |
|------|------|----------------|
| \(e^{\mathrm{ol}}\) | 开环对照、增量主损失 | **首选**。SOC 通道独立，电阻错误留在电压里 |
| \(e^{\mathrm{pri}}\) | EKF 创新、NIS 健康度 | 可用。里面混了一点 SOC 预测误差 |
| \(e^{\mathrm{post}}\) | 看滤波是否自洽 | **不要**当增量损失。KF 已经用 \(s,U_p\) 把电压贴上去了 |

直觉：卡尔曼的工作就是让 \(e^{\mathrm{post}}\) 变白、变小。用它反传等于让 MLP 学习「已被状态吃掉的残渣」。

归一化创新平方（标量测量）：

\[
\mathrm{NIS}_k
=\frac{(e_k^{\mathrm{pri}})^2}{\mathbf{H}_k\mathbf{P}_{k|k-1}\mathbf{H}_k^\top+R_v}
\tag{10}
\]

NIS 长期 \(\gg 1\)：\(R\) 图错、OCV 错，或 \(R_v\) 太小。NIS 健康且 \(e^{\mathrm{ol}}\) 仍有偏：滤波靠改 SOC 在硬撑，正是增量要动 MLP 的时候。

### 3.1 残差形态 → 先动谁

| 现象 | 优先怀疑 | 不要先做 |
|------|----------|----------|
| 边沿尖、稳态还行 | \(R_0\) | 改 SOC 初值 |
| 回弹快慢不对 | \(R_1\) / \(\tau_1\)（方案 B 即 \(R_1\)） | 上方案 A 放 \(C_1\) |
| 静置很久仍有常偏 | OCV 表或 \(s_0\) | 把偏差写进 \(R_0\) |
| 长时间匀速漂 | 电流偏置 / 容量 \(q\) | 增量 MLP |
| 只在某温度大 | MLP 曲面该温区，或温度传感器 | 当全域老化 |
| 平台区 NIS 乱、两端还好 | SOC 不可观 + \(R_v\) 没调度 | 在平台区猛更新 \(s\) 或猛训 MLP |

03-a 的激励不足问题在这里更狠：恒流走到极化稳态后，\(e\approx -I(R_0+R_1)+\Delta U_{\mathrm{ocv}}\)，卡尔曼会用 \(s\) 去补和电阻误差，开环 \(e^{\mathrm{ol}}\) 也拆不开 \(R_0,R_1\)。增量门控必须要求有边沿或足够长的静置。

### 3.2 局部 \(\delta R\) 与全局 MLP

允许 EKF 再带一个很慢的 \(\delta R_0\)（随机游走、过程噪声比 \(s\) 还小）：

\[
R_0^{\mathrm{used}}=R_0^{\mathrm{MLP}}+\delta R_{0,k}
\tag{11}
\]

它吸收「这一趟车比表偏大 50 µΩ」，不改曲面。若 \(\delta R_0\) 在同一 \((s,T)\) 区连续多天同号，再把这些片段送去增量。这就是 03-a §3.7 说的「MLP 先验 + 局部残差」，SOC 滤波和电阻微调共用一个创新，靠 \(\mathbf{Q}\) 分配：\(q_s\) 大则多改 SOC，\(q_{\delta R}\) 大则多改电阻。调反了，老化会被改成 SOC 漂移。

不要把整张 MLP 权重放进 KF。维数几百、不可观、和 \(s\) 强耦合。

## 4. 用电压误差做增量学习

与 03-a 同一原则：冻 `scaler.json`、现场无教师 \(R\)、Replay 或缩放适配、不要逐步反传。这里补上**滤波闭环之后**特有的数据怎么收、损失怎么建。

### 4.1 在线只记账，离线才更新 \(\theta\)

每拍记：\(I,T,s^{\mathrm{ah}},s^-,s^+,U_t,e^{\mathrm{ol}},e^{\mathrm{pri}},\mathrm{NIS},R_0,R_1,\delta R_0\)（若有）。满一次出车或一天，过门控再组轨迹。

门控（同时满足再进增量集）：

1. 滤波健康：一段 NIS 中位数在合理带内（例如 0.2～5），没有连续发散  
2. 开环有内容：\(\mathrm{rms}(e^{\mathrm{ol}})\) 明显高于测量噪声，且不是单个尖峰  
3. 激励够：存在 \(\lvert\Delta I\rvert\) 超过阈值的边沿，或 \(\ge 30\,\mathrm{s}\) 静置回弹（相对 \(\tau_1\approx 18\,\mathrm{s}\)）  
4. 温度落在旧 scaler 的 \(\mu\pm 4\sigma\) 内；超出先当填洞，见 03-a §5.9  
5. 不用平台区片段去拆 \(R_0/R_1\)；平台区最多用来慢纠 \(s_0\)

### 4.2 损失建在开环电压上

增量仍用 03 的电压损失，但 SOC 要用**不依赖本拍 KF 后验**的序列：

\[
L_v
=\tfrac12\mathrm{mean}\bigl(e^{\mathrm{ol}}\bigr)^2
+\lambda_{\mathrm{smooth}} L_{\mathrm{smooth}}
\tag{12}
\]

推荐 \(s^{\mathrm{ah}}\)（开机用上一次停车的 \(s^+\) 当 \(s_0\)）。这样梯度回到 \(R_0,R_1\) 的路径与 03 的 (13) 相同，不经过 \(\mathbf{K}_k\)。

若安时已经明显漂（长时停放后对不上 OCV），用 \(s^-\) 组 \(e^{\mathrm{pri}}\) 也可以，但要降低学习率，并在 \(\lvert\partial U_{\mathrm{ocv}}/\partial s\rvert\) 大的区段降权，免得网络去拟合「KF 还没来得及改的 SOC 误差」。

\(U_p\) 初值：用该段开始时的 \(U_{p|k}\) 当 `u_p0` 传入 `ecm_forward`，或丢掉开段 \(\sim 3\tau_1\)（03-a §5.8）。不要写死 0。

### 4.3 三种增量仍按 03-a 选

闭环多出来的只是「何时触发、用哪条残差」：

| 残差模式 | 选 03-a 的哪条路 |
|----------|----------------|
| \(e^{\mathrm{ol}}\) 只在未覆盖的 \(T\) 大 | Replay 填洞，旧网格必须留着 |
| 各温区 \(e^{\mathrm{ol}}\) 同号，边沿像 \(R_0\) 整体抬 | 浅层 \(k_0,k_1\)（03-a §3.5），最贴老化 |
| \(\delta R_0\) 随寿命爬、形状还在 | 同上，不要微整张网 |
| 形状也变（某 SOC 窗口鼓包） | Replay + 小学习率微调；验收旧探点 |
| 要一张网跨寿命 | 扩维 \(q=\mathrm{SOH}\)，换模型，不是 KF 增量 |

KF **不能**补上缺失的 SOH 输入。它只能把「表错了」的电压暂时按到 \(s\) 或 \(\delta R_0\) 上。长期仍要 03-a 的缺维判断。

### 4.4 一次离线增量的步骤

1. 从日志切出门控片段，写出类似 `Data/grid` 的 CSV（列至少：`i_meas_a, t_meas_c, soc_ah, u_t_meas_v, u_ocv_v`；`u_ocv` 用安时 SOC 查表）  
2. `--resume` 加载旧 `best.pt`，**读旧 `scaler.json`，禁止 `fit_scaler`**  
3. `--no-pretrain`，`voltage_target=meas`，输入用测量列  
4. batch 混旧网格 Replay  
5. 损失用 (12)，不是 NIS，也不是 \(e^{\mathrm{post}}\)  
6. 验收两套：旧网格开环电压；新日志的 \(e^{\mathrm{ol}}\) 和 \(s\) 对照（若有休息满电点）  
7. 更新现场 MLP 后，\(\delta R_0\) 清零，\(\mathbf{P}\) 的 \(s\) 方差可略增大一拍，让滤波重新信任新表

`test.py` 继续只读权重。增量是单独批次，不是测试脚本。合成对照数字见 `Doc/04-a`，按任务选档与门控读法见 `Doc/04-b`。

## 5. 闭环特有的坑

03-a 的 scaler、教师列、方案 B、清网格、OCV 过期这里都成立。下面只写**加上 EKF 之后**会新出现的。

### 5.1 误差归属：SOC 和 \(R\) 抢同一创新

\(e^{\mathrm{pri}}\approx (\partial U_{\mathrm{ocv}}/\partial s)\,\delta s - I\,\delta R_0 - \delta U_p\)。三项观测上共线的时候，卡尔曼按 \(\mathbf{Q}\) 分赃。\(q_s\) 过大：电阻老化被改成 SOC 漂移，满电点越来越歪，MLP 看不到 \(e^{\mathrm{ol}}\) 里的 \(R\) 偏差（若你错误地用了 \(s^+\) 去组开环）。\(q_s\) 过小：电流真偏置无法纠正。

标定：在已知 SOC 的休息点（久置后 OCV）看 \(s^+\) 是否钉住；在脉冲边沿看 \(e^{\mathrm{ol}}\) 是否随 \(I\) 变。前者管 \(q_s\)，后者管要不要增量 \(R_0\)。

### 5.2 用后验 SOC 去训 MLP（循环论证）

\(s^+\) 已经用当前 MLP 的 \(R\) 算过创新。再拿 \((I,s^+,T)\) 和 \(e^{\mathrm{post}}\) 更新 \(\theta\)，梯度是「参数 → 电压 → SOC → 又当输入」的扭曲环，会把 \(R\) 和 \(s\) 一起拧。所以 §4.2 坚持 \(s^{\mathrm{ah}}\) 或最多 \(s^-\)。

### 5.3 容量错了，创新却很小

\(\hat q\neq q\) 时安时尺度错，EKF 在 OCV 斜率大的地方不断改 \(s\)，\(e^{\mathrm{post}}\) 可以很小，\(e^{\mathrm{ol}}\) 呈缓慢斜坡。增量若只看 NIS，会以为 MLP 很好。应同时监视 \(s^+-s^{\mathrm{ah}}\) 的斜率；持续单方向就要先重估 \(q\) 或电流偏置，而不是改 \(R\) 曲面。

仿真安时用 \(Q_{\mathrm{sim}}\)（生成器 `capacity_ah`，默认 100 Ah），EKF 安时用 \(\hat Q\)（`run.py` 的 `--capacity-ah × --capacity-scale`）。两边不是同一个旋钮。纯容量错配应**电流（安培）不变**，只改积分分母：

\[
s^{\mathrm{ah}}-s^{\mathrm{true}}=-A\Bigl(\frac{1}{\hat Q}-\frac{1}{Q}\Bigr)
\tag{13}
\]

\(A=\sum I\Delta t/3600\) 是净安时。\(\hat Q<Q\)：同样多安时被当成更大的 SOC 变化，\(s^{\mathrm{ah}}\) 偏低。静置 \(I=0\) 时这项停住。电流零偏相反：只要测量电流不是真零，静置还在积。

生成器 `--soh-capacity` 还会把 1C 的安培改掉（`c_rate\times Q`），开环电压里叠了 \(IR\) 变化，不是 (13) 这一条。要对 \(\hat q\neq q\)，CSV 仍按 100 Ah 生成，只改 EKF：`run.py --capacity-scale`。

开环 \(e^{\mathrm{ol}}\) 的 SOC 也走 \(\hat Q\)（`filter.py` 里 `soc_ah` 和预测步共用 `q_coulomb`）。所以容量错了，斜的是开环；先验 / 后验仍可被 OCV 纠回，NIS 可以一直 \(O(1)\)。

数字（仿真 \(Q=100\,\mathrm{Ah}\)，`--best`）。默认短波净安时约 4.03 Ah（SOC 0.70→0.66）；`cc_rest` 是 0.3C × 2 h，净 60 Ah（0.70→0.10）。

| 波 | \(\hat Q\) / Ah | 开环 / mV | 先验 | 后验 | 安时终点 | EKF 终点 | 门控 |
|----|-----------------|-----------|------|------|----------|----------|------|
| 短 | 100 | 0.94 | 0.65 | 0.11 | −0.00 pp | −0.03 pp | 拒 |
| 短 | 97 | 0.86 | 0.65 | 0.11 | −0.13 pp | −0.06 pp | 拒 |
| 短 | 95 | 1.18 | 0.65 | 0.11 | **−0.21 pp** | −0.01 pp | 拒 |
| 短 | 105 | 1.87 | 0.65 | 0.11 | **+0.19 pp** | +0.01 pp | **过** |
| 2 h | 100 | 1.22 | 0.65 | 0.11 | 0 | +0.06 pp | 拒 |

| 2 h | 105 | **9.50** | 0.65 | 0.11 | **+2.86 pp** | +0.08 pp | **过** |

安时终点对着 (13)：短波 5% 只有 0.2 pp，开环几乎仍是底板；小时级 60 Ah 才到 3 pp。\(\hat Q=95\) 走到更低 SOC（开环按 ~7% 去对真值 10% 的电压），OCV 更陡、电阻更大，同样 ±5% 比 \(\hat Q=105\) 的开环差一倍（22 vs 9.5 mV）。先验全程 0.65 mV、NIS 中位 0.13——和匹配时一样。

和 5 A 零偏（同一条 `cc_rest`，任务 F）对比：开环 143 mV、安时 −10 pp，也是先验亚毫伏、NIS 健康。两者在「电压好、安时歪」上同形。分开看：**静置段 \(s^{\mathrm{ah}}\) 还在不在漂**（零偏会、纯 \(Q\) 不会），以及误差是否与净安时成比例。

不要用这条开环斜坡去增量 \(R\)，也不要打开 \(\delta R_0\) 去跟它——会写成假内阻。先重估容量或分流器。门控挡不住（小时级 5% 已过；短波 +5% 也会过），过了仍不是电阻任务。

### 5.4 开机 \(U_p\) 和 SOC 抢初值

冷启动只有电压。把残差全给 \(s_0\) 或全给 \(U_{p0}\) 都会偏。习惯：久置（\(\gg \tau_1\)）则 \(U_{p0}=0\)，\(s_0\) 由 OCV 反查；刚停不久则信任上一趟的 \(s^+\)，\(U_p\) 从上一拍续，或给 \(U_p\) 较大初值方差让前几十秒先改极化。

### 5.5 方案 B 下 KF 会把 \(\tau\) 误差推向 \(s\)

真 \(C_1\) 随老化下降，\(\tau\) 变长，回弹更慢。MLP 只能加 \(R_1\)。若增量还没发生，EKF 会在回弹段用 \(U_p\) 和一点点 \(s\) 去跟电压。回弹结束后 \(s\) 可能留下一个台阶。这是「先 B、用 \(e^{\mathrm{ol}}\) 的回弹段更新 \(R_1\)」的理由，不是改成方案 A 的理由。

### 5.6 开环损失与滤波仿真不一致

离线 `ecm_forward` 若仍喂 `soc_true`，和现场 EKF 用的 \(s^-\) 不是同一分布。增量数据应按现场输入列组 batch。合成实验要在注入电流偏置后再比闭环，不要只在无偏仿真上宣布 KF「没用」。

## 6. 建议落地顺序

0. 离线网格继续按现在训方案 B。SOC 仍可用真值，先把 \(R\) 曲面站住。  
1. 写逐步 EKF：状态 (3)，离散化 (4)(5)，MLP 用 \(s^-\)。合成数据加电流偏置，看 \(s\) 是否纠回来。  
2. 日志里同时存 \(e^{\mathrm{ol}}\) 和 \(e^{\mathrm{pri}}\)。`test.py` 类脚本先画开环对照，再画闭环 SOC。  
3. 门控 + 开环电压增量（Replay 或 \(k_0,k_1\)），遵守 05。禁止用 \(e^{\mathrm{post}}\)。  
4. 需要再加很慢的 \(\delta R_0\)。仍不要逐步反传 MLP，不要联合估 \(C_1\)。  
5. 寿命跨度大再立项 SOH 输入。KF 解决不了缺维。

一期明确不做：KF 状态里塞 MLP 权重、每拍 `backward`、增量方案 A、用后验残差当 \(L_v\)、平台区无激励时更新 \(R\)。

## 7. 验收

| 检查 | 通过 |
|------|------|
| 无偏电流、OCV 准 | 闭环 \(s\) 贴近真值或休息 OCV；不比安时差 |
| 人为电流偏置 | \(s^+-s^{\mathrm{ah}}\) 能抵消积分漂，休息点钉住 |
| \(\hat Q\neq Q\)，净安时长 | \(s^{\mathrm{ah}}\) 按 (13) 漂；\(s^+\) 钉住；NIS 仍 \(O(1)\)；**不要**因此改 MLP |
| MLP 故意偏大 \(R_0\) | \(e^{\mathrm{ol}}\) 边沿变大；\(s\) 不应被长期拉走 |
| 增量之后 | 旧网格开环 RMSE 不明显变差；新日志 \(e^{\mathrm{ol}}\) 下降；休息点 \(s\) 不恶化 |
| NIS | 增量后回到 \(O(1)\)，不是靠把 \(R_v\) 调爆 |

电压贴上了但休息 SOC 歪了，优先查 §5.1 和 §5.3，而不是再降 MLP 学习率。
