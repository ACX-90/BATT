## 一句话

查表 + \(k\) 已经能上车（支线 1）。支线 2 要赢，必须做表写不进去的事。**本期默认数据源是 PyBaMM（建议 SPMe）**；BMS 侧仍是等效 1RC LUT + \(k\) + 可选 \(\delta U\)。不问「网当表能不能更准」，只问：单芯轨迹上 **1RC + \(\delta U\)** 相对纯 1RC、物理 2RC、可选滞后，开环 / 休息 SOC 各差多少；以及「打赢 2RC」能不能当通关——**默认不能**。

## 1. 为什么插第 3 期

第 2 期把 180 串共用电流的门和主列跑齐了（方案 06-a，数字 06-b）。AI 叙事如果还停在「把网搬上 PPU」，会被查表打掉（05-c / 07-a）。

插本期，是为了三件事：

1. **AI 不能挡查表上车。** 量产默认仍是 LUT + \(k\)；本期对照不改第 2 期主档门。
2. **先用仿真把 \(\delta U\) 说清楚。** 真芯 / WLTP / 实车 10 Hz 仍归第 N 期；没有预言机数字，残差头没有验收口径。
3. **过关标准先锁死。** 「开环比 2RC 低」不是默认通关——若残差形状就是第二指数，物理升阶优先（07-b §11）。

## 3. 理论基础（锁死再动手）

沿用 03-b / 07-b，本期不再重开架构评估：

1. **接法 Δ，不是接法 R / V。** 主 \(R\) 仍查表（或烤表）；AI 只出 \(\delta U\)。接法 R（GRU 出 \(R\)）取消可查询曲面；接法 V（出电压）拆掉 ECM / KF 接口。点式 \(\Delta R\)（1c）已丢掉，不翻版。
2. **先拆口再训网。** \(R_0(I)\) 归表；静置双指数归物理 2RC；通电两端直线归表面 OCP 或策略。AI 只吃这三口之后仍同号的尾巴（路径 / \(\sqrt{t}\) / 非指数核）。
3. **信封内物理栈已收到 ~2 mV**（`eval_nls.md` §7：\(T\ge 10^\circ\mathrm{C}\)、SOC \(\gtrsim 28\%\)，2RC+BV+OCP）。GRU **没有**另一块 10 mV 可吃；不要用一个头同时复现双指数和通电直线。
4. **「打赢 2RC」不是通关。** 半对数像第二指数 → 升阶优先（07-b §11）；GRU 不许暗含 \(\tau_2\)。
5. **时序记忆在 \(U_p\)，不在宽网。** 残差头隐状态只补表结构写不进去的短记忆；增量时 **冻 \(\theta\)，只动 \(k\)**。

## 4. 四列对照

同一条真电流、同一只芯、同一套 OCV。BMS 估计器侧始终看见测量噪声后的 \(I,U,T\)。**主对照在 PyBaMM 真电压上跑**；列 2 的「物理 2RC」可以是对同一条 PyBaMM 轨迹的 2RC 投影 / NLS 打标列（见 §6），不是换一条 ECM 真值冒充。

| 列 | 真值 / 估计 | 用来答什么 |
|----|-------------|------------|
| **1. 纯 1RC 查表底板** | 真值 = PyBaMM；BMS = **PyBaMM-等效** 1RC LUT + \(k\equiv 1\)（或已齐节点） | 地板：等效表在这条真电压上还能贴多少 |
| **2. 物理 2RC** | 同一 PyBaMM；BMS / 对照 = 钉死 \(C_2\) 的 2RC（+ 可选 BV/OCP 打标），\(R_2\) 冻住 | 若残差是第二指数，这一列应打赢列 4 |
| **3. 1RC + 滞后（可选）** | 残差显式像滞后 / 路径时才开；BMS = 1RC + **显式**滞后状态（不是 GRU） | 拆「路径 / 滞后」和「缺 \(\tau\)」 |
| **4. 1RC + AI 只出 \(\delta U\)** | BMS = 等效 1RC LUT + \(k\) + 冻结 \(\delta U_{\mathrm{AI}}\)（接法 Δ） | AI 是否吃到**表写不进去**的东西 |

约束（锁进任务卡，不是口头）：

- AI **只出 \(\delta U\)**：禁写 \(k\)、禁出 \(\Delta R\)、禁学更新器（07-b §10）。
- \(\delta U\) 幅度封顶、隐状态维数 \(\le 4\)；增量时冻残差只动 \(k\)（若该组允许动 \(k\)）。
- 离开参考点用策略关信封（07-b），不把头加宽去贴末端 / 大电流 / 低温。

## 6. 1RC + AI 详细设计

### 6.1 前向接口

\[
\hat U_k = U^{\mathrm{1RC}}\!\bigl(R^{\mathrm{LUT}}(I_k,s_k,T_k),\,U_{p,k}\bigr) + \mathrm{clip}(\delta U_k),\qquad
\delta U_k = g_\theta(h_{k-1},\,x_k)
\]

- \(R^{\mathrm{LUT}}\)：PyBaMM 轨上的**新烤**等效表（方案 B：出 \(R_0,R_1\)，\(C_1\equiv C_1^\star\)）。
- \(U_p\)：仍由 1RC 离散递推；**不**让 \(h\) 替代 \(U_p\)。
- EKF：状态仍是 \((s,U_p)\)；\(h\) **只前向**，不进 \(\mathbf{P}\)（03-b：\(h\) 进滤波 = 联合估神经网络）。
- 创新 / 开环损失默认仍相对 1RC 预测；报表可另列「1RC+\(\delta U\)」开环，但 \(\delta U\) **不进**保护核。

### 6.2 模型选型与尺寸

| 项 | **默认** | 对照 / 备注 |
|----|----------|-------------|
| 核 | **因果小 GRU，\(d=4\)** | 另开因果 FIR / TCN，感受野 \(\le 2\sim 4\,\mathrm{s}\)；**不上 LSTM**（03-b：收益小） |
| 输出 | 标量 \(\delta U\) | 禁止出 \(\Delta R_0,\Delta R_1\) 或 \(k\) |
| 封顶 | \(\lvert\delta U\rvert\le 15\,\mathrm{mV}\)（先试 8） | 未封顶「打赢」2RC → 作废 |
| 输入 \(x_k\) | \(I_k\)、\(e^{\mathrm{ol}}_{k-1}\)（相对 1RC）、可选 \(\mathrm{sign}(I)\)、短窗 \(\lvert I\rvert\) RMS | **不喂** \(R\)、不喂教师 \(\tau\)、不喂 PyBaMM 内部态 |
| 初值 | 段首静置 \(h_0=0\) | 中途切开单独记负例；不学每条 \(h_0\) |
| 参数量 | 约 \(10^2\) 量级（\(d=4\) + 数维输入） | 小是接法约束，不是跟谁比；禁止先加宽到 \(d\ge 8\) 再宣布更好 |
| 车上 | 出厂训完 **冻 \(\theta\)**（可 INT8）；增量只动 \(k\)（滑窗 SGD） | 残差头与 \(k\) **不同时**解冻 |

**明确不做的头：** 接法 R、接法 V、点式 \(\Delta R\)、用 GRU 暗含第二条 \(\tau\)、故意把 LUT 降稀再让网补。

### 6.3 教师残差（两档，别混）

| 档 | 监督目标 | 用途 |
|----|----------|------|
| **诊断档** | \(e = U^{\mathrm{Py}} - U^{\mathrm{1RC}}\) | 看头会不会偷学第二指数；静置段「假赢」→ **失败对照**，写进 07-d |
| **本职档（默认过关）** | 先减物理 2RC（+ 可选 BV / OCP 打标）后再监督 \(\delta U\) | 吃信封内 ~2 mV 之后的尾巴；换脉宽 / SOC 窗仍须成立 |

打标用 `eval_nls` 的可分离静置 VarPro + 边沿 \(R_0(I)\) 口径；**不要**整段五参数联立 NLS 当表。

### 6.4 训练配方

1. **数据：** `Data/grid_pybamm`（可扩驾驶 / 长静置）；等温；与 LUT 烤表同一套缩放后的 SPMe。
2. **底板先固定：** 对着 PyBaMM 电压烤等效 1RC LUT + `scaler`；**冻住**再训 \(g_\theta\)。不读旧 `Data/ai_mlp`。
3. **损失：** 开环电压 MSE 或 Huber；**分段报**（边沿 / 前 30 s / 静置 60–120 s），不要只报整段一个数。休息 SOC / NIS **只验收、不进损失**。禁止 \(e^{\mathrm{post}}\) / \(s^+\) 反传。
4. **优化：** 离线 Adam 即可；BPTT 截断约 5–20 s（与滑窗同量级）；\(g_\theta\) 近 0 初始化；幅度软/硬封顶始终开。
5. **验证：** 必须换脉宽、换 SOC 窗口、至少一条非 SEQUENCE 节奏；固定 SEQUENCE 上贴静置不够过关。
6. **负例：** 1RC 自洽（ECM 烟测）上 \(\delta U\to 0\)；无边沿长静置不准写 \(k_1\)，也不准头去追 OCV。

### 6.5 过关读法

| 结果 | 读法 |
|------|------|
| 列 4 开环明显低于列 1，休息 SOC / NIS 不差，残差**不是**干净第二指数 | AI 有活；继续抠接法，**不换**量产默认 |
| 列 4 略低于列 1，但列 2 明显更好，半对数是第二指数 | **升阶优先**；记「应 2RC」，不换 AI 默认 |
| 列 4 「打赢」列 2，靠未封顶或动了 \(k\)/\(\Delta R\) | **作废**；重跑 |
| 仅诊断档静置贴上、本职档无增益 | 头在暗含 \(\tau_2\)；失败 |
| 信封外（末端 / 大电流 / 低温）贴上 | 先查策略信封；不为此加宽头 |

策略信封、影子 \(k\)、禁网写 \(k\) 全部沿用 [`Doc/07-b`](07-b-1RC查表残差与策略信封.md)。

## 8. 不做清单

- 本期优先上 180 串 AI 包级
- 把 5-param NLS / `eval_nls` 倒进发布 LUT
- 用旧 `Data/ai_mlp` 当 PyBaMM 轨底板
- AI 写 \(k\)、出 \(\Delta R\)、学门、学更新器
- 接法 R / V；\(d\ge 8\) 先加宽；LSTM 默认
- 故意把 LUT 降稀再让网补交叉项
- \(\delta U\) 进 ASIL 保护核；用 \(\hat U\) 限流代替最值芯测量电压
- \(h\) 扩进 EKF；残差头与 \(k\) 一起解冻
- 写 MCU / PPU 固件；车上 Adam / 整段 BPTT
- 为迁就 AI 改默认 SEQUENCE 或清掉 `Data/grid/` 舰队
- 发明「打赢 2RC 即量产换默认」的口子
