## 一句话

查表 + \(k\) 已经能上车（支线 1）。支线 2 要赢，必须做表写不进去的事。本期不问「网当表能不能更准」，只问：在 PyBaMM 当真电压的单芯轨迹上，**1RC + \(\delta U\)** 相对纯 1RC、物理 2RC、可选滞后，开环 / 休息 SOC 各差多少；以及「打赢 2RC」能不能当通关——默认不能。

---

## 1. 为什么插第 3 期

第 2 期把 180 串共用电流的门和主列跑齐了（方案 06-a，数字 06-b）。AI 叙事如果还停在「把网搬上 PPU」，会被查表打掉（05-c / 07-a）。

插本期，是为了三件事：

1. **AI 不能挡查表上车。** 量产默认仍是 LUT + \(k\)；本期对照不改第 2 期主档门。
2. **先用仿真把 \(\delta U\) 说清楚。** 真芯 / WLTP / 实车 10 Hz 仍归第 N 期；没有预言机数字，残差头没有验收口径。
3. **过关标准先锁死。** 「开环比 2RC 低」不是默认通关——若残差形状就是第二指数，物理升阶优先（07-b §11）。

## 2. 范围

| 做 | 不做 |
|----|------|
| **单芯 / 少量异常芯** 先 | 180 串包级优先（第 2 期已齐；包级 AI 后排） |
| PyBaMM SPMe 当「真电压」预言机 | 用 PyBaMM 换 `NMC100AhECM`；让 MLP 出电化学参数 |
| BMS 仍 1RC + EKF\((s,U_p)\) | 写 MCU / PPU 固件；车上解冻宽网 |
| 开环 \(e^{\mathrm{ol}}\)、休息 SOC、NIS 同一套口径 | 发明新指标；电压单独下降结题 |
| 策略信封沿用 07-b | \(\delta U\) 进保护核；用网写 \(k\) |

工况先短：有边沿、有回弹的 SEQUENCE 级；再加一条长静置看慢尾巴。等温即可；热耦合后排。

## 3. 四列对照

同一条真电流、同一只芯、同一套 OCV。BMS 估计器侧始终看见测量噪声后的 \(I,U,T\)。

| 列 | 真值 / 估计 | 用来答什么 |
|----|-------------|------------|
| **1. 纯 1RC 查表底板** | 真值可 1RC 或 PyBaMM；BMS = LUT（或等效 1RC）+ \(k\equiv 1\)（或已齐节点） | 地板：表在这条真电压上还能贴多少 |
| **2. 物理 2RC** | 真值 2RC（ECM 拆分 / 叠加按 07-a §2.2 口径）或 PyBaMM 投影；BMS = 钉死 \(C_2\) 的 2RC，\(R_2\) 表冻住，车上仍只写 \(k_0/k_1\) | 若残差是第二指数，这一列应打赢列 4 |
| **3. 1RC + 滞后（可选）** | 真值带简单滞后 / 路径项；BMS = 1RC + 显式滞后状态（不是 GRU） | 拆「路径 / 滞后」和「缺 \(\tau\)」；不需要就不跑 |
| **4. 1RC + AI 只出 \(\delta U\)** | BMS = 1RC LUT + \(k\) + 冻结 \(\delta U_{\mathrm{AI}}\)（接法 Δ） | AI 是否吃到**表写不进去**的东西 |

约束（锁进任务卡，不是口头）：

- AI **只出 \(\delta U\)**：禁写 \(k\)、禁出 \(\Delta R\)、禁学更新器（07-b §10）。
- \(\delta U\) 幅度封顶、隐状态维数 \(\le 4\)；增量时冻残差只动 \(k\)（若该组允许动 \(k\)）。
- 离开参考点用策略关信封（07-b），不把头加宽去贴末端 / 大电流 / 低温。

## 4. 双底板

两条轨不要混训练集，也不要混验收分子。

| 轨 | 底板 | 角色 |
|----|------|------|
| **ECM 轨** | 现有 `Data/ai_mlp` → 烤表 / LUT | 续第 0–2 期连续性；真值用乘性 1RC / 可选 2RC |
| **PyBaMM 轨** | **另建**等效 1RC LUT（舰队书式：电压反传 / 烤表，不要把 SPMe 参数塞进 BMS） | 当真电压预言机；BMS 仍查等效表 |

`Branch/eval_pybamm_rc/eval_nls`（及同目录笔记）：

- 角色是 **辨识 / 打标 / 信封数字**（07-b 已引用的 ~2 mV 信封）。
- **不是**把 5-param NLS 倒进车上查找表。
- 本期若用 NLS 曲线，只当教师残差或对照曲线，不进默认 LUT 发布路径。

OCV 仍用仓库 `ocv.py`。PyBaMM 默认参数集必须先缩到本模板 1C / 电压窗口，否则和「换了一只完全不同的芯」分不开（`Plan.md` §5.3）。

## 5. AI 只出 \(\delta U\)；打赢 2RC 非默认通关

过关读法（写进 07-d 表头）：

| 结果 | 读法 |
|------|------|
| 列 4 开环明显低于列 1，休息 SOC / NIS 不差，残差**不是**干净第二指数 | AI 有活：表结构写不进去的形状；继续抠接法，不换默认 |
| 列 4 略低于列 1，但列 2（物理 2RC）明显更好，残差半对数是第二指数 | **升阶优先**；GRU 不要暗含 \(\tau_2\)（07-b §1 / §11） |
| 列 4 「打赢」列 2，靠的是未封顶 \(\delta U\) 或动了 \(k\)/\(\Delta R\) | **作废**；重跑 |
| 信封外（末端 / 大电流 / 低温）列 4 贴上了 | 先查是否该关策略信封；不为此加宽头 |

策略信封、影子 \(k\)、禁网写 \(k\) 全部沿用 [`Doc/07-b`](07-b-1RC查表残差与策略信封.md)。本期不重开「用网更新 \(k\)」对照。

## 6. 任务卡骨架（3A…）

先锁验收口径；具体命令 / 脚本落地后补进 07-d，不在这里发明数字。

| 编号 | 问什么 | 验收口径（过关先写字，再填数） |
|------|--------|--------------------------------|
| **3A1** | ECM 轨：1RC 真值上，列 1 地板 | 开环贴近教师；\(k\equiv 1\) 时无假更新 |
| **3A2** | ECM 轨：2RC 真值，列 1 vs 列 2 | 慢尾巴上列 2 应明显收；列 1 允许系统性残差、休息 SOC 不长漂 |
| **3A3** | ECM 轨：同一 2RC 真值，列 4 vs 列 1 / 列 2 | 列 4 若只靠暗含 \(\tau_2\) 贴静置 → 记失败；形状分析进 07-d |
| **3B1** | PyBaMM 轨：等效 1RC LUT 地板（列 1） | 另建表可复现；不读 `Data/ai_mlp` 当 PyBaMM 底板 |
| **3B2** | PyBaMM 轨：列 1 vs 列 4 | \(\delta U\) 只吃 NLS/机理拆完后的残差；禁 \(\Delta R\) |
| **3B3** | PyBaMM 轨：列 4 vs 物理 2RC 投影（列 2） | **打赢列 2 非默认通关**；第二指数 → 升阶条目，不换 AI 默认 |
| **3C**（可选） | 列 3 滞后 | 仅当 PyBaMM / 真值残差显式像滞后时开；否则跳过 |
| **3G** | 门控负例 | 无边沿静置 / 慢尾巴窗：列 4 冻结时也不许写 \(k_1\) 追第二指数 |

公共断言：

- 更新路径不读旧 `Data/grid/` 做 Replay。
- 冻 `scaler.json`；禁止预热；禁止静默 `fit_scaler`。
- 电压 RMSE 单独下降不能结题；必须看休息 SOC / NIS / 残差形状。

## 7. 不做清单

- 本期优先上 180 串 AI 包级
- 把 5-param NLS / `eval_nls` 倒进发布 LUT
- AI 写 \(k\)、出 \(\Delta R\)、学门、学更新器
- 故意把 LUT 降稀再让网补交叉项
- \(\delta U\) 进 ASIL 保护核；用 \(\hat U\) 限流代替最值芯测量电压
- 写 MCU / PPU 固件；Adam；整段 BPTT 增量
- 为迁就 AI 改默认 SEQUENCE 或清掉 `Data/grid/` 舰队
- 发明「打赢 2RC 即量产换默认」的口子

## 8. 与第 N 期边界

| 第 3 期 | 第 N 期 |
|--------|---------|
| 仿真预言机（PyBaMM SPMe / ECM 2RC） | 真实 100 Ah NMC、认证 WLTP、实车 10 Hz |
| 单芯把 \(\delta U\) 口径跑清 | 用真数据改边沿**定义**，不改默认网格生成器 |
| 若残差确认第二指数 → 记「应升阶」，不在本期换 BMS 默认 | 升 2RC BMS 单独立项：\(C_2\) 钉死、\(R_2\) 冻住，车上仍只写 \(k\)（07-b §11） |
| 数字进 07-d | 重标 JSON / OCV；SOH 输入若立项当新模型 |

第 2 期包级门、停放漏电、驾驶电流（2H / 2I）不在本期重开。本期结论若要回写包级，另开任务卡，不偷偷改 06-a 主档。
