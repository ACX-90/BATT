## 0. 相对 NCM 的评估结论（先看这个）

对 LFP 做 ECM，不要按 NCM 的优先级「先加一只 RC」。量级来自文献与工程经验，不是某一款芯的出厂值。

| 优先级 | 结构 | 常温中段、相对平均 OCV + 1RC 的收益 | 何时才值得 |
|--------|------|--------------------------------------|------------|
| **1** | 充/放分向 OCV，或一只滞后态 \(H\) | 平台区常 **15–40 mV**，低温更大 | **默认就要**。Tran 等：LFP 最优是 1RC+滞后，不是裸 2RC |
| **2** | \(R_0,R_1,C_1=f(s,T,\mathrm{dir})\) | 两端与低温，几十 mV 到上百 mV | 与 NCM 相同，两端要比中段密 |
| **3** | 2RC（\(R_2C_2\)） | 长回弹 / 长恒流再吃 **数 mV 到十几 mV** | 休息 ≥ 数分钟、持续 SOP，且滞后已经单独建模 |
| **4** | 电流维 / Butler–Volmer | 大电流表观 \(R_1\) 下降 | SOP、快充 |
| **5** | 3RC / Warburg / 分数阶 | 时域窗常 **< 3–8 mV** | 只对齐 EIS 低频或 ≥10 min 同号指数尾巴 |
| **不要当 RC** | 两相相界、多颗粒记忆、充电过冲、热弛豫 | 可到 **十几～上百 mV**，换激励就漂 | 仿真用相界 / P2D；BMS 不要用电压去训第三只 \(\tau\) |

一句话：

> **LFP 的「高阶」首先是滞后与路径，其次才是扩散阶次。**  
> 先加 \(R_2\)、不加 \(H\)，平台区 SOC 仍会把十几毫伏的滞后啃成百分之几十的 \(s\)。

对仓库主线的含义（评估，不是改代码）：BMS 仍可锁一阶；LFP 相对 NCM 必须把 **OCV 分向或滞后态** 升成默认，而不是可选项。仿真若要造「1RC 吃不干净」的 LFP 真值，优先 **1RC + 滞后**，再开 2RC；不要只抄 NMC 的 \(R_2\sim 0.3\sim 0.5\,R_1\)、\(\tau_2\sim 90\,\mathrm{s}\) 就当 LFP。

## 1. 模型与参数定义

一阶 RC（Thevenin）ECM 的电路结构为：

```
        I →
  ○── R0 ──┬── R1 ──┬──○  Ut
           │        │
          C1        │
           │        │
           └────────┘
           │
          Uocv(SOC, T) [+ H]
           │
          GND
```

连续时间方程（放电电流 \(I>0\) 时压降为正）：

\[
\begin{aligned}
\dot{U}_{p} &= -\frac{U_{p}}{R_{1}C_{1}} + \frac{I}{C_{1}} \\
U_{t} &= U_{\mathrm{ocv}}(\mathrm{SOC},T) + H - I R_{0} - U_{p}
\end{aligned}
\]

时间常数：

\[
\tau_{1} = R_{1} C_{1}
\]

NCM 文档里 \(H\) 常取 0、用充放分表近似。LFP **不要默认 \(H=0\)**。\(H\) 的方程见 §8.1。

| 参数 | 名称 | 物理对应（集总） | 时间尺度 |
|------|------|------------------|----------|
| \(U_{\mathrm{ocv}}\) | 开路电压 | 两相共存钉住的化学势 + 石墨 staging；平台区 \(\mathrm{d}U/\mathrm{d}s\) 极小 | 静置充分后的平衡（LFP 常要数小时） |
| \(H\) | 滞后电压 | 充放路径、小环、多颗粒两相；热力学分量静置不消失 | 行程级；换向后按安时衰减 |
| \(R_{0}\) | 欧姆内阻 | 电解液离子电阻、集流体/极耳/接触、SEI 欧姆、橄榄石电子电阻 | 瞬时（µs–ms） |
| \(R_{1}\) | 极化电阻 | \(R_{\mathrm{ct}}\)、SEI/CEI，以及被 1RC 吞并的浓差 / 相界前端 | 秒级（典型 2–60 s，常温中段偏十几秒） |
| \(C_{1}\) | 极化电容 | \(C_{\mathrm{dl}}\) 集总，并吸收部分扩散 / 相界动力学 | 与 \(R_{1}\) 共同决定 \(\tau_{1}\) |

> **说明**：1RC 仍是 BMS 工程折中。电化学上 LFP 至少有「电荷转移（快）+ 固/液相扩散（慢）+ 两相相界 / 多颗粒（非指数）」三档。BMS 默认：1RC + 滞后。仿真或离线对照：2RC + 滞后。下文未特别声明时按 1RC 叙述，2RC 在 §7，更高阶与非集总在 §8。

二阶 Thevenin（两条并联 RC 串联在欧姆支路后）：

```
        I →
  ○── R0 ──┬── R1 ──┬── R2 ──┬──○  Ut
           │        │        │
           C1       C2       │
           │        │        │
           └────────┴────────┘
           │
          Uocv(SOC, T) + H
```

\[
\begin{aligned}
\dot{U}_{p1} &= -\frac{U_{p1}}{R_{1}C_{1}} + \frac{I}{C_{1}},\qquad
\dot{U}_{p2} &= -\frac{U_{p2}}{R_{2}C_{2}} + \frac{I}{C_{2}} \\
U_{t} &= U_{\mathrm{ocv}} + H - I R_{0} - U_{p1} - U_{p2}
\end{aligned}
\]

\[
\tau_{1}=R_{1}C_{1},\qquad \tau_{2}=R_{2}C_{2}
\]

| 参数 | 名称 | 物理对应（集总） | 时间尺度 |
|------|------|------------------|----------|
| \(R_{2}\) | 慢极化电阻 | 固相/液相浓差、孔隙扩散；LFP 还混进相界移动的前端 | 几十秒到数分钟，常比 NCM 偏长（典型 40–300 s） |
| \(C_{2}\) | 慢极化电容 | 扩散「储锂」集总，数量级通常大于 \(C_{1}\) | 与 \(R_{2}\) 共同决定 \(\tau_{2}\) |

EIS 对照（便于理解，不要求在线测）：

- \(R_{0}\) ≈ Nyquist 高频实轴截距（\(R_{\Omega}\)）
- \(R_{1}\) ≈ 中频半圆直径（\(R_{\mathrm{ct}}+R_{\mathrm{SEI}}\) 的集总）
- \(C_{1}\) ≈ 半圆对应的等效电容
- 低频 45° 扩散尾巴（Warburg）在 1RC 中被部分并入 \(R_{1}C_{1}\)；2RC 里主要由 \(R_{2}C_{2}\) 承担
- LFP 正极两相 + 粒度分布会把低频弧压扁、时间常数分散，CPE / DRT 比单只 RC 更贴 EIS；车上仍用整数阶 RC
- 再低频的准电容爬升、以及**静置后仍分叉的 OCV**，1RC/2RC 都吃不掉，见 §8.1–§8.2

HPPC / 脉冲对照：

- \(R_{0} = \Delta U_{\mathrm{instant}} / I\)（电流阶跃后第一个采样点的电压跳变）
- 1RC：\(R_{1} \approx (\Delta U_{\mathrm{end}} - \Delta U_{\mathrm{instant}}) / I\)，\(\tau_{1}\) 由搁置单指数拟合，\(C_{1}=\tau_{1}/R_{1}\)
- 2RC：短窗定快支路，长搁置（≥ \(3\tau_{2}\)）定慢支路
- **LFP 多一步**：同一 SOC 的充电脉冲与放电脉冲不要平均进一张表；回弹末点不要直接当 \(U_{\mathrm{ocv}}\)——那是「这条路径上的表观 OCV」，里面有 \(H\)

LFP 电压窗口（工程常用，具体以规格书为准）：

| 项目 | 典型值 |
|------|--------|
| 下限 / 标称 / 上限 | 2.50 / 3.20 / 3.65 V（有的下限 2.0 V，上限 3.60–3.65 V） |
| 平台 | 约 3.20–3.35 V，覆盖大约 15%–90% SOC |
| 斜率有用的区间 | 大约 SOC < 10% 与 SOC > 90%（多半是石墨两端，不是 LFP 正极） |

跨规格比较电阻时仍优先 **mΩ·Ah** 或 **mΩ·cm²**，不要直接比绝对毫欧。

## 2. 参数的共性

LFP 的 \(R_{0}\)、\(R_{1}\)、\(C_{1}\)（以及 2RC 的 \(R_{2}\)、\(C_{2}\)，以及 \(H\)）**都不是常数**：

\[
P = f(\mathrm{SOC},\; T,\; I,\; \mathrm{方向},\; \mathrm{SOH},\; H\text{ 路径},\; \mathrm{体系})
\]

其中 \(P \in \{R_{0}, R_{1}, C_{1}, R_{2}, C_{2}, H\}\)。各因子的相对强度大致为：

| 影响因素 | \(R_{0}\) | \(R_{1}\) | \(C_{1}\) | \(R_{2}\) | \(C_{2}\) | \(H\) / OCV 分叉 |
|----------|-----------|-----------|-----------|-----------|-----------|------------------|
| 温度 \(T\) | 强（Arrhenius，常比 NCM 更陡） | 很强 | 中等偏弱 | 强 | 中等偏弱 | 中：降温变宽 |
| SOC | 中（两端比 NCM 更陡，平台中段平） | 强（低 SOC 升得更猛） | 中，易漂 | 中–强 | 中，易漂 | 中：常在 ~30% 与 ~60% 有局部峰 |
| 电流倍率 / 方向 | 弱–中 | 中–强（Butler–Volmer） | 弱 | 弱–中 | 弱 | 弱于温度；小环幅值随深度变 |
| SOH / 老化 | 中–强，总体升，通常慢于高镍 | 强、总体升 | 总体降 | 强、总体升 | 总体降 | 弱–中，电芯间差得大 |
| 充/放不对称 | 弱–中 | 中–强 | 弱 | 弱–中 | 弱 | **这就是 \(H\) 本身** |
| 辨识可观性 | 高、稳健 | 中 | 偏低，易与 \(R_{1}\) 耦合 | 需很长搁置 | 最低 | 要分向静置；与残余 \(U_p\) 易混 |

LFP 相对 NCM 的整体差别：

- OCV–SOC **极平**。平台区 \(\mathrm{d}U_{\mathrm{ocv}}/\mathrm{d}s\) 常只有 **0.1–1 mV / %SOC**（NCM 中段常 5–15 mV/%）。电压新息几乎看不見 \(s\)，参数误差、滞后、残余极化都会被 EKF **误当成 SOC**。
- 电压滞后 **大**。常温充放 OCV 分叉典型 **15–40 mV**，局部可到 ~40–50 mV；0 °C 相对 25 °C 再加约 10–20%。NCM 常 5–15 mV，分充放表往往够；LFP 建议显式滞后态，至少充放两张 OCV。
- 参数随 SOC：中段更平、**两端更陡**，低 SOC 的 \(R_{1}\) 升幅通常大于同规格 NCM。
- 正极没有高镍 H2–H3；OCV 两端「膝盖」主要来自 **石墨 staging**。因为正极平台太平，负极指纹比 NCM 更刺眼。
- 低温功率通常 **差于** 同能量密度档的 NCM：电子电导差、电解液 + \(R_{\mathrm{ct}}\) 一起掉。有对照：0 °C 相对 40 °C，LFP 的 \(R_0\) 可涨 ~160%，NMC 同条件约 ~44%（见 §14 [11]）。
- 老化：橄榄石不放氧、循环寿命长，\(R_0\) 增长通常慢于高镍；主要短板是低温、铁溶出（高温）、以及平台区 SOC 不准带来的过充/过放。
- 安全窗口电压低（上限 ~3.65 V），日历氧化比 4.2 V 三元温和。

## 3. R0（欧姆内阻）特性

### 3.1 物理图像

\(R_{0}\) 描述电流一施加就立刻出现的电压跳变，不经过电容充电。组成与 NCM 同类，LFP 多一项 **正极本体电子电阻**：

1. 电解液离子电导（隔膜孔隙）
2. 集流体、极耳、焊点 / 软连接、颗粒–集流体接触
3. SEI 欧姆分量
4. **橄榄石正极电子电导低**（LiFePO₄ 本征电导 ~10⁻⁹ S/cm 量级，靠碳包覆、纳米化；FePO₄ 相更差）

因此 LFP 的 \(R_0\) 对碳包覆质量、压实、极片厚度更敏感。功率型（薄电极、重碳包覆）与能量型（厚电极、刀片）的 \(R_0\) 可以差一截。

瞬时压降：

\[
\Delta U_{0} = I \cdot R_{0}
\]

热功率中，欧姆热 \(I^{2}R_{0}\) 仍占主要份额；低温下 \(R_{1}\) 产热占比上升，与 NCM 同方向但来得更早。

### 3.2 随 SOC

典型形态是 **中段平坦、两端翘起（比 NCM 更陡的浅 U）**：

- **20%–80% SOC**：相对平坦。两相共存区化学势钉住，本体电导变化不大。
- **SOC < 15%–20%**：明显升高，升幅常大于同规格 NCM。低 SOC 时放电产物偏 FePO₄（电子更差）、电解液锂活度变化、负极近空。
- **SOC > 90%**：轻度到中度升高。正极已接近单一 Li 富相，但全电芯上更多是石墨 Stage-1 末端与接触变化。
- 中段偶发小凸起：多来自负极 staging，不是 LFP 相变尖峰（LFP **没有** 4.2 V 附近的 H2–H3）。

工程含义：功率限制和低温 SOP 卡在低 SOC；满电附近 \(R_0\) 抬升会放大充电末端压差。平台中段用 \(R_0(s)\) 去「看 SOC」几乎没信息。

### 3.3 随温度（LFP 上往往比 NCM 更陡）

\[
R_{0}(T) = R_{0,\mathrm{ref}} \cdot \exp\left[\frac{E_{a,0}}{R}\left(\frac{1}{T}-\frac{1}{T_{\mathrm{ref}}}\right)\right]
\]

| 项目 | LFP 典型范围 | 对照 NCM（`Doc/01-a`） |
|------|----------------|------------------------|
| 表观活化能 \(E_{a,0}\) | 约 20–45 kJ/mol（常略高于中镍 NCM） | 约 15–35 kJ/mol |
| 25 °C → 0 °C | \(R_{0}\) 约增至 **2–4 倍**（有数据相对 40 °C 已 ~2.6×） | 约 1.5–2.5 倍 |
| 25 °C → −20 °C | \(R_{0}\) 约增至 **4–10 倍** | 约 2–5 倍 |
| 25 °C → 45 °C | \(R_{0}\) 约降至 0.5–0.8 倍 | 约 0.6–0.8 倍 |

物理原因：电解液电导仍是 Arrhenius；LFP 额外叠了碳包覆网络与橄榄石本体电导的热激活。高温 \(R_0\) 下降有利于功率，但加速电解液分解与铁溶出。

> 低温下 \(R_0\) 升高是 LFP 功率差的重要原因，但通常 **仍不如 \(R_1\) 升得猛**。0 °C 以下总极化多半由极化支路主导。预热策略对 LFP 的回报比 NCM 更大。

### 3.4 随电流与充放方向

- 理想欧姆项与电流无关。
- 实测 \(R_0\) 随倍率轻微变化：自热偏低、采样偏晚把快极化算进 \(R_0\)、接触 / SEI 轻微非线性。
- 充/放不对称弱于 \(R_1\)，但低 SOC 放电 \(R_0\) 往往略高（FePO₄ 相更多）。

标定：至少分 **充电表 / 放电表**；SOP 再加 0.5C / 1C / 2C，或把非线性放到 \(R_1\)。

### 3.5 随老化（SOH）

容量衰减的同时 \(R_0\) 总体上升，仍是可用的电学健康因子，但 **单调性和幅度通常弱于高镍 NCM**。

| 机理 | 对 \(R_{0}\) 的作用 |
|------|---------------------|
| SEI 持续生长、电解液消耗 | 离子通路变差（与 NCM 同类，因电压低常更慢） |
| 铁溶出、沉积到负极 | 界面恶化，高温储存更明显 |
| 碳包覆脱落、颗粒开裂、接触松动 | 电子网络变差，\(R_0\) 升 |
| 产气、膨胀导致接触松动 | 间歇或阶跃上升（刀片 / 大面软包要盯机械约束） |
| 析锂（低温 / 大倍率充电） | 表面膜加厚，\(R_0\) 加速上升 |

经验量级（只作量级感）：

- 容量保持 80% 时，\(R_0\) 相对 BOL 常见 **20%–80%**（高镍 NCM 常 30%–100%+）
- 高温高 SOC 储存会抬 \(R_0\)，但上限电压低，日历氧化一般轻于 4.2 V 三元
- 循环寿命长不代表 \(R_0\) 不变：厚电极、低温快充仍会明显涨阻

Tran 等的综合结论仍适用：**SOH 下降时欧姆电阻与极化电阻上升，极化电容下降**。

### 3.6 体系与规格差异

| 体系 / 规格 | \(R_{0}\) 倾向 |
|-------------|---------------|
| 纳米 LFP + 重碳包覆 / 功率型 | \(R_0\) 低、低温相对能用 |
| 厚电极能量型 / 刀片 | \(R_0\) 与极化都更大，沿厚度剖面更重 |
| 磷酸锰铁锂 LMFP | 电压平台抬高，\(R_0\) 常略高于纯 LFP，见 §9.3 |
| LFP + 硅碳负极 | 膨胀大，接触电阻波动与低 SOC 升高更明显 |
| 容量归一 | 仍用 \(R_0\cdot Q\)（mΩ·Ah）比较 |

室温、中 SOC、BOL 的数量级（放电直流、秒级以内）：

| 电芯形态 | 典型容量 | \(R_{0}\) 量级 |
|----------|----------|----------------|
| 26650 / 32700 | 3–6 Ah | 8–25 mΩ |
| 软包 50 Ah 级 | 40–60 Ah | 0.8–2.5 mΩ |
| 方壳 100 Ah+ | 100–280 Ah | 0.3–1.5 mΩ |
| 刀片 / 长薄大电芯 | 100 Ah 级 | 绝对毫欧可以很低，比面积电阻不一定低 |

### 3.7 对系统的影响

- 决定电流阶跃瞬间的电压裕度，直接卡充电上限 / 放电下限。
- SOP 对 \(R_0\) 最敏感。
- 在线内阻、SOH、一致性的首选特征（平台区 SOC 帮不上忙，更要靠 \(R_0\) 散差解释压差）。
- 采样过慢会把 \(R_1\) 快头混进 \(R_0\)。

## 4. R1（极化电阻）特性

### 4.1 物理图像

\(R_{1}\) 描述电流施加后 **逐渐建立、撤流后逐渐消退** 的过电位幅度。1RC 里它是：

1. 电荷转移（Butler–Volmer），\(R_{\mathrm{ct}}\)
2. SEI / CEI 膜中的离子迁移
3. 部分浓差极化
4. **部分两相相界推进的前端**（本不该是线性 RC）

因此 \(R_{1}\) 比 \(R_{0}\) 更「电化学」，对温度、SOC、电流、表面状态更敏感。LFP 上还对「此刻颗粒处于单相还是两相」敏感，换路径会漂。

极化电压动态：

\[
U_{p}(t) = I R_{1}\left(1-e^{-t/\tau_{1}}\right) + U_{p}(0)\,e^{-t/\tau_{1}}
\]

脉冲足够长时，稳态极化压降 \(\approx IR_{1}\)。充电方向有时先过冲再落，单指数不够，见 §8.3。

### 4.2 随 SOC（强于 R0，低端比 NCM 更猛）

典型形态是 **深 U / 浴缸，低 SOC 升幅更大**：

- **30%–70% SOC**：相对最低。两相共存，交换电流由相界面积支撑，中段往往还能用。
- **低 SOC（<20%，尤其 <10%）**：显著升高，常达中段的 **3–8 倍**（NCM 文档写 2–5 倍）。正极近纯 FePO₄、负极脱锂末期，\(i_0\) 掉。
- **高 SOC（>85%–90%）**：升高，但通常弱于低 SOC；充电方向更明显。没有高镍相变尖峰，膝盖主要是石墨 + 单相区动力学。
- 石墨 staging 区间可能出现局部峰（约 50%–60% 全电芯 SOC），在平坦 OCV 上相对更显眼。

工程含义：低 SOC 放电与高 SOC 快充的电压动态误差，多半来自 \(R_{1}\) 表不准。平台中段 \(R_{1}\) 估错 **不会** 像 NCM 那样立刻通过 OCV 斜率被 SOC 滤波吃掉，而会在端电压上直接露出，或被啃进 \(H\)。

### 4.3 随温度（三个电阻里最陡，LFP 更差）

\[
R_{1}(T) = R_{1,\mathrm{ref}} \cdot \exp\left[\frac{E_{a,1}}{R}\left(\frac{1}{T}-\frac{1}{T_{\mathrm{ref}}}\right)\right]
\]

| 项目 | LFP 典型范围 | 对照 NCM |
|------|----------------|----------|
| 表观活化能 \(E_{a,1}\) | 约 35–70 kJ/mol | 约 30–60 kJ/mol |
| 25 °C → 0 °C | \(R_{1}\) 约增至 **3–6 倍** | 约 2–4 倍 |
| 25 °C → −20 °C | \(R_{1}\) 约增至 **8–30 倍** | 约 5–20 倍 |
| 常温附近 | \(R_{1}\) 与 \(R_{0}\) 同量级，常为 \(0.5R_{0}\)–\(2.5R_{0}\) | \(0.5R_{0}\)–\(2R_{0}\) |
| 低温 | \(R_{1} \gg R_{0}\) | 同方向 |

这是 LFP 低温功率差、低温充电易析锂的电路侧表现：同样电流下过电位大，负极电位更容易被打到 0 V vs Li/Li⁺ 以下。预热、脉冲加热、低温降流对 LFP 是刚需，不是锦上添花。

### 4.4 随电流（Butler–Volmer 非线性）

小电流下 \(R_{\mathrm{ct}}\) 近似线性；大过电位下表观电荷转移电阻下降：

\[
R_{\mathrm{ct,eff}}(I) \propto \frac{\eta}{i_{0}\sinh(\alpha F\eta / RT)}
\]

因此：

- 用 0.5C HPPC 辨出的 \(R_{1}\) 直接用于 2–3C 脉冲，往往会 **偏大**；
- 用大电流脉冲辨出的 \(R_{1}\) 用于小电流，可能 **偏小**；
- 自热叠加，进一步降低大电流下的表观 \(R_{1}\)；
- 两相区大电流还可能改变相界面积，表观 \(R_{1}\) 与路径有关，不是纯 BV。

工程做法（按精度需求选一）：

1. \(R_{1}=f(\mathrm{SOC},T)\)，忽略电流（简单；LFP 低温 SOP 会偏）
2. 增加电流维或充放分表
3. 用简化 Butler–Volmer / 非线性电阻替换线性 \(R_{1}\)

### 4.5 充 / 放不对称

LFP 的 \(R_{1}\) 充放不对称 **不小于** NCM，并与 \(H\) 强耦合：

- 低 SOC：放电 \(R_{1}\) 通常更大
- 高 SOC：充电 \(R_{1}\) 往往更大
- 充电时相核形成可造成过冲（看起来像短暂更大的 \(R_{1}\)）
- 放电时相界收缩，过冲少、拖尾多

若 OCV 只用一条平均曲线，辨识会把滞后「吞」进 \(R_{1}\)（以及 \(R_{2}\)）：

- 充电段表观 \(R_{1}\) 偏小或甚至非物理
- 放电段表观 \(R_{1}\) 偏大
- 换向工况（回收、脉冲）参数对不上

正确做法是 **OCV 分充放或带滞后态 + \(R_{1}\) 分充放**。LFP 上这一条是默认，不是增强项。

### 4.6 随老化

总体随 SOH 下降而增大：

- 活性比表面积下降、碳网络断裂 → \(i_0\) 下降 → \(R_{\mathrm{ct}}\) 上升
- SEI 增厚 → 膜电阻上升
- 铁溶出 / 析锂后表面膜可阶跃
- 两相颗粒失联后，剩余颗粒过电位更大，\(R_{1}\) 涨得比 \(R_0\) 更明显

部分实验中 \(R_{1}\) 的相对增幅 **大于** \(R_{0}\)，尤其日历老化与低温循环。不要用平台中段的电压 RMSE 单独当老化指标。

### 4.7 与 R0 的相对关系

室温中 SOC、健康电芯：

\[
R_{1} \sim (0.5\sim 2.5)\,R_{0}
\]

温度降低或 SOC 走到两端时，\(R_{1}/R_{0}\) 迅速变大，低温比 NCM 更极端。只标一个总内阻 \(R_{\mathrm{dc}}\) 可以做粗 SOP，但无法描述回弹；漏掉 \(R_{1}\) 会在低温 / 低 SOC 把电压预测打得偏乐观。

## 5. C1（极化电容）特性

### 5.1 物理图像

\(C_{1}\) 不是一只真实电子学电容，而是把双电层充电、以及被 1RC 吸收的部分扩散 / 相界过程，集总成能存储电荷的元件。数量级仍是 **千法到十万法**：

\[
C_{1} \sim C_{\mathrm{dl}} \cdot A_{\mathrm{active}}
\]

\(C_{1}\) 不产生欧姆热，它决定极化建立 / 消退有多快。

### 5.2 随 SOC

规律不如 \(R_{0}/R_{1}\) 稳定。LFP 上还多一种污染：**把未走完的滞后 / 相界当成电容**。文献中常见：

- 中高 SOC 较大、低 SOC 减小
- 随 SOC 缓慢上升
- 两端略降、中段平坦

辨识上 \(C_{1}\) 与 \(R_{1}\) 强耦合：\(R_{1}\uparrow \leftrightarrow C_{1}\downarrow\) 仍能贴电压。更稳健的做法：

- 先拟合 \(\tau_{1}\) 和 \(R_{1}\)，再算 \(C_{1}=\tau_{1}/R_{1}\)
- 对 \(C_{1}(s)\) 做平滑 / 上下界
- **先扣掉 \(H\)**，再拟合指数；否则 \(\tau_{1}\) 会被拉到分钟级去「追」那条不回零的分叉

### 5.3 随温度

- 双电层电容随温度轻度增加
- \(R_{1}\) 随温度急剧下降

合在一起：温度升高 → \(\tau_{1}\) 变短。低温下不仅极化幅度大，建立 / 消退更慢；LFP 的静置要到小时级才像 OCV，短脉冲辨 \(C_{1}\) 比 NCM 更容易漂。

### 5.4 随老化

多数数据同一方向：

> **SOH 下降 → 极化电容 \(C_{1}\) 下降。**

\(C_{1}\) 下降 + \(R_{1}\) 上升，\(\tau_{1}\) 方向不确定。 **不要单独用 \(C_{1}\) 或 \(\tau_{1}\) 做 SOH**；\(R_{0}\) 或短时 \(R_{\mathrm{dyn}}\) 更可靠。

### 5.5 数量级

| 电芯 | \(C_{1}\) 量级 | \(\tau_{1}\) 量级（1RC） |
|------|----------------|--------------------------|
| 26650 / 32700 | \(10^{3}\)–\(10^{4}\) F | 2–40 s |
| 软包 / 方壳 50–100 Ah | \(10^{4}\)–\(10^{5}\) F | 5–60 s |
| 若拆成 2RC | 快支路 0.5–10 s；慢支路 40–300 s | |

「几千法拉」是正常的。LFP 的 1RC \(\tau_{1}\) 往往被慢过程拉得比 NCM 更长——这经常是阶次不够，不是 \(C_{1}\) 真有那么大。

### 5.6 辨识注意点

- 激励频谱敏感：脉冲太短，\(C_{1}\) 偏小；搁置太短，慢过程 + 滞后没结束，\(C_{1}\) 偏大
- 电流偏置、SOC 漂移先污染 \(C_{1}\)
- 在线 RLS / EKF 应对 \(C_{1}\) 做上下界和慢变化约束
- 工程上辨识 \((R_{0}, R_{1}, \tau_{1})\) 比直接辨 \(C_{1}\) 更稳
- 方案 B（钉死 \(C_{1}^\star\)）对 LFP 仍然合理，甚至更有必要：可观性比 NCM 更差

## 6. 时间常数 τ1 与动态表现

\[
\tau_{1}=R_{1}C_{1}
\]

| 工况 | \(\tau_{1}\) 倾向 | 端电压表现 |
|------|-------------------|------------|
| 常温、中 SOC、BOL | 数秒到几十秒（常被慢过程拉长） | 阶跃先直跳（\(R_{0}\)）再指数弯 |
| 低温 | 明显变长，可到分钟 | 回弹慢，短行程走不到稳态 |
| 低 / 高 SOC | 变长（\(R_{1}\) 主导） | 末端电压拖尾 |
| 老化 | 多数变长 | 同一工况动态误差变大 |
| 大电流 | 表观 \(\tau_{1}\) 可能变短 | 非线性 + 自热 |
| 充电相变核 | 先快后慢，或过冲 | 单指数残差先反号再同号，见 §8.3 |

1RC 的固有缺陷与 NCM 相同：一个 \(\tau_{1}\) 顾不了 1 s 电荷转移和 100 s 级扩散。LFP 额外的缺陷：指数核拟合不了两相与滞后。

- 关心 10 s 功率、HPPC 10 s 电阻：1RC 通常够用（仍要分向 OCV）
- 关心长时间恒流末端、休息 10 min 回弹、低频 EIS：2RC
- 关心休息点 SOC、充放切换、平台区电压：先上滞后，再谈 2RC

## 7. 二阶 RC（R2、C2）特性

2RC 把 1RC 里被吞掉的慢过程拉出来。快支路更接近电荷转移 / 膜，慢支路更接近扩散（LFP 还混相界前端）。边沿几乎只有 \(R_{0}\)，数秒内看见 \(U_{p1}\)，几十秒到数分钟才看见 \(U_{p2}\)。

**LFP 上 2RC 的位置**：有用，但是 **滞后之后** 的下一档，不是替代滞后。Hu / Tran 等比较：LFP 上「1RC+滞后」常优于「2RC 无滞后」。仓库主线对 NMC 是「BMS 1RC、仿真可 2RC」；迁到 LFP 时，仿真优先「1RC+H，可关 2RC」，不要只开 2RC。

### 7.1 物理图像

锂离子在电解液孔隙和活性颗粒内部的扩散，频域接近 Warburg，时域是一串连续时间常数。2RC 用一只慢 RC 做最粗有理近似。LFP 颗粒内还有移动相界：前几分钟的「慢指数」里经常已经混进相界，参数随 SOC 路径变。

- \(R_{2}\)：慢极化幅度（稳态浓差 / 相界过电位 \(\approx I R_{2}\)）
- \(\tau_{2}\)：有多慢
- \(C_{2}=\tau_{2}/R_{2}\) 仍是集总；100 Ah 级常见 \(10^{5}\) F 量级

短脉冲、10 s SOP、边沿内阻看 \(R_{0}+R_{1}\)；停车数分钟后的电压、长时恒流末端看 \(R_{2}\)。**停车后仍按充放方向分叉的那几毫伏到几十毫伏，不是 \(R_{2}\)**。

### 7.2 时间尺度要分开

两条 \(\tau\) 必须差开大约半个数量级以上。LFP 大电芯上常见：

| 支路 | \(\tau\) 典型 | 主要看见它的波形 |
|------|----------------|------------------|
| 快 \(R_{1}C_{1}\) | 0.5–15 s（1RC 里常被拉到几十秒） | 脉冲上升前几秒、撤流后的快回弹 |
| 慢 \(R_{2}C_{2}\) | 40–300 s（常比 NCM 模板 90 s 偏长） | 撤流 1 min 之后的尾巴、数分钟恒流末端 |

\(\tau_{2}/\tau_{1}\lesssim 3\)：双指数不稳。  
\(\tau_{2}\gtrsim 10^{3}\,\mathrm{s}\)：与「OCV / \(H\) 没静置够」分不清。LFP 更容易踩这条：静置 30 min 电压还在爬，不一定是第三只 RC。

### 7.3 随 SOC

\(R_{2}\) 两端升高，低 SOC 更明显：

- 中段相对最低
- 低 SOC：扩散系数下降 + 相界走到颗粒深处，长时放电末端「掉得比 1RC 快」
- 高 SOC：充电末端更明显；石墨 staging 附近可有局部结构

\(C_{2}\)–SOC 易被噪声弄脏。先盯 \(\tau_{2}\) 是否光滑。

### 7.4 随温度

固相扩散、电解液浓差、相界迁移都是热激活。\(R_{2}\) 的表观 \(E_a\) 通常介于 \(R_{0}\) 与 \(R_{1}\) 之间或接近 \(R_{1}\)（约 25–50 kJ/mol）。低温下：

- \(R_{2}\) 升、\(\tau_{2}\) 可到数分钟～十几分钟
- 短脉冲走不到慢稳态，1RC 会把未走完的慢过程误判成更大的 \(\tau_{1}\)
- 低温充电「过电位迟迟不消」里，慢支路 + 滞后一起占比上升

### 7.5 随电流与充放

扩散支路的电流非线性弱于电荷转移。工程上 \(R_{2}(s,T)\) 往往先不加电流维；要加也是弱的正修正。充放不对称存在，但若 \(H\) 没单独建模，慢回弹会被吞进 \(R_{2}\)，表现为充放 \(R_{2}\) 对不上——LFP 上这是默认现象，不是偶发。

### 7.6 随老化

与 \(R_{1}\) 同向：SOH 下降 → \(R_{2}\) 升、\(C_{2}\) 降。孔隙堵塞、颗粒裂纹、碳网络脱落都拉长扩散路径。不要单独用 \(R_{2}\) 或 \(\tau_{2}\) 当 SOH：可观性差。内阻 SOH 仍以 \(R_{0}\) 或短时 \(R_{\mathrm{dyn}}\) 为主。

### 7.7 对 1RC 表的含义

用 1RC 去拟合其实是 2RC 的 LFP 电芯时：

- \(R_{0}\) 仍大致对
- \(R_{1}\) 偏大，\(\tau_{1}\) 落到 \(\tau_{1}^{\mathrm{true}}\) 与 \(\tau_{2}\) 之间，随激励频谱变
- 短窗（10 s）电压往往仍可用；长搁置、长恒流出现系统性慢残差

这不是辨识失败，是模型阶次不够。**若同时没建 \(H\)**，残差里会再混一条「换向才翻号、静置不回零」的分量，看起来像更大的 \(R_{2}\)，换路径就崩。定量阶次误差的写法可对照 `Doc/02-a` §11、`Doc/02-b` §10，但那些数字是 NMC 模板；LFP 要把滞后从「未建模物理」里单列出来，不能算进 2RC 预算。

## 8. 更高阶与非集总

2RC 之后每加一只 RC，多一对 \((R_i,C_i)\) 和一条 \(\tau_i\)，电压上限略升，可观性迅速变差。LFP 上「再往上」的清单与 NCM **不完全一样**：有一类必须先做，有一类加 RC 也吃不掉。

| 结构 | 多出来的是什么 | 时间 / 频率 | LFP 上何时才值得想 |
|------|----------------|-------------|---------------------|
| **滞后态 / 分向 OCV** | 充放分叉、小环、路径 | 行程级 | **默认**。不是「更高阶可选项」 |
| 3RC | 更慢扩散或热–电尾巴 | \(\tau_{3}\) 常 5–30 min | 滞后已建模，且休息 10 min 后 2RC 仍有数 mV **同号指数**残差 |
| PNGV / 串联电容 | 脉冲期内 OCV 随 SOC 下滑 | 与安时同一尺度 | LFP 平台区 \(\Delta U_{\mathrm{ocv}}\) 很小，**比 NCM 更不需要**；两端 SOC 才要扣 |
| Warburg / 有限空间扩散 | \(1/\sqrt{j\omega}\) 连续谱 | 低频 EIS | 对齐 EIS 尾巴；时域几分钟窗增益小 |
| CPE / 分数阶 / DRT | 压扁半圆、分散时间常数 | 中低频 | 离线阻抗；车上离散贵 |
| 两相相界 / 收缩核 | 移动边界，有效 \(\tau\) 随进度变 | 分钟～小时 | 仿真；BMS 不要用电压训 \(\tau_{3}\) |
| 多颗粒记忆 | 颗粒逐个翻转，依赖历史 | 行程级 | 表现为小环 / 记忆效应，用滞后模型而不是 RC |
| 充电过冲（类 RLC） | 成核过电位 | 数秒～数十秒 | 只在充电边沿；加 RC 会把放电也弄坏 |
| P2D / SPMe | 浓度场 | 多尺度 | 仿真对照，不是 BMS 电路 |

经验量级（100 Ah、1C、常温中 SOC，只作**参考点**）：

- 平均 OCV + 1RC → 分向 OCV 或 +H：平台区常再吃 **15–40 mV**（主项）
- 1RC+H → 2RC+H：长回弹 / 长恒流再吃 **数 mV 到十几 mV**
- 2RC+H → 3RC：再吃 **2–8 mV**，且必须有 ≥10 min 搁置
- 3RC → Warburg / 分数阶：时域工况上往往 **< 3 mV**

「显著」在本文：2RC+H 已按自己的窗（约 \(3\tau_{2}\)）辨好之后，仍有 \(\gtrsim 8\)–\(10\,\mathrm{mV}\) 的**同号结构化**残差，或截止电压 / 持续 SOP / 休息点 SOC 被系统性拉偏。短窗 RMSE 好看不算覆盖住。

### 8.1 滞后：LFP 真正的「下一阶」

滞后不是一只 RC。RC 撤流后按指数回零；LFP 充放 OCV 在充分静置后 **仍然分叉**。这是热力学 / 多颗粒两相路径，不是没歇够。

拆成两层：

| 层 | 静置 24 h 后 | 电路上像什么 | 该怎么建模 |
|----|----------------|--------------|------------|
| 残余极化 \(U_{p1},U_{p2}\) | → 0 | 指数回弹 | RC |
| 真滞后 \(H\) | 仍在，符号随上一向电流 | 平行的两条 OCV | 分向表或滞后态 |

常温中段，充放大环半宽 \(M\) 典型 **8–25 mV**（全分叉 15–50 mV）。常见局部峰：约 30% SOC 一峰、约 60%–70% 一峰（石墨 staging 与 LFP 两相叠加，电芯间位置会漂）。低温变宽：0 °C 相对 25 °C 全分叉可再加 ~10–20%（有报告约 +13 mV）。倍率对大环宽度的影响通常弱于温度。

小环（没走满 0–100% 就换向）宽度小于大环，且依赖换向点。车上工况几乎全是小环。只标大环、用平均 OCV，回收 + 再加速时电压误差最大。

工程最小实现（Plett 单状态滞后，OSH）：

\[
\begin{aligned}
U_{\mathrm{ocv}}^{\mathrm{avg}} &= \tfrac12\bigl(U_{\mathrm{chg}}(s,T)+U_{\mathrm{dis}}(s,T)\bigr) \\
M(s,T) &= \tfrac12\bigl(U_{\mathrm{chg}}-U_{\mathrm{dis}}\bigr) \\
\dot H &= \lvert I\rvert\,\kappa\,\bigl(\mathrm{sgn}(I)\,M(s,T) - H\bigr)
\end{aligned}
\]

离散（与常见 BMS 写法一致）：

\[
H_{k+1} = e^{-\lvert \kappa I_k\Delta t\rvert}\,H_k
+\bigl(1-e^{-\lvert \kappa I_k\Delta t\rvert}\bigr)\,\mathrm{sgn}(I_k)\,M(s_k,T)
\]

- \(\kappa\) 控制换向后 \(H\) 追上 \(\pm M\) 有多快（单位 1/C 或 1/Ah）
- \(I=0\) 时 \(H\) 冻结——这是故意的：真滞后不靠搁置消去
- 只走大环时，分向 OCV 查表与 OSH 几乎等价
- 小环要准：OSH 往往不够，再上 Preisach / 若干继电器，或数据驱动 \(U_{\mathrm{ocv}}(s,\text{path},T)\)

对 1RC/2RC 辨识的硬约束：

1. 先定 \(U_{\mathrm{ocv}}^{\mathrm{avg}}\) 与 \(M\)（或两张 OCV），再拟合 \(R,C\)
2. 用休息末电压当 OCV 时，必须带「上一向电流」标签
3. 把 \(H\) 折进 \(R_{1}/R_{2}\) 后，换向工况必然漂；在线 RLS 会把 \(R\) 来回拧

相对 NCM：NCM 滞后 5–15 mV，分向电阻表常常掩盖过去。LFP 平台 \(\mathrm{d}U/\mathrm{d}s\) 太小，**15 mV 的 \(H\) 不是边角，是 SOC 主误差源**。

### 8.2 两相与多颗粒：不是集总 RC

橄榄石正极在很宽的 SOC 内是 LiFePO₄（α，富锂）与 FePO₄（β，贫锂）两相共存。单颗粒常见收缩核 / 核壳：相界径向推进。化学势被两相钉住，这就是平台。

多颗粒（Dreyer 等）：每个颗粒倾向于「要么几乎满、要么几乎空」，电芯 SOC 的连续变化靠 **已经翻转的颗粒分数**，不是每个颗粒的均匀浓度。后果：

1. 大环滞后有热力学分量，静置不消失（§8.1）
2. **记忆效应**：停在平台某处再继续，电压会短暂「记得」上一段，而不是马上回到主曲线
3. 有效活性面积随「正在翻转的颗粒数」变，表观 \(R_{1},R_{2}\) 依赖历史
4. 时间常数随相界位置变：刚成核时快，相界走到深处变慢——**不是恒定 \(\tau_{2}\)**

2RC 用恒定 \(R_{2}C_{2}\) 投影的是相界运动的**前端**。它故意丢掉：移动边界、颗粒间电流分配、成核过电位。某一条恒流可以被 3RC 贴上，换 SOC 或换向后参数乱跳。

显著工况：

- 平台中段部分循环（几乎所有实车）
- 充电开始的成核（过冲，§8.3）
- 长搁置后继续同一方向（记忆）
- 低倍率（C/10 以下）时热力学路径更清晰，滞后相对极化更显眼

对照请用两相 / 多颗粒电化学模型，不要把记忆残差写成 \(\tau_{3}\) 教师。

### 8.3 充电过冲

LFP 充电边沿常见：电压先冲高，再回落到「正常」极化轨。放电边沿少见或弱得多。机理是新相成核过电位，不是电感。

有文献在 2RC+滞后上再加变 \(\tau\) 的 RC，充电时改成 RLC 来拟合过冲。BMS 默认不要上 L：

- 只在充电、只在两相区、对倍率敏感
- 放电支路会被一个虚假振荡极点弄坏
- 过冲幅值常 **数 mV 到十几 mV**（低温 / 大电流更大）

工程处理：充电 \(R_{1}\) 表单独标定；允许充电边沿短窗残差；不要为过冲加电感器进 EKF。

### 8.4 连续谱：Warburg / 有限空间扩散

与 NCM 同构。半无限扩散 \(\propto 1/\sqrt{j\omega}\)；长恒流中间段 \(\propto\sqrt{t}\)，撤流中间段 \(\propto t^{-1/2}\)。单只 \(R_{2}C_{2}\) 从 \(t=0\) 就是指数，核形状对不齐。

LFP 额外让谱更宽：两相、粒度双峰、碳包覆不均匀。DRT 上常看到比 NCM 更散的低频峰。

2RC+H 已按 3–5 min 窗标好之后，仍会显著露馅的工况：

| 工况 | 为何不够 | 残差形态 | 100 Ah 量级（相对参考点） |
|------|----------|----------|---------------------------|
| 常温中 SOC，撤流后 10–30 min | 固相 / 相界有限空间尾巴 | 同号、近 \(t^{-1/2}\)，半对数下凸 | **2–10 mV**（先确认不是 \(H\)） |
| 低温（\(\le 0\,^{\circ}\mathrm{C}\)）同样搁置 | \(D_s\) 掉，\(\tau_s\) 拉到小时 | 同上，幅度放大 | **10–40 mV** |
| 小时级停车 / 把末点当 OCV | 2RC 已平，电压还在爬 **或** 停在分叉上 | 慢爬，或爬完仍分向 | 爬升数 mV；分叉 15–40 mV 归 \(H\) |
| EIS \(\lesssim 1\,\mathrm{mHz}\) | 45° 再转有限空间 | 形状误差 | 时域几分钟窗往往仍 \(<3\,\mathrm{mV}\) |

只为对齐 EIS 低频才上 Warburg。车上分数阶离散贵，且和 \(\tau_{2}\) 抢可观性。BMS 时域：承认 10 min 后有结构残差，**不要用这段去训 \(R\)**。

### 8.5 两条慢过程：3RC 有时能拆

液相 \(\tau_{\mathrm{e}}\) 与固相 \(\tau_{\mathrm{s}}\) 差一个多数量级时，3RC 的 \(\tau_{3}\sim 5\)–\(30\,\mathrm{min}\) 对应固相可观测前端。LFP 上 \(\tau_{\mathrm{s}}\) 还和相界耦合，第三条指数经常其实是「相界变慢」。

值得离线试 3RC 的判据（**同时**满足）：

- 滞后已建模，充放残差不再对翻号
- 2RC 在自己的窗里已经稳（\(\tau_{2}/\tau_{1}\gtrsim 4\)）
- 再搁置 \(\ge 10\,\mathrm{min}\)，仍有稳定数 mV **同号**残差
- 残差近似第三条指数，而不是 \(t^{-1/2}\)，且换倍率 / 换 SOC / **换向** 形状还在

不满足最后两条时，加 \(\tau_{3}\) 只是在这段休息上贴电压。这比方案 A 的 \(R_{1}\leftrightarrow C_{1}\) 补偿更不可观。

### 8.6 非集总：沿厚度的浓度场（P2D）

集总 2RC 假定整片电极一个过电位。大电流下反应挤向隔膜侧，集流体侧电解液可被抽空。盐浓度接近 0 时过电位**发散**，端电压下跌会**加速**，不是 \(1-e^{-t/\tau_{2}}\)。

LFP 能量型厚电极、刀片电芯这条比功率型圆柱更重。再加一只、两只 RC 仍然线性、仍然集总。

显著工况（常叠加才严重）：

- 连续 \(\lvert I\rvert\gtrsim 1.5\)–\(2\mathrm{C}\)（低 T 时 1C 就开始）
- 厚电极 / 长薄大电芯
- \(T\lesssim 10\,^{\circ}\mathrm{C}\)
- 低 SOC 放电或高 SOC 充电
- 快充末端

残差形态：长时恒流**后段**掉得比 2RC 快，对倍率**超线性**。100 Ah 量级：常温 2C 连续可到**几十 mV**；−10 °C × 1C 或低 SOC 2C 可到 **100 mV 量级**。对照用 P2D / SPMe，不要当 3RC 教师。

### 8.7 表面浓度触顶 / 触底

线性 \(R_{2}\)：稳态浓差 \(\propto I\)。真实 \(D_s(c)\) 在空态、满态下降；LFP 单相区（两端）和石墨两端尤其明显。

- 1C 放到 SOC \(\lesssim 10\%\) 的最后几分钟：电压掉切快于 2RC
- 充到 \(\gtrsim 90\%\)：石墨 Stage-1 末端过电位比表深
- 低温叠加上述两端

末端相对 2RC 常 **10–50 mV**，直接吃截止和剩余能量。表上加密两端 SOC，比加 \(\tau_{3}\) 有效。平台中段反而不是这条的主场。

### 8.8 看起来像更高阶、其实不是 RC 的

| 现象 | 时间 | 易被 2RC 当成 | 真正该做 |
|------|------|----------------|----------|
| **OCV 滞后 / 小环** | 行程级 | 充放 \(R_{2}\) 对不上、假 \(\tau_{3}\) | **滞后态**；LFP 主项 |
| 两相记忆 | 行程级 | 同 SOC 不同电压 | 路径状态，不是 RC |
| 充电过冲 | 数秒 | 负电容 / 振荡 | 分向 \(R_{1}\)，不要 L |
| 石墨 staging | 中段 / 低 SOC | \(R_{0}/R_{1}\) 局部峰 | 加密 SOC 网格 |
| 芯热惯性 | 5–30 min | \(\tau_{3}\) | 电–热耦合；大倍率后休息可能**反号** |
| 析锂 | 低温高 SOC 充电 | \(R_{1},R_{2}\) 一起涨且只在充电 | 限制电流；不要写进电阻表 |
| Butler–Volmer | 边沿–数秒 | 与阶次无关 | \(R_{1}\) 的 asinh |
| 电感 / 采样延迟 | µs–ms | 污染 \(R_{0}\) | 对齐采样 |
| 长脉冲未扣 \(\Delta U_{\mathrm{ocv}}\) | 与安时同一尺度 | PNGV / 假 \(R_{2}\) | 平台区这项比 NCM **小**；两端仍要扣 |

热–电：\(\ge 1.5\mathrm{C}\)、100 Ah、冷却一般时，停车 10 min 残差可 **5–15 mV**，符号可能与纯电扩散相反。等温 2RC 会把自热吃进偏小的 \(R\)。

### 8.9 工况对照（2RC 覆盖不了的误差）

| 工况 | 主因 | 2RC 无 H 时 | 2RC+H 后 | 加 RC？ |
|------|------|-------------|----------|---------|
| 常温中 SOC，HPPC 10 s / 1C 数分钟 | 参考点 | 短窗数 mV + 滞后偏置 | 短窗数 mV | 不必 |
| 平台区充放切换 / 回收 | 滞后 | 十几～40 mV，换向翻号 | 小环误差数 mV～十几 mV | **否**；滞后 |
| 撤流后 10–30 min | 固相连续谱 / \(\tau_{3}\) | 与 \(H\) 混在一起 | 同号慢尾巴 2–10 mV | 仅当第三条近似指数且换向仍同号，才离线试 3RC |
| 小时级搁置当 OCV | 有限空间未完 **或** 真滞后 | 末点当 OCV 可偏 15–40 mV | 爬升数 mV | 否；分向静置 |
| \(\le 0\,^{\circ}\mathrm{C}\) 长回弹、长恒流 | \(D_s\)、\(\kappa\) 掉 | 十几～几十 mV | 仍大 | 3RC 也难分；先补低温标定 + \(H(T)\) |
| \(\gtrsim 1.5\)–\(2\mathrm{C}\) 连续（厚电极） | 沿厚度盐剖面 | 后段加速掉压 | 几乎同样 | **否**（P2D） |
| 低 SOC 放电末端 | 表面抽空 + 扩散变差 | 截止前掉切 10–50 mV | 同左 | 否；加密 SOC |
| 高 SOC 充电末端 | 石墨末端 + 单相区 | 过电位比表深 10–30 mV | 同左 | 否；加密、分向 |
| 充电边沿过冲 | 成核 | 数 mV～十几 mV | 仍在 | 否 |
| 部分循环记忆 | 多颗粒 | 同 \(s\) 不同 \(U\) | OSH 不够则上小环模型 | 否 |
| 大脉冲后停车 | 热弛豫叠扩散 | 可能先过冲再爬 | 同左 | 否；热模型 |
| 老化 / 硅碳 / 大颗粒 | 谱变宽 | 长尾巴、两端更重 | 先更新 \(R_0\) 与 \(M(s)\) | 不要默认 3RC |
| 低频 EIS（\(\lesssim 1\,\mathrm{mHz}\)） | Warburg 形状 | 45° 对不齐 | 同左 | 离线才上 Warburg |

读表：10 s SOP、常温中段，2RC 相对 1RC 的增益仍在，但 **小于补上滞后的增益**。打穿 2RC+H 的是**长窗 + 冷 + 两端 + 高倍率 + 厚电极 + 两相记忆**，不是再加一只极点能沿所有轴一起修的。

### 8.10 工程结论

- LFP 仿真要制造「1RC 吃不干净」的真值：先 **滞后**，再 2RC。不要只抄 NMC 模板的 \(R_2,\tau_2\)。
- 要对齐 EIS 低频再谈 Warburg；要对齐高倍率掉切、低温厚电极，用 P2D；要对齐平台换向，用两相 / 多颗粒或至少一个 \(H\) 状态。
- BMS 侧不要用电压误差去训 3RC 或分数阶头——可观性比 \(R_{1}\leftrightarrow C_{1}\) 更差。LFP 上梯度还会在 \(H\) 与 \(R_{2}\) 之间滑。
- 残差若在 2RC 之后仍有慢结构：先看是不是换向翻号（\(H\)）、半对数下凸（连续谱）、充电单边过冲（成核）、后段加速掉压（P2D）。落在「加 RC？否」的，不要再加一只 RC。

## 9. LFP 体系特有的结构特征

这些特征会在参数表面上留下指纹，标定和查异常时有用。

### 9.1 橄榄石两相平台

LiFePO₄ ↔ FePO₄ 两相共存钉住化学势：

- 全电芯 OCV 在约 3.2–3.35 V 形成宽平台
- 正极本身几乎不提供 SOC 斜率；能看见的斜率 / 台阶多来自石墨
- 相界与多颗粒路径 → 滞后、记忆、充电过冲（§8.1–§8.3）
- 没有高镍 H2–H3，高 SOC 不要按 NCM 去找 4.2 V 相变尖峰

### 9.2 石墨负极 staging（比 NCM 更显眼）

即便正极是 LFP，负极 2L/2、2/1 等平台仍在全电芯上显现，而且正极太平，**挡不住**：

- 约 50%–60% SOC：OCV 与 \(R_{1}\) 可能有小台阶 / 小峰
- 低 SOC：石墨清空，全电芯电压下跌的主因常是负极，不是 LFP 正极
- 高 SOC：石墨 Stage-1，充电末端极化与析锂风险在负极

SOC 网格：平台中段 OCV 可以稀，但在石墨 staging 与两端必须加密。电阻表两端同样要密。

### 9.3 LMFP / 硅碳 / 刀片

| 变体 | 对 ECM 的影响 |
|------|----------------|
| LMFP（磷酸锰铁锂） | 平台抬到 ~3.4–3.7 V，斜率略增，SOC 可观性稍好；锰相关老化与 \(R\) 可能略差于纯 LFP；滞后仍在 |
| 硅碳负极 | \(R_0\) 循环波动大，低 SOC 极化更重，\(C_1\) 下降更明显；滞后再叠硅的膨胀滞后 |
| 刀片 / 长薄大电芯 | 沿长度温度与电流密度不均，集总单芯 ECM 是近似；接触 \(R_0\) 受机械约束 |

### 9.4 与 NCM / NCA / LTO 对比（参数层面）

| 项目 | LFP | NCM | NCA | LTO 负极 |
|------|-----|-----|-----|----------|
| \(R_{0}\)–SOC | 中段平、两端更陡 | 浅 U，相对平滑 | 接近高镍 NCM | 两端升，中段较平 |
| \(R_{1}\)–SOC | 低 SOC 升得更猛 | U 形清晰 | 高 SOC 充电极化常更差 | 通常较小 |
| OCV 斜率 | 极平 | 中等，利于 SOC | 类似 NCM | 也较平 |
| 滞后 | **大** | 小到中 | 小到中 | 中 |
| 老化 \(R_{0}\) | 通常较稳 | 中镍稳、高镍快 | 类似高镍 | 稳 |
| 低温 \(R_{1}\) | **往往最差** | 升得很快 | 介于中间 | 好于石墨系 |
| 2RC 必要性 | 长回弹有用，但排在滞后后 | 长回弹 / 长恒流 | 同高镍 | 视功率型而定 |
| BMS 默认建议 | **1RC + 滞后** | 1RC，分向表常够 | 同 NCM | 1RC + 注意平台 |

## 10. 参数表应覆盖的维度

面向实车 / 储能 BMS 的 LFP **1RC + 滞后**，建议最低配置：

```
R0(SOC, T, dir)
R1(SOC, T, dir)
C1(SOC, T)            或 τ1(SOC, T)；钉死 C1★ 更稳
Uocv_avg(SOC, T)
M(SOC, T)             滞后半宽；或直接 Uocv_chg / Uocv_dis
H 状态                单状态即可起步；小环不够再升级
```

仿真或离线对照若用 **2RC**，在上面再加：

```
R2(SOC, T)            电流维可先不加；必须先有 H
C2(SOC, T)            或 τ2(SOC, T)；C2 钉死、只出 R2 更稳
```

增强配置（做准 SOP / 低温快充）：

```
再增加 I 或 |I| 维
再增加 SOH 或循环周次 / 日历时间维
H 升级为 Preisach / 多继电器 / 路径特征
或：R0,R1(,R2) 用 Arrhenius 把温度拆成
    P(SOC, dir, SOH) × exp[Ea/R (1/T − 1/Tref)]
```

SOC 网格建议：

- 平台 15%–85%：OCV 每 5%–10% 即可；**电阻仍建议 5%**（低端升得陡）
- 0%–15%、85%–100%：每 2%–5%（斜率与极化都在这里）
- 石墨 staging 附近（约 50%–60%）若 OCV 有可见台阶，局部加密

温度网格建议：−20、−10、0、10、25、40、55 °C（按应用裁剪）。低于 0 °C 必须实测。LFP 比 NCM 更不能靠常温外推 \(R_{1}\) 和 \(M\)。

静置时长建议（定 OCV / \(M\)）：

| 温度 | LFP 建议静置 | 对照 NCM |
|------|----------------|----------|
| 25 °C | 1–3 h，两端更长 | 30–60 min 常够 |
| 0 °C | 3–8 h | 1–2 h |
| −20 °C | 8–24 h，或承认末点仍含极化 | 数小时 |

## 11. 辨识与使用中的典型陷阱

1. **用平均 OCV 辨电阻**  
   LFP 上这是第一陷阱。滞后被吞进 \(R_{1}/R_{2}\)，换向即漂。

2. **把采样延迟算进 R0**  
   与 NCM 相同。不同采样周期的表不能混用。

3. **OCV 未静置充分，或静置够了却不分向**  
   静置不足：残余极化进 OCV。静置够了仍分叉：那是 \(H\)，不是没歇够。LFP 常温也建议小时级，不要抄 NCM 的 30 min。

4. **充放共用一张电阻表**  
   末端与换向误差明显变大。

5. **C1 与 R1 互相补偿；H 与 R2 互相补偿**  
   后者是 LFP 特有的第二补偿。单看 \(\tau_{2}\) 很大，先查是不是没建滞后。

6. **用常温 HPPC 外推 −20 °C**  
   \(R_{1}\) 的 \(E_a\) 大，LFP 更陡。低温必须单独标定。

7. **忽略自热**  
   大倍率脉冲中芯温已升，辨出的是「偏热」参数。

8. **老化后仍用 BOL 表**  
   平台区 SOC 会静静漂，直到两端才爆。至少用 \(R_0\) 在线更新做缩放。

9. **1RC 硬扛长时扩散**  
   与 NCM 相同；LFP 的 \(\tau_{2}\) 往往更长。

10. **两条 \(\tau\) 没分开就拟合 2RC**  
    \(\tau_{2}/\tau_{1}\) 太近时 \(R_{1},R_{2}\) 对冲。

11. **用短静置去定 \(R_{2}\)**  
    搁置 \(\ll \tau_{2}\) 时慢支路不可观。

12. **2RC 硬扛非集总 / 两相 / 小时级固相**  
    高倍率厚电极、记忆效应、\(t^{-1/2}\) 尾巴，再加一只 RC 只是局部贴电压。

13. **把电压误差当 SOC（平台区）**  
    \(\mathrm{d}U/\mathrm{d}s\sim 0.3\,\mathrm{mV}/\%\) 时，10 mV 模型误差 ≈ 30% SOC。EKF 在平台应降电压增益，靠安时；只在两端 / staging 台阶拉 \(s\)。

14. **长脉冲扣 \(\Delta U_{\mathrm{ocv}}\) 的习惯照搬 NCM**  
    平台区 \(\Delta U_{\mathrm{ocv}}\) 很小，漏扣的危害小于 NCM；**两端**仍必须扣。不要因为「LFP 不用扣」把 5% SOC 以下的脉冲 \(R_{1}\) 标飞。

15. **为充电过冲给模型加 L**  
    放电会被虚假振荡污染。

## 12. 对 BMS 功能的含义

| 功能 | 主要敏感参数 | LFP 上要注意 |
|------|----------------|--------------|
| SOC（EKF/AEKF 等） | 平台区 **几乎不可观**；靠安时 + 两端 / staging 校正 | 必须有 \(H\) 或分向 OCV；电压新息在 15%–85% 要降权；未建模的 \(H\) 会被啃进 \(s\)。状态不要默认五维，\(R_0\) 进表、滤波最多慢 \(\delta R_0\)，见 `Branch/03-c-LFP的EKF状态与R0评估.md` |
| SOP | \(R_{\mathrm{dyn}}(\Delta t)\) | 必须带 T、SOC，低温加电流非线性；10 s 几乎看不到 \(R_{2}\)；分钟级功率加慢支路 |
| SOH | \(R_{0}\) 首选，\(R_{1}\) 辅助 | 容量 SOH 与电阻 SOH 仍要分开；不要用平台电压 RMSE |
| 热模型 | \(I^{2}R_{0} + I\cdot (U_{p1}+U_{p2})\) | 低温 \(R_{1}\) 产热占比上升得比 NCM 早；预热闭环要用低温表，不能用 25 °C \(R\) |
| 均衡 / 一致性 | \(R_{0}\) 散差 | 平台区压差几乎全是内阻 / 温度，不是 SOC；不要在平台用压差猛均衡 |
| 充电控制 | 高 SOC 的 \(R_{0}/R_{1}\) + 负极电位 | 末端才有斜率，满充判断容易晚；低温快充析锂风险不比 NCM 低 |
| 故障诊断 | \(R_{0}\) 阶跃、\(C_{1}\) 异常跌落 | 松动、析锂、析气表现为内阻突增；平台区电压异常不要先当 SOC |

可用功率的 1RC 常用近似（放电、时长 \(\Delta t\)）：

\[
R_{\mathrm{dyn}}(\Delta t) = R_{0} + R_{1}\bigl(1-e^{-\Delta t/\tau_{1}}\bigr)
\]

2RC：

\[
R_{\mathrm{dyn}}(\Delta t) = R_{0} + R_{1}\bigl(1-e^{-\Delta t/\tau_{1}}\bigr) + R_{2}\bigl(1-e^{-\Delta t/\tau_{2}}\bigr)
\]

- 1 s 功率：接近 \(R_{0}\)
- 10 s 功率：\(R_{0}+0.5R_{1}\) 量级（取决于 \(\tau_{1}\)）；\(R_{2}\) 项通常很小
- 持续功率：1RC 逼近 \(R_{0}+R_{1}\)；真值若有慢支路，应逼近 \(R_{0}+R_{1}+R_{2}\)（两端还要叠加 OCV 下滑；平台中段 OCV 下滑可忽略）

SOC 可观性的粗算：

\[
\delta s \approx \frac{\delta U}{\partial U_{\mathrm{ocv}}/\partial s}
\]

| 区间 | \(\partial U_{\mathrm{ocv}}/\partial s\) 量级 | 10 mV 电压误差对应 |
|------|-----------------------------------------------|---------------------|
| LFP 平台 30%–70% | 0.1–1 mV / %SOC | **10%–100% SOC**（电压几乎不能用） |
| LFP 两端 <10% 或 >90% | 数 mV / % 到十几 mV / % | 与 NCM 中段类似，可拉回 |
| NCM 中段 | 5–15 mV / %SOC | 约 0.7%–2% SOC |

所以 LFP 的 EKF：平台信任安时（管电流零偏），两端信任电压；\(H\) 是电压方程的一部分，不是「再调一点 \(R\)」。

## 13. 特性一览

```
H / OCV  滞后与平台 —— LFP 相对 NCM 的主差
    ├─ 平台 dU/ds 极小，电压几乎看不见 SOC
    ├─ 充放分叉 15–40 mV（常温），低温更宽
    ├─ 静置不回零（热力学 / 多颗粒）
    ├─ 小环 < 大环，车上几乎全是小环
    └─ 默认要建模；排在任何额外 RC 之前

R0  欧姆、瞬时、可观性最好
    ├─ SOC：中段平、两端比 NCM 更陡
    ├─ T  ：Arrhenius，常比 NCM 更陡，−20 °C 可升 4–10×
    ├─ I  ：近似线性，大电流因自热/采样略降
    ├─ 老化：总体升，通常慢于高镍
    └─ 充放：弱不对称；低 SOC 放电略高

R1  极化幅度、电化学最强
    ├─ SOC：深 U，低 SOC 可到中段数倍（常大于 NCM）
    ├─ T  ：Arrhenius，Ea 更大，低温可升一个数量级以上
    ├─ I  ：Butler–Volmer；两相区还叠路径
    ├─ 老化：总体升，界面 / 碳网络敏感
    └─ 充放：必须分表；与 H 耦合

C1  极化快慢、辨识最漂
    ├─ SOC：中等变化，易被 H 污染
    ├─ T  ：轻度升；τ1 随 T 升高而变短
    ├─ 老化：总体下降
    └─ 使用：优先盯 τ1，钉死 C1★ 对 LFP 更合适

R2  慢极化幅度、扩散 + 相界前端
    ├─ SOC：两端升高，低 SOC 长时放电末端更明显
    ├─ T  ：Arrhenius；τ2 常比 NCM 偏长（40–300 s）
    ├─ I  ：弱于 R1
    ├─ 老化：总体升；可观性差，不作主 SOH
    └─ 充放：无 H 时会被滞后吞进 R2

C2  慢过程快慢、比 C1 更漂
    ├─ τ2 = R2·C2
    ├─ 老化：总体下降
    └─ 使用：先钉 τ2 或钉 C2，只出 R2；先有 H 再辨 R2
```

定性关系（LFP，常见方向）：

\[
\begin{aligned}
\frac{\partial R_{0}}{\partial T}<0,\quad
\frac{\partial R_{1}}{\partial T}<0,\quad
\frac{\partial R_{2}}{\partial T}<0,\quad
\frac{\partial C_{1}}{\partial T}\gtrsim 0,\quad
\frac{\partial C_{2}}{\partial T}\gtrsim 0,\quad
\frac{\partial \lvert H\rvert}{\partial T}<0 \\[4pt]
R_{0},R_{1},R_{2}\ \text{在低/高 SOC 升高（低端更陡）},\quad
R_{0},R_{1},R_{2}\ \text{随 SOH 下降而升高},\quad
C_{1},C_{2}\ \text{随 SOH 下降而降低}
\end{aligned}
\]

阶次优先级（重复 §0，便于单页带走）：

\[
H \;\succ\; (R_0,R_1,C_1)(s,T,\mathrm{dir}) \;\succ\; R_2C_2 \;\succ\; I\text{ 非线性} \;\succ\; 3\mathrm{RC/Warburg}
\]

两相、P2D、过冲、热：**不要加 RC**。

## 附录 A. 脉冲辨识公式（放电）

电流由 0 阶跃到 \(I\)（持续 \(t_{p}\)），再撤流搁置：

\[
\begin{aligned}
R_{0} &= \frac{U(0^{-})-U(0^{+})}{I} \\[6pt]
R_{1} &= \frac{U(0^{+})-U(t_{p})}{I} - \text{（两端 SOC：扣掉 OCV 随 SOC 的变化）} \\[6pt]
U_{\mathrm{relax}}(t) &= U(\infty) + \bigl[U(t_{p}^{+})-U(\infty)\bigr] e^{-(t-t_{p})/\tau_{1}} \\[6pt]
C_{1} &= \tau_{1} / R_{1}
\end{aligned}
\]

平台区 \(\Delta U_{\mathrm{ocv}}\) 很小，长脉冲漏扣的危害小于 NCM；**SOC < 15% 或 > 85% 必须扣**。  
\(U(\infty)\) 必须带充放标签：放电脉冲的 \(U(\infty)\) 走放电 OCV，不是平均 OCV。

2RC：回弹改成双指数（已扣 OCV，且 \(H\) 在搁置期冻结）

\[
U_{\mathrm{relax}}(t)=U(\infty)
+A_{1}\,e^{-(t-t_{p})/\tau_{1}}
+A_{2}\,e^{-(t-t_{p})/\tau_{2}}
\]

\(R_{1}=A_{1}/I\)，\(R_{2}=A_{2}/I\)，\(C_{i}=\tau_{i}/R_{i}\)。拟合时约束 \(\tau_{2}>\tau_{1}\)（例如 \(\tau_{2}\ge 4\tau_{1}\)），搁置至少覆盖 \(3\tau_{2}\)。单指数残差若在 1 min 后仍同号，再上双指数。若残差在换向后翻号、静置不回零，先建 \(H\)，不要加 \(\tau_{3}\)。
