## 0. 结论（先看这个）

文献里那套 \([s,\,V_1,\,V_2,\,R_0,\,V_{\mathrm{hyst}}]\) 是真的，和 03-c 能对上，**不是 LFP 的 \(R_0\) 另有一套动力学**。五维是把 03-c 里三件可选的东西一次性全打开：

| 维 | 是什么 | 03-c 里 | LFP 上 |
|----|--------|---------|--------|
| \(s\) | 安时 + 电压纠 | 默认 | 默认；平台几乎不可观 |
| \(V_1\) | 快极化 \(U_p\) | 默认 | 默认 |
| \(V_2\) | 慢极化 | 只在生成器 | 仍排在滞后之后；BMS 默认不上 |
| \(R_0\) / \(\delta R_0\) | **慢随机游走**，不是 RC | 可选、默认关 | **仍然可选、默认关**；不要把表 \(R_0(s,T)\) 塞进状态 |
| \(V_{\mathrm{hyst}}\) | OCV 路径记忆，休息冻住 | NCM 不上 | **这才是 LFP 相对 03-c 该改的一维**；或用分向 OCV 代替 |

一句话：

> LFP 的 \(R_0\) 随 \(s,T,\mathrm{SOH}\) 变，那是**查表**。  
> 滤波器里「会变的 \(R_0\)」是 \(\delta R_0\)：吸收「这一趟比表偏几十 µΩ」，过程是随机游走，\(I=0\) 时**完全不可观**。  
> 它既不是 \(V_1/V_2\)，也不是 \(V_{\mathrm{hyst}}\)。LFP 论文爱扩它，是因为平台上 \(s\) 看不见、欧姆边沿却看得见——不是因为橄榄石让 \(R_0\) 自己会积分。

LFP 建议状态（评估，不是改代码）：

```
最低：  [s, V1] + 分向 OCV（Uocv_chg / Uocv_dis）
推荐：  [s, V1, Vhyst]          表仍出 R0,R1；C1 钉死
可选：  再加很慢的 δR0           与 03-c §3.2 同一通道
不要：  默认五维；不要绝对 R0 当状态；不要再加 V2 除非滞后已经稳
```

一条标量创新最多稳妥喂两三张嘴。五维在 LFP 平台上会按 \(\mathbf{Q}\) 分赃，休息 SOC 好看、参数乱。

## 1. 把那五维写回到 03-c 的符号

放电电流为正。测量：

\[
\hat U_{t}
= U_{\mathrm{ocv,avg}}(s,T)
+ V_{\mathrm{hyst}}
- I\,R_0
- V_1
- V_2
\tag{1}
\]

和 03-c 式 (5) 比，多了 \(V_{\mathrm{hyst}}\) 与 \(V_2\)；\(R_0\) 仍是参数。有人把 \(R_0\) 也写成状态，测量雅可比多一列 \(-I\)，过程却几乎是「等于上一拍」。

| 文献记号 | 本仓库记号 | 过程（预测） | \(I=0\) | \(\mathbf{H}\) 这一列 |
|----------|------------|--------------|---------|------------------------|
| \(s\) | \(s\) | \(s^{-}=s^{+}-I\Delta t/q\) | 冻住 | \(\partial U_{\mathrm{ocv}}/\partial s\) |
| \(V_1\) | \(U_p\) / \(U_{p1}\) | \(\alpha_1 V_1+R_1(1-\alpha_1)I\) | \(\to 0\)，\(\tau_1\sim\) 秒 | \(-1\) |
| \(V_2\) | \(U_{p2}\) | \(\alpha_2 V_2+R_2(1-\alpha_2)I\) | \(\to 0\)，\(\tau_2\sim\) 分钟 | \(-1\) |
| \(R_0\) | \(R_0^{\mathrm{表}}+\delta R_0\) | \(\delta R_{0,k}=\delta R_{0,k-1}+w_k\) | **不可观** | \(-I\) |
| \(V_{\mathrm{hyst}}\) | \(H\)（`Branch/01-a` §8.1） | 按安时追 \(\pm M(s,T)\) | **冻住，不回 0** | \(+1\) |

03-c 已经分开写过三件事，只是没写在同一节：

- §1.3 / 代码：\(\mathbf{x}=[s,U_p]\)，可选第三维 \(\delta R_0\)
- §2.5：2RC 扩成 \([s,U_{p1},U_{p2}]\)
- §2.6：\([s,V_1,V_{\mathrm{hyst}}]\)，第三维**不是**第二只 RC

文献五维 = 这三节的并。NCM 模板锁「默认二维 + \(\delta R_0\) 关 + 不上滞后」。LFP 要重判的只有滞后那一维；\(R_0\) 的判据与 03-c 相同。

过程噪声量级直觉（只作相对，不是标定值）：

\[
q_{V_1} \;\gtrsim\; q_{V_2} \;\gg\; q_s \;\gtrsim\; q_{\mathrm{hyst}} \;\gg\; q_{\delta R}
\]

\(V_1\) 允许跟未建模快动态；\(\delta R_0\) 必须比 \(s\) 还慢，否则边沿一跳就把老化写成电阻、把滞后写成电阻。

## 2. LFP 的 \(R_0\)：三层，不要合成「会变」

### 2.1 物理 / 表：会变，但是查表

`Branch/01-a` §3：\(R_0\) 是电流阶跃瞬间的压降，不经电容。LFP 相对 NCM：

| 因子 | 变不变 | 进哪 |
|------|--------|------|
| 温度 | 最强，Arrhenius，常比中镍更陡 | \(R_0(T)\) 表 / MLP |
| SOC | 中段平、两端翘，低端更陡 | \(R_0(s)\) 表 |
| SOH | 总体升，通常慢于高镍 | 缩放 \(k_0\) 或换表，**不是**每拍 EKF |
| 充放 | 弱不对称 | 分向表 |
| 电流 | 近似欧姆；自热 / 采样会显得略变 | 弱；非线性优先给 \(R_1\) |

这些变化的时间尺度是分钟（温度）、行程（SOC）、天到月（老化）。**没有**「\(R_0\) 自己按 \(\tau\) 积分」这一条。边沿看见的就是 \(IR_0\)，休息看不见 \(R_0\)。

LFP 也**没有**与 \(V_{\mathrm{hyst}}\) 同级的 \(R_0\) 滞后。充放辨出来的 \(R_0\) 若差一截，优先查：采样把 \(R_1\) 算进 \(R_0\)、平均 OCV 把 \(H\) 吞进电阻、低 SOC 的 FePO₄ 电子略差。不要给 \(R_0\) 再做一只 OSH。

### 2.2 滤波器：\(\delta R_0\)，不是绝对 \(R_0\)

03-c §3.2 的写法，LFP 原样成立：

\[
R_0^{\mathrm{used}} = R_0^{\mathrm{表}}(s^-,T,I) + \delta R_{0,k}
\tag{2}
\]

\[
\delta R_{0,k|k-1} = \delta R_{0,k-1|k-1}
\qquad\text{（随机游走，}F_{\delta R}=1\text{）}
\tag{3}
\]

观测：

\[
\mathbf{H}_{\delta R} = -I
\tag{4}
\]

因此：

- \(\lvert I\rvert\) 大、有边沿：这一维可观，用来扛「表整体偏」
- \(I=0\)：\(\mathbf{H}\) 这一列是 0，卡尔曼**不得**改 \(\delta R_0\)。实现上 \(q_{\delta R}\) 已极小；休息段再把 \(K_{\delta R}\) 打到 0 更稳
- 它记住的是「这一趟比表偏 50 µΩ」，不是 \(R_0(s)\) 的 U 形

代码现状：`Src/AI/KF/ekf.py` 的 `estimate_dr0` 就是这一维。LFP 不需要换过程模型，只是平台上更依赖它别去抢 \(s\)。

### 2.3 不要把绝对 \(R_0\) 当状态

有的 LFP 论文状态里直接写 \(R_{0,k}\)，预测 \(R_{0,k}=R_{0,k-1}\)，测量 \(-I R_0\)，**不查表**。问题：

1. 一个标量要追 \(R_0(s,T)\) 整张曲面。SOC 一走，状态滞后；温度一变，当老化。
2. LFP 平台 \(\partial U_{\mathrm{ocv}}/\partial s\approx 0\)，\(R_0\) 跟不上的残差会漏进 \(s\) 或 \(V_{\mathrm{hyst}}\)。
3. 和表双轨：表说中段 0.8 mΩ、滤波说 1.1 mΩ，增量不知道信谁。

评估：**表（或 MLP）出 \(R_0(s,T)\)，滤波最多出 \(\delta R_0\)。** 双 EKF（Plett：SOC 一组、参数一组）本质仍是慢 \(\delta R\)，不是「LFP 的 \(R_0\) 有动态」。不要五参数 AEKF 替代 MLP / 查表。

### 2.4 和 \(V_{\mathrm{hyst}}\)、\(V_2\) 怎么分赃

同一条创新：

\[
e
\approx
(\partial U_{\mathrm{ocv}}/\partial s)\,\delta s
-\delta V_1-\delta V_2
-I\,\delta R_0
+\delta V_{\mathrm{hyst}}
\tag{5}
\]

| 现象 | 该给谁 | 错给 \(R_0\) 会怎样 |
|------|--------|---------------------|
| 电流阶跃边沿尖 | \(\delta R_0\) 或表 \(R_0\) | —（这才是它的活） |
| 数秒指数弯 | \(V_1\) | 边沿 \(R_0\) 偏大、回弹 \(R_1\) 偏小 |
| 分钟级慢尾巴 | \(V_2\)（若有） | \(\delta R_0\) 在有电流时爬，停车翻回来 |
| 充放休息点分叉、静置不回零 | \(V_{\mathrm{hyst}}\) / 分向 OCV | 有电流时 \(\delta R_0\) 跟分叉，换向乱跳 |
| 平台区小电流慢漂 | 安时 / \(b_I\) / \(q\) | 把容量错写成电阻 |

03-c 门控「静置很久仍有常偏，不要写成 \(R_0\)」对 LFP **更硬**：常偏 15–40 mV 是 \(H\) 的主项，不是欧姆。

## 3. 其余四维在 LFP 上改不改判据

### 3.1 \(s\)：平台要降权，不是多开一维能修好

LFP 中段 \(\partial U_{\mathrm{ocv}}/\partial s\) 常 0.1–1 mV/%SOC（`Branch/01-a` §12）。10 mV 模型误差在电压反查里可以是 10%–100% SOC。EKF 该做的是 03-c 已有的 \(R_v\) 调度 + \(K_s\) 限幅，不是再给 \(s\) 加状态。

两端 / 石墨 staging 台阶才让电压拉 \(s\)。平台信任安时，管 \(b_I\)；停车后用分向 OCV（带 \(V_{\mathrm{hyst}}\)）钉休息点，不要用平均 OCV。

### 3.2 \(V_1\)：留着，钉 \(C_1\)

与 03-c 默认相同。方案 B（\(C_1\equiv C_1^\star\)）对 LFP 更合适：\(C_1\) 可观性比 NCM 更差，还容易被 \(H\) 污染（`Branch/01-a` §5）。不要把 \(R_1\) 或 \(C_1\) 扩进 EKF。

### 3.3 \(V_2\)：仍然不是 LFP 的第一扩维

2RC 对长回弹有用，排在滞后之后（`Branch/01-a` §0、§7）。观测上 \(V_1\) 与 \(V_2\) 共线，只靠 \(\alpha_1\neq\alpha_2\) 分开。LFP 的 \(\tau_2\) 往往比 NMC 模板 90 s 更长，短静置更分不开。

BMS 默认 1RC 的理由与 03-c §2.5 相同。未建模 \(V_2\) 会在休息后段被啃进 \(s\) 或 \(V_{\mathrm{hyst}}\)；对照应像任务 H：报开环慢尾巴和休息 SOC 被拉多少，**不要**用静置段去训 \(R\)，也**不要**把慢尾巴写进 \(\delta R_0\)。

先上 \(V_2\)、不上 \(V_{\mathrm{hyst}}\)：平台换向残差会被慢 RC 吃，参数随路径漂。这是 LFP 上最常见的扩维顺序错误。

### 3.4 \(V_{\mathrm{hyst}}\)：LFP 相对 03-c 唯一建议改默认的一维

过程不是指数回弹（03-c 式 (4h)）：

\[
V_{\mathrm{hyst},k}
=\beta_k V_{\mathrm{hyst},k-1}
+(1-\beta_k)\,M(s_k,T)\,\mathrm{sgn}(-I_k),
\qquad
\beta_k=\exp\bigl(-\gamma\lvert I_k\rvert\Delta t\bigr)
\tag{6}
\]

\(I=0\) 时 \(\beta=1\)，**冻住**。这是它和 \(V_1,V_2\) 能分开的唯一理由。常温 LFP 主环半宽 \(M\) 典型 8–25 mV（全分叉 15–50 mV），低温更宽。NCM 那数 mV～十几 mV 用分向表常常够；LFP 平台上 15 mV 不是边角。

两条等价起步，不要两套一起上：

1. **分向 OCV 表**：按电流符号（或上一向）查 \(U_{\mathrm{chg}}/U_{\mathrm{dis}}\)。大环够用，小环（车上部分循环）会偏。
2. **平均 OCV + 一只 \(V_{\mathrm{hyst}}\)**：大环与 (1) 几乎等价，小环靠 \(\gamma\) 近似。

小环要准再上 Preisach / 多继电器，那是换 OCV 模型，不是再扩 EKF 维。

观测上休息段仍和 \(s\) 共线：

\[
e^{\mathrm{pri}}\approx (\partial U_{\mathrm{ocv}}/\partial s)\,\delta s+\delta V_{\mathrm{hyst}}
\]

LFP 上第一项 ≈ 0，所以休息创新几乎全是 \(\delta V_{\mathrm{hyst}}\)。这是功能，不是 bug：滤波应改 \(H\)，不该改 \(s\)。\(q_{\mathrm{hyst}}\) 过小会把分叉拧进 SOC；过大则 \(V_{\mathrm{hyst}}\) 会扛 OCV 表误差和容量斜坡。要上就 **生成器 / ECM / 开环损失一起上**（03-c §2.6）。只改 EKF 维数：闭环休息好看，\(e^{\mathrm{ol}}\) 仍分叉，增量会把分叉写成 \(R_1\)。

03-c 一期「不上 \(V_{\mathrm{hyst}}\)」对 **NMC 主线**仍成立。LFP 支线评估：这一条应该解开，改成「默认分向 OCV 或单状态滞后；不要五维一起开」。

## 4. 可观性：一条创新，五张嘴

线性化测量：

\[
\mathbf{H}
=\bigl[
\partial U_{\mathrm{ocv}}/\partial s,\;
-1,\;
-1,\;
-I,\;
+1
\bigr]
\quad\text{对 }[s,\,V_1,\,V_2,\,\delta R_0,\,V_{\mathrm{hyst}}]
\tag{7}
\]

| 工况 | 实际有效的列 | 危险 |
|------|----------------|------|
| LFP 平台、小电流 | \(V_1,V_2,V_{\mathrm{hyst}}\) 混在一起；\(\delta R_0\) 弱；\(s\) 近 0 | 猛纠 SOC；\(\delta R_0\) 跟滞后 |
| 电流阶跃边沿 | \(\delta R_0\) 突然可观 | 同时改 \(V_1\) 会抢边沿 |
| 回弹前几秒 | \(V_1\) | 把 \(H\) 或 \(V_2\) 折进 \(\tau_1\) |
| 回弹 1 min 后 | \(V_2\)（若 \(\tau\) 分开） | \(\tau_2/\tau_1\) 太近则与 \(V_1\) 对冲 |
| 久置 \(I=0\) | \(s\) 与 \(V_{\mathrm{hyst}}\)；\(\delta R_0\) 消失；\(V_1,V_2\to 0\) | 无 \(H\) 则整段啃进 \(s\) |
| 两端大斜率 | \(s\) 终于可观 | 表 \(R\) 与 \(H\) 仍会偏满空点 |

NCM 中段 \(\partial U_{\mathrm{ocv}}/\partial s\sim 5\)–\(15\,\mathrm{mV}/\%\)，\(s\) 列还能干活，五维已经挤。LFP 平台把 \(s\) 列关掉，剩下四维抢符号相反或相同的毫伏，**更挤**。

因此「文献五维」不是 LFP 的推荐默认，是「把能写进 ECM 的东西都写进状态」的清单。工程上按 §0 的优先级开，每开一维要能指出它和已有维在**哪段波形**上可分。

## 5. 推荐配置（LFP 支线，不改主线代码）

和 03-c 同一套分立：MLP / 表出 \(R\)，EKF 只管电路状态 + 可选慢 \(\delta R_0\)。不要联合估 \(R_1,C_1,R_2\)。

| 档 | 状态 | OCV | \(R\) | 适用 |
|----|------|-----|-------|------|
| A 最低 | \([s,V_1]\) | 分向两张表 | 表 / MLP，方案 B | 大环工况、部分循环要求不高 |
| B 推荐 | \([s,V_1,V_{\mathrm{hyst}}]\) | 平均表 + \(M(s,T)\) | 同上 | 车上小环、回收 |
| C 可选 | B + \(\delta R_0\) | 同 B | 表 + 慢偏置 | 表整体老化、温度传感器偏 |
| D 仿真对照 | \([s,V_1,V_2]\) 或再加 \(H\) | 必须先有 \(H\) | 生成器 2RC；BMS 仍 1RC | 任务 H 一类错配 |
| 不上 | 绝对 \(R_0\)、\(R_1\)、\(C_1\)、\(V_2\) 默认、Preisach 进 EKF、MLP 权重 | | | 可观性 / 03-c 已锁 |

一拍顺序仍是 03-c §2.2：先安时 \(s^-\)，再查 \(R_0,R_1\)（及 \(M\)），再推 \(V_1\)（和 \(V_{\mathrm{hyst}}\)），再创新，再更新。**不要**用后验 \(s^+\) 回代本拍 \(R_0\)。\(\delta R_0\) 叠在表 \(R_0\) 上，与现在 `estimate_dr0` 相同。

增量接口（03-c §2.6、§4 对 LFP 仍成立）：

- 开环 ECM 必须带同一套 \(H\) / 分向 OCV，否则 \(e^{\mathrm{ol}}\) 的分叉会被写成 \(R_1\)
- \(\delta R_0\) 连续多天同号，再送去 \(k_0\) 缩放；不要逐步反传
- 静置常偏：先查 OCV / \(H\) / \(s_0\)，禁止当 \(R_0\) 增量
- 平台区无边沿：不更新 \(R\)，不猛更新 \(s\)

## 6. 典型陷阱（LFP 加严的几条）

1. **把表 \(R_0(s,T)\) 和滤波 \(R_0\) 当成同一个「会变」。** 前者是曲面，后者是慢偏置。
2. **休息段更新 \(\delta R_0\)。** \(H_{\delta R}=-I=0\)，改了就是乱写。
3. **用 \(\delta R_0\) 跟充放分叉。** 有电流时能贴电压，换向翻号。
4. **先扩 \(V_2\) 再上滞后。** LFP 主误差是 \(H\) 不是扩散。
5. **五维一起开、靠 \(\mathbf{Q}\) 碰运气。** 休息 SOC 会好看，参数不可复现。
6. **只给 EKF 加 \(V_{\mathrm{hyst}}\)、开环仍平均 OCV。** 03-c 已写：滤波和曲面各解释一套。
7. **平台区用电压猛纠 \(s\)。** 与有没有 \(\delta R_0\) 无关；\(R_v\) 调度必须留。
8. **把 \(R_0\) 充放差当成滞后态。** 弱不对称用分向电阻表；路径记忆在 OCV。
9. **长脉冲漏扣 \(\Delta U_{\mathrm{ocv}}\) 的 NCM 习惯。** 平台区危害小，两端仍必须扣；扣完的残差仍不是 \(\delta R_0\) 的理由。
10. **用后验残差或 NIS 去训 \(R_0\)。** 03-c 原判据，LFP 不变。

| 平台区无激励时更新 \(R\) | 仍不做 | **更不做** |
| 把 \(V_{\mathrm{hyst}}\) 扩进 EKF | 仍不上 | **建议解开**：默认分向 OCV 或单状态 \(H\)；生成器 / 开环一起改 |
| 用滞后吸收 OCV 表误差 / 容量斜坡 | 仍不做 | 仍不做；\(q_{\mathrm{hyst}}\) 不能当万能偏置 |
| 默认 \(\delta R_0\) | 可选、关 | 可选、关；需要时再开，过程模型不用改 |
| 默认 2RC 进 BMS | 不上 | 不上；仿真可开，且必须先有 \(H\) |
| 五参数 AEKF | 不上 | 不上 |

主线代码与 `Doc/03-c` 不动。LFP 若落地，新开生成器 / OCV / 状态维，不要在 NMC 的 `[s,U_p]` 上打补丁冒充平台区可观。

## 8. 验收（LFP 若做对照实验时）

在 03-c §7 之外加这些。没有数字之前，不宣称五维优于三维。

| 检查 | 通过 |
|------|------|
| 同一 SOC，充完休息 vs 放完休息 | 有 \(H\) 或分向 OCV 时 \(s\) 对齐；无 \(H\) 时分叉应落在 \(e^{\mathrm{ol}}\)，**不要**被 \(\delta R_0\) 吃掉 |
| 边沿 \(R_0\) 表故意 ×1.2 | \(e^{\mathrm{ol}}\) 边沿变大；开 \(\delta R_0\) 时慢追上偏置，\(s\) 不被长期拉走（与 03-c 同） |
| 休息 \(I=0\) 开着 \(\delta R_0\) | \(\delta R_0\) 轨迹应冻住，不爬 |
| 平台小电流 | \(K_s\) 接近 0；SOC 跟安时；不靠电压「钉」出假精度 |
| 先 2RC 无 \(H\) vs 1RC+\(H\) | 换向工况后者电压 / 休息 SOC 应明显好；这是 LFP 扩维顺序的验收 |
| 开环与闭环同一套 \(H\) | \(e^{\mathrm{ol}}\) 不分叉残留；否则增量会写 \(R_1\) |
| 五维 vs 推荐三维 | 五维若只在长回弹上小几个 mV、参数随激励跳，则丢掉 \(V_2\) |

## 9. 特性一览

```
R0  欧姆、瞬时、表会变、滤波里最多一个慢偏置
    ├─ 表：R0(s,T,dir)，T 最强，两端 SOC 升
    ├─ 滤波：δR0 随机游走，H = −I
    ├─ I=0：不可观，必须冻住
    ├─ 不是 RC，不是 Vhyst
    └─ LFP 论文常扩它 = 边沿可观、平台 s 不可观；不是橄榄石动力学

Vhyst / H  路径 OCV，LFP 主项
    ├─ 过程按安时，休息冻住
    ├─ 与 s 在休息段共线；平台上应改 H 不改 s
    └─ 要上就生成器 + ECM + 开环一起上

V1  快极化，默认留下，C1 钉死
V2  慢极化，排在 H 之后，BMS 默认不上
s   平台降权，两端再拉
```

优先级（重复 §0）：

\[
(s,V_1)
+
(\text{分向 OCV 或 }V_{\mathrm{hyst}})
\;\succ\;
\delta R_0
\;\succ\;
V_2
\;\succ\;
\text{绝对 }R_0\text{ 进状态}
\]
